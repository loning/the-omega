\section{可复现验证协议（摘要级描述）}

本节只给出可复现接口的结构性说明；具体实现可由任意编程语言完成。

\subsection{切投影点集生成}

\textbf{输入：}投影 $(\pi_{\parallel},\pi_{\perp})$、窗口 $W$、相位 $u$、截断半径 $R$。\\
\textbf{输出：}$\Lambda(u)\cap B_R$ 的点集与补丁统计。

\textbf{验证项：}
\begin{enumerate}
  \item 对不同 $u$ 比较补丁集合差异；
  \item 估计补丁频率并检验对 $u$ 的稳定性（在可疑边界条件下需处理窗口边界事件）。
\end{enumerate}

\subsection{环面旋转与二值读出}

\textbf{输入：}$\alpha$ 与初相位 $\theta_0$，分割 $\mathcal{P}$。\\
\textbf{输出：}机械词 $w_t$；计算复杂度 $p(n)$ 并检验 $p(n)=n+1$。

\textbf{周期近似：}用连分数收敛子 $\alpha_k=p_k/q_k$ 生成周期序列，对比有限前缀统计与误差随 $k$ 的衰减趋势。

\subsection{稳定化与纤维谱}

\textbf{输入：}$m$、窗口词 $\omega_t^{(m)}$。\\
\textbf{输出：}$x_t=\mathrm{Fold}_m(\omega_t^{(m)})$；统计 $\card{\mathcal{F}_m(x)}$ 的分布；构造经验转移核 $P(\cdot\mid x)$。

\subsection{时间箭头的熵率检验}

在遍历样本上估计柱集测度（或等价的压缩率/负对数似然增长），拟合其线性增长率并与熵率估计一致性比较。该检验属于协议层，不依赖物理诠释。
