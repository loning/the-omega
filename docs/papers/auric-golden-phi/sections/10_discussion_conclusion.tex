\section{讨论与结论}

\subsection{可证定内容与可替换假设}

本文的确定性结论集中于：
\begin{itemize}
  \item 切—投影模型集与核化读出的统一定义（第 2--3 节）；
  \item 相干叠加项的代数结构（T3.3）；
  \item Sturmian 复杂度不变量与 Zeckendorf 合法语言计数（T5.2，命题 \ref{prop:zeckendorf-count}）；
  \item $\Fold_m$ 的规范化性质、纤维与闭包固定点结构（定理 \ref{thm:closure-fixed-points}）；
  \item SMB 机制为信息论时间箭头提供的严格模板（T6.3）；
  \item 推前分布的退化谱频率律与误差上界（T8.2）。
\end{itemize}

与物理语义的连接依赖（H）层假设：无理取向与遍历性、环因子近似、以及读出核与实验装置之间的映射。上述假设具有可替换性与可检验性，属于模型化任务而非定理结论。

\subsection{与既有理论接口与开放问题}

\begin{enumerate}
  \item 若需与量子场论的幺正动力学严格对齐，需要给出 $\sigma$ 的演化规则与幅度映射 $a$ 的相位结构，并证明在适当极限下恢复标准干涉统计与守恒律。
  \item 若需与准晶衍射理论直接对接，需要将 $I_{\varepsilon,u}$ 的统计量与纯点衍射谱及其窗口傅里叶权重建立严格对应，并给出有限核宽对谱线的可控修正。
  \item 若需将“光速上界”表达为读出传播上界，需要引入明确的局域相互作用结构与传播锥约束，并区分群速度、信号速度与因果可达域。
\end{enumerate}

\subsection{结论}

本文给出一套六维黄金取向切—投影读出框架，将三维可见结构、相干强度重构、符号稳定化与信息论时间箭头统一于同一协议体系之内。框架的核心优势在于：所有关键命题均对应明确数学对象（投影、窗口、核、扫描、规范化算子、纤维、熵率），并可通过统计检验模板获得可证伪接口。其进一步推进依赖于：将对象层配置与动力学闭包、以及与精密实验的误差预算接口作系统化耦合。
