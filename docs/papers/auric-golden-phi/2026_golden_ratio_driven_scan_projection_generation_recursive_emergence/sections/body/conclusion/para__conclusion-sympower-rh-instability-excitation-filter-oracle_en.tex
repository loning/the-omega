\paragraph{Square-root spectral-bound instability under symmetric-power upgrade: first-variation amplification, linear excitation filtering, and oracularized selection axis}
In the moment-kernel compilation caliber of this paper, ``occupation-number symmetric-power quotient'' is a natural polynomial-state compression route (Propositions~\ref{prop:pom-moment-symmetric-power},~\ref{prop:pom-factorized-sympower-upper-bound}).
However, symmetric power is not conservative on spectral bounds: it systematically amplifies any non-Perron mode along the multiplicative scale to eventually cross the square-root bound, thereby elevating ``kernel-version RH'' from a verifiable constraint to a structural engineering problem \emph{requiring an additional selection axis to maintain}. The conclusive interface can be summarized as:
\begin{enumerate}
  \item \textbf{Symmetric-power square-root spectral-bound instability: except for spectral-rank-one, any primitive kernel eventually violates kernel-version RH.}
  For a primitive non-negative matrix \(A\), if the non-Perron spectral radius \(\eta>0\), then there exists \(b_0\) such that for all \(b\ge b_0\), the non-Perron spectral radius of \(\mathrm{Sym}^b(A)\) is strictly greater than \(\sqrt{\rho(A)^b}\), so the symmetric power eventually necessarily violates the square-root spectral bound of kernel-version RH (Theorem~\ref{thm:pom-sympower-sqrt-bound-instability}).
  Moreover, ``satisfying the square-root spectral bound for all \(b\ge 2\) always'' holds if and only if \(\eta=0\), i.e., the non-zero spectrum contains only the Perron root (spectral-rank-one degeneration) (Corollary~\ref{cor:pom-sympower-sqrt-bound-stable-iff-spectral-rankone}).

  \item \textbf{First-variation fidelity \texorpdfstring{$\Rightarrow$}{=>} impossibility of higher-order kernel-version RH: fatal amplification of MOM multiplicative upgrade.}
  If the multiplicative upgrade \(a\mapsto ab\) compilation admits a surjective intertwiner \(\Pi_{a,b}:\mathrm{Sym}^b(A_a)\twoheadrightarrow A_{ab}\) not annihilated in the first-variation sector (first-variation fidelity), then for sufficiently large \(b\), \(A_{ab}\) necessarily exhibits crossing \(\eta_{ab}>\sqrt{\rho_{ab}}\) (Definition~\ref{def:pom-first-variation-sector}; Theorem~\ref{thm:pom-first-variation-fidelity-rh-breaking}).

  \item \textbf{Linear ``excitation filtering'' lower bound: maintaining kernel-version RH requires annihilating a linear proportion of low-excitation sectors.}
  For any non-zero subquotient \(B_b\) of \(\mathrm{Sym}^b(A)\), if it satisfies kernel-version RH, then the minimal surviving excitation number \(k_b\) must satisfy the explicit linear lower bound
  \(k_b\ge \frac{b}{2}\frac{\log\rho}{\log(\rho/\eta)}\); in the RH-sharp case, this further forces \(k_b\ge b\) (Theorem~\ref{thm:pom-excitation-filter-linear-bound}).

  \item \textbf{Unavoidable obstruction of symmetric-power quotient compilation: infinite kernel-RH necessarily requires additional selectors, equivalent to an oracle axis.}
  If the realization of \(A_{ab}\) is given only by the occupation-number symmetric-power quotient (without introducing additional \(b\)-dependent projections/selectors to annihilate low-excitation sectors), then higher-order kernel-version RH necessarily breaks;
  conversely, requiring kernel-version RH to hold simultaneously for all \(b\ge 2\) at fixed \(a\) necessitates, except in spectral-rank-one degeneration, introducing an excitation-filtering selector family \(P_{a,b}\) satisfying the linear threshold, which in protocol semantics manifests as an externalized ``selection/oracle'' compilation axis (Theorem~\ref{thm:pom-occupancy-symquotient-rh-obstruction}).
\end{enumerate}
