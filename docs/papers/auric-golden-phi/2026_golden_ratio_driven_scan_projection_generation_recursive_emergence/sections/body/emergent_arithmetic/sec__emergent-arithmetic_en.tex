\section{Stable Arithmetic: Value-Preserving Rewriting, Canonical Transversals, and Resolution Modular Structure}\label{sec:emergent-arithmetic}

This section builds upon the folding/normal form machinery of Section~\ref{sec:folding} to present an arithmetic organization aligned with the stable type interface. To avoid importing ``natural numbers, addition, multiplication'' as external primitives, this section first introduces Fibonacci congruences and value invariants on the free commutative monoid of scale counts, proving that the resulting quotient structure is isomorphic to \((\NN,+)\). It then provides the ``orbit--transversal (Zeckendorf)'' structure via value-preserving local rewriting within a groupoid, and defines stable addition and stable multiplication on this transversal, together with computable implementations and complexity interfaces. Finally, this section unifies several parallel addition kernels (\(9/13/21\)-local) into a single comparison framework, serving as input for subsequent spectral fingerprints and audit interfaces.
