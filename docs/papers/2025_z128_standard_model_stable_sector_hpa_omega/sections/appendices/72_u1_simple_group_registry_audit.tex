\subsection{U1 simple-group registry (SU(5), SO(10), E6) and complexity keys (audit)}
\label{app:u1_simple_group_registry_audit}

This appendix records a bounded registry of common simple-group unification candidates and compares them using explicit complexity keys, in the spirit of the audit-facing candidate-family discipline used elsewhere in the paper.
No theorem-level group unification claim is made; this is a counterfactual registry that sharpens what would be required to upgrade U1 beyond a benchmark.

\subsubsection{Registry and keys}
\paragraph{Candidate set.}
\AuditTag We register the standard minimal list:
\[
SU(5),\qquad SO(10),\qquad E_6.
\]

\paragraph{Complexity keys (bounded, explicit).}
\AuditTag We report the following keys:
\begin{itemize}
\item Lie-algebra dimension $\dim(\mathfrak{g})$ (a minimal structural size proxy);
\item a minimal faithful complex representation dimension $d_{\min}$ (a minimal carrier size proxy);
\item a note on whether the candidate can be CAP-minimal under the holonomy-driven (H2)--(H3) requirements used for the three-factor closure (Appendix~\ref{app:gauge3_holonomy_candidate_closure}).
\end{itemize}

\subsubsection{Certificate-style consequence (why this does not upgrade U1)}
\AuditTag The three-factor closure uses a holonomy-driven interface rule with explicit bounded keys (Appendix~\ref{app:gauge3_holonomy_candidate_closure}).
Within that logic, $SU(2)$ is CAP-minimal for the rotation-skeleton proxy (smallest non-abelian compact simple factor), and $SU(3)$ is CAP-minimal for the genuinely complex $3\times 3$ unitary support proxy.
The registry above makes explicit that common simple-group unification candidates exceed these minimal keys and are therefore not CAP-minimal \emph{within the declared key ordering}.
\par
\AuditTag Upgrading U1 within this paper's discipline would require adding a new bounded candidate-family route that outputs a single-group hypothesis from protocol diagnostics (or an explicit matching-layer audit that links U1 to a falsifiable high-energy observation chain), without using unification benchmarks as tuning targets.
