\section{符号系统层：Sturmian、返回词与最终周期替换结构}

\subsection{二元窗口编码}

定义观测
\[
\chi_E(x)=
\begin{cases}
1,&x\in E,\\
0,&x\notin E,
\end{cases}
\]
并定义编码序列
\[
\omega(x)=\bigl(\chi_E(T_\theta^n x)\bigr)_{n\in\ZZ}\in\{0,1\}^{\ZZ}.
\]
其闭包给出移位系统 $(\Omega,\sigma)$ 及推前测度。

\subsection{Sturmian 最小复杂度与诱导的返回词分解}

当 $E$ 为区间且 $\theta$ 无理时，得到 Sturmian 类符号系统，其复杂度函数满足
\[
p(n)=n+1.
\]
诱导到窗口对应于语言的“返回词”分解：首返时间的有限值性对应返回词集合的有限生成，且连分数指令决定返回词替换规则。

\subsection{最终周期连分数与替换系统}

当 $\theta$ 最终周期时，指令序列最终周期，$S$-adic 描述最终退化为有限替换的周期迭代，符号系统成为 substitutive Sturmian。黄金参数对应 Fibonacci 型替换，其替换矩阵主特征值为 $\varphi$，与第 5 节尺度常数一致。
