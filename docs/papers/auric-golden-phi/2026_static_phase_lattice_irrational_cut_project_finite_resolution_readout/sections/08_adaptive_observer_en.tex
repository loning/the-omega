\section{Adaptive Observer: Parameterized Readout, Closed-Loop Update, and Self-Referential Structure}

\subsection{Observer as a Parameterized Readout System}

Let the observer be controlled by parameters $\theta$ governing its readout protocol:
\[
\theta := (E_{\parallel},W,\varepsilon,\ldots),
\]
which includes projection subspace, acceptance window, resolution, and possible internal calibration. Observation data is denoted as
\[
y_t = \mathcal{R}_{\theta_t}\big(\Sigma(u_t)\big),
\]
where $\mathcal{R}_{\theta}$ is a readout map from geometric objects to discrete records.

\subsection{Phase Shift and Controllable Degrees of Freedom}

In the cut-and-project model, the complementary phase offset $u$ is a key parameter determining $\Sigma(u)$. This paper formulates ``agency'' as: without changing the ontological layer $\Lambda$ and global state, the observer can change its observable cross-section and equivalence class decomposition by controlling $u$ or $\theta$, thus selecting different observable trajectories. Formally, these are control variables on parameter space, rather than changes to ontological layer structure.

\subsection{Closed-Loop Update and Self-Reference}

To characterize the ``observation affects the observer's own protocol choice'' self-referential structure, set the update law as
\[
\theta_{t+1} = \mathcal{U}(\theta_t, y_t),
\qquad
u_{t+1} = \mathcal{V}(u_t, y_t).
\]
This closed-loop system is mathematically a parameter--data coupled discrete dynamical system. Its ``self-reference'' derives from: $y_t$ simultaneously depends on $(\theta_t,u_t)$, while $(\theta_{t+1},u_{t+1})$ is conversely determined by feedback from $y_t$.

\subsection{Protocol Formulation of Update Rationale}

``Why update'' in this paper is not stated teleologically, but via auditable variational principles or constraint satisfaction. Given a computable mismatch functional
\[
\mathcal{J}(\theta,u; y_{0:t}) ,
\]
such as prediction error, constraint violation budget, or negative information gain, the update law can be taken as
\[
(\theta_{t+1},u_{t+1})
=
\arg\min_{\theta,u}\ \mathcal{J}(\theta,u; y_{0:t}),
\quad \text{or an approximate gradient step.}
\]
Thus, observer structure changes can be interpreted as: under finite resource and stability constraints, parameter re-adjustment to reduce mismatch. This formulation requires neither introducing randomness at the ontological layer nor postulates of purpose beyond the protocol.
