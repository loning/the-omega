\section{附录 B：二值退化的等价形式与尾部公式的严格化}

\subsection*{B.1 端点重合与线性等式}

三段结构中间段退化当且仅当左端点与右端点重合。由构造可得重合条件为
\[
b-\delta_i=K\delta_i+\delta_{i+1},
\]
从而
\[
b=(K+1)\delta_i+\delta_{i+1}.
\]

\subsection*{B.2 与 $\delta_{i-1}$ 的表示}

由 $\delta_{i-1}=a_{i+1}\delta_i+\delta_{i+1}$，令 $c=a_{i+1}-(K+1)$ 得
\[
b=\delta_{i-1}-c\delta_i,\qquad 0\le c<a_{i+1}.
\]

\subsection*{B.3 尾部公式}

由 $b=(a_{i+1}-c)\delta_i+\delta_{i+1}$ 得
\[
\rho(E)=\frac{\delta_i}{b}=\frac{1}{(a_{i+1}-c)+\delta_{i+1}/\delta_i}.
\]
另一方面，$\delta_{i+1}/\delta_i$ 与连分数尾部 $[0;a_{i+2},a_{i+3},\dots]$ 等价；将二者代入即可得到
\[
\rho=[0;\ a_{i+1}-c,\ a_{i+2},\ a_{i+3},\dots]
\]
或其反演共轭 $1-\rho$。
