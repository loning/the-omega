\section{讨论与开放问题}

\subsection{相关工作与新意定位（面向审稿）}
Fibonacci/Zeckendorf 表示与有限自动机的关系在自动序列与线性数制系统文献中有系统发展，
尤其包括基于该表示的有限状态算术与可判定性框架。\cite{Frougny1991FibonacciAutomata,AlloucheShallit2003AutomaticSequences,AhlbachEtAl2013ZeckendorfArithmetic}
本文与上述工作不同之处在于：我们固定一个“截断折叠”函数 $\Fold_m:\{0,1\}^m\to X_m$，
并研究它在\emph{有限长度右作用}意义下的残差状态复杂度；主定理给出了该复杂度的闭式与显式状态同构，
从而把“残差最小化”落到可计算对象与可复现证据上。

\subsection{关于“残差”的两种语义}
本文采用 Myhill--Nerode 式的右等价刻画残差，其优点是可严格最小化并可复现计算。
另一条重要路线是以“未来可观测分布等价”（computational mechanics / PSR）定义残差，
并将残差解释为预测的最小充分统计量。两者之间的关系取决于：
\begin{itemize}
  \item 允许动力学类与可观测代数的具体生成方式；
  \item 误差容忍（精确等价 vs 近似等价）；
  \item 在线性（同步转导器）约束下的可实现性。
\end{itemize}

\subsection{与 Zeckendorf 规范化转导器文献的对齐}
Zeckendorf/Fibonacci 表示的规范化存在经典的有限状态转导器实现。将本文的 $\Fold_m$ 与这些实现精确对齐，
并将“残差态”解释为转导器内部状态，是本稿后续版本希望强化的方向。

\subsection{开放问题}
\begin{itemize}
  \item 给出 $|U_{m,k}|$ 的解析界（或渐近标度），并解释其与纤维谱/熵量的关系。
  \item 把右等价残差与预测等价残差统一到同一最小化范式（含近似版本）。
  \item 构造“可逆化目标”下的最小残差，并给出可计算的下界证据（区分串/证人集合）。
\end{itemize}
