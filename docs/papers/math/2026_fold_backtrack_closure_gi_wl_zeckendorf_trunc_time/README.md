# 2026_fold_backtrack_closure_gi_wl_zeckendorf_trunc_time 工作追踪

## 定位（这篇解决什么）

以“Zeckendorf 截断折叠 + 尾部时间纤维”为核心，把折叠边与微观邻接边装入同一个闭包图对象，在该对象上运行 WL 并讨论 GI/WL 的翻译关系；同时做维数/几何邻接（含 2D/3D Hilbert-lattice）的实验扫描，以刻画“塌缩速度/残余时间位”的现象学。

## 核心对象（最小集合）

- **微观态**：$X_m=\{0,1\}^m$（或等价的索引 $[0,2^m-1]$）。
- **折叠映射**：把整数的 Zeckendorf 数码取前 $m$ 位作为可见稳定态（稳定语言大小为 $F_{m+2}$）。
- **时间纤维**：被截断的 Zeckendorf 尾部视为“时间/纤维”坐标。
- **闭包图**：顶点为微观与稳定态的不交并；边包含（i）微观邻接（多种几何模型），（ii）折叠边（微观指向稳定态）。
- **WL 稳定化与 GI 翻译**：在闭包图上比较 WL 诱导的分割与 GI 的同构判别关系。
