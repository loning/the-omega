\section{Functorial refinement under window uplift}
\label{app:functorial_refinement}

This appendix records a minimal, auditable notion of functorial refinement of the field-level labeling map under window uplift $m\mapsto m'$.

\subsection{Prefix projection and a functorial lift}

For $m\ge 6$, define the truncation (prefix) projection
\[
\pi_{m\to 6}:X_m\to X_6,\qquad
\pi_{m\to 6}(w_1\cdots w_m):=w_1\cdots w_6.
\]

\begin{lemma}[Well-definedness and surjectivity of $\pi_{m\to 6}$]\label{lem:pi_m6_surj}
For every $m\ge 6$, the map $\pi_{m\to 6}$ is well-defined and surjective.
\end{lemma}
\begin{proof}
If $w\in X_m$ has no adjacent ones, then any prefix has no adjacent ones, hence $\pi_{m\to 6}(w)\in X_6$ and the map is well-defined.
For surjectivity, given any $u\in X_6$, the word $u0\cdots 0\in X_m$ (padding with $m-6$ zeros) satisfies $\pi_{m\to 6}(u0\cdots 0)=u$.
\end{proof}

Given the closed labeling map $\mathcal{L}_{\mathrm{SM}}:X_6\to \mathcal{F}_{\mathrm{SM}}\sqcup\mathcal{G}_{\mathrm{SM}}$ (Section~\ref{sec:sm_labeling_closure}),
we define its functorial lift to window length $m$ by composition:
\[
\mathcal{L}_m:=\mathcal{L}_{\mathrm{SM}}\circ \pi_{m\to 6}:X_m\to \mathcal{F}_{\mathrm{SM}}\sqcup\mathcal{G}_{\mathrm{SM}}.
\]
This definition makes the refinement under successive truncations explicit:
for $m\ge k\ge 6$, one has $\pi_{m\to 6}=\pi_{k\to 6}\circ \pi_{m\to k}$, hence $\mathcal{L}_m=\mathcal{L}_k\circ \pi_{m\to k}$.

\subsection{Deterministic refinement multiplicities}

Although $\mathcal{L}_m$ uses only the first six digits to assign an SM label, each base type in $X_6$ admits multiple higher-window extensions in $X_m$.
This yields a computable refinement multiplicity per base label.

\begin{proposition}[Extension counts depend only on the last bit]\label{prop:prefix_extension_count}
Fix $m\ge 6$ and $u=u_1\cdots u_6\in X_6$.
Let
\[
\mathrm{Ext}_m(u):=\{w\in X_m:\ \pi_{m\to 6}(w)=u\}.
\]
Then $|\mathrm{Ext}_m(u)|$ depends only on $u_6$:
\[
|\mathrm{Ext}_m(u)|=
\begin{cases}
F_{m-4}, & u_6=0,\\
F_{m-5}, & u_6=1,
\end{cases}
\]
where $(F_k)$ are Fibonacci numbers with $F_1=F_2=1$.
\end{proposition}
\begin{proof}
Let $L:=m-6$ be the extension length.
If $u_6=1$, the next bit must be $0$, and the remaining $L-1$ bits form an admissible word in $X_{L-1}$, so $|\mathrm{Ext}_m(u)|=|X_{L-1}|=F_{(L-1)+2}=F_{m-5}$ by Lemma~\ref{lem:xm_fib}.
If $u_6=0$, there is no forced initial $0$ and the $L$ extension bits form an admissible word in $X_L$, so $|\mathrm{Ext}_m(u)|=|X_L|=F_{L+2}=F_{m-4}$.
\end{proof}
