\section{Time Fibers and Information-Theoretic Time}
\label{sec:information-time}

\subsection{Time Fibers}

For any $x\in X_m^{\mathrm Z}$, define the time fiber
\[
\mathcal{F}_m(x)=\mathrm{Fold}_m^{-1}(x)\subseteq\Omega_m.
\]
The time fiber is the preimage structure of the stabilization kernel, characterizing the set of residual indistinguishable differences under fixed resolution.

\subsection{KS Entropy and Generating Partitions}

The standard definition of Kolmogorov--Sinai entropy is: for a finite partition $\xi$, define $h(T,\xi)$, then take
\[
h(T)=\sup_{\xi} h(T,\xi).
\]
If $\xi$ is a generating partition, then $h(T)=h(T,\xi)$ \cite{ScholarpediaKSEntropy}.

\subsection{SMB Theorem and Exponential Contraction of Cylinder Set Measure}

For ergodic systems and generating partitions, the Shannon--McMillan--Breiman theorem can be stated as: the exponential decay rate of cylinder set measure equals the metric entropy almost everywhere (when entropy is finite) \cite{GatechSMB}.
Thus if $\xi^{(n)}=\bigvee_{k=0}^{n-1}T^{-k}\xi$, then
\[
-\frac{1}{n}\log\mu(\xi^{(n)}(s))\to h_\mu(T)\quad(\mu\text{-a.e.}).
\]
Based on this, this paper defines the ``arrow of time'' as the exponential contraction rate of posterior cylinder set measure; and objectifies ``future'' as the scale of uncertainty in conditional distributions (e.g., conditional entropy) rather than reifying residuals as new ontological objects.
