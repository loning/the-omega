\subsection{Temperature as an external proxy (matching layer)}
\label{subsec:teff_proxy}

\paragraph{Thermodynamic definition (internal).}
\InterfaceTag Appendix~\ref{app:thermodynamics_from_equivalence} defines temperature as a conjugate scale in the coarse-graining/free-energy dictionary.
This provides the canonical internal meaning of ``temperature'' in the present framework.

\paragraph{Leakage-based proxy (optional).}
\MatchTag In some data-facing contexts one prefers to report an \emph{effective temperature} $T_{\mathrm{eff}}$ as a proxy for emission intensity.
To do so, one must add an explicit matching dictionary that maps leak observables (e.g.\ a rate proxy $\Gamma$ or an emission power proxy) to a temperature parameter.
This matching dictionary is not derived from protocol structure alone.
For compact bookkeeping of such optional inputs, see Appendix~\ref{app:physics_consensus_inputs} (Assumptions~\ref{ass:ppl_low_leakage_low_temp}--\ref{ass:ppl_gap_suppression_model}).
