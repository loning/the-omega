\section{Folding-map counterfactuals at the \texorpdfstring{$m=6$}{m=6} anchor}
\label{app:fold_family_sensitivity}

This appendix records a bounded counterfactual family of deterministic maps from the dyadic microstate index set $\{0,\dots,63\}$ to the admissible set $X_6$.
The purpose is audit clarity: it makes explicit which finite combinatorial properties of the $64\to 21$ folding picture are tied to the specific folding map adopted in the paper, and which properties survive under nearby low-complexity alternatives.

\subsection{A bounded counterfactual family}
At the $m=6$ anchor we identify microstates with a dyadic register $\{0,\dots,2^6-1\}$ and identify stable types with admissible words $X_6$ (no adjacent ones).
The main text fixes the folding map $\mathrm{Fold}_6$ by truncating Zeckendorf digits (Section~\ref{sec:folding_core}).
To provide look-elsewhere context at the level of the folding map itself, we compare $\mathrm{Fold}_6$ to a small explicit family of counterfactual deterministic maps of comparable discrete description complexity:
\begin{itemize}
\item \textbf{FoldZ:} the baseline Zeckendorf-truncation map $\mathrm{Fold}_6$ as defined in \eqref{eq:fold6_def};
\item \textbf{FoldZ-shift:} a one-digit shift of the Zeckendorf digit window (still a Zeckendorf substring);
\item \textbf{FoldZ-rev:} reversal of the baseline output word (preserves admissibility as a word grammar);
\item \textbf{Bin-repair:} a direct dyadic-word repair rule that removes each occurrence of the substring ``11'' by deterministically flipping the right bit in each offending pair.
\end{itemize}

\paragraph{Explicit definitions (self-contained).}
Let $N\in\{0,\ldots,63\}$ and let $(c_k)_{k\ge 1}$ be its Zeckendorf digits.
\begin{itemize}
  \item \textbf{FoldZ.} $\mathrm{FoldZ}(N):=(c_1,\ldots,c_6)$ (Definition~\eqref{eq:fold6_def}).
  \item \textbf{FoldZ-shift.} $\mathrm{FoldZ\mbox{-}shift}(N):=(c_2,\ldots,c_7)$, padding by zeros if needed
  (i.e.\ set $c_k:=0$ for $k$ beyond the Zeckendorf expansion length).
  \item \textbf{FoldZ-rev.} $\mathrm{FoldZ\mbox{-}rev}(N):=\mathrm{rev}(\mathrm{FoldZ}(N))$ where
  $\mathrm{rev}(w_1\cdots w_6):=w_6\cdots w_1$.
  \item \textbf{Bin-repair.} Write the dyadic word of $N$ as
  $b(N)=b_1\cdots b_6\in\{0,1\}^6$.
  Scan left-to-right and whenever a substring $b_i b_{i+1}=11$ occurs, flip the right bit $b_{i+1}\leftarrow 0$.
  The resulting repaired word lies in $X_6$ by construction.
\end{itemize}

For each map we record: the image size (how many stable types are realized), whether the image equals $X_6$, and the induced preimage-size histogram over $\{0,\dots,63\}$.

\paragraph{Interpretation.}
Within this bounded family, surjectivity onto $X_6$ is not unique.
What varies across maps is the induced fiber structure (the support and distribution of $g(w)$), which is the protocol-native input for later compensation/connection constructions.
The main text fixes Fold$_6$ by the Zeckendorf-truncation definition and therefore fixes a specific fiber statistics package (Section~\ref{sec:folding_core} and Appendix~\ref{app:folding_core_proofs}).

\paragraph{A partial closure: a natural fixed-point property selects FoldZ in this family.}
Define the Zeckendorf value map $V:X_6\to\{0,\ldots,20\}$ by
Definition~\ref{def:zeckendorf_value}.
\begin{definition}[Value consistency at the anchor]
\label{def:value_consistency_anchor}
A deterministic map $F:\{0,\ldots,63\}\to X_6$ is \emph{value-consistent} if
\[
F(V(w))=w\qquad\text{for all }w\in X_6.
\]
\end{definition}
\begin{proposition}[Within the bounded family, value consistency selects FoldZ]
\label{prop:value_consistency_selects_foldz}
Within the four-map family $\{\mathrm{FoldZ},\mathrm{FoldZ\mbox{-}shift},\mathrm{FoldZ\mbox{-}rev},\mathrm{Bin\mbox{-}repair}\}$,
the unique value-consistent map (Definition~\ref{def:value_consistency_anchor}) is $\mathrm{FoldZ}$.
\end{proposition}
\begin{proof}
Lemma~\ref{lem:fold6_surjective} shows $\mathrm{FoldZ}(V(w))=w$ for all $w\in X_6$, hence $\mathrm{FoldZ}$ is value-consistent.

To rule out the other three maps, take $w=100000\in X_6$.
Then $V(w)=1$ by \eqref{eq:Vw_def}.
The Zeckendorf digits of $1$ satisfy $c_1=1$ and $c_k=0$ for $k\ge 2$.
Therefore $\mathrm{FoldZ\mbox{-}shift}(1)=(c_2,\ldots,c_7)=000000\neq 100000$, so $\mathrm{FoldZ\mbox{-}shift}$ is not value-consistent.
Also $\mathrm{FoldZ\mbox{-}rev}(1)=\mathrm{rev}(\mathrm{FoldZ}(1))=000001\neq 100000$, so $\mathrm{FoldZ\mbox{-}rev}$ is not value-consistent.
Finally, $b(1)=000001$ and Bin-repair leaves it unchanged, hence $\mathrm{Bin\mbox{-}repair}(1)=000001\neq 100000$, so Bin-repair is not value-consistent.
\end{proof}

\paragraph{Scope.}
All theorem-level statements in Section~\ref{sec:folding_core} and Appendix~\ref{app:folding_core_proofs} apply to the folding map as defined there.
This appendix does not claim invariance under arbitrary map changes; it only records sensitivity within an explicit bounded counterfactual family.
