\section{Output Fiber Statistics and Derived Observables}
\label{sec:fiber-observables}

\subsection{Zero-Information Constraint on Nodes}

The zero-information constraint on nodes is stated as: nodes carry no directly observable information in the sense of intrinsic label semantics; observables must be generated by statistical functors of input/output fibers adjacent to nodes.

\subsection{Transition Kernel and Successors}

From the stable-type sequence, define the transition kernel
\[
P(y\mid x)=\mathbb{P}(x_{t+1}^{(6)}=y\mid x_t^{(6)}=x),
\]
and define the successor set $\mathrm{Succ}(x)=\{y:P(y\mid x)>0\}$.

\subsection{Observable Definition}

Define the class mass indicator
\[
M(x)=\kappa\,H(P(\cdot\mid x))\quad\text{or}\quad M(x)=\kappa'\log\card{\mathrm{Succ}(x)}.
\]
Define the class scattering delay
\[
\tau(x\to y)=\mathbb{E}\!\left[\inf\{n\ge 1:x_{t+n}^{(6)}=y\}\,\middle|\,x_t^{(6)}=x\right].
\]
The above quantities are entirely defined by output fiber statistics and are compatible with the zero-information constraint on nodes.
