\section{Computational certification for the arithmetic window}
\label{app:certification}

Section~\ref{sec:chebotarev} uses two kinds of input in the range
\(q=9,\dots,17\): exact integer recurrences for the collision moments
\(S_q(m)\), and finite certificate tables extracted from those recurrence
polynomials.  Since these data are part of the proof architecture, we record
their provenance here.

For each \(m\ge 0\), let \(c_m(r)\) denote the number of binary words
\(\omega\in\{0,1\}^m\) whose Fibonacci-weighted sum is congruent to
\(r\bmod F_{m+2}\).  Then
\[
  S_q(m)=\sum_{r\bmod F_{m+2}} c_m(r)^q.
\]
Thus \(S_q(m)\) can be computed exactly by modular dynamic programming on
\(\ZZ/F_{m+2}\ZZ\), without enumerating all \(2^m\) words.  The recurrence
polynomials \(P_q\) used in Section~\ref{sec:chebotarev} are defined from the
exact coefficients listed in Table~\ref{tab:appendix-recurrences-q9-17}.

\medskip
\noindent\textbf{Provenance of the certificate tables.}
The ancillary scripts used for the arithmetic window are the following:
\begin{enumerate}[\upshape (1)]
  \item \path{exp_fold_collision_moment_recursions.py} and
        \path{exp_fold_collision_moment_recursions_mod_dp.py}, which compute
        exact values of \(S_q(m)\) and verify the printed recurrences on an
        audit window in \(m\);
  \item \path{exp_fold_collision_moment_charpoly_irreducible_q9_17.py}, which
        exports the irreducibility, cycle-type, and discriminant-squareclass
        tables used in Section~\ref{sec:chebotarev};
  \item \path{exp_fold_collision_resonance_aitken_certificate_q9_17.py}, which
        exports the root fingerprints used in
        \Cref{tab:secondary-spectral-q9-17}.
\end{enumerate}
In each case the source tree contains both machine-readable JSON exports and
the corresponding \LaTeX{} tables.

\medskip
\noindent\textbf{Role in the paper.}
The proofs in Section~\ref{sec:chebotarev} use only the exact polynomials
\(P_q\) determined by Table~\ref{tab:appendix-recurrences-q9-17}, the
finite mod-\(p\) factorization patterns displayed in
\Cref{tab:galois-certificates-q9-17,tab:disc-squareclass-q12-15}, and the
high-precision root ordering recorded in \Cref{tab:secondary-spectral-q9-17}.
The appendix is included to make these inputs explicit and citable inside the
submission itself, rather than leaving them implicit in an external source
tree.
