\section{Unit Circle Area Phase Coordinate Gate: Parameter-Free Compactification, Structure Transport, and Finitization of Integrals}\label{app:unit-circle-phase-gate}
This appendix provides a \textbf{parameter-free coordinate gate} directly aligned with the three main threads of this paper:
(i) lifting the unbounded real-axis variable \(x\in\RR\) to a phase angle on the unit circle (or, equivalently, to a sector area fraction coordinate);
(ii) defining, via \emph{structure transport} within this bounded phase box, addition and multiplication strictly isomorphic to \((\RR,+,\cdot)\), thereby pushing all ``divergence/overflow'' uniformly to the boundary;
(iii) deriving the natural weight and change-of-variable formulae induced by this lift, which rewrite unbounded integrals as finite expressions on the unit circle.
The gate itself is invertible; any irreversibility arises solely from subsequent projection/truncation/discretization and can, following the ``extension-preserving'' principle, be externalized as an auditable residual register (consistent with the fold conditional expectation caliber in Appendix~\ref{app:op-algebra}).
