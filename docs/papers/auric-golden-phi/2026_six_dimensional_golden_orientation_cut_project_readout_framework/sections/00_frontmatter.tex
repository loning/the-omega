\begin{abstract}
本文提出一套可审计的“切—投影—读出”形式体系，用以统一刻画三维可见结构的生成、相干叠加所对应的强度重构、以及时间箭头在观测协议层的定义。体系将六维超空间表示严格限定为秩为 $6$ 的几何闭合模型类，并将观测者刻画为携带内部相位与读出参数的算子族；有限资源下的可实现采样通过环因子与有理逼近层级刻画。符号层以圆周二分割得到 Sturmian/Fibonacci 类过程，并以 Zeckendorf 合法语言与稳定化核 $\Fold_m$ 规范化有限窗口输出；主文固定带宽 $m=6$，以 $\Fold_6$ 的预像纤维对象化不可区分自由度，并以后验柱集测度的指数收缩率（SMB/KS 口径）严格定义时间箭头与“未来”的条件不确定性。进一步，内部规范自由度以 $\mathrm{SU}(3)$ 纤维扩展并入而不提高超空间秩，并给出固定带宽递归读出（分割细化）的可检验对照口径与一组可证伪统计指纹。
\end{abstract}
