\section{可证伪预测与区分性检验模板}\label{sec:falsifiable}

\subsection{Fibonacci 回归尺度指纹}

在黄金分支扫描下，统计量（如干涉可见度自相关、局部补丁计数自相关、稳定态序列的回返时间分布）应出现 Fibonacci 尺度分层或谱峰。检验步骤：
\begin{enumerate}
  \item 固定读出核与装置参数，采样长序列；
  \item 估计回返时间直方图与自相关；
  \item 与周期近似体（有理旋转数）及随机对照序列比较；
  \item 拟合 Fibonacci 指标上的峰结构与尺度不变性误差。
\end{enumerate}

\subsection{核宽 \texorpdfstring{$\varepsilon$}{epsilon} 控制的干涉可见度曲线}

由第 \ref{sec:cut-project-readout} 节的相干叠加结构，干涉可见度应随 $\varepsilon$ 连续变化：当 $\varepsilon$ 小到足以分离内部坐标通道时，交叉项被抑制；当 $\varepsilon$ 足够大时，交叉项增强。检验策略为在同一几何配置下系统扫描 $\varepsilon$ 并拟合单参数族曲线，从而区分“核诱导互补”与“本体二态切换”的解释。

\subsection{响应核非局域性的相关上界}

通过改变装置响应函数（等效改变 $G_{\theta}(\tau)$ 的正支撑权重），测得的“表观逆向相关”强度应与 $\Gamma_+$ 同步变化，并在核局域化时显著衰减。该检验用于区分“协议非局域”与“本体逆因果”叙述。

\subsection{退化谱频率律（离散原型可穷举验证）}

在离散原型中，若微观边缘分布近均匀，则稳定态频率应近似 $q(x)=d(x)/2^m$。该检验可在可逆置换动力学的数值模拟中直接验证，并作为更复杂模型的基准线。
