\section{协议层：无理取向切投影与三维可观测集}

\subsection{直和分解与投影算子}

取一个正交直和分解
\[
\RR^{6}=E_{\parallel}\oplus E_{\perp},\qquad \dim E_{\parallel}=3,\ \dim E_{\perp}=3.
\]
记正交投影为
\[
\pi_{\parallel}:\RR^{6}\to E_{\parallel},\qquad \pi_{\perp}:\RR^{6}\to E_{\perp}.
\]

\subsection{接受窗与模型集}

取一个紧致集合 $W\subset E_{\perp}$（接受窗），并引入“相位偏移”参数 $u\in E_{\perp}$。定义切投影产生的三维点集
\[
\Sigma(u):=\Big\{\pi_{\parallel}(n)\ :\ n\in\Lambda,\ \pi_{\perp}(n)+u\in W\Big\}\subset E_{\parallel}.
\]
当取向满足无理性条件
\[
E_{\parallel}\cap \Lambda = \{0\},
\]
且 $\pi_{\perp}(\Lambda)$ 在 $E_{\perp}$ 中稠密时，$\Sigma(u)$ 为典型的准周期“模型集”（model set），可呈现离散且非周期的长程有序结构。

\subsection{无理取向与“黄金支系”}

本文将“黄金支系”表述为一种满足两类需求的无理参数选择：
\begin{itemize}
  \item \textbf{反共振性：}避免短周期近似导致的读出锁定；
  \item \textbf{编码规范性：}使扫描迭代可与最小复杂度的符号编码（如 Sturmian 机械字）及其对应的 Ostrowski/Zeckendorf 表示对接。
\end{itemize}

在一维原型中，扫描常以圆周旋转
\[
x_{t+1}=x_t+\alpha\ \mathrm{mod}\ 1,\qquad \alpha\notin \QQ
\]
建模。黄金支系可取 $\alpha=\varphi^{-1}$，其中 $\varphi=(1+\sqrt{5})/2$。其连分数部分商全为 $1$，使之在有理逼近意义上达到极小共振，从而为有限前缀读出提供一种规范的反锁定选项。本文在高维情形中使用与此兼容的无理取向/扫描方向选择：其本质并非“唯一正确”，而是“在有限复杂度约束下的一类规范候选”。
