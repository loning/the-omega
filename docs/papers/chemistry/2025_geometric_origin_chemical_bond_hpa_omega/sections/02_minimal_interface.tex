\section{Minimal scan--readout interface and phase friction}
\label{sec:minimal_interface}

This section recalls the minimal interface assumptions used throughout the HPA--$\Omega$ literature and fixes notation. We only require two axioms (readout-induced probability and a Weyl pair) plus a discrepancy definition used as a computable proxy for ``phase friction'' \cite{Ma2025HPOT,Ma2025HHU,KuipersNiederreiter1974,DrmotaTichy1997}.

\subsection{O5: finite-resolution readout induces probability}
\begin{axiom}[O5: scan--projection readout induces probability]\label{ax:O5}
For a given readout resolution $\varepsilon>0$, an observer has access to a POVM (or instrument) $\{E_k^{(\varepsilon)}\}_k$ on an effective observer Hilbert space $\hilbert_{\mathrm{eff}}$, satisfying $\sum_k E_k^{(\varepsilon)}=\id$. For an effective state (positive normalized functional) $\omega_{\mathrm{eff}}$, the outcome probabilities are
\begin{equation}
P_k^{(\varepsilon)}=\omega_{\mathrm{eff}}\!\left(E_k^{(\varepsilon)}\right).
\end{equation}
\end{axiom}
This axiom encodes the HPA principle that probability is not an external sampling postulate but is induced by finite-resolution readout. For background on POVMs and instruments in standard quantum measurement theory, see \cite{NielsenChuang2010}.
In the standard density-operator representation, this reduces to $P_k^{(\varepsilon)}=\mathrm{Tr}(\rho_{\mathrm{eff}}\,E_k^{(\varepsilon)})$.

\subsection{O6: a Weyl pair and intrinsic noncommutativity}
\begin{axiom}[O6: Weyl pair]\label{ax:O6}
On $\hilbert_{\mathrm{eff}}$ there exist unitary operators $U_{\mathrm{scan}}$ and $V$ satisfying the Weyl relation
\begin{equation}
U_{\mathrm{scan}}V=\e^{2\pi\iu\nu}VU_{\mathrm{scan}},
\qquad
\nu\in(0,1)\setminus\QQ.
\end{equation}
\end{axiom}
In a standard model on $L^2([0,1))$, one may take $(U_{\mathrm{scan}}\psi)(x)=\psi(x+\nu)$ and $(V\psi)(x)=\e^{2\pi\iu x}\psi(x)$, so that the scan orbit is the Kronecker sequence $x_n=x_0+n\nu \pmod{1}$ \cite{Ma2025HHU}.
For mathematical background on Weyl relations and phase-space representations, see \cite{Folland1989}.

\subsection{Discrepancy and phase friction as mismatch accumulation}
Finite readout resolution makes mismatch unavoidable. A convenient quantitative proxy is star discrepancy. For a point sequence $(x_1,\dots,x_N)\subset[0,1)$ define the empirical distribution function
\begin{equation}
F_N(a)=\frac{1}{N}\#\{1\le n\le N:\ x_n<a\},\qquad 0\le a\le 1,
\end{equation}
and the one-dimensional star discrepancy and its cumulative mismatch
\begin{equation}
D_N^\ast=\sup_{0\le a\le 1}\left|F_N(a)-a\right|,
\qquad
E_N:=N D_N^\ast.
\end{equation}
The discrepancy literature provides sharp bounds for Kronecker sequences and related low-complexity protocols \cite{KuipersNiederreiter1974,DrmotaTichy1997}.

\begin{remark}[Higher-dimensional discrepancy]
For multi-degree-of-freedom readouts, one uses multi-dimensional discrepancy notions (e.g.\ star discrepancy on $[0,1)^d$) and corresponding Koksma--Hlawka-type bounds; see \cite{KuipersNiederreiter1974,DrmotaTichy1997}. In this paper, we use the one-dimensional definition only as a minimal interface proxy and only in the optional appendix-level template (Appendix~\ref{app:interface_phase_friction}).
\end{remark}

\begin{remark}[Quantitative size for Kronecker scanning]
For Kronecker sequences $x_n=x_0+n\nu\ (\mathrm{mod}\ 1)$, discrepancy bounds are controlled by the continued-fraction data of $\nu$. In particular, for bounded partial quotients (e.g.\ the golden-ratio case relevant in the HPA literature), one has logarithmic discrepancy bounds of the form $D_N^\ast=O((\log N)/N)$ and hence $E_N=O(\log N)$; see \cite{KuipersNiederreiter1974,DrmotaTichy1997}.
\end{remark}

In HPA phase thermodynamics, a computable ``phase-friction entropy proxy'' can be defined by
\begin{equation}
S_{\mathrm{pf}}(N)=k_B E_N,
\end{equation}
so that mismatch accumulation plays the role of an irreducible cost under coarse-grained (unconditional) readout \cite{Ma2025HPT}.

For chemistry, this language will be used only in the interpretation layer: bonding and reactions can be modeled as rearrangements that reduce mismatch accumulation under a given readout interface (Appendix~\ref{app:interface_phase_friction}).
