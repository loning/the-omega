
\section{时间作为“不可恢复的正交纤维”：残余对称与正交信息位}

我们用“\WL{} 在闭包图上仍无法细分的轨道方向”形式化“不可恢复的正交信息位”，即残余自同构（或残余等价类）。

\subsection{正交时间位：由 \WL{} 残余不确定性定义}

\begin{definition}[\WL{} 残余不确定性]
在 $\Clo_m$ 上运行 $1$-\WL{} 至稳定后，微观顶点 $X_m$ 被划分为颜色类分割 $\mathcal{P}$。若存在大小大于 $1$ 的颜色类，则称其内部差异为\textbf{不可由闭包图局部不变量恢复的正交分量}。当最大类大小为 $2$ 时，对应一个残余 $\ZZ_2$ 时间位。
\end{definition}

\subsection{Z2 纤维对称的可检验判据（充分条件）}

设 $G_m^{\mu}$ 为 hypercube 邻接，令 $\delta\in\{0,1\}^{m}$ 表示按位异或平移 $x\mapsto x\oplus \delta$。

\begin{lemma}[Z2 残余对称的充分条件]\label{lem:z2-sufficient}
若存在子集 $S\subseteq X_m$ 与非零 $\delta$，使得对所有 $x\in S$：
\begin{enumerate}
  \item $f_m(x)=f_m(x\oplus \delta)$；
  \item 在闭包图的任意 \WL{} 迭代中，$x$ 与 $x\oplus \delta$ 的邻居颜色多重集始终一致，
\end{enumerate}
则 $1$-\WL{} 无法区分 $x$ 与 $x\oplus \delta$，它们最终落在同一颜色类中。
\end{lemma}

\begin{proof}
$1$-\WL{} 的更新仅依赖当前颜色及邻居颜色多重集；若两点在每一步这些数据一致，则可用归纳法证明其颜色序列恒等，故不可区分。
\end{proof}

\begin{remark}
该引理给出“信息被存入时间维度”的严格版本：$\delta$ 方向是闭包图局部统计不变量无法破坏的轨道。
\end{remark}
