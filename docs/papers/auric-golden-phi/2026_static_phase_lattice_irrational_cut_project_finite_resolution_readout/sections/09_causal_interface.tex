\section{因果结构接口：光锥边界读出与“恒定传播速度”的角色}

\subsection{光锥边界读出}

在相对论语境中，观测者可获得的信息受因果结构限制：可访问数据主要位于其过去光锥或类光边界的场数据。本文将该事实在协议层表述为：\textbf{经验记录可近似建模为对本体态在类光边界上的限制与再编码}。形式上，可将读出映射扩展为
\[
\mathcal{R}_{\theta}:\ (\text{全局态/格点配置}) \ \longrightarrow\  (\text{光锥边界数据流})\ \longrightarrow\  (\text{离散记录}).
\]
在该接口中，“传播速度常数”不被解释为“万物由光构成”，而被解释为：它设定了从扫描迭代（协议时间）到因果可达集合的标定比例，并约束可观测信息通道的几何形状。

\subsection{与本框架的兼容性}

切投影—扫描读出框架并不要求把所有自由度都约化为无质量传播模。相反，它允许：
\begin{itemize}
  \item 质量、相互作用等作为稳定扇区与缺陷通道的结构性代价出现；
  \item 光锥边界读出作为“观测可达性约束”的接口层加入，而不替代本体层的高维相位格假设。
\end{itemize}
因此，在严格表述下，经验上“以光锥约束的边界数据为主导的观测记录”与本文框架相容，但不构成对“万物仅为类光投影”的逻辑推出。
