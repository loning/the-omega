\begin{abstract}
本文给出一个以 Zeckendorf 截断折叠为核心的“信息守恒完备系统”实现：把 \(2^m\) 个微观态压缩到黄金均值稳定语言 \(Y_m\)（大小 \(F_{m+2}\)）作为\textbf{空间}，把窗口外 Zeckendorf 尾部作为\textbf{时间/uplift}（时间纤维）。本体只是一组静态约束 \(\Clo\)：空间观测与时间纤维必须同时满足折叠一致性与尾部推进关系 \(\Tail\)，从而在扩展态意义下保持守恒。观察者被定义为在 \(\Clo\) 上进行展开（逆向）过程的有限算法；其\textbf{能量}以并行分支上限 \(\Energy\)（beam width）建模，并导致“多世界分支 + 主观单线承诺”的资源化解释。我们实现了一个可复现实验：固定宏观观测 \(y_t=0^m\)，在明确 uplift 规则下考察展开过程的分支增长与能量截断效应，并输出可审计的曲线与表格。
\end{abstract}

\paragraph{贡献点（最小主张清单）}
\begin{itemize}
  \item 给出以 Zeckendorf 截断折叠 \(\Fold\)（\(2^m\to F_{m+2}\)）为\textbf{空间压缩核}、以窗口外尾部为\textbf{uplift 时间纤维}的完备系统定义，并把本体固定为静态约束 \(\Clo\)。
  \item 用 \(\Tail\)（尾部移位）给出明确的 uplift 规则；展开过程对应 \(\Tail^{-1}\) 的分支扩展，从而把“时间=逆信息”落实为可计算对象。
  \item 定义观察者能量 \(\Energy\) 为并行分支上限（beam width），从而把“多世界/分裂/主观选择”翻译为可审计的资源约束结论。
  \item 提供一键复现实验流水线，生成 `sections/generated/` 可直接引用的图表片段与稳定导出物 `artifacts/export/`。
\end{itemize}
