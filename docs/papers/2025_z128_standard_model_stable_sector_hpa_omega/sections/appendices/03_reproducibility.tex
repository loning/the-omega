\section{Reproducibility}
\label{app:reproducibility}

This paper includes minimal, auditable scripts that reproduce the finite combinatorics, folding statistics, and the Hilbert chirality-index checks.
All scripts are standard-library Python and live under:
\[
\texttt{docs/papers/2025\_z128\_standard\_model\_stable\_sector\_hpa\_omega/scripts/}.
\]

\subsection{What is reproduced}
The scripts reproduce:
\begin{itemize}
\item enumeration of $X_6$ and verification $|X_6|=21$ (Lemma~\ref{lem:xm_fib});
\item Hamming-weight distribution of $X_6$ and the $18\oplus 3$ cyclic/boundary split (Proposition~\ref{prop:cyc_bdry_6});
\item computation of $\mathrm{Fold}_6(N)$ for $N=0,\dots,63$, including surjectivity and the degeneracy histogram (Theorem~\ref{thm:fold6_stats});
\item generation of a complete Fold$_6$ table (Appendix~\ref{app:fold6_full_table});
\item computation of the Hilbert chirality index $\chi$ at order $n=3$ and its sign flips under reflection and traversal reversal (Proposition~\ref{prop:chi_flip}).
\end{itemize}

\subsection{Main entry points}
\begin{itemize}
\item \path{exp_x6_enumeration.py}: enumerates $X_6$ and writes \path{sections/generated/x6_*.tex}.
\item \path{exp_fold6_stats.py}: computes Fold$_6$ statistics and writes \path{sections/generated/fold6_*.tex}.
\item \path{exp_hilbert_chirality_index.py}: computes $\chi$ on the $n=3$ Hilbert path and writes \path{sections/generated/hilbert_chi_summary.tex}.
\end{itemize}

\subsection{How to run (examples)}
\begin{itemize}
\item \texttt{python scripts/exp\_x6\_enumeration.py}
\item \texttt{python scripts/exp\_fold6\_stats.py}
\item \texttt{python scripts/exp\_hilbert\_chirality\_index.py}
\end{itemize}
