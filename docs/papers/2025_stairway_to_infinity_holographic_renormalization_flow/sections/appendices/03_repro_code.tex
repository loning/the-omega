\subsection{Reproducible paper figures (Python + Matplotlib)}
The figures included in the main text are generated by a separate script and require a small third-party stack (NumPy/Matplotlib) pinned in \texttt{requirements\_figures.txt}. A Python virtual environment is recommended. From the repository root:
\begin{Verbatim}[fontsize=\small]
./.venv/bin/python -m pip install --upgrade pip
./.venv/bin/python -m pip install -r docs/papers/2025_stairway_to_infinity_holographic_renormalization_flow/requirements_figures.txt
./.venv/bin/python docs/papers/2025_stairway_to_infinity_holographic_renormalization_flow/scripts/build_figures.py --png
\end{Verbatim}
This produces \texttt{docs/papers/2025\_stairway\_to\_infinity\_holographic\_renormalization\_flow/figures/figXX\_*.pdf} (and optional \texttt{.png} previews), which are included in the LaTeX source via \texttt{\textbackslash includegraphics}.
