\section{Introduction}\label{sec:introduction}

This paper isolates a single normalizing map---\emph{resolution folding} $\Fold_m$---as the minimal interface that turns finite-resolution binary window readouts into canonical symbolic objects with computable invariants and auditable certificates.
The central loop is
\[
\Omega_m\ \xrightarrow{\ \Fold_m\ }\ X_m\ \xrightarrow{\ \Phi_m\ }\ Y_m
\quad\Longrightarrow\quad
\text{Markov cover invariants and an information ledger}.
\]

\paragraph{Finite-window readout and the audit objective.}
Given a binary time series, the length-$m$ window state space is $\Omega_m=\{0,1\}^m$.
Our aim is to replace raw windows by stable \emph{types} that admit:
(i) a unique canonical representative (normal form);
(ii) multiscale compatibility across $m$;
(iii) a symbolic-dynamics factor $Y_m$ with a computable Markov cover;
(iv) an information-theoretic decomposition that separates visible from residual microstructure.

\paragraph{Main results (five theorems).}
The main statements are organized as five theorems:
\begin{itemize}
  \item Section~\ref{sec:certificates} (Theorems~\ref{thm:tv-certificate-hist} and \ref{thm:markov-tv-envelope}): finite-sample total-variation certificates for folded histograms, both deterministic (discrepancy-based) and probabilistic (Markov concentration).
  \item Section~\ref{sec:folding} (Theorem~\ref{thm:fold-normal-form-multiscale}): $\Fold_m$ as a confluent local rewriting normalizer, with idempotence, surjectivity, and multiscale compatibility via a fold-aware restriction.
  \item Section~\ref{sec:sofic-cover} (Theorem~\ref{thm:phi-sofic-fischer}): the induced sliding block factor $\Phi_m$ produces a sofic shift $Y_m$ with an explicit labeled graph and a right-resolving / Fischer-cover interface for computing $h_{\mathrm{top}}$, Parry data, and cover zeta determinants.
  \item Section~\ref{sec:ledger} (Theorem~\ref{thm:information-ledger}): the information ledger identity
  \[
  H(\mu)=H(P_m\mu)+\mathbb{E}[\log d_m]-D_{\mathrm{KL}}(\mu\|Q_mP_m\mu),
  \]
  which makes the KL term the unique residual carrier beyond folded types and fiber volumes.
\end{itemize}

\paragraph{Relation to prior work.}
The symbolic-dynamics side uses standard sofic/cover theory \cite{LindMarcus1995,Kitchens1998SymbolicDynamics,Weiss1973SFTandSofic,CovenPaul1975SoficSystems}.
The folding normal form is anchored in Zeckendorf representations \cite{Zeckendorf1972}.
The certification layer relies on discrepancy bounds \cite{KuipersNiederreiter1974} and Markov concentration \cite{Paulin2015MarkovConcentration}, while the information ledger uses Shannon/KL calculus \cite{CoverThomas2006,SasonVerdu2016fDivergence}.
