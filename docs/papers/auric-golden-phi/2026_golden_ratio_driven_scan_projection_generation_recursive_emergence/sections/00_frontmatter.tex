\begin{abstract}
本文在统一的扫描—投影读出模型中组织一组可审计的数学结论，并将其与解释性叙述严格分层。对象从单生成作用 $T^t$ 与二元读出 $s_t=\ind_W(T^t x)$ 出发，引入长度-$m$ 窗口微态 $\Omega_m=\{0,1\}^m$ 与稳定语法集合 $X_m$（禁止相邻 $11$），并定义分辨率折叠 $\Fold_m:\Omega_m\to X_m$。

本文的主要结论包括：在 Zeckendorf 语法下证明 $\Fold_m$ 的良定义、幂等、满射与跨分辨率相容（逆系统/逆极限）；给出由 $\Fold_m$ 诱导的序列级滑动块算子 $\Phi_m$ 的显式有限图表示与可计算接口；并建立与投影读出相容的算子代数桥接表述。进一步，本文提出投影本体数学（POM）作为统一接口：以先验纤维与双投影语法组织稳定算术与投影词编译（含 ISA/微码抽象端口）；对高阶碰撞矩给出模态约束导致 Hankel 秩下降的充分判别，并在 \(q=9,\dots,16\) 上提供秩缺口证据以形成可复核的共振机制指纹；并在核版 GRH 假设下给出素数寄存器（profinite）轴上的 Chebotarev 等分布提升。

反共振选择的“最优性”仅在 Hurwitz/Markov 的最坏逼近尺度及其对应的差异度型有限样本证书链条内成立（参见 \cite{Cassels1957,KuipersNiederreiter1974}）；对更强的统计泛函（例如相对 Parry 基线的 TV/KL 距离）不作全局最优或唯一性主张，并在正文中以误差分解区分证书项与模型差异项（见推论 \ref{cor:tv-decomposition-parry} 与命题 \ref{prop:parry-baseline-gap-sturmian}）。

文中“涌现”仅作为解释性术语，指折叠/规范形将微观自由度压缩为可复核的稳定类型与可实现的归一化规则；其不作为证明前提，亦不引入与经典结构非同构的新代数对象。
\end{abstract}
