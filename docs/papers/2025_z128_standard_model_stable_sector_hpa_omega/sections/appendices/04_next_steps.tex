\section{Further computable work packages (interface road map)}
\label{app:next_steps}

This appendix records concrete next-step work packages that turn the interface hypotheses into computable mapping problems.
They are not premises for any result in the main text.

\subsection{Functorial refinement of the field-level labeling map}

Given the closed labeling map $\mathcal{L}_{\mathrm{SM}}$ at $(m,n)=(6,3)$ (Section~\ref{sec:sm_labeling_closure}), the next computable task is to refine it under protocol lifts and to test its rigidity.
Concretely, one should define refined labels as invariants of a protocol encoding built from:
\begin{itemize}
\item the $\pi$ split $X_6^{\mathrm{cyc}}\sqcup X_6^{\mathrm{bdry}}$;
\item embedding of indices $\{0,\dots,63\}$ into a Hilbert grid at $n=3$;
\item invariance under orientation-preserving layout changes and gauge rephasings.
\end{itemize}
The deliverable is a family of maps that refines functorially under $(m,n)\mapsto (m',n')$ and yields a unique minimal solution at bounded complexity at each resolution scale, together with explicit covariance rules under protocol swaps.

\subsection{Mixing matrices as holonomy of protocol connections}

Treat mixing matrices (CKM/PMNS) as holonomy data of a protocol connection on an internal parameter manifold.
Compute holonomy along basic loops induced by protocol recursion (Hilbert refinement, window growth), and extract rephasing-invariant CP-odd observables.
The deliverable is an explicit protocol manifold $\mathcal{M}$ and connection $\mathcal{A}$ whose holonomy matches mixing data at minimal complexity.

\subsection{Resolution flow and running couplings}

Track how stable type counts and analytic pole barriers change under window uplift $m\mapsto m+1$ and spatial refinement $n\mapsto n+1$.
Relate the distance to the Abel pole barrier and the combinatorics of new admissible types to effective coupling running.
The deliverable is a computable renormalization-template model in which thresholds are Fibonacci-structured and coupling drift is protocol-geometric.
