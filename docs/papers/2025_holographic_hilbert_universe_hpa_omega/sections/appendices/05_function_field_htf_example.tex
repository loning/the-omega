\section{An explicit HTF model: Frobenius trace and Weil zeta for curves over finite fields}
\label{app:htf_function_field}

This appendix records a fully explicit instance of an HTF-style trace bridge in a setting where the analogue of RH is known: zeta functions of smooth projective curves over finite fields.
The purpose is not to re-prove the Weil conjectures, but to exhibit a concrete trace identity in which spectral modes appear through resolvent factors and the pole-barrier mechanism becomes an elementary spectral-radius statement.

\subsection{Weil zeta and Frobenius eigenmodes}
Let $C$ be a smooth projective geometrically connected curve of genus $g$ over $\mathbb{F}_q$.
Define the point counts $N_n:=\#C(\mathbb{F}_{q^n})$ and the Weil zeta function
\[
Z_C(u):=\exp\!\left(\sum_{n\ge 1} \frac{N_n}{n}\,u^n\right).
\]
It is a rational function of the form
\begin{equation}
\label{eq:weil_zeta_rational}
Z_C(u)=\frac{P_C(u)}{(1-u)(1-qu)},
\qquad
P_C(u)=\prod_{j=1}^{2g}\left(1-\alpha_j u\right),
\end{equation}
where the $\alpha_j$ are algebraic numbers encoding the Frobenius spectrum on the first cohomology of $C$ (see, e.g., \cite{Rosen2002}).
The nontrivial zeros of $Z_C$ occur at $u=\alpha_j^{-1}$.
The Weil RH statement for curves is the modulus condition
\[
\abs{\alpha_j}=q^{1/2}\qquad (1\le j\le 2g),
\]
equivalently $\abs{\alpha_j^{-1}}=q^{-1/2}$.

\subsection{A resolvent trace generating function and interior poles}
Define the normalized eigenvalues
\[
\lambda_j:=\frac{\alpha_j}{q^{1/2}},
\qquad 1\le j\le 2g.
\]
Consider the formal power series
\begin{equation}
\label{eq:function_field_trace_series}
G(r):=\sum_{n\ge 0}\left(\sum_{j=1}^{2g}\lambda_j^n\right) r^n,
\qquad r\in\CC.
\end{equation}
Whenever the sequence $\sum_j\lambda_j^n$ is bounded, the series \eqref{eq:function_field_trace_series} is holomorphic on the unit disk $|r|<1$ (cf.\ Lemma~\ref{lem:bounded_trace_holomorphy}).
On the other hand, for $|r|<1$ one has the resolvent identity
\begin{equation}
\label{eq:function_field_resolvent}
G(r)=\sum_{j=1}^{2g}\frac{1}{1-r\lambda_j},
\end{equation}
which is meromorphic with poles at $r=\lambda_j^{-1}$.
Thus:
\begin{itemize}
\item if $\abs{\lambda_j}>1$ for some $j$, then $r=\lambda_j^{-1}$ is a pole strictly inside $|r|<1$;
\item if $G(r)$ is holomorphic on $|r|<1$, then necessarily $\abs{\lambda_j}\le 1$ for all $j$;
\item applying the same argument to the dual spectrum (or using the functional equation symmetry in \eqref{eq:weil_zeta_rational}) forces $\abs{\lambda_j}=1$ for all $j$.
\end{itemize}

\subsection{Relation to the pole-barrier mechanism}
The identity \eqref{eq:function_field_resolvent} is a concrete trace bridge in the same structural form as Assumption~\ref{ass:HTF}:
the geometric-side holomorphy of an Abel-type trace on $|r|<1$ is incompatible with interior poles created by exponential-growth spectral modes.
In the function-field setting, the spectral data are explicit (Frobenius eigenvalues), and the ``critical line'' statement becomes the unit-modulus constraint $\abs{\lambda_j}=1$, i.e.\ $\abs{\alpha_j}=q^{1/2}$.
This provides a fully worked model demonstrating that HTF can be realized as a genuine trace identity rather than as a purely heuristic slogan.
