\subsection{附录 K：可审计性与可复现性说明（形式化视角）}\label{app:audit}

本文核心结构可被组织为“对象—接口—证书”的三元组：
\begin{itemize}
  \item \textbf{对象：}稳定地址空间与扩展残差空间（含三纤维）；
  \item \textbf{接口：}投影词正规形与 unitary slice 审计口径；
  \item \textbf{证书：}正规形判等、$\varepsilon$-sound 误差预算、根区间/strictification 拒绝证书。
\end{itemize}
在该组织方式下，“数学断言”被还原为可核对证书的存在性与可执行验证过程，从而将可审计性作为体系内部属性而非外部承诺。本文所有涉及“桥接”的结论均以显式合同形式给出（假设 \ref{ass:bridge-rh}），并将其义务分解为可逐项核验的接口约束（附录 \ref{app:bridge-rh-obligations}）。
