\section{Inverse interface diagnostics: recovering quantum-number patterns from invariants}
\label{app:inverse_quantum_numbers}

This appendix records exploratory inverse problems on the physical identification layer: given the closed labeling map and the intrinsic invariants available at window length $6$, to what extent can Standard Model quantum-number patterns be recovered by bounded-complexity rules built from those invariants?
These are not premises for any result in the main text.

\subsection{A bounded-complexity classifier for $(6Y)^2$}

Under the PDG convention $Q=T_3+Y$, the chiral fermion multiplets in one generation take hypercharges with $(6Y)^2\in\{0,1,4,9,16,36\}$.
Using the closed labeling $\mathcal{L}_{\mathrm{SM}}$ (Section~\ref{sec:sm_labeling_closure}), we can treat $(6Y)^2$ as a supervised target on the cyclic stable types and ask whether a low-complexity rule built from intrinsic invariants can recover it.

We test the simplest linear-score family on cyclic stable types:
\[
S(w)=a\,V(w)+b\,g(w)+c\,|w|_1+d,\qquad a,b,c,d\in\mathbb{Z},
\]
and predict $(6Y)^2$ by snapping $S(w)$ to the nearest allowed value in $\{0,1,4,9,16,36\}$ with a deterministic tie-break rule.
Table~\ref{tab:inverse_hypercharge_fit} reports the best and second-best solutions under a bounded search box together with the accuracy gap.
