
\section{引言}

在许多离散系统中，“状态压缩—规范型—可逆搜索”三者往往纠缠：压缩带来多对一退化，规范型要求结构刚性，可逆搜索要求分支可控。本文提出并分析一个最小但可审计的核：\textbf{Zeckendorf 数码的有限窗口截断}。其核心特征如下。

\begin{enumerate}
\item \textbf{稳定语言。}窗口长度为 $m$ 的合法词集合 $X_m\subset\{0,1\}^m$ 为禁止相邻 $11$ 的语言，并满足 $\abs{X_m}=F_{m+2}$（Fibonacci 计数）。
\item \textbf{折叠核。}将 $[0,2^m-1]$ 的整数 $N$ 写成 Zeckendorf 数码 $(c_k(N))_{k\ge 1}$，取前 $m$ 位定义
$$
\Fold_m(N)=(c_1(N),\dots,c_m(N))\in X_m.
$$
\item \textbf{边界驱动。}与传统的 $[F_n,F_{n+1})$ 取样不同，我们取 dyadic 上界 $2^m-1$。这一选择使得“边界态”成为主导对象：很多精细结构可由 $B_m=2^m-1$ 的数码局部窗口解释。
\end{enumerate}

为避免“已证明结论/经验观察/开放问题”的混淆，本文在表述上严格区分证据等级：\textbf{定理级结论}给出完整证明，\textbf{计算结论}明确样本区间与可复现脚本，\textbf{猜想}与\textbf{开放问题}集中置于讨论部分。

本文的主要贡献可概括为三条线索。

\begin{itemize}
\item \textbf{（A）纤维三值定理（定理级）。}证明 $s_m(w)=\abs{\Fold_m^{-1}(w)}$ 仅依赖值坐标 $V_m(w)$，并给出其两阈值三段阶梯结构与三值性 $\{a_m,b_m,b_m-1\}$；进一步推出分裂侧判别的刚性等价。
\item \textbf{（B）边界态有限换能器（计算级、可复现）。}以边界窗口态 $\sigma_m^{(L)}$ 为观测量，在给定样本区间上构造确定/可变长的规则系统，量化“时间维度搜索深度”，并输出可复现的映射表与统计摘要。
\item \textbf{（C）加权有限 $\zeta$（接口级）。}以纤维权重构造加权转移算子 $M_m$ 与有限 $\zeta_m$；给出与 Abel 型解析对象对接的有限层接口，并为后续谱/复杂度问题提供实验与理论的共同基座。
\end{itemize}

\subsection*{相关工作与本文定位}

Zeckendorf 表示作为黄金比例相关的经典数码系统，其唯一性与禁邻结构可追溯到 \cite{zeckendorf1972representation}；关于典型区间内 summand 数与统计分布的现代研究可参考 \cite{kologlu2011summands}。在“数码正规化/进位/可计算性”方面，线性数码系统与有限自动机之间的关系是标准主题（见 \cite{frougny1992representations,allouche2003automatic}）；本文的边界态换能器实验可以视为在一个完全可审计的有限样本平台上，对“carry 状态机/搜索深度”的具体量化。最后，符号动力系统中的有限 $\zeta$ 函数与转移算子（尤其对有限型移位）有成熟的解析框架（见 \cite{lind1995symbolic,bowenlanford1970zeta}）；本文引入的加权有限 $\zeta_m$ 旨在提供一个可复现的有限层接口，以连接纤维权重与谱/解析对象。
