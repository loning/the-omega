\section{Projection readout: binary windows imply Sturmian and Fibonacci structure}
\label{sec:readout}

\subsection{Window projection and binary readout}
Fix a half-open window interval $W\subset X$ and define the binary readout
$$
s_k := \ind_W(x_0+k\alpha)\in\{0,1\}.
$$
Equivalently, on $\hilbert=L^2(X,\mu)$ one may regard $\Pi_W$ as the orthogonal projection (multiplication operator) $(\Pi_W f)(x)=\ind_W(x)f(x)$, so that orbit sampling admits an operator-theoretic interpretation; cf.~Remark~\ref{rem:omega_choice}.
This realizes criterion (C3) and provides a minimal alphabet for scan observables.

\subsection{Mechanical word form and Sturmian minimal complexity}
Fix the interval window $W=[1-\alpha,1)$. Then the binary sequence can be written as a mechanical word: there exists an intercept $\beta\in\RR$ (determined by $x_0$) such that
$$
s_k=\big\lfloor (k+1)\alpha+\beta\big\rfloor-\big\lfloor k\alpha+\beta\big\rfloor.
$$

\begin{proposition}[Window coding as a mechanical word]
\label{prop:window_mechanical}
Let $W=[1-\alpha,1)$ and set $\beta:=x_0$ (viewed as a real representative in $[0,1)$). Then the orbit coding $s_k=\ind_W(x_0+k\alpha)$ satisfies
$$
s_k=\big\lfloor (k+1)\alpha+\beta\big\rfloor-\big\lfloor k\alpha+\beta\big\rfloor
$$
for all $k\ge 0$.
\end{proposition}

\begin{proof}
Write $x_k=\{k\alpha+\beta\}\in[0,1)$ for the fractional part. One has $s_k=1$ iff $x_k\in[1-\alpha,1)$, i.e. iff $\{k\alpha+\beta\}+\alpha\ge 1$. This is equivalent to
$$
\lfloor k\alpha+\beta+\alpha\rfloor=\lfloor k\alpha+\beta\rfloor+1,
$$
which is exactly the claimed difference-of-floors identity.
\end{proof}

When $\alpha$ is irrational, this sequence is Sturmian, i.e. its factor complexity satisfies $p(n)=n+1$, which is minimal among aperiodic binary sequences; see~\cite{MorseHedlund1940,Lothaire2002}.
\begin{remark}[Beyond minimal complexity: linear repetitivity and Diophantine type]
Sturmian minimal complexity holds for every irrational slope. Stronger uniformity notions (such as linear repetitivity/linear recurrence and uniform return-time bounds) depend on the continued fraction of $\alpha$ and are governed by bounded-type Diophantine conditions; see e.g.~\cite{LagariasPleasants2003,BugeaudLaurent2005}.
\end{remark}

\subsection{The golden branch yields the Fibonacci word}
For $\alpha=\varphi^{-1}$, the associated Sturmian sequence is, up to a shift and an exchange of symbols, the Fibonacci word. A standard representative arises as the fixed point of the substitution
$$
0\mapsto 01,\qquad 1\mapsto 0.
$$
Applying the symbol exchange $0\leftrightarrow 1$ yields the conjugate substitution $0\mapsto 1$, $1\mapsto 10$, which matches the present convention for the window readout $s_k=\ind_W(x_0+k\alpha)$. See e.g.~\cite{Lothaire2002}. Geometrically, this encodes a Fibonacci chain with two spacings (Long/Short), ordered aperiodically but with strong combinatorial constraints; see e.g.~\cite{Moody2000}.
