\section{引言：从折叠核到“时间作为 uplift”}

本文的出发点是一个最小的、可审计的设定：\textbf{本体是静态约束系统} \(\Clo\)，而非先验给定的演化历史。观察者只能访问部分数据并进行一致性搜索；“时空”与“时间”因此不是输入，而是搜索过程与隐藏自由度组织方式的输出。

\subsection{层级审计纪律：本体/协议/解释三层分离}
为避免在“本体约束—观察过程—解释叙事”之间循环论证，并与 \S\ref{subsec:layer_audit_rule} 的写作纪律对齐，本文把相关概念严格分层：
\begin{itemize}
  \item \textbf{Layer 0（本体）}：仅包含静态约束系统 \(\Clo\) 与允许扩展态集合（例如由 \(\mathrm{Enc}_m/\mathrm{Rec}_m\) 决定的可行对 \((y,t)\in\mathcal A_m\)），不预设概率、主观体验或连续时间。
  \item \textbf{Layer 1（协议）}：观察者以互逆原子步 \(\mathcal U/\mathcal D\) 在扩展态 \((y,t,\mathsf{tr},W)\) 上推进/回滚，并在资源上限 \(W\) 下对候选集合执行确定性截断（commit）。本篇的“守恒/抵消/湮灭”均指这一层的可逆更新与账本审计。
  \item \textbf{Layer 2（解释）}：把宏观稳定类型 \(y\) 解释为空间，把 uplift 尾部与其推进关系解释为时间，把资源上限 \(W\) 解释为能量/带宽，把 commit 后的持续追踪解释为主观单线。
\end{itemize}
该分层确保：时间、概率、离散标签等不作为本体输入出现，而是由协议层的可审计过程产生并在解释层获得语义。

\subsection{空间压缩核：\texorpdfstring{$2^m\to F_{m+2}$}{2^m->F_{m+2}}}
在 Zeckendorf 规范中，长度为 \(m\) 的黄金均值语言
\[
\Ym=\{y\in\{0,1\}^m:\ y_i y_{i+1}=0\}
\]
满足 \(|\Ym|=F_{m+2}\)。它可以被视为一个“稳定宏观类型空间”。与之相对，微观读出空间可以等价地取为二进制词集合 \(\Xm:=\{0,1\}^m\)，或取为索引集 \(\{0,\dots,2^m-1\}\)。折叠映射 \(\Fold\) 把每个微观索引（或其对应的二进制词）压缩到一个宏观稳定态（定义 \ref{def:fold}），从而形成空间压缩核。

\subsection{时间作为 uplift：尾部时间纤维}
压缩 \(\Fold\) 一般是多对一，因此若只看 \(\Ym\) 层信息，信息不可逆。本文的关键是：把“不可逆所需的逆信息”显式放入时间纤维，使可逆性发生在扩展态上。对 Zeckendorf 截断折叠而言，时间纤维（uplift 坐标）有一个自然且可计算的实现：\textbf{窗口外的 Zeckendorf 尾部} \(t=\tautime_m(N)\in T_m\)。为保证展开/折叠互为逆操作，观察者维护一条\textbf{路径 trace} \(\mathsf{tr}\in\{0,1\}^\ast\) 记录每一步展开所做的选择（定义 \ref{def:bit_registers_space_time_log}）。本文把“展开/折叠”视为一对互逆原子步：展开推进一步会做出一次分支选择并产生新的时间纤维/微观解释候选，同时把该步选择追加到 trace；折叠则以逆操作弹出 trace 的末位并湮灭相应的时间纤维与微观解释候选，从而回到先前状态（定义 \ref{def:up_down_interface}）。

\subsection{资源上限：并行分支上限与主观单线}
观察者不是全知的：它无法同时追踪所有时间纤维候选。本文用资源上限 \(W\in\NN\) 作为并行分支上限（定义 \ref{def:energy_beam}）。当展开诱导的可行候选数超过该上限时，观察者按可审计的确定性规则截断候选集合（commit/剪枝），从而把“多分支可追踪集合”压缩为“受限的可追踪子集”；主观单线对应在该约束下持续追踪的一条 trace。
