\section{干涉结构、互补性与延迟选择的协议重构}

\subsection{投影干涉与莫尔结构的形式对应}

切投影将高维周期结构映射到低维时，若读出核具有有限宽度，低维呈现的统计结构一般表现为准周期条纹、拍频与莫尔型干涉纹理。本文将“波动性”与“粒子性”区分为协议效应：
\begin{itemize}
  \item 当读出核宽（低分辨率）时，多个微态等价类叠加，输出呈现连续或条纹化统计；
  \item 当读出核窄（高分辨率）时，等价类被分裂，输出趋于离散事件序列。
\end{itemize}
该区分不依赖于本体层引入随机性，而是由 $\Fold_m$ 的退化结构与读出核宽度共同诱导。

\subsection{非对易结构与互补性}

若扫描由移位算子 $U$ 与相位算子 $V$ 生成，并满足 Weyl 关系
\[
UV=e^{2\pi i\alpha}VU,
\]
则对扫描相位与读出定位的同时精确化存在结构性限制。本文将互补性解释为：在同一协议中，试图同时最小化“扫描定位误差”与“读出定位误差”将受到非对易结构的下界约束；这一点可被转写为统计辨识任务的样本复杂度下界或误差权衡关系，从而成为可检验的协议层命题。

\subsection{延迟选择类现象的协议解释}

延迟选择类实验可在本框架中表述为：在读出记录生成后改变投影参数（例如改变读出核、改变接受窗或改变余维相位偏移的选择规则），从而改变“同一静态本体在低维读出中的等价类分解方式”。在该解释中：
\begin{itemize}
  \item 不需要引入对本体层的逆因果影响；
  \item 重构发生在协议层：改变的是读出算子对静态信息结构的分解与归类，而非改变静态结构本身。
\end{itemize}
可检验点在于：该重构应当对应于可计算的等价类再分配与退化结构变化，并在统计上呈现可预测的重权重迁移。
