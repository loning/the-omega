\section{引言}

\subsection{动机：把“解析难题”降到“可枚举、可验证”的离散层}
本文的切入点不是直接在 $\zeta(s)$ 上进行解析延拓，而是遵循“scan--projection--coding--certificate”的分层纪律：
\begin{enumerate}
  \item 在有限分辨率读出中，哪些离散结构可以被严格枚举并可验证；
  \item 这些结构如何递归到更高分辨率，并形成跨尺度不变量；
  \item 如何把谱性质与算法代价之间的关系写成封闭不等式链条，从而得到不依赖 RH 真假的强结论；
  \item 在额外、可单点审计的桥接假设下，是否能把“零点偏离临界线”转化成“单位圆盘内出现极点”的硬矛盾（阿贝尔极点屏障机制）。
\end{enumerate}
