# 2026_hpa_ca_fold6_lossless 工作追踪

## 定位（这篇解决什么）

以固定核 $m=6$ 为本体，构造一个一维环上、两相分区（Margolus）并行更新的分块元胞自动机。每个 6-bit 块通过折叠映射从 $64$ 个微观态压到 $21$ 个稳定态，同时把信息亏损记录为离散 uplift 边标签，从而在“扩展态（可见层 + uplift）”意义下严格可逆。

## 本体模型（最小描述）

- **可见态**：长度为 $L$ 的二进制环 $s_t\in\{0,1\}^L$，要求 $6\mid L$。
- **两相分块**：偶数步 offset 为 0，奇数步 offset 为 3；每步把链分成不重叠的 6 块并行更新。
- **块级更新核（固定 $m=6$）**：
  - 输入：块内 6-bit 词，解释为整数 $N\in\{0,\dots,63\}$
  - 输出：稳定词（禁邻约束）+ uplift
  - uplift 取值集合为 $U=\{0,21,34,55\}$
- **一步演化（扩展态）**：$s_t\mapsto (s_{t+1},u_t)$，其中 $u_t\in U^{L/6}$。
