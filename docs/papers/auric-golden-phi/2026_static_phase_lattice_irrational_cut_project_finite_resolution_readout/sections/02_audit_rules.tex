\section{分层审计规则与最小依赖链}

\subsection{分层}

\textbf{层 0（本体层）}：给定一个静态全局态与其代数结构；不引入外部时间与外部概率公设。\\
\textbf{层 1（协议层）}：指定扫描算子、投影/接受窗、有限分辨率读出核；在协议内定义操作时间（迭代次数）与诱导统计。\\
\textbf{层 2（识别层）}：将层 1 的结构映射为时空/粒子/场等语义对象；该层仅作为解释与可检验接口。

\subsection{最小依赖链}

本文使用的依赖链为：
\[
\begin{aligned}
&\text{静态格点本体}\ \Rightarrow\ \text{切投影几何}\ \Rightarrow\ \text{扫描迭代（协议时间）}\\
&\Rightarrow\ \text{有限分辨率读出}\ \Rightarrow\ \text{稳定扇区与类型折叠}\ \Rightarrow\ \text{可检验接口命题}.
\end{aligned}
\]
该链条的关键在于：离散性与统计性并非外加解释，而由“有限分辨率读出”诱导。
