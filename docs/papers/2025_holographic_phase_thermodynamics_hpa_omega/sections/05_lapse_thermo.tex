\section{Relativistic thermodynamics: computational lapse and gravitational cooling}
\label{sec:lapse_thermo}

This section connects entropy production to gravitational redshift via the $\Omega$ implementation dictionary: time dilation is computational slowdown.

\subsection{Routing overhead and computational lapse}

In the $\Omega$ program, microscopic evolution is modeled by a local unitary update (e.g.\ a PQCA step) that can be exactly compiled into a one-dimensional nearest-neighbor circuit on a finite region \cite{Ma2025FoP,Ma2025CAP}. The required circuit depth defines the \emph{routing overhead} field $\kappa(x)$: the operational cost of moving information through local connectivity to realize the update. A reference region defines $\kappa_0$ and the \emph{computational lapse}
\begin{equation}
\lapse(x)=\frac{\kappa_0}{\kappa(x)},\qquad \dd \tau_{\mathrm{loc}}(x)=\lapse(x)\,\dd t.
\end{equation}
Higher routing overhead means fewer realizable logical updates per unit background depth $\dd t$, hence a slower local clock. Identifying $\lapse$ with the GR lapse gives an operational dictionary for redshift in static spacetimes \cite{Wald1984,Carroll2004,MisnerThorneWheeler1973}.

\subsection{Entropy-production rescaling}

Let $S_{\mathrm{pf}}(x;\tau)$ denote the accumulated phase-friction entropy generated by a fixed readout protocol up to intrinsic scan time $\tau$ at location $x$ (Section~\ref{sec:asm}). We define the (possibly time-dependent) mismatch density by the scan-time derivative
\begin{equation}
  \sigma(x,\tau) := \frac{1}{k_B}\frac{\dd S_{\mathrm{pf}}(x;\tau)}{\dd \tau},
\end{equation}
interpreted in discrete scan time as a difference quotient when needed. With this definition, the scan-time entropy production law is simply
\begin{equation}
\frac{\dd S_{\mathrm{pf}}}{\dd \tau}=k_B\,\sigma(x,\tau).
\end{equation}
Then the entropy production rate with respect to external time $t$ is rescaled by the computational lapse:
\begin{equation}
\frac{\dd S_{\mathrm{pf}}}{\dd t} = \frac{\dd S_{\mathrm{pf}}}{\dd \tau}\frac{\dd \tau}{\dd t}
  = k_B\,\sigma(x,\tau)\,\lapse(x).
\label{eq:lapse_rescaling}
\end{equation}

\noindent Equation~\eqref{eq:lapse_rescaling} is the thermodynamic content of gravitational time dilation in this framework:
\begin{itemize}
  \item larger mismatch density $\sigma$ produces more entropy per scan step;
  \item stronger gravity corresponds to smaller $\lapse$ (larger routing overhead), so external observers see \emph{slower} entropy flow.
\end{itemize}
We call this effect \textbf{computational cooling}: in regions where computation is slowed by geometric overhead, the externally observed entropy-production rate is suppressed.

\subsection{Interpretation and limits}

The lapse rescaling does not imply that mismatch disappears in strong gravity; rather, it means that mismatch accumulation is ``time-dilated'' in the external description. When $\lapse\to 0$ (an idealized horizon limit in the GR dictionary), external entropy flow tends to zero, consistent with clock freezing. In Section~\ref{sec:entropy_force_gravity} we connect the same mismatch density to a phase potential and a phase-pressure acceleration.
