\section{隐维—窗口接口：cut-and-project 模型集}

\subsection{模型集定义}

分解 $\RR^n=E_\parallel\oplus E_\perp$，设晶格 $L\subset\RR^n$，投影 $\pi_\parallel,\pi_\perp$，窗口 $W\subset E_\perp$。定义模型集
\[
\Lambda=\{\pi_\parallel(\ell):\ell\in L,\ \pi_\perp(\ell)\in W\}.
\]
在该语言下，“存在性”可被形式化为内部空间窗口成员关系；“可见结构”由外部投影给出。

\subsection{与旋转编码的接口}

一维 Sturmian 序列可视为二维 cut-and-project 的剖分编码；多维环面扫描对应更高维 cut-and-project。由此可将“隐维—窗口—可见序列”的对应关系纳入统一协议层，并为准晶体类非周期有序结构提供数学接口。
