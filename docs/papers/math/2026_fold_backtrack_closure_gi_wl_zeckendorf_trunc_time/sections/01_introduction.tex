
\section{引言}

我们研究一个由两种数据形式共存而自然诱发“空间--时间分解”的离散系统：
\begin{itemize}
  \item \textbf{微观数据：}二进制态 $X_m=\{0,1\}^{m}$，规模 $\abs{X_m}=2^{m}$；
  \item \textbf{宏观稳定态：}Zeckendorf/Fibonacci 字 $Y_m\subset\{0,1\}^{m}$，满足无相邻 $1$，规模 $\abs{Y_m}=F_{m+2}$。
\end{itemize}
在 $m=6$ 时，$\abs{X_6}=64$，$\abs{Y_6}=21$，对应我们讨论中的 $64\to 21$ 最小闭合版本。

本文核心观点是：\textbf{稳定态不是“另一种编码”，而是 Zeckendorf 表示的截断前缀；被截断的尾部天然形成“时间纤维”。}当我们把“折叠边”（微观态指向其稳定前缀）与“微观邻接”（由某种规则给出）合并成一个闭包图时，图同构（\GI{}）与 Weisfeiler--Leman（\WL{}）稳定化就成为同一对象的两个侧面：\GI{} 关注“是否存在保持结构的重标号”，\WL{} 则是“用局部可计算不变量逼近规范标号”的迭代过程。Babai 的准多项式 \GI{} 框架以相干配置与 \WL{} 系列程序为基础构件 \cite{babai2016gi}。

本文贡献分三类：
\begin{enumerate}
  \item \textbf{构造：}定义 Zeckendorf 截断折叠 $f_m:X_m\to Y_m$ 与闭包图 $\Clo_m$；
  \item \textbf{翻译：}给出闭包图 \GI{} 与“折叠相容的微观 \GI{}”的严格等价；把 \WL{} 稳定化解释为闭包图诱导的相干配置细化；
  \item \textbf{实验：}系统扫描维数/拓扑（开边界、环面、超立方体）与 $m$ 的关系，观察到三维为“快速塌缩临界”，并识别少数 $m$ 上的残余 $\ZZ_2$ 时间对称。
\end{enumerate}
