\begin{proposition}[Depth--Height Two-Level Extremal Decomposition: Strongest Indistinguishability and Strongest Distinguishability of Height Phase Under Fixed Depth Orbit]\label{prop:xi-depth-height-two-level-extremal}
Fix the depth-side Stieltjes orbit \(S(t)=\int\frac{1}{t+a}\,\dd\mu(a)\) (equivalently fix the depth measure \(\mu\), thus fixing all decay amplitude/weight calibers).
Under this premise, the height parameter \(\gamma\) can only enter the visible spectral fingerprint through phase characters \(e^{-\mathrm{i}\gamma n\Delta}\ (n\in\ZZ)\) of the grid address step size \(\Delta\) (Proposition \ref{con:xi-grid-scan-aliasing-threshold}).
Then there exist two complementary extremal principles:
\begin{enumerate}
  \item \textbf{(Strongest Indistinguishability)} Under a single step size \(\Delta\) regime, the height parameter can only be determined up to congruence group
  \[
  \Gamma_{\Delta}:=\frac{2\pi}{\Delta}\ZZ,
  \]
  and this congruence recycling cannot be eliminated by any enhancement relying solely on the depth-side \(\mu\) (depth side only changes magnitude/decay without changing phase invariance group).
  \item \textbf{(Strongest Distinguishability)} If a second step size \(\Delta'>0\) is allowed, then the height congruence group contracts to the intersection
  \(
  \Gamma_{\Delta}\cap\Gamma_{\Delta'}
  \)
  (Proposition \ref{con:xi-grid-scan-two-step-dealiasing}), and achieves strongest distinguishability when \(\Delta/\Delta'\notin\QQ\): \(\Gamma_{\Delta}\cap\Gamma_{\Delta'}=\{0\}\).
\end{enumerate}
Therefore, the direct product coupling between depth orbit and height carrier is not only a necessary structure (see the minimal direct product proposition for depth--height), but also has a clear extremal phase diagram: any depth-side enhancement cannot break the congruence recycling of the height side, while minimal enhancement on the height side (dual address) can compress congruence recycling to minimal intersection.
\end{proposition}
