\begin{abstract}
本文以“本体是静态约束系统”作为第一性起点，提出一个以观察者为中心的时空构造：对观察者 \(O=(\proj,\mathcal A,\mathcal G)\)，其“时空”被定义为在本体约束 \(\Clo\) 上进行 lifting/一致性搜索时生成的搜索图。本文把“时间”定义为为保持本体可逆性而必须记录的 uplift/历史胶带的编码长度（负信息时间）\(\tautime\)，并在最小假设下给出 \(\kappaobs\)（搜索成本）与 \(\tautime\) 的同阶等价关系。本文进一步把 Hilbert 曲线族作为观察者的“尺子” \(\mathcal G\)：固定几何（1D/2D/3D）用于比较局部性选择对推断结构的影响；自适应维度切换用于刻画观察者在传播停滞时通过改变消元序/局部性结构来推进搜索的机制。最后以两条既有实例线索（\(m=6\) 的无损分块折叠核与一般 \(m\) 的 Zeckendorf 截断折叠）展示该框架的可审计可复现性。
\end{abstract}

\paragraph{贡献点（最小主张清单）}
\begin{itemize}
  \item 给出以观察者为中心的形式化三元组 \(O=(\proj,\mathcal A,\mathcal G)\)，并定义 lifting 集合、负信息时间 \(\tautime\)（uplift 胶带编码长度）与观察者成本 \(\kappaobs\)。
  \item 把“观察者时空”定义为搜索过程生成的可审计图对象：时间轴由 uplift 胶带组织（\(\tautime\)），而“时间变慢”由 \(\kappaobs\)（搜索成本）刻画，并在最小假设下与 \(\tautime\) 同阶等价。
  \item 将 Hilbert 曲线族提升为观察者的尺子：固定几何对比 + 自适应维度切换策略，形成可复现实验指标。
\end{itemize}
