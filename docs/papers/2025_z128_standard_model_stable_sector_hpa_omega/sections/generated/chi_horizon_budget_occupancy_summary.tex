\paragraph{Audit summary (budget-triggered cloud occupancy).} \AuditTag This table is capacity-only and deterministic. For each $(m,n)$ and observer budget $I_{\mathrm{obs}}$ (bits), it reports the minimal required cloud-site count $|\mathcal R_\star|$ such that $I_{\chi}=m|\mathcal R_\star|\ge c\,I_{\mathrm{obs}}$, together with the implied occupancy fraction $|\mathcal R_\star|/4^n$. If the required site count exceeds $4^n$, the budget-trigger criterion is infeasible at that resolution.
