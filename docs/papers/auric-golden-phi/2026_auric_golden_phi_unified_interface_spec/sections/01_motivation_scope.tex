\section{动机与范围}

\subsection{为什么需要“总论/接口规范”}

本目录中的分篇论文已经各自形成了闭合的“定义—定理—可复现协议”链条，但它们高度复用同一组结构模块：
\begin{itemize}
  \item \textbf{动力系统模块：}紧阿贝尔群/环面上的平移与诱导，或其几何等价的超空间 cut-and-project 截面；
  \item \textbf{读出模块：}有限分辨率窗口/二分割投影所诱导的二值序列与转移核；
  \item \textbf{符号与稳定化模块：}Sturmian 最小复杂度、黄金均值合法语言与 Zeckendorf 规范形；
  \item \textbf{纤维与时间模块：}稳定化核预像纤维、柱集后验测度收缩与熵率；
  \item \textbf{协议/算术接口模块：}差异度证书、Hecke 骨架、$\zeta$ 接口等可审计端口。
\end{itemize}

因此最合理的整合方式是：保留分篇论文的主证明链，同时增加一个“接口规范”作为总入口，使得
每个分篇都能被表述为同一接口的一个实例（或扩展），并把它的额外假设显式归类为：几何实现假设/读出假设/稳定化规则/统计假设/算术接口假设。

\subsection{本总论的输入最小化}

本总论只固定最小输入：
\begin{itemize}
  \item 可测动力系统 $(X,\mathcal{B},\mu,T)$（或紧群平移/因子系统）；
  \item 有限字母表读出与有限窗口长度 $m$；
  \item 稳定化核 $\Fold_m$ 的可计算性与规范形唯一性（Zeckendorf 逻辑）；
  \item SMB/KS 的调用条件（遍历性、生成分割或等价假设）。
\end{itemize}
其余结构均作为“可选扩展端口”出现。
