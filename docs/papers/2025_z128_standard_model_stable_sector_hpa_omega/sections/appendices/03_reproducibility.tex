\section{Reproducibility}
\label{app:reproducibility}

This paper includes auditable scripts that reproduce the finite combinatorics, folding statistics, and the Hilbert chirality-index checks.
All scripts are written in Python and live under:
\[
\texttt{docs/papers/2025\_z128\_standard\_model\_stable\_sector\_hpa\_omega/scripts/}.
\]
Some extended audit and plotting utilities use a small scientific stack recorded in \path{requirements.txt}.

\subsection{What is reproduced}
The scripts reproduce:
\begin{itemize}
\item enumeration of $X_6$ and verification $|X_6|=21$ (Lemma~\ref{lem:xm_fib});
\item Hamming-weight distribution of $X_6$ and the $18\oplus 3$ cyclic/boundary split (Proposition~\ref{prop:cyc_bdry_6});
\item computation of $\mathrm{Fold}_6(N)$ for $N=0,\dots,63$, including surjectivity and the degeneracy histogram (Theorem~\ref{thm:fold6_stats});
\item generation of a complete Fold$_6$ table (Appendix~\ref{app:fold6_full_table});
\item computation of the Hilbert chirality index $\chi$ at order $n=3$ and its sign flips under reflection and traversal reversal (Proposition~\ref{prop:chi_flip}).
\item a coarse-grained scalar parity check on the $n=3$ Hilbert grid that contrasts the parity-odd chirality index with parity-even block-averaged intrinsic observables (Table~\ref{tab:scalar_coarse_grain}).
\item generation of the closed $21\to$SM labeling table (Table~\ref{tab:sm_labeling_table});
\item generation of the mass-spectrum closure table (Table~\ref{tab:mass_spectrum}).
\item bounded-coefficient rigidity search for the depth ansatz (Table~\ref{tab:mass_depth_rigidity}).
\item generation of a PMNS mixing-angle closure and its induced matrix tables (Section~\ref{sec:pmns_neutrino_closure}).
\item generation of a resolution-threshold staircase table for Fibonacci-structured uplifts (Section~\ref{subsec:p3_resolution_jumps}).
\item generation of finite-resolution connection/holonomy audit tables on the $n=3$ Hilbert grid (Section~\ref{sec:protocol_connections_holonomy}).
\item generation of uncertainty-robustness audit tables (Appendix~\ref{app:audit_uncertainty}).
\item generation of counterfactual baseline audit tables (Appendix~\ref{app:audit_counterfactual}).
\item generation of the quantitative rigidity-target summary table used in the main text (Table~\ref{tab:quant_summary}).
\end{itemize}

The scripts write small LaTeX fragments into:
\begin{center}
\path{docs/papers/2025_z128_standard_model_stable_sector_hpa_omega/sections/generated/}

This repository includes the generated fragments so the paper can compile out of the box, but they can be regenerated at any time.
