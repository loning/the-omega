# 2026_dyadic_zeckendorf_window_folding_kernel 工作追踪

## 定位（这篇解决什么）

研究一般窗口长度 $m$ 的 Zeckendorf 截断折叠核（在 dyadic 上界 $2^m-1$ 的取样下），把“原像纤维大小”写成可审计的 tail 计数问题，并沿着边界态构造有限换能器与加权有限 $\zeta$ 算子。

这篇更偏“结构定理/工具箱”，可用于解释为什么在固定基例（如 $m=6$）会出现极小的离散 uplift 字母表与刚性纤维直方图。

## 核心对象（最小集合）

- **折叠映射**：对 $N\in[0,2^m-1]$，取其 Zeckendorf 数码前 $m$ 位作为可见稳定态。
- **纤维计数**：对固定输出词 $w$，原像大小可写为满足不等式约束的 tail 计数。
- **边界态**：以 $2^m-1$ 诱导的边界窗口态为主导对象，构造确定/可变长换能器并量化时间深度。
- **加权有限 $\zeta$**：以纤维权重构造有限层转移算子与生成函数，作为与谱语言对接的接口。
