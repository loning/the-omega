\section{Weinberg operator scale (dimension-5 EFT; audit)}
\label{app:neutrino_weinberg_operator_closure}

This appendix records a standard effective-field-theory (EFT) bridge for Majorana neutrino masses via the dimension-5 Weinberg operator.
The purpose is \emph{not} to introduce new continuous fit freedom, but to expose a minimal and auditable map between the protocol-selected neutrino spectrum and a single high-energy scale.

\paragraph{EFT assumption (standard).}
\AuditTag We use the conventional SM EFT embedding (Appendix~\ref{app:protocol_eft_embedding}) together with the CAP-minimal Higgs-doublet count $N_H=1$ (Proposition~\ref{prop:minimal_higgs_doublet_count}) and assume that lepton-number violation at energies above the anchor is captured, at lowest dimension, by the Weinberg operator \cite{Weinberg1979WeinbergOperator}:
\[
\mathcal{L}\supset \frac{c_{ij}}{\Lambda}\,(L_iH)(L_jH)+\mathrm{h.c.}
\]
After electroweak symmetry breaking, the induced Majorana mass matrix satisfies (in the charged-lepton mass basis)
\[
m_\nu = \frac{v^2}{2\Lambda}\,c,
\]
where $v$ is fixed by the $Z$-scale interface dictionary (Proposition~\ref{prop:vev_from_mz_closed_ew}).

\paragraph{Coefficient normalization (bounded-coefficient convention).}
\AuditTag To extract a single scale from a fixed spectrum, we adopt a bounded-coefficient convention by setting the largest effective coefficient to unity, $c_{\max}=1$, so that
\[
\Lambda_W := \frac{v^2}{2\,m_{\nu,\max}}.
\]
This is an interface normalization that turns the spectrum into a single auditable scale; any alternative convention corresponds to a bounded rescaling of $\Lambda$ and $c$.

\paragraph{Resolution-staircase identification (audit).}
\AuditTag We compare the resulting $\Lambda_W$ to the closed staircase thresholds $\mu_{\mathrm{th}}(m)=m_e\varphi^{2\pi(m-6)}$ (Table~\ref{tab:resolution_thresholds}), selecting the nearest threshold by a deterministic minimizer over a fixed finite window $m\in\{6,\dots,40\}$.
