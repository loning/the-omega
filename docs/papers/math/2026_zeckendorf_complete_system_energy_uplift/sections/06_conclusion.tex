\section{结论}

本文以 Zeckendorf 截断折叠作为空间压缩核（\(2^m\to F_{m+2}\)），以窗口外尾部作为明确 uplift 规则（时间纤维），构造了一个本体为静态约束系统 \(\Clo\) 的信息守恒完备系统实现。全文的观察者动力学被压缩为一对互逆操作：\textbf{展开}与\textbf{折叠}。展开每推进一步产生新的时间纤维/微观解释候选，并把该步选择写入 trace \(\mathsf{tr}\)；并行候选集合的规模由资源上限 \(W\) 约束。折叠作为逆操作逐步湮灭对应候选并回到先前状态，从而把“守恒”严格落实为可逆接口本身（定义 \ref{def:up_down_interface}）。

由于折叠核 \(\Fold\) 的多对一简并度，在 \(m=6\) 的 \(64\to 21\) 基例中出现 \(s_6(y)\in\{2,3,4\}\) 的三值纤维结构：当 \(s>2\) 时携带更高的可区分简并度，其量级由 \(\Energy_{\mathrm{pot}}(y)=\log_2 s_m(y)\) 量化。实验部分给出该 \(2/3/4\) 分布的可复现直方图，并展示固定观测下展开深度与资源上限 \(W\) 共同决定的分支行为。

附录进一步给出：在不改动 Layer 0 本体约束的前提下，若把协议层的 trace 视作可编程 tape，则协议内部可出现可逆通用计算子系统，并由此在严格计算论意义下导出自指固定点（第二递归定理）与 Quine 作为必然推论。
