\section{Bulk reportables registry (what the ``bulk'' means in this manuscript)}
\label{app:holo_bulk_observables_registry}

\paragraph{Purpose.}
\AuditTag This appendix fixes the ``bulk'' side of the holographic dictionary as a \emph{registry of reportable quantities}.
It does not posit an ontic continuum; it collects the manuscript's already-closed outputs that can serve as bulk-facing
targets for reconstruction or capacity bounds.

\subsection{Holo2: definition of the bulk reportables registry}
\label{subsec:holo2_bulk_registry_def}

\begin{definition}[Bulk reportables registry]
\label{def:holo_bulk_reportables_registry}
\MathTag Define the bulk reportables registry $\mathfrak{Obs}_{\mathrm{bulk}}$ as the set of quantities that are:
\begin{itemize}
\item well-defined from the tick\,+\,CAP closed chain and declared protocol state $(m,n,K)$,
\item reportable as invariants or audited representatives (Appendix~\ref{app:inference_ledger}),
\item equipped with an explicit scheme/matching contract whenever scheme dependence is present
(Appendix~\ref{app:scheme_invariance_audit_contract}).
\end{itemize}
\end{definition}

\paragraph{Audit note (no hidden enlargement).}
\AuditTag Definition~\ref{def:holo_bulk_reportables_registry} is intentionally conservative:
any quantity that requires a nonperturbative existence claim (e.g.\ 4D constructive QFT) is excluded by the R3 boundary
and belongs at most to a CP interface package (Appendix~\ref{app:renormalization_dictionary_and_boundaries}).

\subsection{Holo2: canonical members used by this paper}
\label{subsec:holo2_registry_members}

\paragraph{Representative list.}
The following list records the canonical reportables already present in the manuscript
(with pointers to their closure modules). This list is not exhaustive but is sufficient to support the PT statements of
Appendices~\ref{app:holo_capacity_bound}--\ref{app:holo_reconstruction_surrogate}.

\begin{itemize}
\item \textbf{Weak-field bulk proxies from $\chi$.}
The overhead$\to\chi\to g_{00}\to\Phi$ closure and the weak-field curvature proxy
$\widehat G_{00,h}$ are closed with an explicit error budget
(Appendix~\ref{app:overhead_to_gravity_closure}, Appendix~\ref{app:weak_field_curvature_from_chi},
Appendix~\ref{app:protocol_to_continuum_error_control}).
\item \textbf{Determinant/trace/pressure certificates.}
Pole-barrier and pressure language is packaged as determinant/trace objects and audited within declared candidate families
(Section~\ref{sec:rigidity_bridge_spine}, Appendix~\ref{app:thermodynamic_formalism_pressure},
Appendix~\ref{app:operator_mother_space}).
\item \textbf{Protocol capacity and uplift staging.}
The protocol capacity $I_{\mathrm{prot}}(m,n)=m4^n$ and its capacity-first uplift selection are closed as finite-family CAP outputs
(Appendix~\ref{app:resolution_uplift_fusion_horizon_unification}).
\item \textbf{Black-hole boundary capacity calibration (matching-layer hook).}
When PBH inputs are declared (Appendix~\ref{app:physics_consensus_inputs}), the black-hole boundary capacity
is calibrated against $I_{\mathrm{prot}}(m,n)$ as a deterministic CAP audit
(Appendix~\ref{app:bh_planck_capacity_calibration}).
\item \textbf{Record-algebra recovery surrogates (audit artifacts).}
Page-surrogate and island-equivalent toy reconstructions are available as auditable artifacts on an external record algebra
(Appendix~\ref{app:bh_scope_contract}, Appendix~\ref{app:bh_page_surrogate}, Appendix~\ref{app:bh_island_equiv}).
These support \AuditTag narratives but are not used as theorem premises.
\end{itemize}

\subsection{Holo2: scheme and matching boundaries (must be referenced whenever a bulk quantity is compared)}
\label{subsec:holo2_scheme_boundaries}

\paragraph{Scheme contract.}
\AuditTag Any comparison that treats a bulk reportable as ``the same quantity'' across modules must invoke the scheme
invariance contract (Appendix~\ref{app:scheme_invariance_audit_contract}).
When a matching-layer dictionary is used (units, thresholds, PDG/CODATA conventions), it must be recorded as such and
must not be used as a theorem-level premise (Section~\ref{sec:limitations_related_work}).
