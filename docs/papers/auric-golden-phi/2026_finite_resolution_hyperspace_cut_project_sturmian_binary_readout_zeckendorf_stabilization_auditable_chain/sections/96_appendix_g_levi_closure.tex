\section{附录 G：Levi 图闭包正确性（证明提纲）}
\label{app:levi-closure-proof}

令 $\mathcal{S}$ 为节点子集的幂集，定义单调算子 $\mathcal{T}:\mathcal{S}\to\mathcal{S}$ 为
\[
\mathcal{T}(S):=\mathrm{Node}(\mathrm{Reach}(\mathrm{Fib}(S))).
\]
若 $\mathrm{Reach}$ 单调，则 $\mathcal{T}$ 单调。有限集上的单调算子从任意初值出发的 Kleene 迭代在有限步达不动点；该不动点为包含初始集合的最小不动点。由此得到定理 \ref{thm:finite-closure}。
