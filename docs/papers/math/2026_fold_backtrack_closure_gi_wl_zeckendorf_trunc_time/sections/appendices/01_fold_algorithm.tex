
\section{折叠 f\_m 的可复现定义与算法}
\label{app:fold}

\subsection{Zeckendorf 转换（贪心）}

给定整数 $N\ge 0$，令 $k$ 为满足 $F_k\le N$ 的最大下标，置 $c_k=1$，并令 $N\leftarrow N-F_k$；随后禁止选择相邻的 $F_{k-1}$，并重复上述步骤直至 $N=0$。由 Zeckendorf 定理，该过程产生唯一系数序列 $\mathbf{c}(N)=(c_1,c_2,\dots)$ \cite{zeckendorf1972representation}。

\subsection{截断折叠与时间尾}

对微观态 $x\in X_m$，定义：
\begin{itemize}
  \item 可见部分：$f_m(x)=(c_1,\dots,c_m)\in Y_m$；
  \item 时间尾：$\tau_m(x)=(c_{m+1},c_{m+2},\dots)$。
\end{itemize}
在 $m=6$ 的最小闭合版本中，$f_6$ 实现 $64\to 21$ 的压缩，且 $\tau_6$ 记录被截断的高位信息。
