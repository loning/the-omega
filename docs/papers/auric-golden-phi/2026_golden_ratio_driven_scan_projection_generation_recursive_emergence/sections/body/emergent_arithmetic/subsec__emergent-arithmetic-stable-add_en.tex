\subsection{Addition as Normalization: From Normal Forms to a Commutative Monoid}\label{subsec:emergent-arithmetic-stable-add}

Consider the infinite Zeckendorf address space
\[
X_\infty=\{(c_1,c_2,\dots): c_k\in\{0,1\},\ c_kc_{k+1}=0,\ \text{only finitely many }1\}.
\]
Define the value map
\[
\mathrm{Val}(c)=\sum_{k\ge1}c_kF_{k+1}\in\NN.
\]

To avoid assuming ``confluence/termination'' as additional hypotheses, this paper first gives a mathematical definition of the operations via Zeckendorf uniqueness (\cite{Zeckendorf1972}), and subsequently describes their computable implementation (Appendix~E).

\begin{definition}[Stable addition]\label{def:stable-add}
For $c,d\in X_\infty$, define
\[
c\oplus d:=\mathrm{Val}^{-1}\bigl(\mathrm{Val}(c)+\mathrm{Val}(d)\bigr)\in X_\infty.
\]
\end{definition}

\begin{remark}[Clarification on ``tautology'': definitional isomorphism vs.\ observable implementation]\label{rem:arith-not-novel-as-abstract}
It should be acknowledged that Definition~\ref{def:stable-add} pulls the operation back directly to $(\NN,+)$; hence the conclusion that ``\(\mathrm{Val}\) gives an isomorphism'' is \textbf{definitional} at the abstract algebra level and does not produce a new monoid structure non-isomorphic to \((\NN,+)\).

The purpose of stating this isomorphism as a theorem is solely to fix notation and emphasize that ``$+$ need not be imported as a primitive.'' The main mathematical content of this section consists of two other classes of results, aligned with the ``scan--projection readout'' interface:
\begin{itemize}
  \item \textbf{(Orbit/folding content)} The orbits generated by groupoid rewriting coincide with the value fibers, and there exists a unique transversal (Theorem~\ref{thm:zeckendorf-transversal}). This gives the rigorous formulation of ``folding = projection along value-preserving symmetry orbits onto the unique stable representative.''
  \item \textbf{(Pure digit-level content)} The operation can equivalently be expressed as ``componentwise superposition/convolution $\Rightarrow$ normalization fold'' (Corollary~\ref{cor:add-as-fold}), thereby converting the abstract \(\mathrm{Val}^{-1}\) definition into an implementable, auditable normalization rule; complexity bounds are given in Appendix~E$'$.
\end{itemize}
\end{remark}

\begin{theorem}[Pure digit-level implementation of Zeckendorf addition (linear time / finite state)]\label{thm:zeckendorf-add-fst}
Let $c,d\in X_\infty$ have only finitely many $1$'s, and let
\(
m:=\max\{k:\ c_k=1\text{ or }d_k=1\}
\)
be the effective resolution. Then there exists an algorithm that performs only local finite operations on the Zeckendorf digits (equivalently, a deterministic finite-state transducer / finite-delay sequential transducer) that computes the Zeckendorf digit output of $c\oplus d$ in time $O(m)$ directly from $(c_1,\dots,c_m)$ and $(d_1,\dots,d_m)$, without explicitly constructing the integers $\mathrm{Val}(c),\mathrm{Val}(d)$.
\end{theorem}

\begin{proof}
This is the specialization to addition of the standard result that ``normalization can be realized by a finite automaton'' for the Zeckendorf / golden ratio Ostrowski numeration system: addition can be viewed as first performing componentwise addition to obtain non-canonical digits over the alphabet $\{0,1,2\}$, then executing a value-preserving normalization (eliminating $2$'s and adjacent $11$'s) to obtain the unique Zeckendorf form. For Pisot bases (in particular the golden ratio), such normalization maps can be realized by finite automata / sequential transducers, yielding a linear-time algorithm (see \cite{Frougny1992NumbersAutomata,Frougny1999OnlineAddition}; for explicit efficient algorithms and implementation details for the Zeckendorf case, see \cite{AhlbachUsatineFrougnyPippenger2013}; the golden ratio special case of the Ostrowski three-pass scan algorithm is also given in \cite{HieronymiTerry2018OstrowskiAddition}).
\end{proof}

\begin{remark}[On-line and non-parallelizability: implementation-side constraints of the temporal readout semantics]\label{rem:online-not-parallel}
In the semantics of ``scan--readout,'' if an operation rule can be implemented by an on-line transducer, it means that the readout can be executed as a unidirectional stream along time while maintaining a finite-memory state; this is consistent with the sliding block code / sequence-level operator perspective of Section~\ref{sec:folding}. On the other hand, although addition in the golden ratio base can be implemented on-line, it is in general not parallelizable (i.e., there is no addition circuit caliber that partitions the input into parallel blocks and completes in a constant number of rounds). In the context of this paper, this phenomenon can be interpreted as: \textbf{stable readout is finite-memory, yet it still carries cross-scale carry/normalization dependencies}; see \cite{Frougny1999OnlineAddition} for precise results and discussion.
\end{remark}
