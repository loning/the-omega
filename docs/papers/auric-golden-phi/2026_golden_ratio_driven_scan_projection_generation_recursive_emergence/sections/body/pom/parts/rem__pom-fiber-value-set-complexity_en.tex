\begin{remark}[Subexponential complexity of fiber cardinality value set: \texorpdfstring{$\exp(\Theta(\sqrt m))$}{exp(Theta(sqrt m))}]\label{rem:pom-fiber-value-set-complexity}
Following the notation in Definition~\ref{def:pom-top-fiber-spectrum}, denote:
\[
\mathcal{V}_m:=\{d_m(x):x\in X_m\}.
\]
By Theorem~\ref{thm:pom-fiber-indset-factorization}, for any $x\in X_m$ there exists a component length multiset $\{\ell_i\}_{i=1}^r$ such that:
\[
d_m(x)=\prod_{i=1}^r F_{\ell_i+2},
\qquad
\sum_{i=1}^r \ell_i\le k_{+}=\left\lceil\frac{m}{2}\right\rceil.
\]
Therefore, each value $d_m(x)$ is induced by at most one integer partition (given by $\{\ell_i\}$).
Let $p_{\mathrm{part}}(n)$ denote the number of partitions of integer $n$, then we obtain the upper bound:
\[
|\mathcal{V}_m|
\le
\sum_{L=0}^{k_{+}} p_{\mathrm{part}}(L)
\le
(k_{+}+1)\,p_{\mathrm{part}}(k_{+})
=\exp(O(\sqrt m)).
\]
\par
On the other hand, one can construct non-interfering reversible site component embeddings on candidate chains: for any partition
$\lambda\vdash \bigl\lfloor m/3\bigr\rfloor$, one can realize some $x\in X_m$ such that its induced component length multiset contains $\lambda$ (with remaining lengths absorbed by padding blocks without introducing additional interference), thereby obtaining at least $p_{\mathrm{part}}(\lfloor m/3\rfloor)$ distinct product values, thus:
\[
|\mathcal{V}_m|
\ge
p_{\mathrm{part}}\!\left(\Big\lfloor\frac{m}{3}\Big\rfloor\right)
=\exp(\Omega(\sqrt m)).
\]
In summary, the value set of fiber cardinalities is strictly subexponential on the exponential scale:
\[
|\mathcal{V}_m|=\exp(\Theta(\sqrt m)).
\]
This forms a structural contrast with the type space size $|X_m|=F_{m+2}=\exp(\Theta(m))$: the type space is exponentially large, while the fiber multiplicity value set is only subexponentially large.
\end{remark}
