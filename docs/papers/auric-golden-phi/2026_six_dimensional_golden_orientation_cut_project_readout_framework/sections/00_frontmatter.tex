\begin{abstract}
本文提出一套可审计的“切—投影—读出”形式体系，用以统一刻画三维可见结构的生成、相干叠加所对应的强度重构、以及时间箭头在观测协议层的定义。体系以六维超立方晶格（或其有限信息着色）为对象层本体，以三三分解的切—投影模型集为几何生成原语，并将观测者刻画为携带内部相位与分辨率核的读出算子。为避免有限深度读出产生的周期锁定，本文给出黄金分支取向与无理扫描的定量化条件，并在符号层引入圆周因子与二值符号化，将读出序列纳入 Sturmian/Fibonacci 类。进一步，定义 Zeckendorf 合法语言与规范化算子 $\Fold_m$，以其预像刻画不可见自由度（时间纤维），并以柱集后验测度的指数收缩率（熵率）给出“时间箭头”的协议化定义。文末给出一组可证伪的统计指纹与实验模板，覆盖 Fibonacci 回归尺度、核宽控制的干涉可见度曲线、以及读出核非局域性诱导的表观逆向相关上界。
\end{abstract}
