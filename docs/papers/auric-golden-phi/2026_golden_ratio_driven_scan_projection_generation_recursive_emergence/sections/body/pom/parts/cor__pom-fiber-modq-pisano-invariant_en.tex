\begin{corollary}[Pisano residue class invariant for path component lengths: finite-state reduction for arbitrary modulus]\label{cor:pom-fiber-modq-pisano-invariant}
Adopt the component decomposition from Theorem \ref{thm:pom-fiber-indset-factorization}: let
\(
\Gamma_x\simeq\bigsqcup_{i=1}^r P_{\ell_i}
\)
and
\(
d_m(x)=\prod_{i=1}^r F_{\ell_i+2}
\).
Let \(q\ge 2\) be an integer, and denote by
\[
\pi(q):=\min\{T\ge 1:\ F_{n+T}\equiv F_n\ (\bmod\ q)\ \ \forall n\ge 0\}
\]
the Pisano period of the Fibonacci sequence modulo \(q\).
Then \(d_m(x)\bmod q\) is determined solely by the residue class counting vector of component lengths: let
\[
N_a(x):=\#\{\,i:\ \ell_i\equiv a\ (\bmod\ \pi(q))\,\},
\qquad a\in \mathbb{Z}/\pi(q)\mathbb{Z},
\]
then there exists a finite map depending only on \(q\),
\(
\mathsf{Eval}_q:\mathbb{N}^{\pi(q)}\to \mathbb{Z}/q\mathbb{Z}
\),
such that
\[
\boxed{\;
d_m(x)\equiv \mathsf{Eval}_q\bigl((N_a(x))_{a\in\mathbb{Z}/\pi(q)\mathbb{Z}}\bigr)\quad(\bmod\ q).\;}
\]
In particular, the ``fiber multiplicity modulo \(q\)'' induces a class of finite-state homomorphic invariants on component length residue classes;
when \(q=2\), we have \(\pi(2)=3\) and this finite-state reduction automatically degenerates to the \((\bmod\ 3)\) criterion of Corollary \ref{cor:pom-fiber-parity-mod3}.
\end{corollary}
\begin{proof}
By definition of the Pisano period, \(F_n\bmod q\) depends only on \(n\bmod \pi(q)\).
Therefore each factor \(F_{\ell_i+2}\bmod q\) depends only on \(\ell_i+2\bmod \pi(q)\), equivalently only on \(\ell_i\bmod \pi(q)\) (the shift by \(+2\) is a bijection on \(\mathbb{Z}/\pi(q)\mathbb{Z}\)).
Grouping factors sharing the same residue class,
\(
d_m(x)=\prod_i F_{\ell_i+2}
\)
modulo \(q\) is determined solely by the occurrence counts \(N_a(x)\) of each residue class, yielding the stated finite map.
The last assertion follows directly from \(\pi(2)=3\) and the parity periodicity of Fibonacci numbers (\(F_n\equiv 0\ (\bmod 2)\iff n\equiv 0\ (\bmod 3)\)).
\end{proof}
