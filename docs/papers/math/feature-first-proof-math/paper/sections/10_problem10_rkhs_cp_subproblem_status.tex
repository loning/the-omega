\section{Problem 10: RKHS-Constrained CP Mode-$k$ Subproblem}

\textbf{Latest Reviewed Version:} Q10-R1 (PASS).

\textbf{Current Status.}
Closed in the stated scope: matrix-free PCG formulation, adjoint/operator derivation, SPD condition, and complexity accounting are consistent.

\textbf{Submission Record.}

\textbf{Q10-V1 (user submission).}
Main delivered claims:
\begin{itemize}
\item Rewrites
\[
\big[(Z\otimes K)^T SS^T (Z\otimes K)+\lambda(I_r\otimes K)\big]\,\mathrm{vec}(W)
=(I_r\otimes K)\,\mathrm{vec}(B)
\]
into operator form
\[
\mathcal A^*(\mathcal A_\Omega(W)) + \lambda K W = K B,
\quad \mathcal A(X)=KXZ^T,
\quad \mathcal A^*(Y)=KYZ.
\]
\item Gives matrix-free matvec
\[
X\mapsto K\,\mathcal M_\Omega(KXZ^T)\,Z + \lambda KX,
\]
implemented with observed set $\Omega$ only.
\item Proves SPD when $K\succ0$ and $\lambda>0$, justifying CG/PCG.
\item Proposes Kronecker preconditioner
\[
P=(G+\lambda I_r)\otimes K,
\quad G=\sum_{(i,j)\in\Omega} z_j z_j^T = Z^T D Z,
\]
and shows application of $P^{-1}$ via solves with $K$ and $(G+\lambda I_r)$ without forming any $N\times N$ matrix.
\end{itemize}

\textbf{Review Outcome (Q10-R1).}
PASS. No blocking correctness gap under the explicit assumptions ($K\succ0$ for strict SPD; for singular $K$, add nugget or solve on $\mathrm{range}(K)$).
