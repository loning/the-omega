# 2026_hpa_64to21_slack_product_trellis_wl 工作追踪

## 定位（这篇解决什么）

研究一个 $2^n\to F_{n+2}$ 的离散折叠—时间分解系统：微观态为 $\{0,1\}^n$，稳定态为不含相邻 $11$ 的语言。折叠采用“段首保留”的局部规则，时间推进采用“段尾剥离”。在此基础上构造 trellis 图与宏观带权动力学，并研究 WL（尤其是 WL-2）与相干配置、以及在宏观层的压缩计算。

> 备注：本篇的折叠规则是段首算子（局部 CA 风格），不是 Zeckendorf 截断折叠。

## 核心对象（最小集合）

- **折叠算子**：对 $x\in\{0,1\}^n$，输出在每段连续 1 中只保留段首的稳定态。
- **时间算子**：剥离段首后的剩余部分进入下一时刻；时间深度等于最长连续 1 段长度。
- **trellis 图**：把折叠边（微观到宏观）与时间边（微观到微观）编码到同一有向带类型图中。
- **宏观带权动力学**：在稳定态层上定义权重与转移，用于避免展开全部微观态。
- **WL/相干配置**：统计 WL-1/WL-2 的稳定化行为，并给出压缩 WL-2 的实现与对照。
