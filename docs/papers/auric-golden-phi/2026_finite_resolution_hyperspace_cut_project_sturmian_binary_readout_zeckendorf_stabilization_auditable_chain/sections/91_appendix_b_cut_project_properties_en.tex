\section{Appendix B: Several Properties of Cut-and-Project Scheme (Outline)}
\label{app:cut-project-properties}

\subsection{Density and Non-Periodicity (Typical Conditions)}

If the image of $\pi_{\parallel}(L)$ is dense in $E_{\parallel}$ and window $W$ is bounded, then $\Lambda(u)$ is a relatively dense and uniformly discrete Delone set. If furthermore $\pi_{\perp}(L)$ is also dense, then $\Lambda(u)$ is typically non-periodic.

\subsection{Phase Change and Patch Change}

As $u$ crosses certain equivalence classes of window boundary, the set of lattice points falling into/out of the window changes, inducing local patch changes in $\Lambda(u)$. This mechanism is the geometric source of ``observer difference.''
