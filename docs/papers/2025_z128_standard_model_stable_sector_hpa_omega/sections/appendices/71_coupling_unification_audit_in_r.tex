\subsection{Coupling unification as a bounded matching-layer audit in the $r$ coordinate}
\label{app:coupling_unification_audit_in_r}

This appendix records a minimal, fully explicit \MatchTag{} audit for \emph{coupling unification} (U2) in the resolution coordinate $r$ (Appendix~\ref{app:running_couplings_resolution_flow}).
It does not assert gauge-group unification (U1) as a theorem-level claim; it treats unification as a matching-layer question whose outcome depends on scheme and threshold conventions (Appendix~\ref{app:renormalization_dictionary_and_boundaries}; Appendix~\ref{app:unification_branching_counterfactual_audit}).

\subsubsection{Setup: anchor values at \texorpdfstring{$\mu_Z$}{muZ}}
\paragraph{Electroweak anchor (closed).}
At the $Z$ scale, the paper fixes the matching normalization
\[
\alpha_w^{-1}(\mu_Z)=3\pi^2,\qquad
\alpha_Y^{-1}(\mu_Z)=W_Y(K^\ast(\mu_Z))\,\pi^2
\]
(Definition~\ref{def:ew_volumes} and Theorem~\ref{thm:weinberg_angle}).
The selected protocol state $(m^\ast(\mu_Z),n^\ast(\mu_Z),K^\ast(\mu_Z))$ used by the paper is recorded in \path{sections/generated/protocol_state_selected.tex}, and the corresponding electroweak kernel-family sweep table reports the implied $W_Y$ (Appendix~\ref{app:generated_tables}).
We take $r=0$ at $\mu=\mu_Z$.

\paragraph{Strong-coupling anchor (bounded family).}
\MatchTag The strong coupling at $\mu_Z$ is not closed from the tick-only folding core in this manuscript.
To keep look-elsewhere freedom explicit, we treat the inverse strong coupling as a bounded discrete family
\begin{equation}
\label{eq:alpha3_pi2_family}
\alpha_3^{-1}(\mu_Z)\in\{n\pi^2:\ 1\le n\le 50\},
\end{equation}
to be used only for audit-facing comparisons under a deterministic tie-break rule.

\subsubsection{One-loop running in the \texorpdfstring{$r$}{r} coordinate (reference dictionary)}
\paragraph{Affine running of inverse couplings.}
\InterfaceTag Under the one-loop SM gauge running template (Appendix~\ref{app:running_couplings_resolution_flow}),
\[
\frac{\dd g_i}{\dd\log\mu}=\frac{b_i}{16\pi^2}g_i^3,\qquad (b_1,b_2,b_3)=\left(\frac{41}{6},-\frac{19}{6},-7\right),
\]
one obtains
\[
\frac{\dd\alpha_i^{-1}}{\dd\log\mu}=-\frac{b_i}{2\pi}.
\]
Since $\dd/\dd r=(\log\varphi)\,\dd/\dd\log\mu$, the $r$-flow is
\begin{equation}
\label{eq:alpha_inv_affine_in_r}
\alpha_i^{-1}(r)=\alpha_i^{-1}(0)-\frac{b_i\log\varphi}{2\pi}\,r.
\end{equation}

\paragraph{Pairwise intersection points.}
For $i\ne j$, define the (formal) intersection location
\begin{equation}
\label{eq:r_intersection_ij}
r_{ij}:=\frac{2\pi}{(b_i-b_j)\log\varphi}\left(\alpha_i^{-1}(0)-\alpha_j^{-1}(0)\right),
\end{equation}
whenever $b_i\ne b_j$.
At one loop, exact unification would require $r_{12}=r_{13}=r_{23}$ under a shared scheme/threshold convention.

\subsubsection{A bounded audit: does any candidate family yield near-coincident intersections?}
\paragraph{Audit objective and tie-break.}
\AuditTag For each candidate $n$ in \eqref{eq:alpha3_pi2_family}, compute the three intersection points $r_{12},r_{13}(n),r_{23}(n)$ using \eqref{eq:r_intersection_ij}.
Define the mismatch score
\[
E_\infty(n):=\max\{|r_{12}-r_{13}(n)|,\ |r_{12}-r_{23}(n)|,\ |r_{13}(n)-r_{23}(n)|\},
\]
and select the CAP-style audit winner by lexicographic minimization of $(E_\infty,n)$.

\paragraph{Scope note.}
\AuditTag This module is a matching-layer audit.
It does not claim that one-loop running is sufficient, nor that threshold corrections are negligible.
Its purpose is to make the unification question explicit, bounded, and reproducible within a declared family, so that future extensions (threshold registries, higher-loop terms) can be added without changing the layer semantics.

\paragraph{Audit objective.}
\AuditTag For each scheme and each discrete anchor $\alpha_3^{-1}(\mu_Z)=n\pi^2$ in \eqref{eq:alpha3_pi2_family},
we compute the one-loop piecewise-linear running of $\alpha_i^{-1}(r)$ under the scheme's declared decoupling rules and minimize the maximum pairwise mismatch
$
E_\infty(r)=\max_{i<j}|\alpha_i^{-1}(r)-\alpha_j^{-1}(r)|
$
over a bounded search window in $r$ with a fixed grid step.
We select the winner by lexicographic minimization of $(E_\infty,n)$ within each scheme and report the best $r_\star$ where the minimum is achieved.

\subsubsection{Threshold correlation modes (structured look-elsewhere control; audit)}
\label{subsec:coupling_unification_threshold_corr_modes}
\AuditTag The independent threshold-location perturbation family used in the two-loop audit makes uncertainty explicit but can overstate freedom by allowing each threshold to move independently.
To make the look-elsewhere budget structured, we also register a small correlated mode family in which all threshold shifts are determined by a single signed amplitude $a$ and a mode ID (e.g.\ all-shift, heavy-quarks-only, top-only).
This produces an auditable envelope with strictly fewer degrees of freedom.

\subsubsection{Two-loop running and bounded threshold-location uncertainty (audit)}
\label{subsec:coupling_unification_two_loop_audit}
\paragraph{Two-loop dictionary (gauge sector only).}
\MatchTag Beyond one loop, the gauge running depends on additional scheme-dependent terms and, in the full SM, on Yukawa and scalar couplings.
For an audit-facing extension, we use the standard two-loop gauge--gauge dictionary coefficients as a declared matching-layer input, and keep the family bounded and reproducible.
Concretely, we use the conventional two-loop form (in the paper's $Q=T_3+Y$ normalization)
\[
\frac{\dd \alpha_i^{-1}}{\dd\log\mu}
=-\frac{b_i}{2\pi}\ -\ \frac{1}{8\pi^2}\sum_{j} b_{ij}\,\alpha_j\ +\ \cdots,
\]
where the ellipsis stands for Yukawa/scalar contributions and higher loops.
In the $r$ coordinate, $\dd/\dd r=(\log\varphi)\,\dd/\dd\log\mu$ (Appendix~\ref{app:running_couplings_resolution_flow}).

\paragraph{Bounded audit with threshold uncertainty band.}
\AuditTag We reuse the named-threshold registry above and add a bounded threshold-location perturbation family around the discrete anchor depths:
for each of the threshold labels $(H,t,b,c,s)$ we shift the registered location by $\Delta r\in\{-0.25,0,0.25\}$ and re-minimize the mismatch score
$
E_\infty(r)=\max_{i<j}|\alpha_i^{-1}(r)-\alpha_j^{-1}(r)|
$
over the same bounded search window in $r$.
Within each scheme, we first select the discrete strong-coupling anchor $n$ at the central thresholds by lexicographic minimization of $(\min_r E_\infty(r),n)$, then report the resulting bounded band across the perturbation family.
