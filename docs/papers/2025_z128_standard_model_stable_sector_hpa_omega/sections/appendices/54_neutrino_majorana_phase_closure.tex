\section{Majorana phase closure (bounded family; audit)}
\label{app:neutrino_majorana_phase_closure}

This appendix records an explicit bounded candidate-family closure for the two Majorana phases.
As emphasized in Section~\ref{sec:pmns_neutrino_closure}, oscillation probabilities depend on the Dirac phase but are insensitive to Majorana phases; therefore a phase rule must be supplied at the interface layer if one wants a deterministic $m_{\beta\beta}$ prediction.

\paragraph{Inputs.}
\AuditTag We use:
\begin{itemize}
\item the globally selected neutrino mass-mechanism candidate from the registry in Appendix~\ref{app:neutrino_mass_mechanism_candidates} (generated by \texttt{scripts/exp\_neutrino\_mass\_mechanisms.py});
\item the closed PMNS angles (hence the e-row phases in PDG convention);
\item the external audit upper bound on $m_{\beta\beta}$ (0$\nu\beta\beta$) recorded in Appendix~\ref{app:neutrino_external_audit_channels}.
\end{itemize}

\paragraph{Bounded candidate family and CAP rule.}
\AuditTag We restrict
\[
\alpha_{21}=\frac{k_{21}\pi}{d_{21}},\qquad
\alpha_{31}=\frac{k_{31}\pi}{d_{31}},
\qquad d_{21},d_{31}\in\{1,2,4,8\},\quad
k_{21}\in\{0,\dots,2d_{21}-1\},\ k_{31}\in\{0,\dots,2d_{31}-1\}.
\]
For a fixed spectrum $(m_1,m_2,m_3)$ and closed PMNS row $(U_{e1},U_{e2},U_{e3})$, define
\[
m_{\beta\beta}(\alpha_{21},\alpha_{31})
\;:=\;
\Bigl|\,
U_{e1}^2 m_1
\;+\;
U_{e2}^2 m_2 e^{i\alpha_{21}}
\;+\;
U_{e3}^2 m_3 e^{i\alpha_{31}}
\,\Bigr|.
\]
The CAP rule is:
\begin{itemize}
\item feasibility filter: $m_{\beta\beta}(\alpha_{21},\alpha_{31})\le m_{\beta\beta}^{\mathrm{(bound)}}$;
\item selection key: minimize the phase complexity (smallest denominators; then smallest distance to $0$ mod $2\pi$; then lexicographic tie-break).
\end{itemize}
