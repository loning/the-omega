\section{六维超晶格对象层与三三分解}

\subsection{六维晶格与有限信息着色（D2.1）}

令本体晶格为
\[
\mathcal{L}=\ZZ^{6}\subset \RR^{6}.
\]
为允许每个格点携带有限内部信息，引入有限字母表 $\mathcal{A}$，定义着色（或标记）
\[
\sigma:\mathcal{L}\to \mathcal{A}.
\]
本文不预设 $\sigma$ 的动力学形式；$\sigma$ 仅作为对象层数据，供读出算子调用。

\subsection{三三分解与投影算子（D2.2）}

固定正交直和分解
\[
\RR^{6}=E_{\parallel}\oplus E_{\perp},\qquad \dim E_{\parallel}=3,\ \dim E_{\perp}=3,
\]
并记正交投影
\[
\pi_{\parallel}:\RR^{6}\to E_{\parallel},\qquad
\pi_{\perp}:\RR^{6}\to E_{\perp}.
\]
此处 $E_{\parallel}$ 被用作三维几何承载空间，$E_{\perp}$ 被用作内部空间。该区分属于结构定义（D），其物理语义属于（I）层。

\subsection{无重叠与一般位置条件（H2.3）}

为避免不同格点在 $\pi_{\parallel}$ 下产生系统性重合，需要一般位置条件。本文采用如下可替换假设：
\begin{itemize}
  \item \textbf{（H2.3-a）}窗口边界具有零测度；
  \item \textbf{（H2.3-b）}对几乎处处内部相位 $u$，满足窗口约束的格点集合上 $\pi_{\parallel}$ 近乎处处单射。
\end{itemize}
相关充分条件与后续统计性质见附录 \ref{app:general-position}。
