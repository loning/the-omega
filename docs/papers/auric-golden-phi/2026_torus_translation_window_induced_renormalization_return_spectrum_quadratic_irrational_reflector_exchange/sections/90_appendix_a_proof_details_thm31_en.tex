\section{Appendix A: Refined Proof of Theorem \ref{thm:three-value}: Return-Tower Decomposition and Three-Value Bound}
\label{app:proof-thm31}

This appendix provides a completely reproducible proof chain for Theorem \ref{thm:three-value}.

\subsection*{A.1 Interval Property of Return Domains}

For any $n\ge 1$, define
\[
E_n=\{x\in E:\ r_E(x)=n\}.
\]
Since $T_\theta$ is an equidistant homeomorphism and $E$ is an interval, each $E_n$ is at most a single interval. The proof strategy is: if $x<y$ and both have first-return time $n$, then by monotonicity and equidistance, for any $z\in(x,y)$ we can show that $T_\theta^k z\notin E$ for $1\le k<n$ and $T_\theta^n z\in E$, hence $z\in E_n$.

Therefore $r_E$ is a piecewise-constant function.

\subsection*{A.2 Restrictions on Possible Return Times}

Take $i\ge 0$ such that $\delta_i<b\le \delta_{i-1}$. This choice means that the $\bmod 1$ displacement $\delta_i$ of $q_i\theta$ is smaller than the window length, while the previous-level displacement $\delta_{i-1}$ is not smaller than the window length. By the optimality of continued-fraction approximation, we can show that return times can only take values in a finite set within $\{q_i, q_{i+1}-k q_i\}$, with the range of $k$ controlled by $a_{i+1}$.

\subsection*{A.3 Parameter $K$ and Three-Value Structure}

Define
\[
K=\max\{k\ge 0:\ k\delta_i+\delta_{i+1}<b\}.
\]
Comparing the position of $b$ relative to $k\delta_i+\delta_{i+1}$ determines whether a ``third tower height'' appears and the relative position of the corresponding return domain within $E$. Thus we can partition $E$ into at most three interval pieces with return times respectively $q_i$, $q_{i+1}-(K-1)q_i$, $q_{i+1}-Kq_i$ (order determined by parity and endpoint convention). Simultaneously, from $\delta_{i-1}=a_{i+1}\delta_i+\delta_{i+1}$ and $\delta_i<b\le\delta_{i-1}$ we derive $0\le K\le a_{i+1}-1$.

\subsection*{A.4 Additive Closure Relation}

From the denominator recurrence $q_{i+1}=a_{i+1}q_i+q_{i-1}$ and the three-value expression, we obtain: the values on the two sides and the middle value satisfy a linear relationship; under suitable rearrangement this reduces to ``the middle value equals the sum of the two side values''. This relation corresponds to the combinatorial structure of return-tower splicing.
