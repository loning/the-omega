\paragraph{Ribosome pausing: window-level proxy (codon-score average).}
As a lightweight window-level check (offline; not read-level Ribo-seq), we averaged published codon pause scores across the $k$-codon window immediately upstream of terminal stops in the human RefSeq candidate set.
Dataset size: $n=716$ (UAA=238, UAG=238, UGA=240); $k=10$.

\textbf{Correlations (Spearman).}
Pause$_{\mathrm{before}}$ vs $U_{\mathrm{before}}$: $\rho=-0.356$ ($p=$<$0.001$).
Pause$_{\mathrm{before}}$ vs $U_{\mathrm{after}}$: $\rho=0.102$ ($p=0.006$).
Pause$_{\mathrm{before}}$ vs $(U_{\mathrm{after}}-U_{\mathrm{before}})$: $\rho=0.300$ ($p=$<$0.001$).

\textbf{GC-controlled (partial Spearman).}
Pause$_{\mathrm{before}}$ vs $U_{\mathrm{before}}\mid\mathrm{GC}_{\mathrm{before}}$: $\rho=-0.366$ ($p=$<$0.001$).
Pause$_{\mathrm{before}}$ vs $(U_{\mathrm{after}}-U_{\mathrm{before}})\mid\mathrm{GC}_{\mathrm{before}}$: $\rho=0.300$ ($p=$<$0.001$).

\textbf{Stratified comparisons (proxy quantiles from candidate sets).}
High-$U_{\mathrm{after}}$ vs low-$U_{\mathrm{after}}$: $d=-0.06$ ($p=0.659$), means 1.073 vs 1.080.
Composition-matched high-$U_{\mathrm{after}}$ vs low-$U_{\mathrm{after}}$: $d=-0.03$ ($p=0.796$), means 1.074 vs 1.079.
High-$(U_{\mathrm{after}}-U_{\mathrm{before}})$ vs low: $d=0.95$ ($p=$<$0.001$), means 1.100 vs 1.001.

\textbf{Interpretation.} This proxy tests whether window-level pausing patterns are already implied by known slow/fast codons. It does not replace the planned read-level window pausing analysis from raw Ribo-seq coverage.
