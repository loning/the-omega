\section{Rewriting system details: termination and confluence}\label{app:rewrite-system}

This appendix records additional details for Proposition~\ref{prop:fold-termination-confluence}.
The main text already provides the lexicographic measure and the Newman's lemma closure argument; here we restate the key points in a self-contained form.

\subsection{A decreasing measure}\label{app:rewrite-measure}
Let $a\in\mathcal{D}$ and define
\[
A(a):=\sum_{k\ge 1} a_k,\qquad
B(a):=\sum_{k\ge 1} k\,a_k,\qquad
C(a):=a_2,
\qquad
\mu(a):=(A(a),B(a),C(a)).
\]
Each rewrite rule in Definition~\ref{def:fold-rewrite-rules} strictly decreases $\mu(a)$ in lexicographic order; hence infinite rewrite sequences are impossible.

\subsection{Local confluence and Zeckendorf uniqueness}\label{app:rewrite-local-confluence}
Every rewrite preserves $\mathrm{Val}(a)$ by Fibonacci identities.
Any irreducible configuration is a $0$--$1$ sequence with no adjacent $11$, hence corresponds to a Zeckendorf digit sequence.
Since the Zeckendorf representation is unique \cite{Zeckendorf1972}, two irreducible configurations with the same value must coincide.
This yields local confluence and therefore global confluence under strong termination.
