\section{周期重整化与黄金固定点：自诱导闭包与 Fibonacci 尺度}

\subsection{最终周期连分数与周期轨道}

若 $\theta$ 的连分数最终周期，则尾部更新算子 $\mathcal{R}$ 在某个阶段进入周期指令，从而诱导参数在有限 Möbius 变换字下形成周期轨道。等价地，存在双曲矩阵 $A\in \mathrm{SL}_2(\ZZ)$ 的吸引不动点为 $\theta$，周期矩阵的谱半径给出指数尺度常数。

\subsection{黄金参数的不动点}

设 $\varphi=(1+\sqrt 5)/2$，取
\[
\alpha=\varphi^{-1}=[0;1,1,1,\dots].
\]
则对任意尾部更新，连分数尾部保持不变，从而 $\alpha$ 为最短周期不动点。对应的最短周期矩阵的主特征值为 $\varphi$，给出尺度自相似常数。

\subsection{规范嵌套窗口链与自诱导闭包}

定义嵌套窗口
\[
E_n=(0,b_n),\qquad b_n=\delta_{n-1}(\alpha).
\]
由于部分商恒为 $1$，每层两值退化参数 $c$ 唯一确定，诱导保持在旋转类并在缩放后回到同一参数。

\begin{theorem}[黄金自诱导闭包]\label{thm:golden-self-induced}
对 $\theta=\alpha$ 与窗口链 $\{E_n\}$，存在线性共轭 $\phi_n:E_n\to\TT$ 使
\[
\phi_n\circ T_{\alpha,E_n}=T_\alpha\circ \phi_n
\]
在 $m_{E_n}$-几乎处处意义下成立。
\end{theorem}

\begin{proof}
由定理 \ref{thm:tail}，诱导旋转数尾部更新保持 $\alpha$ 不变；结合命题 \ref{prop:induced-step} 得到每层诱导系统与原旋转系统测度共轭。证毕。
\end{proof}

\subsection{平均首返时间}

取窗口测度 $m(E)=\alpha=\varphi^{-1}$，则由 Kac 公式
\[
\mathbb{E}_{m_E}[r_E]=\varphi.
\]
该结论将黄金尺度常数解释为平均回归长度。
