
\section{时空结构对象：折叠、空间关系与时间关系}

本节给出本文的统一对象与同构概念。其核心是把“观测折叠”与“时空关系”作为数据层显式写出，再把同构问题归约为带颜色图同构。

\subsection{时空结构对象}

\begin{definition}[时空结构对象]\label{def:spacetime_object}
一个时空结构对象 $\mathsf S$ 由以下数据构成：
\begin{itemize}
  \item 一个有限集合 $X$（微观态集合）与一个有限集合 $Z$（宏观观测集合）；
  \item 一个折叠映射 $f:X\to Z$；
  \item 一个空间关系 $R_{\mathrm{space}}\subseteq X\times X$（可为无向/有向；可带类型）；
  \item 一个时间关系 $R_{\mathrm{time}}\subseteq X\times X$（用于描述纤维内的可检索自由度、或可演化/可回溯结构）；
  \item 可选的颜色/标签：例如要求 $Z$ 端点携带唯一颜色，以强制同构在 $Z$ 上逐点固定。
\end{itemize}
我们把 $\mathsf S$ 记为
$$
\mathsf S=(X,Z; f, R_{\mathrm{space}}, R_{\mathrm{time}}).
$$
\end{definition}

\begin{remark}
定义 \ref{def:spacetime_object} 并不要求 $R_{\mathrm{time}}$ 是函数图（如 $x\mapsto \Tail(x)$），也不要求 $R_{\mathrm{space}}$ 与 $R_{\mathrm{time}}$ 彼此独立。本文在第 \ref{sec:experiments} 节采用 Zeckendorf 截断诱导的一个典型时间关系作为规范实例。
\end{remark}

\subsection{同构：保持时空语义与折叠相容}

\begin{definition}[时空结构同构]\label{def:spacetime_iso}
给定两个对象
$$
\mathsf S=(X,Z; f, R_{\mathrm{space}}, R_{\mathrm{time}}),\qquad
\mathsf S'=(X',Z'; f', R'_{\mathrm{space}}, R'_{\mathrm{time}}),
$$
一个同构由双射 $(\pi_X,\pi_Z)$ 构成，其中 $\pi_X:X\to X'$、$\pi_Z:Z\to Z'$，满足：
\begin{enumerate}
  \item \textbf{折叠相容：}对一切 $x\in X$，有 $f'(\pi_X(x))=\pi_Z(f(x))$；
  \item \textbf{空间保持：}$(x,x')\in R_{\mathrm{space}} \iff (\pi_X(x),\pi_X(x'))\in R'_{\mathrm{space}}$；
  \item \textbf{时间保持：}$(x,x')\in R_{\mathrm{time}} \iff (\pi_X(x),\pi_X(x'))\in R'_{\mathrm{time}}$；
  \item \textbf{颜色保持（如有）：}若 $Z$ 端点带唯一颜色，则 $\pi_Z$ 被强制为恒等。
\end{enumerate}
\end{definition}

本文后续把该同构问题翻译为一个带颜色图同构问题，从而接入 \WL{} 与相干配置。
