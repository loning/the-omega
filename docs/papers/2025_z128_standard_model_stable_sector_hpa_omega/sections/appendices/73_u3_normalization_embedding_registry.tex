\subsection{U3 normalization and embedding registry (hypercharge and unification conventions; audit)}
\label{app:u3_normalization_embedding_registry}

This appendix records a bounded registry of normalization and embedding conventions (U3) that mediate between the paper's $Q=T_3+Y$ choice and the conventions typically used in unification benchmarks.
The purpose is not to select a convention by fit; it is to make the convention-dependence auditable and to pin down what changes (and what does not) when one switches conventions.

\subsubsection{Normalization conventions for the abelian factor}
\paragraph{Paper convention (fixed).}
\InterfaceTag The paper uses $Q=T_3+Y$ and writes the covariant derivative in the form
$D_\mu=\partial_\mu-\iu g_1 Y B_\mu-\iu g_2 W_\mu^a\tau^a-\iu g_3 G_\mu^A T^A$
(Appendix~\ref{app:running_couplings_resolution_flow}).
At $\mu_Z$ the electroweak anchors are fixed as
$\alpha_w^{-1}(\mu_Z)=3\pi^2$ and $\alpha_Y^{-1}(\mu_Z)=W_Y(K^\ast(\mu_Z))\,\pi^2$ (Definition~\ref{def:ew_volumes} and Theorem~\ref{thm:weinberg_angle}).
The selected protocol state $(m^\ast(\mu_Z),n^\ast(\mu_Z),K^\ast(\mu_Z))$ is recorded as a generated artifact \path{sections/generated/protocol_state_selected.tex}.

\paragraph{Rescaling registry.}
\AuditTag Any rescaling $g_1\mapsto c\,g_1$ can be absorbed into a rescaling of the hypercharge generator $Y\mapsto Y/c$ and therefore corresponds to a convention change unless additional embedding structure is supplied.
To make this explicit, we register a bounded set of rescaling factors
\[
c^2\in\left\{1,\ \frac{5}{3}\right\},
\]
where $c^2=5/3$ is the canonical SU(5)-normalized choice used in many GUT references.
Under this change, $\alpha_1=c^2\alpha_Y$ and therefore $\alpha_1^{-1}=\alpha_Y^{-1}/c^2$.

\subsubsection{Embedding conventions (benchmark-only dictionary)}
\paragraph{Benchmark embedding note.}
\AuditTag In a simple-group embedding, the normalization of the abelian generator is fixed by the embedding (up to discrete choices), which is why a factor like $5/3$ is not a free knob in that context.
In this manuscript, U1 is not a theorem-level claim; therefore U3 is tracked as a bounded registry rather than as a derived identity.

\subsubsection{Interface to the U2 coupling-unification audits}
\AuditTag The U2 audit in Appendix~\ref{app:coupling_unification_audit_in_r} uses $\alpha_Y$ as the abelian input consistent with the paper's fixed convention.
If one wishes to compare to benchmarks that report $\alpha_1$ in SU(5)-normalized units, the conversion above must be applied before comparing intersection locations or mismatch scores.
This appendix therefore serves as the convention ledger for interpreting U2 audit outputs across normalization choices, without changing the tick+CAP closure chain.
