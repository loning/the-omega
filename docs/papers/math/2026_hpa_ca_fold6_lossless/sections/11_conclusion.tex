
\section{结论与未解决问题}

\subsection{结论}

\begin{enumerate}
  \item $m=6$ 的 $\Fold_6$ 是一个完全显式的 $64\to 21$ 折叠核：稳定态集合 $X_6$ 大小为 $21$，并存在刚性的 $21=18\oplus 3$ 分裂。
  \item $\Fold_6$ 的多对一纤维结构可被完全分类：原像大小只可能为 $2/3/4$ 并满足固定直方图 $(8,4,9)$；边界三态原像对可给出明确数值。
  \item 通过把 uplift 作为时间边标签记录，HPA-CA 在“空间层（$21$ 态）+ 时间边层（uplift）”意义下无损可逆。
  \item 若观察者不直接读取 uplift，则逆向可逆性退化为一致性搜索；其复杂度可作为“观察者时间尺度”的纯数学定义。
  \item 数值实验显示：仅靠该折叠核与两相分块，系统可产生跨初态的分形纹理、稳定密度平台与近幂律谱特征。
\end{enumerate}

\subsection{未解决问题（推进方向）}

以下问题是下一阶段的关键数学推进方向（按优先级排序）：
\begin{enumerate}
  \item \textbf{全局逆向重建复杂度的理论上界。} 已知单块分支 $\le 4$，但全局受重叠约束耦合。需要证明：对长度 $L$ 的链，一步逆向重建在某类规范算法下是否存在亚指数/准多项式上界，或给出反例。
  \item \textbf{不变测度与遍历性。} 刻画 HPA-CA 在随机初态下收敛的统计稳态：是否存在唯一不变测度？是否对初态分布具有吸引性（universality）？
  \item \textbf{分形维数与谱指数的解析来源。} 实验显示盒维数 $D\approx 1.81$ 稳定。需要建立从 $\Fold_6$ 的有限纤维图/接口规则到 $D$ 的解析估计（至少给出上下界或可计算近似）。
  \item \textbf{$m\to m+1$ 的递归与 uplift 层化。} 将 HPA-CA 的两相分块动力学推广到一般 $m$，并研究 uplift 字母表与纤维结构如何随 $m$ 生长。
  \item \textbf{计算通用性（图灵完备性）。} 需要严格证明或给出可计算嵌入（例如构造滑翔子与逻辑门，或与已知通用 CA 的编译关系）。
  \item \textbf{与图同构/对称破缺的对应。} 将逆向重建形式化为某类有界度约束满足/同构判别问题，并证明其复杂度与群作用结构之间的关系。
\end{enumerate}
