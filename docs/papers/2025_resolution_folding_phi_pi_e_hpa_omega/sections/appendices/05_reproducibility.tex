
\section{Reproducibility notes}
\label{app:reproducibility}

This paper includes minimal, auditable scripts that reproduce the finite combinatorics and the folding-map statistics.
All scripts are standard-library Python and live under:
\[
\texttt{docs/papers/2025\_resolution\_folding\_phi\_pi\_e\_hpa\_omega/scripts/}.
\]

\subsection{What is reproduced}
The scripts reproduce:
\begin{itemize}
\item enumeration of $X_6$ and verification $|X_6|=21$;
\item Hamming-weight distribution of $X_6$;
\item the $18\oplus 3$ cyclic/boundary split;
\item computation of $\mathrm{Fold}_6(N)$ for $N=0,\dots,63$ and preimage-size statistics;
\item generation of a complete Fold\_6 table (Appendix~\ref{app:fold6_table}) listing $w\in X_6$, $V(w)$, and $\mathrm{Fold}_6^{-1}(w)$.
\item generation of the Fold\_m mean-degeneracy scaling rows used in Table~\ref{tab:foldm_scaling}.
\end{itemize}

\subsection{Generated LaTeX fragments (optional)}
If desired, scripts can write small LaTeX fragments (table rows) into
\[
\texttt{docs/papers/2025\_resolution\_folding\_phi\_pi\_e\_hpa\_omega/sections/generated/}
\]
following the same pattern used elsewhere in the repository.

\paragraph{Scripts and fragments.}
In particular:
\begin{itemize}
\item \path{exp_fold6_stats.py} writes \path{fold6_degeneracy_rows.tex}. It also writes \path{fold6_full_table_rows.tex}.
\item \path{exp_foldm_scaling_table.py} writes \path{foldm_scaling_rows.tex}.
\end{itemize}
