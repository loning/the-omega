\section{Reproducible Verification Protocol (Abstract-Level Description)}

This section provides only structural description of the reproducible interface; concrete implementation can be done in any programming language.

\subsection{Cut-and-Project Point Set Generation}

\textbf{Input:} Projections $(\pi_{\parallel},\pi_{\perp})$, window $W$, phase $u$, truncation radius $R$.\\
\textbf{Output:} Point set $\Lambda(u)\cap B_R$ and patch statistics.

\textbf{Verification items:}
\begin{enumerate}
  \item Compare patch set differences for different $u$;
  \item Estimate patch frequencies and verify stability with respect to $u$ (boundary events at window edge need careful handling under suspicious conditions).
\end{enumerate}

\subsection{Torus Rotation and Binary Readout}

\textbf{Input:} $\alpha$ and initial phase $\theta_0$, partition $\mathcal{P}$.\\
\textbf{Output:} Mechanical word $w_t$; compute complexity $p(n)$ and verify $p(n)=n+1$.

\textbf{Periodic approximation:} Generate periodic sequences using continued fraction convergents $\alpha_k=p_k/q_k$, comparing finite-prefix statistics with convergent decay trends in error as function of $k$.

\subsection{Stabilization and Fiber Spectrum}

\textbf{Input:} $m$, window word $\omega_t^{(m)}$.\\
\textbf{Output:} $x_t=\mathrm{Fold}_m(\omega_t^{(m)})$; compute distribution of $\card{\mathcal{F}_m(x)}$; construct empirical transition kernel $P(\cdot\mid x)$.

\subsection{Entropy Rate Verification of Time Arrow}

On ergodic samples, estimate cylinder set measure (or equivalently compression rate/negative log-likelihood growth), fit its linear growth rate, and compare consistency with entropy rate estimates. This verification belongs to the protocol layer, independent of physical interpretation.
