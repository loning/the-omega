\section{递归地址化：新概念由旧概念读出序列生成}\label{sec:recursive-addressing}

\subsection{地址的复合生成}

设在层级 $L$ 已得到一族概念 $\mathcal{C}^{(L)}\subseteq \mathcal{F}_{m_L}$。对任意有限选择 $C_1,\dots,C_r\in \mathcal{C}^{(L)}$，其读出向量
\[
\mathbf{b}(x)=(\ind_{C_1}(x),\dots,\ind_{C_r}(x))\in\{0,1\}^r
\]
可作为下一层级概念的地址元件。通过对 $\mathbf{b}(x)$ 的窗口化、拼接与归一化，可定义新的地址集合 $A^{(L+1)}$。这实现了：\textbf{新概念地址来自旧概念读出数据}。

\subsection{Null 到投影的递归语义}

对任意候选地址 $a\in A^{(L+1)}$，定义新概念 $C_a^{(L+1)}$ 之前不进行赋值；一旦地址 $a$ 被选定，概念值即为二元投影 $\ind_{C_a^{(L+1)}}(x)$。从而层级递归满足：
\begin{itemize}
  \item “无地址 $\Rightarrow$ null（不定义）”；
  \item “有地址 $\Rightarrow$ 二元投影（$0/1$）”；
  \item “地址 $\Rightarrow$ 由旧层读出生成”。
\end{itemize}
该语义可与布尔代数闭包兼容，也可在算子代数层面以投影算子及其乘积实现（见附录 \ref{app:op-algebra}）。
