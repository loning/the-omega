\section{自指固定点原型：黄金存在态（语义层）}

为形式化“存在/不存在的叠加态”并与后续“现实固定点语义”保持同构，先给出一个低维原型。

取态域 $\mathcal{G}=\mathbb{P}^{1}(\RR_{\ge 0})\cong[0,\infty]$，用比值 $t=a/b$ 表示“存在/不存在权重比”。定义自指更新算子
\[
E(t)=1+\frac{1}{t}.
\]
自洽态定义为固定点 $t=E(t)$，从而
\[
t=1+\frac{1}{t}\iff t^2-t-1=0\iff t=\varph.
\]
后文将以完全同构的方式把“对象态固定点”提升为“集合态固定点”：对象从 $t$ 升级为 $S\subseteq Y_m$，更新从 $E$ 升级为 $\Psi=\Phi\circ U$。
