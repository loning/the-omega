\section{Appendix D: Key Points for the Sturmian-Complexity and Fibonacci-Substitution Frequency Closure}
\label{app:sturmian-pf}

\begin{enumerate}
  \item The Sturmian minimal complexity $p(n)=n+1$ follows from the two-interval partition for rotation coding and exchange-map structure: each length-$n$ factor corresponds to an interval on the phase circle, whose endpoints come from the ordered set $\{x_0+k\alpha\}$; the number of endpoints is $n+1$.
  \item For the Fibonacci substitution matrix $M$, the dominant eigenvalue $\varphi$ and its Perron eigenvector yield letter frequencies; frequency convergence for primitive substitutions follows from the Perron--Frobenius theorem.
  \item Unique ergodicity of the rotation system implies that symbol frequencies equal window measures; thus substitution frequencies and window measures coincide, yielding a closed loop.
\end{enumerate}
