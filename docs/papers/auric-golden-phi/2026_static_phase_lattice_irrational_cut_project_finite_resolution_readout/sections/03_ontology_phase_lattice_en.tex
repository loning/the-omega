\section{Ontological Layer: Six-Dimensional Integer Lattice Phase Backbone}

\subsection{Microscopic Index Lattice}

Let
\[
\Lambda := \ZZ^{6}\subset \RR^{6}
\]
be the six-dimensional hypercubic integer lattice. This paper views $\Lambda$ as the ``phase--index backbone'' for organizing microscopic degrees of freedom and computable address structures. This setup is not equivalent to ``empirical space is six-dimensional,'' but rather a discrete substrate used to construct protocol readout and observable projections.

\subsection{Static Global State}

At the abstract level, operator algebra language can be adopted: given a quasi-local operator algebra $\mathcal{A}$ and a unique normalized state $\omega_{\Omega}$. This state exists statically; empirically-understood ``evolution'' is not an ontological layer input, but is produced by the protocol layer's scan readout. To maintain auditability of this paper, in most subsequent constructions only the geometry and computable structure of $\Lambda$ are employed, without relying on specific microscopic implementation of $\omega_{\Omega}$.
