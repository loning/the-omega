\section{常数与算术骨架：\texorpdfstring{$\varph$、$\pi$、$e$}{phi, pi, e} 与素数的协议角色}

\subsection{\texorpdfstring{$\varph$}{phi}：自相似替换与 Perron--Frobenius 特征值}

$\varph$ 的出现具有两种等价刻画：
\begin{enumerate}
  \item 稳定类型计数的指数增长率 $h_{\mathrm{top}}=\log\varph$；
  \item Fibonacci 替换（如 $0\mapsto 01,1\mapsto 0$）的替换矩阵 $A=\begin{pmatrix}1&1\\1&0\end{pmatrix}$ 的主特征值。
\end{enumerate}
因此 $\varph$ 表征“语法稳定的自相似增长”，并决定黄金存在态的有效维数。

\subsection{\texorpdfstring{$\pi$}{pi}：闭合相位几何与周期轨道不变量}

$\pi$ 的作用不应被理解为与 $\varph$ 竞争的“另一种神秘常数”，而应被理解为闭合相位几何的度量规范化常数：当读出对象具有周期识别（例如 $U(1)$ 上的相位）或需要对周期轨道进行计数与正则化时，$\pi$ 作为圆周、群体积或轨道积分的度量单位不可避免地出现。
在本文的通道语言中，$\pi$ 通道对应“环接闭合”与“周期轨道可容许性”，其离散化表现为 $\card{X_m^{\mathrm{cyc}}}$ 的 Lucas 迹结构。

\subsection{\texorpdfstring{$e$}{e}：乘法权重到加法代价的唯一连续读出基}

在将乘法组合的权重解释为可加的“代价”或“阻抗”时，对数读出由结构唯一性确定，$e$ 因而成为该读出选择的规范化常数：
\[
C=-\log w,\qquad w=e^{-C}.
\]
当解析稳定性通过 $\zeta$ 函数、生成函数或转移算子谱半径刻画时，指数衰减与极点屏障进一步使 $e$ 成为“解析稳定域”的自然基底。

\subsection{素数：乘法生成元与谱组织骨架}

素数在该框架中的地位来自乘法骨架的生成性：任意正整数 $n$ 的分解
\[
n=\prod_{p} p^{v_p(n)}
\]
将乘法结构拆解为素数方向的独立计数。若将本体层的相位数据或权重数据定义为乘法同态（或其推广），则其全部信息由在素数上的取值决定。
在更高阶的谱组织中，素数还可作为一族可交换算子的索引（例如 Hecke 作用的标号），从而将“观测到的谱”组织为素数参数化的局部数据集合。此处素数的角色可概括为：内部自由度的最小生成标签。
