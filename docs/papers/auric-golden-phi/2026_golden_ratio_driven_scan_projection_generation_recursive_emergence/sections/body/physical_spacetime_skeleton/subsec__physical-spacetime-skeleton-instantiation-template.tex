\subsection{数学实例化模板：哪些对象代入后才可能产生“物理型时空”}\label{subsec:physical-spacetime-skeleton-instantiation-template}

到上一小节为止，本章已经把一条完整的解释链拉了出来：观察者作为状态纤维进入结构，事件—区域—覆盖给出最小的局域因果骨架，状态精化与残差展开给出时间投影，共同支撑与局部比较给出空间的最小形式，资源账本把这种前几何空间进一步推进为可比较的代价结构，而时间迹与 primitive 谱的交换又说明空间并非外加容器，而可以在某些实例化中由动力学读出。与此同时，局部可读而全局受阻的现象又为规范差与曲率候选留下了结构位置。然而，恰恰因为这一主线已经足够强，接下来就必须把一个边界说得更清楚：并不是任何数学对象一旦被代入这套统一骨架，就都能自动产生一种可被物理化理解的时空。若这一点不加区分，那么前面各小节得到的全部结论都将重新退化为松散类比。因此，本小节的任务不是再添加新的结构，而是明确：什么样的实例化才有资格进入物理型时空的解释层。

这里首先需要澄清实例化一词在本章中的含义。它不是把某个数学对象随意贴上像时间、像空间、像观察者的标签，也不是把逻辑语言机械翻译成另一个领域中的术语。所谓实例化，必须仍然保持小节 \ref{subsec:logic-expansion-chain-instantiation-interface} 已经确立的严格要求：统一上位逻辑中的公式、状态、更新、局部支撑、失败标签与读出接口，不是在新对象中找到差不多对应的影子，而是要在保持其结构角色的前提下，被实现为该对象中的真实操作。定义 \ref{def:logic-expansion-concrete-implementation-system}、定义 \ref{def:logic-expansion-instantiation-map} 与定义 \ref{def:logic-expansion-realization} 已经把这一点写成具体实现系统、实例化映射与实现条件的三层接口。换言之，一个数学对象若要成为本小节意义下的实例化，不是因为它看上去能讲出某种时空故事，而是因为它能够承载前文已经给出的 forcing 结构、局部性纪律、动态顺序、残差口径与谱—资源接口。没有这种保持性，代入就只是解释，而不是实现。

最先必须保持的，是语义层的保持。前文的全部讨论都不是围绕裸对象展开，而是围绕某状态在某局部背景中是否强迫某命题展开。因此，任何候选实例化若不能把状态、命题与 forcing 关系同时实现出来，就根本谈不上把统一上位逻辑落实到该对象上。这里被保持的不能只是结果值，而必须连同类型、证书接口与失败方式一起保持。定义 \ref{def:logic-expansion-realization} 中的类型保持、状态保持、forcing 保持与失败模式保持，正是这一步的最低门槛。若一个数学对象虽然能为某些公式分配数值，却无法区分对象层不存在、局部支撑不存在、协议失配返回 \(\mathsf{NULL}\)、证书不足导致未定这几类不同失败来源，那么它即使在形式上看似给出了一个解释，也不足以承载本章所需的物理化读法。因为本章中的时间、空间、延迟定解、局部可读与全局障碍，全都依赖于失败模式之间的结构区别；一旦这些区别在实例化中被压平，整条主线也就一起丢失了。

其次必须保持的，是时空可读性的最低结构，而这一点又可分为三个不可彼此替代的方面。第一，观察者纤维必须可定义。若候选对象只能给出一个全局状态空间，却无法在结构内部区分哪个局部信息边界上的状态，那么前面关于局部参考系、跨观察者比较与 shared forcing 的内容都将失去落点。第二，事件定位必须可定义。若对象中没有一种自然方式把状态锚定到何时何处发生的事件位置上，那么时间投影便只能退化为纯参数化演化，而无法与命题定位结合。第三，区域支撑与覆盖也必须可定义。若对象只有整体结构，没有局部片段、重叠关系与覆盖细化，那么空间就不可能被理解为共同支撑与局部可比较性的网络，而只能重新退化为一个整体的抽象对象。定义 \ref{def:logic-expansion-concrete-implementation-system} 中对 \(I^{\mathcal C},X^{\mathcal C},\iota^{\mathcal C},\lambda^{\mathcal C},\varrho^{\mathcal C}\) 的要求，以及定义 \ref{def:logic-expansion-realization} 中的时空保持，正是把这三项最低结构压成了实例化的正式入口。

第三个门槛，是因果与更新方式的保持。前文之所以能够把事件—区域系统读作最小时空骨架，关键并不只在于存在事件与区域，还在于状态更新与跨观察者通信必须服从因果相容性。也就是说，实例化中的动态不能是任意的状态变换，而必须能区分哪些变化是同一观察者纤维内部的信息精化，哪些变化是跨纤维的通信诱导，哪些变化违反了既定的先后秩序因而不应被允许。若一个数学对象只能提供静态结构，或者虽有演化却完全不带方向性、不可审计性与局部保持性，那么它或许可以作为一个代数模型，却还不能作为时空候选。因为在本章中，时间之所以能够从状态更新中涌现，不是因为有一个参数写在公式旁边，而是因为更新本身构成了由粗到细、由未定到定解、由隐藏残差到外置记录的顺序链。失去这种顺序纪律，时间投影便不再有根。定义 \ref{def:logic-expansion-realization} 中的动态保持，正是这一门槛的抽象化表达。

第四个门槛，是资源接口的保持。前几小节已经反复表明，在这套体系中最早自然出现的几何量不是长度，而是恢复预算、纤维体积、压缩损失、同步成本与最小在线延迟。因此，一个候选实例化若不能为这些量提供明确载体，就无法把前几小节的资源几何真正落实下来。这里真正需要的不是某个抽象复杂度指标，而是可以区分如下几类量的结构接口：哪些微态被投影到同一对象层读出上，纤维多重度如何分布，恢复这些被折叠差异需要多少额外侧信息，当前层无法消化的残差必须沿何种记录轴外置，以及这种外置所对应的最小在线步数是多少。定义 \ref{def:pom-space-time} 中的空间—时间代价、命题 \ref{prop:pom-injectivization-sideinfo-exact-entropy} 中的侧信息预算、命题 \ref{prop:pom-delay-min} 中的最小在线延迟，以及定义 \ref{def:pom-cost-functor} 中的资源预序，共同给出了这一门槛的可核对口径。若一个对象没有压缩—恢复这一双向结构，那么它即使能够表达局部可比，也无法表达近为何是资源上的近；而一旦这一层不能实例化，前面关于准度规、同步成本与时间—空间资源折算的读法便都只能停留在抽象层面。

第五个门槛，则是谱接口的保持。上一小节已经说明，时间—空间交换之所以成立，并不只是因为系统既有时间也有空间，而是因为时间侧有可一致记录的轨道迹、返回数或 trace 数据，空间侧有可识别的 primitive 原子谱，而两侧之间又存在通过 \(\zeta\) 封装与 Möbius/Witt 反演建立起来的正规对应。因此，一个候选实例化若没有足够稳定的时间侧统计，或者没有可分离的空间侧 primitive 结构，或者虽两者兼有却缺少把二者闭合到同一生成对象中的接口，那么它就还不能承载本章最强的那部分结论。命题 \ref{prop:time-space-commuting-diagram}、定义 \ref{def:pom-proj-prim}、定义 \ref{def:pom-atom-space-cost} 与定理 \ref{thm:pom-unified-closure} 已经把这条接口从时间迹、primitive 谱到统一闭环的层层条件全部给出。更直白地说，若时间只是一串步数，而空间只是一堆局部片段，二者之间没有代数可逆的桥，那么我们至多只能说这里有时间和空间的并列读法，还不能说这里有时间—空间交换。而本章真正有辨识度的部分，恰恰在于后一种更强的情形。

第六个门槛，是局部—全局层次的保持。前文之所以能够把局部截面、粘接唯一性、Čech 障碍与规范差联系起来，是因为实例化中不但要有局部对象，还要有重叠、限制、拉回与更高阶一致性这类结构。若一个候选对象只能给出局部片段，却没有局部如何沿重叠相互约束的机制，那么它虽可讨论局部可读，却永远无法产生局部可读而全局受阻的现象。相反，若对象中存在天然的覆盖、重叠、过渡与高阶复合，那么前文关于 \(\mathsf{NULL}\) 的深层来源、关于全局化失败的障碍解释、关于规范差与曲率候选的整套读法，才有真正的落脚点。命题 \ref{prop:null-as-local-section-obstruction}、定义 \ref{def:prefix-site-h2-gluing-obstruction}、命题 \ref{prop:null-as-h2-obstruction} 以及小节 \ref{subsec:pom-bc-gauge-anomaly-pressure} 中的 Beck--Chevalley 曲率链，共同说明物理型时空所要求的并不是一块平滑的全局对象，而恰恰是能够局部化，又可能无法平坦全局化的那类对象。

综合起来看，本章意义下的物理型实例化，其实并不是一个单一条件，而是一组逐层加严的接口要求。最弱的一层，只要求候选对象能够承载观察者纤维、事件定位、区域支撑与因果相容更新。满足这一层时，我们至多得到一个局域因果骨架，可以谈论最小意义上的观察者时空，但还谈不上更深的物理读法。更强的一层，还要求压缩、恢复、残差外置与在线延迟可定义。满足这一层时，资源几何开始出现，空间才不只是共同支撑，还进一步带上恢复难度与同步成本。再更强的一层，则要求时间迹与空间谱之间存在可审计的交换接口，并且局部对象的全局化成败可以由障碍类或异常签名控制。只有到了这一层，本章前面关于时间可读出空间、局部障碍可读作规范差、曲率作为全局不闭合的候选这些最强的结论，才真正有了实例化资格。由此看来，所谓物理型时空并不是一步到位的，而是一个由弱到强逐层收缩出来的层级概念。

这也说明，为什么不是任何数学对象都适合被放到这套框架中。一个纯静态的集合对象，哪怕可以被人为地赋予若干关系，只要没有可审计的更新纪律，就无法承载时间投影；一个纯全局的代数对象，哪怕具有丰富的不变量，只要不能给出局部覆盖与共同支撑，就无法承载空间的最小起源；一个只重结果、不保留失败模式的数值模型，哪怕拟合得很好，只要把 \(\mathsf{NULL}\)、未定与局部缺席压成同一种数值，就无法承载延迟观测与全局障碍；一个只保留时间序列而没有 primitive 原子分解的动力系统，也无法支撑时间—空间交换。反过来说，真正适合进入本章的对象，往往是那些同时具有局部化能力、动态可追踪性、失败模式分层、谱分解能力以及资源账本的结构。它们并不一定已经长成传统物理学里的流形、场或算符代数，但至少已经具备了朝这些方向收缩的接口。

因此，本小节真正想确立的并不是一张封闭的允许实例化列表，而是一条明确的判别原则：某个数学对象之所以有资格被解释为统一上位逻辑的物理型时空候选，不在于它与熟悉的物理语言有多少表面相似，而在于它是否同时保持了 forcing、局部性、因果性、失败结构、资源代价与谱接口这些前文已经建立的核心层。只有在这种保持下，前几小节的全部推理链，从观察者纤维到事件—区域骨架，从时间投影到空间共同支撑，从资源几何到时间—空间交换，再到局部—全局障碍，才会在该对象中重新闭合。也只有到这时，我们才能说：这里出现的已不只是一个抽象数学结构，而是一个真正具有物理型时空解释资格的实例化。

接下来，本章就可以进入最后的收束：既然前文的主线已经被抽出，而本小节又把适用这条主线的实例化边界说清，那么最后就需要把全章的结果明确分层，区分哪些已经是严格结构命题，哪些仍是有根据的猜想，哪些则构成可证伪的接口锚点。这就是下一小节要完成的工作。
