\section{附录 B：计数定理与证明要点}

\subsection{\texorpdfstring{$\card{X_m}=F_{m+2}$}{|X\_m| = F\_{m+2}}}

令 $a_m=\card{X_m}$。按最后一位分类：若 $w_m=0$，前缀任取 $X_{m-1}$；若 $w_m=1$，则 $w_{m-1}=0$，前缀对应 $X_{m-2}$。故
\[
a_m=a_{m-1}+a_{m-2},\quad a_1=2,\ a_2=3,
\]
解得 $a_m=F_{m+2}$。

\subsection{循环/边界分裂}

边界条件等价于 $w_1=w_m=1$。由禁止律得 $w_2=w_{m-1}=0$，剩余中间段长度 $m-4$ 的自由度等价于长度 $m-4$ 的线性可容许词计数，故
\[
\card{X_m^{\mathrm{bdry}}}=\card{X_{m-4}}=F_{m-2}.
\]
循环可容许集为补集，得
\[
\card{X_m^{\mathrm{cyc}}}=F_{m+2}-F_{m-2}=F_{m-1}+F_{m+1}.
\]
同时 $F_{m-1}+F_{m+1}$ 为 Lucas 数 $L_m$，并满足 $L_m=\Tr(A^m)$，其中 $A=\begin{pmatrix}1&1\\1&0\end{pmatrix}$。
