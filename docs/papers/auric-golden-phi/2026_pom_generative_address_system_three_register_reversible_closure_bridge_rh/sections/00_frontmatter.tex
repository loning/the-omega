\begin{abstract}
研究如何在不预置算术原语的条件下，以“可寻址读出”刻画对象存在，并将经典解析零点事件纳入可核验的形式语义。
本文提出投影本体数学（Projection Ontological Mathematics, POM）：以地址触发读出定义存在性，并以空值 $\NULL$ 表示读出不定义，约定 $\NULL\neq 0$；在最小公理体系 POMmin 下构造稳定语法与折叠归一化，从二元微态读出生成稳定地址空间。
在该地址空间上定义运算 $(\oplus,\otimes)$ 并证明其与 $(\NN,+,\times)$ 半环同构，从而得到加法与乘法的涌现；同时以素数寄存器外置折叠残差，构造无损提升与可逆回放，并建立信息账本恒等式。
在投影词（projection word, PW）证书系统的可判定片段内，证明正规形唯一与判等可判定；并在 unitary slice 约束下给出类型安全：任何满足 $\Re(s)\neq\tfrac12$ 的点不可寻址且读出为 $\NULL$。
在桥接假设 BridgeRH 成立时，导出条件主定理：BridgeRH 推出经典黎曼猜想；相应推论的完备性依赖桥接条件，离开 unitary slice 的径向自由度需额外寄存器（第四寄存器）方可证书化。
\end{abstract}
