\section{Reproducible numerics (in-repo)}
\label{sec:reproducible_numerics}

This repository follows an in-repo reproducibility discipline: numerical checks are generated by scripts committed alongside the manuscript, and the manuscript records the exact commands, parameters, and random seeds required to reproduce tables and figures.
This section states the reproducibility contract for CAP-II.

\subsection{Build instructions}
\label{subsec:build_instructions}

The paper is compiled from the project directory by:
\begin{center}
  \path{latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex}
\end{center}

\subsection{Determinism and randomness}
\label{subsec:determinism_randomness}

All numerical scripts used by this manuscript must:
\begin{itemize}
  \item take parameters only via explicit command-line flags (with defaults printed on start), and
  \item fix all pseudo-randomness by a recorded integer seed.
\end{itemize}
When randomness is not required, scripts should be deterministic by construction.

\subsection{Generated artifacts}
\label{subsec:generated_artifacts}

To keep the \LaTeX\ build deterministic and lightweight, scripts write \LaTeX\ fragments (typically table rows) under a dedicated directory (e.g.\ \path{sections/generated/}) which are then included by the paper.
The build remains valid even if generated artifacts are absent; in that case the manuscript should fall back to static tables or omit the corresponding figure.

\paragraph{End-to-end microscopic example: interaction graph $\rightarrow$ $\kappa(x)$ $\rightarrow$ coarse-grained lapse $\rightarrow$ WS recovery.}

\emph{(i)} a weighted interaction graph $G_{\mathrm{phys}}$ given by \texttt{data/demo\_chain\_edges.csv},
\emph{(ii)} a local clock-task family $G_x$ parameterized by nodes at radii in \texttt{data/demo\_chain\_nodes.csv} (each task requires interaction with a fixed reference node), and
\emph{(iii)} a shortest-path scheduler in which the compilation depth is the weighted path cost plus a unit local cost.
The induced lapse profile $N(x)=\kappa_0/\kappa(x)$ is compared against the corresponding normalized Schwarzschild target and against a WS-based recovery via linewidth calibration with stated relative error.
