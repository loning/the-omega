
\section{引言}

将“物理演化”视为离散规则在有限带宽下的稳定化过程，最小可检验的切入点之一，是寻找一个\textbf{完全显式、可枚举、可运行}的局部核：它既能执行压缩（投影到稳定态），又能通过某种方式保留全部信息，从而使得“时间”自然表现为信息的组织方式而非外加参数。

本文聚焦于窗口长度 $m=6$ 的最小模型：局部 $6$ 比特窗口共有 $2^6=64$ 个微观读出态；黄金均值（无相邻 $1$）文法筛选出 $21$ 个稳定态。该 $64\to 21$ 的落差迫使任何稳定化映射都必然多对一，但关键之处在于：在“Zeckendorf 归一化 + 窗口截断”这一选择下，多对一结构并非杂乱，而是\textbf{刚性}、\textbf{可分类}、并且携带一组离散 uplift 值（Fibonacci 高位权重）。这为“把丢失信息变成时间边标签”提供了天然接口。

本文的贡献可概括为三点。
\begin{enumerate}
  \item \textbf{最小折叠核的完整形式化。} 给出 $\Fold_6$、稳定态集合 $X_6$、窗口值标记 $V$ 与原像分类定理；明确 $21=18\oplus 3$ 的“环闭合（cyclic）/边界（boundary）”分裂及其边界原像对。
  \item \textbf{无损化机制（uplift 边标签）。} 将 $\Fold_6$ 的多对一信息亏损提升为显式边标签，从而得到“空间层 $21$ 态 + 时间层 uplift 边”的单一图式数据结构，并导出扩展态下的显式可逆性。
  \item \textbf{可运行实验与指标。} 提供可复现的 HPA-CA 原型与指标管线，展示分形纹理、稳定密度平台、近幂律谱与稳定盒维数，并给出“观察者时间 = 逆向搜索成本”的数学化定义，用于刻画仅观测稳定层时的时间尺度。
\end{enumerate}
