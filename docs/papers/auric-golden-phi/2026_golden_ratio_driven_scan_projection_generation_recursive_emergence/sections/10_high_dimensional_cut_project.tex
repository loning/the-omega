\section{高维切投影与 \texorpdfstring{$(e,\pi,\varphi)$}{(e, pi, varphi)} 的统一出现：纯数学表述}\label{sec:high-dimensional-cut-project}

本节仅作为背景引用点：cut-and-project/model set 框架说明 \(\varphi\) 可作为代数无理方向与膨胀因子出现，而 \((e,\pi)\) 来自紧阿贝尔群角色的指数形式与周期归一化。本文不在此复述相关结论与证明，参见 \cite{BaakeGrimmAperiodicOrder1,MeyerAlgebraicNumbers,QueffelecSubstitution}。

\subsection{三层口径}\label{subsec:three-layer-epi-phi}
\begin{itemize}
  \item \textbf{\(\varphi\) 层（几何/膨胀）}：在 Fibonacci 等代数无理方向下，\(\varphi\) 同时出现在投影斜率与自相似膨胀常数中。
  \item \textbf{\((e,\pi)\) 层（角色/倾斜）}：紧阿贝尔群（如 \(\TT^n\)）的角色为 \(\chi_k(x)=e^{2\pi i\langle k,x\rangle}\)，因此 \(e\) 与 \(\pi\) 由谱坐标归一化强制出现。
  \item \textbf{迭代层（时间复合）}：扫描/更新通过迭代形成动力学；当相空间含圆周/环面坐标时，周期归一化携带 \(2\pi\)。
\end{itemize}

\subsection{cut-and-project/model set（最小定义）}
取格子 \(\Lambda=\ZZ^d\subset\RR^d\) 与分解 \(\RR^d=E_{\parallel}\oplus E_{\perp}\)，给定窗集 \(W\subset E_{\perp}\)，定义
\[
\Sigma=\{\pi_{\parallel}(\lambda):\lambda\in\Lambda,\ \pi_{\perp}(\lambda)\in W\}.
\]
在正则窗条件（如 \(\mathrm{vol}(\partial W)=0\)）下的唯一遍历与补丁频率存在性见 \cite{BaakeGrimmAperiodicOrder1,MeyerAlgebraicNumbers}。

\subsection{二维 Fibonacci 例（坐标锚点）}\label{subsec:fib-model-set-e-pi-phi}
取 \(d=2\) 的 Fibonacci model set：\(\pi_{\parallel}(m,n)=m+n\varphi\)、\(\pi_{\perp}(m,n)=m+n\varphi'\)（\(\varphi'=1-\varphi\)），窗取 \(W=[0,1)\)。
窗指示函数 Fourier 系数含标准因子 \(\int_0^1 e^{-2\pi i\xi y}\,\dd y\)，因此 \((e,\pi)\) 在谱/频率接口中以不可消去的归一化出现（详见 \cite{BaakeGrimmAperiodicOrder1,MeyerAlgebraicNumbers}）。
