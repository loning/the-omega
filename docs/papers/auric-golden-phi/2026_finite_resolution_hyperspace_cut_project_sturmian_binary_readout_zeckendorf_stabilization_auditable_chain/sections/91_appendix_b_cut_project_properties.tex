\section{附录 B：切投影方案的若干性质（要点）}
\label{app:cut-project-properties}

\subsection{稠密性与非周期性（典型条件）}

若 $\pi_{\parallel}(L)$ 的像在 $E_{\parallel}$ 中稠密且窗口 $W$ 有界，则 $\Lambda(u)$ 为相对稠密且均匀离散的 Delone 集。若进一步 $\pi_{\perp}(L)$ 也稠密，则 $\Lambda(u)$ 典型非周期。

\subsection{相位变化与补丁变化}

当 $u$ 穿越窗口边界的某些等价类时，落入/落出窗口的晶格点集合发生改变，从而诱导 $\Lambda(u)$ 的局部补丁变化。该机制为“观察者差异”的几何来源。
