\begin{corollary}[Ihara--Chebotarev square-root level error criterion: necessary and sufficient characterization via the error exponent \texorpdfstring{$\Lambda(u)/\lambda_1(u)$}{Lambda/lambda1}]\label{cor:ihara-chebotarev-grh-criterion}
Using the notation of Theorem \ref{thm:ihara-chebotarev-exp}, let
\(
\lambda_1(u)=\rho(B(u))
\)
and
\(
\Lambda(u)=\max\{\lambda_\star(u),\eta(u)\}
\).
Then the following statements are equivalent:
\begin{enumerate}
  \item \textbf{(Square-root level error)}
  For each conjugacy class \(C\subseteq G\), as \(n\to\infty\),
  \[
  q_{n,C}(u)=\frac{|C|}{|G|}\cdot\frac{\lambda_1(u)^n}{n}
  +O\!\left(\frac{\lambda_1(u)^{n/2}}{n}\right),
  \]
  where the error term is uniform over \(C\) (the constant may depend on \(u\) and the underlying graph/kernel).
  \item \textbf{(Ihara--GRH/Ramanujan type spectral gap)}
  \[
  \Lambda(u)\le \lambda_1(u)^{1/2}.
  \]
\end{enumerate}
Thus, the Ihara--(G)RH/Ramanujan type spectral gap can be promoted to a necessary and sufficient criterion for the Chebotarev-stratified error exponent.
\end{corollary}
\begin{proof}[Proof sketch]
\((2)\Rightarrow(1)\) follows directly from Theorem \ref{thm:ihara-chebotarev-exp}.
\par
\((1)\Rightarrow(2)\) By varying \(C\), one uses representation-theoretic Fourier coefficients of the class function \(C\mapsto q_{n,C}(u)\) to isolate each irreducible representation via character orthogonality; this shows that the twisted component for each irreducible representation \(\rho\neq\mathbf 1\) satisfies the square-root level bound, and hence its spectral radius \(\rho(B_\rho(u))\) does not exceed \(\lambda_1(u)^{1/2}\), i.e., \(\eta(u)\le\lambda_1(u)^{1/2}\). Likewise, taking \(G\) to be the trivial group reduces to the untwisted prime-count case, so the square-root level error forces \(\lambda_\star(u)\le\lambda_1(u)^{1/2}\). Combining gives \(\Lambda(u)\le\lambda_1(u)^{1/2}\). \qedhere
\end{proof}
