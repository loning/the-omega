\begin{conclusion}[Reset event point process "bounded-remainder" clock: density \texorpdfstring{$\varphi^{-(m+2)}$}{phi^{-(m+2)}} and error \texorpdfstring{$O(1)$}{O(1)} strict linearization]\label{con:xi-terminal-reset-bounded-remainder-clock}
Let the reset event set \(\mathcal R_m\) be as in Definition \ref{def:terminal-reset-events}, and write its increasing enumeration as \(\mathcal R_m=\{r_1<r_2<\cdots\}\).
Then:
\begin{enumerate}
  \item \textbf{Return time binary spectrum:} For all \(n\ge 1\), the difference takes only two values
  \[
  r_{n+1}-r_n\in\{F_{m+3},F_{m+4}\}.
  \]
  \item \textbf{Sturmian difference word:} Let letters \(A:=F_{m+4}\), \(B:=F_{m+3}\); then the difference word over alphabet \(\{A,B\}\) is the Fibonacci substitution fixed point (Sturmian, slope \(\varphi^{-1}\)).
  \item \textbf{Density and strong uniform error bound:} The natural density exists and equals
  \[
  \lim_{N\to\infty}\frac{\#(\mathcal R_m\cap[0,N))}{N}=\varphi^{-(m+2)},
  \qquad
  \sup_{N\ge 1}\Bigl|\#(\mathcal R_m\cap[0,N))-\varphi^{-(m+2)}N\Bigr|\le 1.
  \]
  \item \textbf{Return time linearization:} There exists constant \(C_m<\infty\) such that
  \[
  \sup_{n\ge 1}\Bigl|\varphi^{-(m+2)}\,r_n-n\Bigr|\le C_m,
  \]
  so that the reset clock is strictly a cut-and-project point process in scale: the main frequency is anchored by \(\varphi^{-(m+2)}\), while the deviation does not diverge in \(n\).
\end{enumerate}
\end{conclusion}
\begin{proof}[Proof]
The first three items are in Theorem \ref{thm:terminal-reset-events-sturmian}.
Let \(A(N):=\#(\mathcal R_m\cap[0,N))\) and \(\delta:=\varphi^{-(m+2)}\), then \(|A(N)-\delta N|\le 1\) holds for all \(N\in\NN\).
For \(N=r_n\) we have \(A(r_n)=n-1\), so \(|(n-1)-\delta r_n|\le 1\), thus \(|n-\delta r_n|\le 2\), and we can take \(C_m=2\). Proof complete.
\end{proof}

\begin{conclusion}[Logarithmic-time algorithm for reset clock: computing \texorpdfstring{$r_n$}{rn} requires only Fibonacci substitution matrix]\label{con:xi-terminal-reset-clock-logtime}
Continue with the notation of Conclusion \ref{con:xi-terminal-reset-bounded-remainder-clock}, and write the difference word
\(
w=w_1w_2\cdots\in\{A,B\}^{\mathbb N}
\)
as the fixed point of the Fibonacci substitution
\(
\sigma(A)=AB,\ \sigma(B)=A
\)
starting with \(A\) (Theorem \ref{thm:terminal-reset-events-sturmian}).
For any \(L\ge 0\) define prefix counts
\[
c_A(L):=\#\{1\le t\le L:\ w_t=A\},\qquad
c_B(L):=L-c_A(L),
\]
and write \(A:=F_{m+4}\), \(B:=F_{m+3}\).
Then for all \(n\ge 1\) there is the strict prefix-sum expression
\[
r_n=r_1+A\,c_A(n-1)+B\,c_B(n-1).
\]
Moreover, the vector \((c_A(L),c_B(L))\) can be determined in \(O(\log L)\) time by fast exponentiation of the substitution matrix
\[
M:=\begin{pmatrix}1&1\\ 1&0\end{pmatrix}
\]
: for any \(k\ge 0\), the letter count of \(\sigma^k(A)\) equals \(M^k(1,0)^{\mathsf T}\), and its prefix count can be obtained by recursively decomposing via the concatenation identity
\(
\sigma^{k+1}(A)=\sigma^k(A)\sigma^{k-1}(A)
\).
Therefore, the reset time sequence \(\{r_n\}\) can be computed as a deterministic discrete clock in \(O(\log n)\) time, and this complexity is independent of \(m\).
\end{conclusion}
\begin{proof}[Proof]
By Theorem \ref{thm:terminal-reset-events-sturmian}, the difference word \(w\) is a Fibonacci substitution fixed point, satisfying the standard concatenation structure
\(
\sigma^{k+1}(A)=\sigma^k(A)\sigma^{k-1}(A)
\).
The definition of the substitution matrix \(M\) ensures: writing the count vector of the two letters in \(\sigma^k(A)\) as
\[
\mathbf c_k:=
\begin{pmatrix}
\#\{1\le t\le |\sigma^k(A)|:\ (\sigma^k(A))_t=A\}\\
\#\{1\le t\le |\sigma^k(A)|:\ (\sigma^k(A))_t=B\}
\end{pmatrix},
\]
then \(\mathbf c_{k+1}=M\mathbf c_k\) and \(\mathbf c_0=(1,0)^{\mathsf T}\), thus \(\mathbf c_k=M^k(1,0)^{\mathsf T}\).
For given \(L\), take minimal \(k\) such that \(|\sigma^k(A)|\ge L\), and split the prefix of length \(L\) into \(O(k)\) blocks along the above concatenation and accumulate letter counts, yielding \(c_A(L),c_B(L)\).
Since \(|\sigma^k(A)|\) grows at Fibonacci rate, \(k=O(\log L)\); meanwhile \(M^k\) can be obtained in \(O(\log k)\) \(2\times 2\) matrix multiplications via binary exponentiation.
Substituting \((c_A(n-1),c_B(n-1))\) into the prefix-sum expression yields \(r_n\). Proof complete.
\end{proof}

\begin{conclusion}[Computability of energy--length Newton support extreme slopes, and saturation density strictly \texorpdfstring{$1/2$}{1/2} for real-input kernel]\label{con:xi-terminal-newton-extreme-slopes-alpha-half}
For the joint primitive count \(p_{n,k}\) (length \(n\), energy \(k\)) Newton support, define extreme slopes
\[
\alpha_{\min}:=\inf\left\{\frac{k}{n}:p_{n,k}>0\right\},\qquad
\alpha_{\max}:=\sup\left\{\frac{k}{n}:p_{n,k}>0\right\}.
\]
Then \(\alpha_{\min},\alpha_{\max}\) are equivalent to the minimum/maximum mean energy densities of directed cycles, and can be found in polynomial time by a Karp-type mean-cycle algorithm:
\[
\alpha_{\min}=\min_{\gamma\ \mathrm{cycle}}\frac{\sum_{e\in\gamma}\kappa(e)}{|\gamma|},\qquad
\alpha_{\max}=\max_{\gamma\ \mathrm{cycle}}\frac{\sum_{e\in\gamma}\kappa(e)}{|\gamma|}.
\]
Meanwhile, for the endpoint saturation of pressure \(P(\theta)=\log\rho(B(e^\theta))\) we have
\(
\lim_{\theta\to\pm\infty}P'(\theta)=\alpha_{\max/\min}
\).
In the output potential weighting of the real-input \(40\)-state kernel, the extreme saturation density is
\[
\alpha_{\max}=\frac12,
\]
so that no cycle with mean energy density exceeding \(1/2\) exists; equivalently the joint primitive support satisfies the hard wedge domain constraint \(p_{n,k}>0\Rightarrow k\le n/2\).
\end{conclusion}
\begin{proof}[Proof]
Mean-cycle characterization and computability of extreme slopes are in Proposition \ref{prop:sync-newton-extreme-slopes}.
The real-input kernel's \(\alpha_{\max}=1/2\) is in Corollary \ref{cor:real-input-40-alpha-max}. Proof complete.
\end{proof}

\begin{conclusion}[Scalable estimation of primitive spectrum for intermediate weights \texorpdfstring{$u\in(0,1)$}{u in (0,1)}: Möbius--Hutchinson's correlated combination converts cancellation noise to controlled variance]\label{con:xi-terminal-intermediate-u-mobius-hutchinson}

one can use Hutchinson random trace estimation to unbiasedly estimate
\(
a_n(u)=\Tr(M_K(u)^n)
\)
at cost of only \(n\) sparse matvecs, and substitute into Möbius inversion to obtain primitive approximation
\[
\widehat B_{K,n}(u)=\frac1n\sum_{d\mid n}\mu(d)\,\widehat a_{n/d}(u^d).
\]
To suppress noise amplification from Möbius cancellation, one can simultaneously reuse the same set of random probes \(\{\mathbf r_s\}\) for all \(u^d\) and all required powers, and complete the Möbius combination at the sample level before taking the mean (common random numbers + correlated combining), thereby converting instability from "independent noise difference" to "correlated noise cancellation."
When estimating PSD objects (such as \(\Tr((M_K(u)^n)^{\mathsf T}M_K(u)^n)\) or block symmetrized objects), Hutch++ can improve sample complexity from \(O(\varepsilon^{-2})\) to \(O(\varepsilon^{-1})\) (using only matvec).
Additionally, global block-level objects of the kernel satisfy single-stream lifting relations, so expensive computation can be completed in single stream while maintaining reproducibility.
\end{conclusion}

Implementation regime in the main text is in \S\ref{sec:experiments} subsection "Intermediate weights \(u\in(0,1)\): matrix-free random trace estimation + Möbius inversion";
