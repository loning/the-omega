\paragraph{Uplift vs RNA structure: de-confounding analysis.}
Testing whether Uplift captures information beyond composition and structure:
\textbf{Window 30nt} (n=200): raw $\rho=-0.215$, partial (GC) $\rho=0.009$, partial (GC+dinuc) $\rho=-0.009$.
\textbf{Window 60nt} (n=200): raw $\rho=-0.140$, partial (GC) $\rho=0.056$, partial (GC+dinuc) $\rho=0.014$.
\textbf{Window 120nt} (n=200): raw $\rho=-0.142$, partial (GC) $\rho=0.123$, partial (GC+dinuc) $\rho=0.033$.
\textbf{Finding:} Uplift--MFE correlation is fully explained by GC and dinucleotide composition.
