# docs/papers/math 工作追踪（数学方向）

本目录收集一组彼此关联但可独立推进的论文工程。每篇论文目录内都有独立的 `README.md`（工作追踪、复现入口、产物位置与下一步）。

## 总体主题（高层）

- **共同母题**：将“微观二进制态”通过某种折叠映射压到“禁邻语言”的稳定态，并把折叠造成的信息亏损组织为可审计的“时间/纤维/边标签”，进而研究：
  - 可逆扩展（无损化）
  - 逆向重建复杂度（观察者时间）
  - 图构造（trellis/闭包图/覆盖图）上的 WL/GI 行为
  - 图谱对象（谱隙、Ihara 型 $\zeta$）与复杂性之间的联系
- **路线 B（固定核）**：当前多条线索可以选择以固定的 $m=6$ 核为“本体模型”，把 $m$ 视为模型定义的一部分（而不是运行参数）。

## 论文列表（按目录）

- **`2026_infinite_dimensional_ontology_finite_time_fiber_zeckendorf_folding/`**
  - **定位**：建立“无限维本体—有限观测—有限预测状态”的时间纤维框架，在分辨率 $m$ 下以 Zeckendorf 折叠定义两层时间纤维并刻画稳定语言的组合结构。
  - **核心方法**：
    - **观测投影与折叠核**：以 $\pi_m:\mathcal H\to X_m$ 与 $\Fold_m:\Omega_m\twoheadrightarrow X_m$ 组织观测压缩。
    - **两层时间纤维**：第一层原像纤维 $\mathcal F_m(x)$ 与第二层残差纤维 $R_m(x)$，并提出有限残差充分性公理。
    - **语言计数与最小核**：$|X_m|=F_{m+2}$、$|C_m|=L_m$、$|B_m|=F_{m-2}$，并以 $m=6$ 给出 $21=18\oplus 3$ 锚点。
    - **纤维熵指标**：定义推前分布与纤维熵以量化隐藏自由度。

- **`2026_hpa_ca_fold6_lossless/`**
  - **定位**：固定 $m=6$ 的分块元胞自动机（两相分区），以 $64\to 21$ 折叠核 + uplift 边标签实现“扩展态可逆”；在仅观测稳定层时，逆向变为约束搜索并定义观察者时间。
  - **核心方法**：
    - **固定核本体化**：将 $m=6$ 视为模型定义的一部分；链长 $L$ 要求 $6\mid L$，采用两相分块（Margolus）并行更新（offset 0/3）。
    - **折叠核（$64\to 21$）**：每个 6-bit 微观块压到“禁邻语言”的稳定词（计数 $F_8=21$），把信息亏损从块内结构化出来。
    - **uplift 无损化**：用离散 uplift 字母表（如 $U=\{0,21,34,55\}$）记录折叠损失，使一步演化在“可见态 + uplift”的扩展态上严格可逆。
    - **观察者时间/逆向复杂度**：仅观测稳定层时的逆向重建被形式化为“逆向一致性搜索成本”，并通过脚本枚举统计其分布与结构关联。
  - **建议阅读顺序**：先读这篇以建立“固定核（路线 B）”的统一模型直觉与记号。

- **`2026_hpa_64to21_slack_product_trellis_wl/`**
  - **定位**：以段首/段尾规则把 $2^n$ 微观态折到禁邻稳定态 $F_{n+2}$；构造 trellis 与宏观带权动力学，研究 WL/相干配置与压缩 WL2。
  - **核心方法**：
    - **段首折叠（非 Zeckendorf）**：对 $x\in\{0,1\}^n$，在每段连续 1 中只保留段首得到稳定态（禁邻语言），从而实现 $2^n\to F_{n+2}$ 的压缩。
    - **段尾剥离时间分解**：把被剥离的段内剩余部分推进到下一时刻，时间深度等于最长连续 1 段长度，形成“折叠—时间”的可计算分解。
    - **trellis 统一编码**：把折叠边（微观$\to$宏观）与时间边（微观$\to$微观）装入同一有向带类型图，作为 WL 与复杂度分析的公共载体。
    - **宏观带权动力学与压缩 WL-2**：在稳定态层上定义权重/转移以避免全量展开，并给出压缩 WL-2 的实现与对照实验（与相干配置框架对接）。
  - **备注**：该篇的折叠规则是局部段首算子，不是 Zeckendorf 截断折叠。

- **`2026_fold_backtrack_closure_gi_wl_zeckendorf_trunc_time/`**
  - **定位**：以 Zeckendorf 截断折叠为主，构造“折叠—回溯闭包图”，在同一对象上连接 GI/WL 与“时间纤维（尾部）”，并做多种几何邻接（含 2D/3D Hilbert）实验扫描。
  - **核心方法**：
    - **Zeckendorf 截断折叠**：将微观整数/二进制态的 Zeckendorf 数码取前 $m$ 位作为可见稳定态（规模 $F_{m+2}$），把截断尾部视为结构化的“时间纤维”坐标。
    - **折叠—回溯闭包图**：构造顶点为（微观态 ⊔ 稳定态）的闭包图，同时包含（i）微观邻接边（多种几何模型），（ii）折叠边（微观$\to$稳定），把信息组织与几何输入固定在同一对象上。
    - **在闭包图上运行 WL 并翻译 GI**：比较 WL 稳定化诱导的分割与 GI 判别之间的关系，作为“折叠导致的可见同类/不可分辨性”的图论语言化。
    - **几何邻接扫描（含 2D/3D Hilbert）**：把几何邻接作为实验输入，系统扫描维数/几何对“塌缩速度/残余时间位”的影响，并输出可审计统计图表。

- **`2026_dyadic_zeckendorf_window_folding_kernel/`**
  - **定位**：一般 $m$ 的 Zeckendorf 截断折叠核与 dyadic 边界计数；纤维结构、边界态换能器与加权有限 $\zeta$ 算子。
  - **备注**：这篇更偏“结构定理/工具箱”，但不要求把 $m$ 当作统一本体的自由参数。
  - **核心方法**：
    - **一般窗口 $m$ 的 Zeckendorf 截断核**：在 dyadic 上界取样（如 $N\in[0,2^m-1]$）下，把输出稳定词定义为 Zeckendorf 数码的前 $m$ 位，实现 $2^m\to F_{m+2}$ 的结构化压缩。
    - **纤维计数的 tail 约束化**：将固定输出词的原像大小写成满足不等式约束的 tail 计数问题，使“信息亏损直方图”可枚举、可对照、可推广。
    - **边界态驱动的有限换能器**：以边界窗口态（由 $2^m-1$ 诱导）为核心对象，构造确定/可变长换能器并量化时间深度，作为复杂度与可逆扩展的接口。
    - **加权有限 $\zeta$ 算子接口**：以纤维权重构造有限层转移算子/生成函数（有限 $\zeta$），为后续谱语言与跨尺度构造提供可计算的桥梁对象。

- **`2026_cross_scale_resolution_folding_spectral_rigidity/`**
  - **定位**：从 $m=6$ 的折叠核与无损编码出发，构造单图覆盖与跨尺度接口，建立 Ihara 型 $\zeta$ 字典与“复杂性—谱刚性”不等式链；含一段条件性桥接假设（HTF）。
  - **核心方法**：
    - **以 $m=6$ 可枚举基例作为公共地基**：固定 $m=6$ 的折叠核（$2^6=64$、$F_8=21$）提供全表与退化直方图，使后续图/谱对象建立在可审计的离散基底上。
    - **无损编码到单图覆盖**：把稳定态与 uplift 组合成块级可逆编码，并据此构造可验证的覆盖图（single cover graph）与跨尺度接口，输出统计摘要与可复现产物。
    - **Ihara 型 $\zeta$ 字典化**：将图的谱对象与 Ihara 型生成函数组织到统一记号系统中，用“字典”形式对齐不同尺度/不同图构造下的可比量。
    - **复杂性—谱刚性不等式链**：把混合时间/谱隙等谱量与逆向复杂度/信息亏损等复杂性量连接为可审计的不等式链，并将条件性桥接（HTF）单独隔离为模块化推论层。

## 复现与产物的一般约定

- **运行方式（每篇独立）**：在各论文目录执行：

```bash
python3 -m pip install -r requirements.txt
python3 scripts/run_all.py
```

- **生成物位置（常见）**
  - `sections/generated/`：可被 `main.tex` 直接 `\input{...}` 的 `.tex` 片段，以及用于摘要的 `.json`/`.csv`
  - `artifacts/`：内容寻址或带 `manifest.json` 的实验产物（不同论文可能存在或命名不同）

## 工作追踪建议（持续推进方式）

- **每篇只保留一条主线**：将“本体模型/观测层/派生图/谱对象”的接口写清楚，避免把不同折叠定义混为一谈。
- **优先把结论写成可审计链条**：定义/假设 $\to$ 命题/定理 $\to$ 可复现实验或一致性检查（脚本生成，不手工改 `.tex`）。
