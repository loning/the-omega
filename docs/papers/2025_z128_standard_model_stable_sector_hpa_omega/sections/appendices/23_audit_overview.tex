\paragraph{Implicit constraint registry (reader-facing pointers).}
\AuditTag Several cross-module rigidity constraints are used repeatedly in the manuscript and are easy to miss if one reads only within a single module.
For fast navigation, the unified statements are recorded in Section~\ref{sec:rigidity_bridge_spine} and summarized as an audit registry in the closure tracker \texttt{theory\_closure\_tracker.md}.
The most frequently used constraints are:
\begin{itemize}
\item \AuditTag \textbf{Dyadic--cosmology consistency pin:} the dyadic baseline $p=7$ and the cosmology-side discrete match are tied by the low-complexity relation $m_b^\ast=2p+1$ (Corollary~\ref{cor:dyadic_cosmology_consistency_pin}).
\item \AuditTag \textbf{Pole-barrier certificate family:} pole-barrier gates (including the QCD proxy$\leftrightarrow$Pad\'e gate) are instances of the same analyticity-discipline template, with a pressure/spectral-radius form when transfer-operator packages exist (Corollary~\ref{cor:pole_barrier_equals_exp_minus_pressure}).
\item \AuditTag \textbf{Legality threshold for invariant verdicts:} if an output is intended to be invariant under a declared equivalence, the tie-break key must be invariant as well (Proposition~\ref{prop:rigidity_legality_invariant_verdicts}).
\item \AuditTag \textbf{Identifiability boundary (cycle-type-only):} cycle-type histograms are complete for class-function summaries; additional distinctions require enlarging loop families or changing readouts (Proposition~\ref{prop:cycle_type_identifiability_boundary}).
\item \AuditTag \textbf{Capacity bits as entropy proxies:} capacity bits are log-count entropy in the protocol language (up to matching factors), so capacity-facing modules implicitly carry entropy/typicality semantics and must respect finite-observability squeezing bounds when they derive from quotients (Remark~\ref{rem:rigidity_capacity_bits_entropy}).
\item \AuditTag \textbf{WS delay as a logdet derivative (unitary window):} on a declared unitary band, the WS trace is $-\iu\,\dd(\log\det S)/\dd\omega$, aligning delay audits with determinant/trace bookkeeping (Lemma~\ref{lem:wigner_smith_trace_logdet}).
\item \AuditTag \textbf{Scheme as origin shift in $r$:} scheme rescalings are to be treated as coordinate-origin choices in the $r$ coordinate under the declared scheme contract, not as hidden continuous knobs (Corollary~\ref{cor:rigidity_scheme_shift_origin_r}).
\item \AuditTag \textbf{DPI irreversibility certificate:} data processing provides a canonical monotonicity/irreversibility certificate whenever a step is modeled as a declared coarse-graining channel (Corollary~\ref{cor:rigidity_dpi_irreversibility_certificate}).
\item \AuditTag \textbf{Kernel pressure/pole-barrier alignment:} kernel-view weighted pressure proxies are $\log$ spectral radii and share the same pole-barrier interpretation $|r|_\star=\exp(-P)$ (Corollary~\ref{cor:rigidity_kernel_pressure_polebarrier_alignment}).
\item \AuditTag \textbf{Global MDL registry accounting:} cross-family look-elsewhere control is closed only inside an explicit finite family registry with a prefix-code prior; enlarging the registry is an explicit audit choice (Appendix~\ref{app:global_model_selection_mdl}).
\item \AuditTag \textbf{Projection residual (gap) bookkeeping:} embedding-based projection readouts induce residuals; when organized as a gap field on an interaction complex, a nontrivial $H^1$ class is a structured failure mode (Section~\ref{sec:embedding_gap_projection}).
\item \AuditTag \textbf{Time-advance vs.\ delay separation:} energy-dependent time advance from a dispersion slope is distinct from overhead-induced delay/lapse proxies; mixing the two requires an explicit matching dictionary (Section~\ref{sec:dispersion_time_advance} and Appendix~\ref{app:time_mass_delay}).
\end{itemize}
