\section{Conceptual Definability and Three-Valued Existential Logic}

\subsection{Addressed Concepts and Definability}

Let $\mathcal{A}$ be the observer's ``concept address space,'' which may be a countable set or computable structure (such as strings, natural numbers, or pointers). Let $\mathcal{O}$ be the set of observable objects (e.g., projection operators, effect operators, predicates, or computable functions). Define \textbf{concept storage} as the partial map
\[
\Gamma:\mathcal{A}\rightharpoonup \mathcal{O}.
\]
For an address $a\in\mathcal{A}$, if $\Gamma(a)$ is undefined, we say the concept is in a \textbf{null state}, denoted $\bot$; if $\Gamma(a)$ is defined, the concept ``exists'' at the semantic level.

This yields a three-valued logic: for each address $a$, define its existence value domain before readout as
\[
\mathrm{Val}(a)\in\{\bot,0,1\}.
\]
Here $\bot$ denotes undecidability (concept is undefined or inaccessible), while $0/1$ denote binary judgment results of the system state under some readout protocol. This distinction avoids equating ``undefined'' with ``false,'' thus strictly separating conceptual existence from truth-value of properties.

\subsection{Concept Composition and Hilbertification}

Let $\mathcal{C}$ be a set of basic concepts. Concept composition can first be realized at the algebraic level: for example, linearize concept combinations using the free vector space $\mathrm{span}(\mathcal{C})$ over $\CC$, and after equipping with inner product, complete to a Hilbert space $\mathcal{H}$. More generally, take a $C^*$-algebra $\mathfrak{A}$ as the observable algebra, and obtain a representation $(\pi_\omega,\mathcal{H}_\omega,\Omega_\omega)$ through GNS construction from a state $\omega$. Concepts then correspond to projections or effect operators in $\mathfrak{A}$, and concept composition corresponds to algebraic operations or tensor product extensions.

This structure provides rigorous semantics for ``concept superposition'': concept combination is not merely set juxtaposition, but forms new observable objects within $\mathcal{H}$ or $\mathfrak{A}$, with computable spectrum and measurement statistics.

\subsection{Readout as Instrumented Map from $\bot$ to Binary Values}

Given concept address $a$, if $\Gamma(a)$ corresponds to a binary effect operator $E_a$ (with $0\le E_a\le I$), then a single readout produces a classical result $y\in\{0,1\}$ with probability given by
\[
\mathbb{P}(y=1)=\omega(E_a),\qquad \mathbb{P}(y=0)=1-\omega(E_a);
\]
simultaneously accompanied by state update described by a set of Kraus operators or Lüders-type rule. Crucially, before the readout protocol is determined, $\bot$ carries no probabilistic semantics; probability appears only after $E_a$ is selected and acts on the system state.

Therefore, the statement ``both exists and does not exist'' can be rigorously decomposed into two layers:
\begin{enumerate}
  \item \textbf{Conceptual layer:} Whether $a$ is definable (whether $\Gamma(a)$ exists).
  \item \textbf{Event layer:} Given $E_a$ and system state $\omega$, the uncertainty of readout result $y$ (probabilistic mixing or quantum superposition).
\end{enumerate}
