\paragraph{Audit summary (Padé pole barrier).} \AuditTag We treat the finite Wilson-loop magnitude sequence as coefficients of a sparse power series $F(z)=\sum_{n=0}^{36} c_n z^n$ with $c_0=1$ and $c_{k^2}=|W_k|$ for $k\in\{1,\dots,6\}$. For a bounded family of Padé orders $[L/M]$, we compute the denominator polynomial $Q_{L,M}(z)$ and a numerical root set, then report whether any root lies inside the unit disk (interpreted as a heuristic interior pole). This check is audit-only: Padé can introduce spurious poles and zeros for short/sparse series.
