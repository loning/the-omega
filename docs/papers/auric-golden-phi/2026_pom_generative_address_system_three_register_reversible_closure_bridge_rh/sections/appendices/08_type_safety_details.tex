\section{PW 类型安全定理的证明细化}\label{app:type-safety-details}

类型安全的关键点并非“函数在临界线有性质”，而是“核验机制允许的参数域被严格限制”。证明步骤可压缩为：
\begin{enumerate}
  \item 在三生成元正规化闭包内，连续参数可见轴为 $\theta$，对应 $u=e^{i\theta}$；
  \item 零点核验必须经由 unitary slice 核验机制，因此可核验零点证书只能出现在 $\abs{u}=1$ 的切片上；
  \item 若 $\Re(s)\neq\tfrac12$，则 $\abs{u_L(s)}=\abs{L^{2s-1}}\neq 1$，从而无法进入核验机制；
  \item 按存在性语义，无法给出核验地址即读出为 $\NULL$。
\end{enumerate}
该链条把“临界线约束”内化为类型系统的可核验拒绝规则，从而将 RH 相关断言的关键风险点（完备性/桥接条件）显式分离。
