\section{Limitations and open problems}
\label{app:limitations}

\begin{enumerate}
  \item The constitution is mathematically closed, but turning it into a physical law requires additional dynamical closure and a concrete data interface. For example, one must embed the Hecke structure into a specific QCA update rule or effective Hamiltonian and derive observable spectral/scattering predictions with an error budget.

  \item Interpreting $S$-inversion as a physical ``wormhole/entanglement'' mechanism is a strong analogy. A physicalization requires a testable map between modular variables and operational observables (energy scales, lengths, entanglement scales, etc.).

  \item Treating ``discrete matter $=$ $q$-coefficients'' is an interface hypothesis. To become predictive, one must specify which families of modular forms (weight, level, character) correspond to which physical sectors and provide systematic spectrum matching.
\end{enumerate}
