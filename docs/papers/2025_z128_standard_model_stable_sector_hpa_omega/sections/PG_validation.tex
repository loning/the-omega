\paragraph{Observation class and budget comparability (audit note).}
\AuditTag The wormhole sweep and adaptive-search scripts evaluate a metrics-only oracle that reports a single final snapshot and on/off deltas by contract.
This observation class is robust for accumulated or steady-state quantities (e.g.\ $\Delta E_{\mathrm{emit}}$ and late-time $\Delta\tau_{\mathrm{trap}}$), but it can be insensitive to intermittent or gated channels (e.g.\ endpoint-gated $\tau_{\mathrm{wh}}$ contributions or rare pointer-jump events).
\AuditTag Moreover, since the shortcut ledger $E_{\mathrm{wh}}$ is accumulated over time, an absolute budget constraint $E_{\mathrm{wh}}\le B$ is not directly comparable across different run lengths unless a normalization convention (e.g.\ $E_{\mathrm{wh}}/T$ or $E_{\mathrm{wh}}/\text{steps}$) or matched step budgets is used.
