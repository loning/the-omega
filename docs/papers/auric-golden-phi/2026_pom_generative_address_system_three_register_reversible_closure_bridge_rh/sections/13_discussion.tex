\section{讨论：可发表边界、可审计义务与后续任务分解}

\subsection{soundness/completeness 的逻辑分离}
定理 \ref{thm:type-safety-offcritical} 给出 soundness：可寻址且可审计的零点证书必在临界线上；而 completeness（零点必可寻址）并非由空值语义自动推出，必须作为桥接假设（如假设 \ref{ass:xi-address-completeness}）或由具体构造证明。该分离保证推理链条的可审计性：任何“经典 RH”层面的结论必须显式声明其桥接义务（如假设 \ref{ass:bridge-rh}）。

\subsection{BridgeRH 的验证义务}
BridgeRH 的内容可拆分为两层硬接口：
\begin{enumerate}
  \item 在核/行列式层建立与经典对象一致的解析刚性（零点集与重数一致）；
  \item 将经典零点事件编译为 PW 可寻址地址，并保证核验路径被锁定到 unitary slice 审计接口。
\end{enumerate}
因此，无条件证明 RH 的工作量被转写为对 BridgeRH 义务清单的逐项完成，而非在同一层面混合分析数论与体系语义。该任务分解为形式化与计算验证提供路线图。

\subsection{三寄存器最小性与可计算实现}
三纤维的语义不仅是结构描述，也可落到可执行层：可见寄存器存储外表纤维 $X_\infty$ 的规范地址，素数寄存器用于线性化乘除或承载残差；相位纤维控制角色扭曲与谱接口。该实现层面的可审计性体现为：操作成本与残差预算可被计数器分解，并与序投影等不可并行门形成可辨识边界。
