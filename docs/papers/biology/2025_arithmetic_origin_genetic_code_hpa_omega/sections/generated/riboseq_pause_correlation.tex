\paragraph{Uplift vs ribosome pause score (codon level).}
Using published codon-level pause scores from human Ribo-seq data (n=61 sense codons):
Spearman $\rho=-0.121$ ($p=0.352$).
\textbf{Finding:} No strong correlation between Uplift and pause scores at the codon level.
Within synonymous families (n=6): average $\rho=-0.089$, indicating no consistent within-family pattern.
