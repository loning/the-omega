\begin{theorem}[Minimality of time compensation axis: reversibility minimal delay and minimal state number]\label{thm:xi-time-min-delay-min-states}
Let \(m\ge 3\), and consider the sliding block code \(\Phi_m\) induced by window folding.
For any causal finite-state right inverse decoder \(\Psi\) (allowing fixed delay \(D\)), if
\[
\Psi\circ\Phi_m=\mathrm{id}_{\{0,1\}^{\mathbb Z}}
\]
holds on almost every orbit, then necessarily
\[
D\ge m-1,
\qquad
|\mathrm{States}(\Psi)|\ge 2^{m-1}.
\]
Moreover, this lower bound can be achieved simultaneously: there exists a suffix state machine \(V_m=\{0,1\}^{m-1}\) achieving
\(
D=m-1,\ |\mathrm{States}|=2^{m-1}
\).
\end{theorem}

\begin{proof}
By Theorem \ref{thm:Phi_m-conjugacy-threshold}, the inverse code memory of \(\Phi_m\) is \(m-1\) and this memory threshold is sharp.
Again by graph representation \(|V_m|=2^{m-1}\) (\S\ref{subsec:Phi_m-graph}), distinguishing all length-\(m-1\) suffixes requires at least this order of states.
Thus obtaining dual lower bounds on delay and state number, achieved by the same inverse code construction.
\end{proof}

\begin{theorem}[Dual-budget capacity phase transition: unified exponential scale of time budget and resolution budget]\label{thm:xi-time-resolution-dual-budget-phase-transition}
Fix resolution \(m\) and temperature threshold \(u\).
Let \(T_m\) be synchronization time, \(\mathrm{Col}_u(m)\) be address collision probability.
For \(N\) independent objects, time budget \(n\), and resolution budget \(m\), define failure event
\[
\mathrm{Fail}_{m,n,N}:=\{\text{synchronization disambiguation (\(\mathsf{NULL}\)) or collision exists}\}.
\]
If regular exponential laws hold
\[
\nu_m(T_m>n)\asymp e^{-\varepsilon_m n},
\qquad
\mathrm{Col}_u(m)\asymp e^{-h_2(u)m},
\]
then for any fixed \(\eta\in(0,1)\):
\[
\log N\le (1-\eta)\min\!\left\{\varepsilon_m n,\frac12 h_2(u)m\right\}
\Longrightarrow
\mathbb P(\mathrm{Fail}_{m,n,N})\to 0,
\]
\[
\log N\ge (1+\eta)\min\!\left\{\varepsilon_m n,\frac12 h_2(u)m\right\}
\Longrightarrow
\mathbb P(\mathrm{Fail}_{m,n,N})\to 1.
\]
Thus the exponential scale of addressable size satisfies
\[
\log N\asymp \min\!\left\{\varepsilon_m n,\frac12 h_2(u)m\right\}.
\]
\end{theorem}

\begin{proof}
Synchronization disambiguation is given by Theorem \ref{thm:Ym-sync-tail} with exponential tail; collision side is given by \(\mathrm{Col}_u(m)\) exponential law.
For \(N\) objects, using parallel union and second moment standard bounds, threshold is controlled by the smaller of two exponential types.
\end{proof}
