\section{Substitutability list for the three-channel \texorpdfstring{$\alpha$}{alpha} model}
\label{app:alpha_substitutability}

Theorem~\ref{thm:alpha_three_channel} is a closed-theory statement conditional on explicit axiom choices. We list the main substitution points (each of which defines an alternative closed model that is tested against data).

\begin{enumerate}
    \item \textbf{Channel-composition and readout projection.} Axiom~\ref{ax:serial_impedance} uses multiplicative composition of serial constraints ($w_{\mathrm{tot}}=\prod_j w_j$) together with the logarithmic readout projection $\alpha_{\mathrm{geo}}^{-1}=-\log w_{\mathrm{tot}}$. Replacing either ingredient changes the value of $\alpha_{\mathrm{geo}}^{-1}$ and is falsifiable by the same rigidity protocol.
    \item \textbf{Impedance functional (volume vs alternative invariants).} Axiom~\ref{ax:impedance_volume} uses canonical volume. Replacing it by other geometric/spectral invariants (e.g., spectral determinants, analytic torsion, or normalized action functionals) yields alternative quantitative predictions.
    \item \textbf{Normalization / scale.} The canonical-volume choice presupposes a unit-radius normalization for the underlying compact manifolds. Changing this normalization rescales the impedance and must be fixed by an independent calibration convention.
    \item \textbf{Stratum identification.} Axiom~\ref{ax:em_phase_spaces} fixes the phase spaces as $U(1)\times SU(2)$, $SO(3)$, and $\mathbb{R}P^1$. Alternative identifications (e.g., different quotients or bundles) define distinct closed models.
\end{enumerate}
