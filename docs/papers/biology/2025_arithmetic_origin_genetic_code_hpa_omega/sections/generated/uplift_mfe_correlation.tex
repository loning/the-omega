\paragraph{Uplift vs RNA MFE correlation ($k=10$, n=900).}
Using ViennaRNA to compute actual minimum free energy (MFE) for stop-context windows:
Before-window: raw $\rho=-0.294$ ($p=$<$0.001$); After-window: raw $\rho=-0.197$ ($p=$<$0.001$).
Partial (GC-controlled): before $\rho=-0.060$ ($p=0.072$); after $\rho=0.071$ ($p=0.034$).
Sanity check: GC--MFE correlation $\rho=-0.641$ ($p=$<$0.001$; expected strong negative).
\textbf{Finding:} High Uplift correlates with \emph{lower} MFE (more stable structure), \emph{contrary} to the ``arithmetic friction'' hypothesis.
