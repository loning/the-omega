\subsubsection{Right-Resolving Representation and Fischer Cover (Retaining Only the Computable Interface)}\label{subsubsec:Phi_m-right-resolving-fischer-cover}
For sofic shifts, there exists a \textbf{right-resolving} labeled graph representation, which can be further minimized to the right Fischer cover. This paper requires only its computable interface and two structural conclusions; the relevant construction background can be found in \cite{LindMarcus1995,Kitchens1998SymbolicDynamics}.

\begin{definition}[Determinization Caliber for Right-Resolving Representation]\label{def:Phi_m-right-resolving}
Let $G_m=(V_m,E_m,\ell_m)$ be the labeled graph of Definition \ref{def:G_m} (alphabet $X_m$). For any subset state $S\subset V_m$ and output symbol $a\in X_m$, define the transition
\[
\delta_m(S,a):=\{v'\in V_m:\exists\,e:v\to v'\ \text{s.t. } v\in S,\ \ell_m(e)=a\}.
\]
Starting from the initial state $V_m$, take all reachable $S$ as the state set and add edges according to $S\xrightarrow{a}\delta_m(S,a)$, obtaining a deterministic right-resolving labeled graph representation, denoted $H_m^{\mathrm{det}}$.
\end{definition}

\begin{proposition}[Existence and Equivalence of Right-Resolving Representation]\label{prop:Phi_m-right-resolving}
The labeled graph $H_m^{\mathrm{det}}$ obtained by the determinization construction of Definition \ref{def:Phi_m-right-resolving} is right-resolving and presents the same label language as $G_m$; therefore its label shift equals $Y_m$.
\end{proposition}

\begin{proof}
Determinization guarantees that ``given state $S$ and label $a$, the successor is unique,'' hence right-resolving; that $H_m^{\mathrm{det}}$ and $G_m$ recognize the same regular language follows directly from automaton determinization. See \cite{LindMarcus1995,Kitchens1998SymbolicDynamics}.
\end{proof}
