\begin{corollary}[Entropy Non-Drop of Sequence-Level Folding: Each Step Retains \texorpdfstring{$1$}{1} Bit of Freedom]\label{cor:Phi_m-entropy-no-drop}
For any \(m\ge 2\), let \(Z_m\subset E_m^{\ZZ}\) be the two-sided edge shift of the graph \(G_m\), let \(\mathcal{L}_m:Z_m\to X_m^{\ZZ}\) be the map taking each edge to its label (Definition \ref{def:G_m}), and write \(Y_m=\mathcal{L}_m(Z_m)\) (Theorem \ref{thm:Phi_m-sofic-graph}).
Then:
\begin{enumerate}
  \item \(Z_m\) is conjugate to the binary full shift \(\{0,1\}^{\ZZ}\), so \(h_{\mathrm{top}}(Z_m)=\log 2\);
  \item The labeled graph \(G_m\) is right-resolving (any two outgoing edges from the same vertex have distinct labels; Theorem \ref{thm:pom-right-resolving}), so \(\mathcal{L}_m\) is a finite-to-one factor code (the number of lifts of each output sequence is at most \(|V_m|=2^{m-1}\));
  \item Consequently, topological entropy is preserved:
  \[
  \boxed{\ h_{\mathrm{top}}(Y_m)=h_{\mathrm{top}}(Z_m)=\log 2\ }.
  \]
\end{enumerate}
This conclusion provides the rigorous statement of ``window-level many-to-one compression'' versus ``sequence-level memory compensation'': \(\Phi_m\) transfers the fiber degrees of freedom lost at the window level into finite-state memory in the time direction, without compressing the per-step \(1\)-bit degree of freedom in the entropy sense.
\end{corollary}
\begin{proof}
\textbf{(1)}--\textbf{(2)} follow from Theorem \ref{thm:Phi_m-sofic-graph} (conjugacy) and right-resolvingness; \textbf{(3)} entropy preservation under finite-to-one factor codes can be found in \cite{LindMarcus1995,Kitchens1998SymbolicDynamics}.
\end{proof}

\begin{remark}[Temporal Memory as an Implicit Register]\label{rem:Phi-m-memory-implicit-register}
Window-level many-to-one compression is not equivalent to information loss at the time level: when $m\ge 3$, Theorem \ref{thm:Phi_m-conjugacy-threshold} provides a finite-window inverse code $\Psi_m$, so the degrees of freedom erased by folding can be transferred to finite-state memory in the time direction and recovered after a finite delay. This provides an alternative realization of the ``third register'': it need not be stored explicitly as a static axis, but can be implicitly carried as the internal state of a synchronizing filter. Under the gauge groupoid caliber, this implicit register corresponds to the gluing data between local sections (see Section \ref{subsec:pom-gauge-groupoid}).
\end{remark}
