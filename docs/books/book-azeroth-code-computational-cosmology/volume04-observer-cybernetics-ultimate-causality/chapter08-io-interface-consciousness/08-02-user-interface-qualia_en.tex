\begin{quote}
\textbf{``For programmers, `red' is code RGB(255, 0, 0); but for players, `red' is danger alert. Qualia---the pain, itch, sourness, pleasure you feel---is not mysterious soul sparks; it's the graphical user interface (GUI) rendered by the brain's graphics card. Its only purpose: Let you understand that complex physical data in 0.1 seconds.''}
\end{quote}

In section 8.1, we said consciousness is the player. What does the player use to see the game?
Can't directly look at binary code, right?
There must be a \textbf{rendering engine} that turns boring data into intuitive images. In \textbf{Code of Azeroth}, this image is \textbf{qualia}.

\subsection{Mapping Physical Data to Subjective Experience}

Philosophy has a ``hard problem'': Why does neuron firing (physical process) produce pain (subjective experience)?
Our answer: \textbf{Because the system needs to feedback status to users.}

\begin{itemize}
\item \textbf{Physical input}: 700nm electromagnetic wave (raw data).
\item \textbf{Neural encoding}: Optic nerve signals (processing data).
\item \textbf{Qualia}: Visual experience of ``red'' (UI display).
\end{itemize}

\textbf{Definition 8.2.1 (Qualia Mapping)}

Qualia are icons after physical data undergoes \textbf{compression} and \textbf{rendering}.
Just like the computer desktop's ``trash'' icon is not a real trash can, the ``red'' in your eyes is not real light. It's a \textbf{symbolic label}.
The system renders it as red to let you distinguish it from ``green.''

\subsection{Weber-Fechner Law: Logarithmic Compression}

Our senses follow the \textbf{Weber-Fechner Law}:
\[
\text{sensation} \propto \ln(\text{stimulus})
\]
To feel sound twice as loud, physical energy must be ten times greater.

\textbf{Computational principle}:
This is \textbf{logarithmic encoding} commonly used in computers.
To transmit extremely wide signal ranges (from mosquito buzz to thunder) under limited bandwidth, the system performs \textbf{lossy compression}.
Qualia are compressed system feedback.

\subsection{Pain Is System Interrupt (Alert)}

Qualia not only transmit information, but also \textbf{value}. Most typical is \textbf{pain}.

For pure machines, taking damage is just \texttt{hp -= 10}.
But for systems with players, pain is a \textbf{high-priority system interrupt}.

\begin{enumerate}
\item \textbf{Force preemption}: When your hand is burned, intense pain forcibly pulls your attention back from elsewhere.
\item \textbf{Negative feedback}: It's a huge red popup: ``Warning! System damaged!''
\end{enumerate}

\textbf{Corollary 8.2.1 (Cybernetics Function)}
\begin{itemize}
\item \textbf{Pleasure}: \texttt{System Status = OK}. Encourages you to continue.
\item \textbf{Pain}: \texttt{System Status = CRITICAL}. Forces you to stop.
\end{itemize}

Conscious experience is not an evolutionary byproduct; it's \textbf{dashboard readings sent by the biological mech to the pilot}.

\subsection{Interface Illusion Theory: We Live on Desktop}

This leads to \textbf{Interface Theory}.

If we could directly see the world's truth (Hilbert space, wave functions), we couldn't play at all. Because that world is too complex.
\begin{itemize}
\item To make it playable, the system must \textbf{lie} to us.
\item The system renders ``a bunch of organic molecules'' as \textbf{``delicious apple''}.
\item The system renders ``gene carriers suitable for reproduction'' as \textbf{``beautiful girl''}.
\end{itemize}

These experiences don't exist physically; they're completely \textbf{rendered by this specific hardware called client}.

\textbf{Theorem 8.2.1 (Interface Closure)}

Players can only operate the game through UI (qualia), cannot bypass UI to directly modify code (physical laws).
The physics we study is essentially studying \textbf{desktop icon logic}, not underlying assembly code.

\subsection{Summary: Immersive Experience}

Qualia are the bridge connecting \textbf{physical machine (brain)} and \textbf{virtual machine (consciousness)}.

\begin{itemize}
\item \textbf{Without qualia}: Players face boring 0s and 1s, can't play.
\item \textbf{With qualia}: Data becomes images, sounds, emotions. You sit in the cockpit, through these dashboards, piloting this carbon-based mech.
\end{itemize}

This mechanism is extremely efficient, but also brings a consequence: \textbf{Immersion}.
The interface is so good that players often forget they're playing a game, mistakenly thinking the interface itself is all of reality.
