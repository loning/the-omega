\paragraph{HTF-lite bridge audit summary.} \AuditTag This module provides reproducible, finite-family evidence for two ingredients used in the HTF-lite bridge vocabulary. (i) For a fixed irrational rotation scan and a finite Fourier kernel family $K_m(x)=\cos(2\pi m x)$, the scan readout sequence is bounded and its Abel generating function satisfies the standard unit-disk bound (Appendix~\ref{app:abel_finite_part_notes}, Subsection~\ref{subsec:abel_holomorphy}); Table~\ref{tab:htf_lite_kernel_holomorphy_audit} records a deterministic numeric sanity check. (ii) The mode factor $M_\rho(r)=(1-r\,\e^{(\rho-\frac12)})^{-1}$ has an interior pole whenever $\RePart(\rho)>\tfrac12$ (Appendix~\ref{app:trace_pole_barrier_template}); Table~\ref{tab:htf_lite_zero_mode_pole_audit} lists the corresponding pole radii for a small fixed set of reference $\gamma$ values and hypothetical real parts $\beta$. This audit does not assert the existence of a true trace-bridge identity (HTF); that remains an explicit bridge gate (Assumption~\ref{ass:htf_lite_operator_pack} and failure point IC13).
