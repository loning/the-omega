\subsection{Wigner's Friend: Version Conflict}

Quantum mechanics has a paradox called \textbf{Wigner's Friend}:
\begin{itemize}
\item Friend in lab sees cat alive (version A).
\item Wigner outside door thinks friend is in superposition state of ``seeing dead cat'' and ``seeing alive cat'' (version B).
\end{itemize}

If everyone has their own private reality, the world would have split into countless parallel dreams long ago.
Since we can chat in one world, the system runs a strict \textbf{synchronization protocol}.

\subsection{Reality Is Intersection of Perspectives}

\textbf{Definition 9.1.1 (Objective Reality)}

Objective reality is neither God's perspective nor your private perspective.
Objective reality is the \textbf{greatest common divisor (intersection)} of all player perspectives.

\[
Real = \text{View}_{\text{A}} \cap \text{View}_{\text{B}} \cap \text{View}_{\text{C}} \dots
\]

Like World of Warcraft server:
\begin{itemize}
\item Player A sees a tree.
\item Player B sees that tree.
\item System only maintains one ``tree'' object and broadcasts its reference to everyone.
\end{itemize}

Only states \textbf{jointly locked} (observed) by multiple players are ``hard'' physical reality. Hallucinations in your brain because only you see them (no consensus) are judged ``illusory'' by the system.

\subsection{Bayesian Update: Wave Function Synchronization}

How is consensus reached? Through \textbf{chat (information exchange)}.

\begin{enumerate}
\item \textbf{Initial}: I think electron is left, you think right (belief conflict).
\item \textbf{Interaction}: You shout to me: ``I caught it on the right!''
\item \textbf{Synchronization}: I receive information. If I trust you (treat you as reliable measuring instrument), I update my probability distribution.
\item \textbf{Result}: My wave function also instantly collapses to the right.
\end{enumerate}

\textbf{Theorem 9.1.1 (Consensus Convergence)}

As long as everyone is reasonable (follows Bayesian rules), everyone's wave functions rapidly converge to a \textbf{globally consistent state}. This state is called ``objective fact.''

\subsection{Physical Laws Are Nash Equilibrium}

Why does consensus always converge to physical laws ($F=ma$), not magic?
This is a result of \textbf{game theory}.

Treat the universe as a \textbf{prediction game}. Everyone guesses what happens next second.
\begin{itemize}
\item If everyone guesses randomly, error is huge.
\item If everyone agrees on a \textbf{stable rule} (like stones fall down), everyone's prediction error is minimized.
\end{itemize}

\textbf{Newton's laws are not truth; they are evolutionarily stable strategies (ESS).}
That player who believed ``stones fly up'' was eliminated long ago due to prediction errors (crushed by stones). Surviving players all have the same physics engine in their brains.

\subsection{Universe Is Blockchain}

To engineers, this is \textbf{blockchain}.

\begin{enumerate}
\item \textbf{Blocks}: Every physical event that occurs (collapse).
\item \textbf{Hash chain}: Causality. Present must contain past information.
\item \textbf{Consensus mechanism}:
\begin{itemize}
\item \textbf{Proof of Work (PoW)}: To change reality, you must consume energy (do work). Prevents someone from modifying data with thoughts.
\item \textbf{Broadcast}: Light speed $c$ is network latency. Once any event occurs, light speed broadcasts to entire server.
\item \textbf{Confirmation}: Once information is recorded by environment, block is \textbf{confirmed}, becomes unchangeable history.
\end{itemize}
\end{enumerate}
