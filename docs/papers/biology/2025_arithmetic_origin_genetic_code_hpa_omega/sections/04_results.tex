\subsection{The start--stop \texorpdfstring{$14/48$}{14/48} symmetry: same boundary, different uplift}
\label{sec:start_stop_symmetry}

Under $\mu^\ast$, the start codon and the canonical stop codon satisfy:
\[
N_{\mu^\ast}(\mathrm{AUG})=14,\qquad
N_{\mu^\ast}(\mathrm{UAA})=48,
\qquad
w_{\mu^\ast}(\mathrm{AUG})=w_{\mu^\ast}(\mathrm{UAA})=100001\in X_6^{\mathrm{bdry}}.
\]
By Proposition~\ref{prop:boundary_preimages}, $\{14,48\}$ is exactly the boundary preimage pair of $100001$.
Hence start and stop share the same topological boundary type, while their uplift variables split:
\[
\Delta_{\mu^\ast}(\mathrm{AUG})=0,\qquad
\Delta_{\mu^\ast}(\mathrm{UAA})=34.
\]
\begin{remark}[Interpretation layer (non-premise)]
The equal folded boundary type but split uplift values provide a natural gate model: a low-uplift preimage (start) corresponds to a purely window-visible boundary, while the $F_9$-uplifted preimage (stop) corresponds to the same local boundary carrying an external load.
This interpretive picture is not used in any proof.
\end{remark}

\subsection{Bitwise complement matches Watson--Crick complement (emergent)}
\label{sec:bitwise_complement}

The encoding $\mu^\ast$ has an additional property not used in the identification criterion:
Watson--Crick complement corresponds to bitwise negation:
\[
A\leftrightarrow U \quad\Longleftrightarrow\quad 00\leftrightarrow 11,\qquad
C\leftrightarrow G \quad\Longleftrightarrow\quad 01\leftrightarrow 10.
\]
This makes base-pair complementarity a literal logical symmetry at the two-bit layer.
\cite{WatsonCrick1953,Alberts2014}

\subsection{Stop codon fine structure}
\label{sec:stop_fine_structure}

The three standard stop codons exhibit three distinct structures under $\mu^\ast$:
\begin{definition}[Stop-codon structural classes at window length $6$]
\label{def:stop_classes}
Fix $\mu^\ast$.
For a stop codon $c\in\{\mathrm{UAA,UAG,UGA}\}$, define:
\begin{itemize}
\item \emph{boundary stop} if $w_{\mu^\ast}(c)\in X_6^{\mathrm{bdry}}$;
\item \emph{uplifted blocker} if $w_{\mu^\ast}(c)\notin X_6^{\mathrm{bdry}}$ but $\Delta_{\mu^\ast}(c)=34$;
\item \emph{projection mismatch} if $\Delta_{\mu^\ast}(c)=55$ (the maximal window-$6$ uplift).
\end{itemize}
These are purely arithmetic classes induced by $(w_{\mu^\ast}(c),\Delta_{\mu^\ast}(c))$.
\end{definition}

\subsection{Amino-acid Zeckendorf spectra and notable extrema}
\label{sec:aa_spectra}

For each amino acid $a$, consider the multiset of Zeckendorf levels $\{V_{\mu^\ast}(c): \mathsf{Gen}(c)=a\}$ over its synonymous codons.
This defines an amino-acid spectrum interval $[V_{\min}(a),V_{\max}(a)]$ and a discrete spectrum set.
Appendix~\ref{app:generated_tables} records the full table generated by the scripts.
Here we highlight two extrema.

\paragraph{Minimal level ($V=0$).}
There are exactly four codons at $V=0$:
\[
\{\mathrm{AAA}(\mathrm{Lys}),\ \mathrm{CCC}(\mathrm{Pro}),\ \mathrm{GAG}(\mathrm{Glu}),\ \mathrm{UCU}(\mathrm{Ser})\}.
\]

\paragraph{Maximal level ($V=20$).}
There are exactly two codons at $V=20$:
\[
\{\mathrm{CCA}(\mathrm{Pro}),\ \mathrm{UCG}(\mathrm{Ser})\}.
\]

\paragraph{Full-spectrum proline.}
Among amino acids with four synonymous codons, proline achieves the maximal possible spectral span:
\[
V_{\min}(\mathrm{Pro})=0,\qquad V_{\max}(\mathrm{Pro})=20.
\]
\begin{remark}[A falsifiable codon-usage hypothesis]
The fact that a single residue can be called by both minimal and maximal Zeckendorf levels motivates a testable hypothesis: in organisms with strong codon-usage bias, proline synonym choices may show systematic shifts in the distribution of $(V_{\mu^\ast}(c),\Delta_{\mu^\ast}(c))$ across structural contexts.
Appendix~\ref{app:stat_tests} specifies codon-usage tests against folding spectra.
\end{remark}
