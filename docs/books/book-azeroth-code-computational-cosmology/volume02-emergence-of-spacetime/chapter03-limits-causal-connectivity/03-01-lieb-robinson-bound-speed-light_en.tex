\section{Max Transfer Rate (Lieb-Robinson Bound and the Speed of Light)}

\textit{(Max Transfer Rate - Lieb-Robinson Bound and the Speed of Light)}

\begin{quote}
\textbf{``The speed of light is not about how fast light travels, but about the server's maximum data transmission bandwidth limit. You think spacetime is an empty box, but actually it's a local area network woven from countless network cables.''}
\end{quote}

In Volume I, we established the ``world as code'' axiomatic system. Now, we need to make this code run.

For this abstract system to become the physical world we see with length, width, and height, the system must have a \textbf{topological structure}.

The core constraint of this structure is \textbf{locality}. Simply put, \textbf{you can only attack monsters within your attack range}.

This section will prove that as long as the server follows this rule, information propagation must have a maximum speed limit. In physics, this is called the \textbf{speed of light (c)}. In our theory, this is \textbf{global maximum bandwidth}.

\subsection{Interaction Graph: Who Are Your Neighbors?}

In classical physics, distance is innate. But in computational cosmology, distance comes later.

We first define the system's \textbf{interaction graph}:
\begin{itemize}
\item \textbf{Nodes}: Each independent quantum bit, or each smallest spatial pixel.
\item \textbf{Edges}: Who can directly exchange data with whom.
\end{itemize}

If physical laws are \textbf{local} (to prevent server overload, cannot allow full connection between all pixels), then interactions can only occur between adjacent pixels.

This means information cannot teleport. It must be transmitted step by step, like running across the map.

\subsection{Lieb-Robinson Bound: Physical Limit of Ping}

In 1972, two physicists Lieb and Robinson proved a theorem. Translated into World of Warcraft language:

\textbf{Theorem 3.1.1 (Lieb-Robinson Bound / Maximum Ping Theorem)}

In a grid system, as long as each cell only interacts with adjacent cells, the influence range of any event has an \textbf{upper limit on diffusion speed}.

\textbf{Physical meaning}:

Outside the \textbf{light cone} defined by slope $v_{LR}$, that is, places this speed cannot catch up, no event can affect you.

This is like shouting in the Eastern Kingdoms; people in Kalimdor absolutely cannot hear. Although mathematically there may be extremely weak probability (due to continuous evolution tails), at physical measurement precision, this constitutes an \textbf{effective causal horizon}.

\subsection{The True Face of Light Speed: System Bus Bandwidth}

If we adopt a more fundamental \textbf{cellular automaton} model, time is discrete (Server Tick). In this case, the limit becomes absolutely strict.

Each time the system ticks, data can only be transmitted from one cell to an adjacent cell.

From this, we derive \textbf{the true definition of light speed c}:

\[
c \equiv \frac{\text{minimum pixel side length}}{\text{minimum server refresh period}} = \frac{l_P}{t_P}
\]

In this framework, light speed invariance is no longer a strange assumption, but a direct manifestation of \textbf{system bus bandwidth}.

\begin{itemize}
\item \textbf{Bus frequency}: The server's refresh rate is locked (Planck time).
\item \textbf{Bus bit width}: Each cycle, data can only be moved this far.
\end{itemize}

Therefore, any attempt to exceed light speed is computationally equivalent to \textbf{trying to transmit data to an address outside the bus architecture in one cycle}. This will be directly intercepted by underlying hardware logic, and the chat box will show: \textbf{``Target not in view''} or \textbf{``Too far away''}.

\subsection{Preventing Server Avalanche}

Special relativity is usually thought to limit our exploration of the universe, but in computational cosmology, this is actually to \textbf{protect the server}.

If \textbf{teleportation} (superluminal/infinite propagation speed) were allowed, then any tiny disturbance in the network (like you sneezing in Stormwind) would instantly spread throughout the universe. This means every pixel must simultaneously process information from the entire universe.

This would cause computational complexity to explode from $O(N)$ to $O(N^2)$ or even exponential. The server would instantly \textbf{avalanche}, directly blue screen crash.

\textbf{Corollary 3.1.1 (Instance Partitioning)}

The existence of light speed divides the universe into countless relatively independent \textbf{causal diamonds}, like diverting players to different \textbf{planes or channels}.

This allows the system to process local tasks in parallel without waiting for global synchronization. Relativity is not just about motion; it's the \textbf{partition tolerance protocol} that this supercomputer universe must follow to achieve \textbf{large-scale parallel computation}.

Therefore, we should thank the light speed limit. It's precisely because of it that lag in Stormwind doesn't affect Orgrimmar.
