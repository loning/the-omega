\section{Neutrino splittings as bounded rational resolution offsets (audit attempt)}
\label{app:neutrino_splitting_depth_closure}

This appendix records an explicit bounded candidate-family attempt to compress neutrino oscillation splittings into the same $\varphi$-resolution language used elsewhere in the paper.
In contrast to the PMNS closures, mass splittings do not follow from unitarity or mixing alone; any closure must either (i) introduce additional protocol-side structure that differentiates the three eigenvalues or (ii) treat oscillation splittings as external interface inputs.
We therefore separate a \emph{protocol-only} CAP-minimizer from a \emph{match} minimizer against recorded reference splittings and use the comparison to expose a minimal failure point.

\paragraph{Baseline scale.}
\AuditTag We take the baseline lightest mass $m_{\mathrm{lightest}}$ from the globally selected feasible neutrino-mechanism candidate in Appendix~\ref{app:neutrino_mass_mechanism_candidates} (generated by \texttt{scripts/exp\_neutrino\_mass\_mechanisms.py}).

\paragraph{Bounded rational offsets in the $r$-coordinate.}
\AuditTag For a bounded denominator cap $q\le 12$, we consider rational offsets $\Delta r=k/q$.
For the normal ordering (NO) we parameterize
\[
m_1=m_{\mathrm{lightest}},\qquad
m_2=m_1\,\varphi^{\Delta r_{21}},\qquad
m_3=m_1\,\varphi^{\Delta r_{31}},
\qquad 0<\Delta r_{21}<\Delta r_{31},
\]
and for the inverted ordering (IO) we parameterize
\[
m_3=m_{\mathrm{lightest}},\qquad
m_1=m_3\,\varphi^{\Delta r_{13}},\qquad
m_2=m_3\,\varphi^{\Delta r_{23}},
\qquad 0<\Delta r_{13}<\Delta r_{23}.
\]
In each case, the implied splittings are computed as $\Delta m_{21}^2=m_2^2-m_1^2$ and $\Delta m_{3}^2:=|m_3^2-m_1^2|$ (NO) or $\Delta m_{3}^2:=|m_1^2-m_3^2|$ (IO).

\paragraph{Three selection modes.}
\AuditTag Within the same finite pool we record:
\begin{itemize}
\item \texttt{cap}: protocol-only CAP-minimizer by rational complexity (minimize $q$, then numerators, then ordering tie-break);
\item \texttt{proto}: an invariant-derived anchor candidate that ties the denominator to $(m+1)$ at $m=6$ and uses the closed split sizes $18\oplus 3$ as numerators (a bridge rule; see Proposition~\ref{prop:cyc_bdry_6});
\item \texttt{match}: mismatch-minimizer against recorded reference splittings (minimize $\max(|\log(\Delta m_{21}^2/\Delta m_{21,\mathrm{ref}}^2)|,\ |\log(\Delta m_3^2/\Delta m_{3,\mathrm{ref}}^2)|)$, tie-break by rational complexity).
\end{itemize}
