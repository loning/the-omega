\subsection{Induced Process and Transition Structure: Explicit Finite Labeled Graph}\label{subsec:Phi_m-graph}

Below we give a fully explicit sofic graph representation of $Y_m$, thereby characterizing ``the state/transition structure of the output process when $\Fold_m$ is continuously applied to overlapping windows along a long trajectory.''

\begin{definition}[Length-\texorpdfstring{$m-1$}{m-1} Suffix State Graph]\label{def:G_m}
Let the vertex set be
\[
V_m:=\{0,1\}^{m-1}.
\]
For any vertex $v=v_1\cdots v_{m-1}\in V_m$ and any $b\in\{0,1\}$, define a directed edge
\[
e=(v,b):\ v\to v':=v_2\cdots v_{m-1}b,
\]
and label this edge by $\ell_m(e)\in X_m$:
\[
\ell_m(e):=\Fold_m(v_1\cdots v_{m-1}b)\in X_m.
\]
This yields a finite labeled graph $G_m=(V_m,E_m,\ell_m)$ with $|V_m|=2^{m-1}$ and $|E_m|=2^{m}$.
\end{definition}

\begin{theorem}[Explicit Sofic Representation and Computable Induced Structure]\label{thm:Phi_m-sofic-graph}
Let $Z_m\subset E_m^{\ZZ}$ be the two-sided edge shift (i.e., the two-sided path space) of the graph $G_m$, and let
\[
(\mathcal{L}_m(e))_t:=\ell_m(e_t)\in X_m
\]
be the sequence obtained by taking edge labels. Then
\[
Y_m=\mathcal{L}_m(Z_m),
\]
so $Y_m$ is a sofic subshift presented by $G_m$; moreover, $G_m$ provides an auditable finite-state induced structure: the states are length-$(m-1)$ input suffixes, the transitions consist of appending one bit, and the output is the stable type of the corresponding window under $\Fold_m$.
\end{theorem}

\begin{proof}
\textbf{(Inclusion $\subset$)} Given any input sequence $s\in\{0,1\}^{\ZZ}$, define
\[
v_t:=s_t s_{t+1}\cdots s_{t+m-2}\in V_m,\qquad
e_t:=(v_t,s_{t+m-1})\in E_m.
\]
Then $e=(e_t)_{t\in\ZZ}$ is a two-sided path on $G_m$ (because $v_{t+1}$ is precisely the update of $v_t$ by dropping the first bit and appending the last). Moreover, by the label definition,
\[
(\mathcal{L}_m(e))_t=\ell_m(e_t)=\Fold_m(s_t\cdots s_{t+m-1})=(\Phi_m(s))_t.
\]
Therefore $\Phi_m(s)\in \mathcal{L}_m(Z_m)$, i.e., $Y_m\subset \mathcal{L}_m(Z_m)$.

\textbf{(Inclusion $\supset$)} Conversely, take any two-sided path $e=(e_t)\in Z_m$. Each edge $e_t$ has the form $(v_t,b_t)$, and the path condition guarantees that $v_{t+1}$ equals the update of $v_t$ by dropping the first bit and appending the last. From this one can consistently construct a binary sequence $s\in\{0,1\}^{\ZZ}$: set $s_{t+m-1}:=b_t$, and use $v_t$ to supply the remaining $m-1$ bits of the window (path compatibility ensures this definition is non-contradictory). Then for this $s$,
\[
(\Phi_m(s))_t=\Fold_m(s_t\cdots s_{t+m-1})=\Fold_m(v_t b_t)=\ell_m(e_t)=(\mathcal{L}_m(e))_t.
\]
Therefore $\mathcal{L}_m(e)\in Y_m$, hence $\mathcal{L}_m(Z_m)\subset Y_m$. Both inclusions yield equality, completing the proof.
\end{proof}

\begin{remark}[On Markov Property and Computable Approximation]\label{rem:Phi_m-not-markov}
Theorem \ref{thm:Phi_m-sofic-graph} provides a \emph{topological/combinatorial} finite-state representation: all admissible sequences of $Y_m$ are characterized by a finite graph. However, for any input process (for example, the Sturmian sequence generated by the rotational scan in Section \ref{sec:experiments}), the pushforward measure $(\Phi_m)_*\mu$ on $Y_m$ is not necessarily a first-order Markov measure. If a numerical approximation of the ``induced transition structure'' is needed, one can estimate edge/state frequencies on the graph $G_m$ from long samples, thereby obtaining an auditable finite-state Markov approximation; this approximation aligns with the histogram/deviation metrics of Section \ref{sec:quant-fit}.
\end{remark}
