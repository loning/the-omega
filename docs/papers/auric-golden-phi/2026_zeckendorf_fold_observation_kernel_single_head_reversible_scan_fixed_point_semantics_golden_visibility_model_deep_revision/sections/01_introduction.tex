\section{引言}

有限分辨率观测的基本特征在于不可逆性：观测输出是对本体态的压缩与粗粒化；即便本体演化在信息意义上可逆，观测层仍可能呈现多值性、不可逆性、周期化伪像与边界效应。本文目标是在严格可审计的数学层面建立一条闭合逻辑链，使以下对象与命题能够在同一形式系统内被定义、证明与实验验证：
\begin{enumerate}
  \item \textbf{观测核：}将有限观测形式化为一个不可逆的规范化算子。
  \item \textbf{稳定可见态：}将“可见稳定结构”刻画为观测核的不动点集合。
  \item \textbf{不可见自由度（时间纤维）：}将观测核的非单射性严格对象化为纤维。
  \item \textbf{现实闭包与自指：}将“自洽现实”定义为闭包—演化合成算子的固定点。
  \item \textbf{可逆本体动力学：}构造可逆微观时间推进并展示其在投影下的宏观多值性。
\end{enumerate}

本文采取“定义—定理—证明—可复现实验—讨论”的组织结构。解释层（例如高维周期本体与低维投影）仅作为动机与对接，不反向进入定理层推导。
