\section{Symbolic Layer: Sturmian Systems, Return Words, and Ultimately Periodic Substitution Structure}

\subsection{Binary Window Encoding}

Define the observation
\[
\chi_E(x)=
\begin{cases}
1,&x\in E,\\
0,&x\notin E,
\end{cases}
\]
and define the coding sequence
\[
\omega(x)=\bigl(\chi_E(T_\theta^n x)\bigr)_{n\in\ZZ}\in\{0,1\}^{\ZZ}.
\]
Its closure yields a shift system $(\Omega,\sigma)$ with a pushforward measure.

\subsection{Sturmian Minimal Complexity and Return-Word Decomposition Under Induction}

When $E$ is an interval and $\theta$ is irrational, we obtain a Sturmian symbolic system whose complexity function satisfies
\[
p(n)=n+1.
\]
Induction to the window corresponds to a ``return-word'' decomposition of the language: the finiteness of return-time values corresponds to finite generation of the return-word set, and the continued-fraction instruction determines the return-word substitution rules.

\subsection{Ultimately Periodic Continued Fractions and Substitution Systems}

When $\theta$ is ultimately periodic, the instruction sequence is ultimately periodic, and the $S$-adic description eventually degenerates to periodic iteration of a finite substitution, and the symbolic system becomes a substitutive Sturmian. The golden parameter corresponds to a Fibonacci-type substitution, whose substitution matrix has principal eigenvalue $\varphi$, consistent with the scaling constant from Section 5.
