\paragraph{Center-wired encoding movie (gif).} \AuditTag A movie-like encoding visualization on the $m=6$ Hilbert screen: the global scan is a center-to-center Hilbert wiring (no crossings), and refined cells (between \texttt{101001} and \texttt{100101}) embed a micro Hilbert wiring on subcell centers, with same-$m$ wiring axis-aligned and cross-$m$ links drawn as shortest diagonals.
