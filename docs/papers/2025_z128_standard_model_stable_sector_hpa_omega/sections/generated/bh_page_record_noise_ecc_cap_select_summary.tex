\paragraph{CAP-selected redundancy for record-noise recovery (finite family).} \AuditTag For each noise budget $p$ and corruption model, we CAP-select the minimal repetition factor $r^\*(p)\\in\\{1,3,5,7\\}$ that reaches a target exact-recovery rate (here: $\\ge 0.95$) under the record-noise audit. This turns a robustness audit into a deterministic protocol choice over a finite family.
