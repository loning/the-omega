\section{Complexity--geometry dictionary}
\label{app:dictionary}

For convenience we collect the main identifications used throughout the paper.

\begin{enumerate}
    \item \textbf{Scan time.} $k\in\ZZ_{\ge 0}$, iteration count of the unitary scan $\Theta^k$.
    \item \textbf{Readout operator.} Window projection $\PiW$ producing binary readout bits $s_k\in\{0,1\}$.
    \item \textbf{Readout resolution.} Prefix length $N$ and canonical code length $m$ (Ostrowski digit depth; Zeckendorf in the golden branch).
    \item \textbf{Compilation time.} 1D nearest-neighbor circuit depth $\mathrm{depth}(C_R)$ implementing a local PQCA step on region $R$.
    \item \textbf{Routing overhead.} $\kappa(x)$, the overhead functional controlling depth under 1D embedding; computational lapse $\lapse(x)=\kappa_0/\kappa(x)$.
    \item \textbf{Workspace capacity.} $S_{\mathrm{QCA}}(R)=|R|\log d$ for local dimension $d$.
    \item \textbf{Undecidability pivot.} Local reachability predicate ``$\exists t:\Pi_K$ triggers'' is undecidable in a universal QCA.
\end{enumerate}
