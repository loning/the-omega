\section{复现与代码}

\subsection{内核 CA（计算 $(a+b)\bmod 64$ 的局域重写）}

文件约定：
\begin{itemize}
  \item 规则表：\verb|artifacts/fold64_ca_rules_phase90.json|
  \item 解释器（含全 $64^2$ 验证）：\verb|scripts/fold64_ca.py|
  \item 生成器（从轨迹提取相位规则表）：\verb|scripts/generate_fold64_ca_rules.py|
\end{itemize}

本地验证命令（在本目录下执行）：
\begin{verbatim}
python3 scripts/generate_fold64_ca_rules.py
python3 scripts/fold64_ca.py artifacts/fold64_ca_rules_phase90.json
\end{verbatim}
