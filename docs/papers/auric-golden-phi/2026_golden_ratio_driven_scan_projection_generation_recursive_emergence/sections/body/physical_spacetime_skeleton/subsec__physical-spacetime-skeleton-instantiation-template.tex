\subsection{数学实例化模板：哪些对象代入后才可能产生“物理型时空”}\label{subsec:physical-spacetime-skeleton-instantiation-template}

前几小节已经把物理型时空从 forcing 骨架内部逐步导出出来：观察者被还原为状态纤维，空间被还原为共同支撑、局部比较与区域共识，时间被还原为决定包络增长的投影，因果被还原为可容许精化链的偏序闭包，资源被还原为这些精化链上的方向化长度，而谱则被理解为闭环精化的边界不变量。到这里，一个更根本的问题便自然出现：究竟哪些数学对象，在被代入这套骨架之后，才有资格生成物理型时空？

这个问题的答案不能是任何足够复杂的结构都可以，因为前面各小节已经隐含给出了反例：一个裸集合没有局部性，一个单纯拓扑空间没有决定包络，一个纯群作用没有时间箭头，一个孤立范畴没有资源几何，一个单独的算子半群没有观察者纤维，一个纯数值系统没有区域共识。换言之，本章导出的物理型时空并不是某一种单一对象的别名，而是一类复合实例模板的输出：只有当一个对象同时提供局部状态、限制、拼接、更新、观察、资源与闭环可读性时，它才可能在本章意义下产生物理型时空。

因此，本小节的目标不是再引入一个新的对象类，而是给出一个实例化模板：任何数学对象若能被装配进这个模板，并满足若干最小条件，就会自动诱导出前几小节所建立的观察者—区域—时间—因果—资源—谱骨架；反之，若缺失其中任一关键部件，它就不能被读成物理型时空，最多只能提供其中一部分影子结构。

\subsubsection{物理型时空的实例化数据}

首先给出最小的数据模板。称一个九元组
\[
\mathfrak I=
(\mathcal U,\operatorname{Cov},\mathcal S,\rho,\mathcal O,\mathcal A,\mathcal T,\mathcal R,\mathcal K)
\]
为一个时空实例化数据，若满足以下解释：
\begin{enumerate}
  \item \(\mathcal U\) 是区域系统，\(\operatorname{Cov}\) 是其覆盖结构；
  \item \(\mathcal S(U)\) 是区域 \(U\) 上的局部状态、局部证书或局部表示空间；
  \item \(\rho^U_V:\mathcal S(U)\to \mathcal S(V)\) 是限制映射；
  \item \(\mathcal O\) 是观察族，用于把局部状态投影到可比较或可判定数据上；
  \item \(\mathcal A\) 是允许更新的原子动作族；
  \item \(\mathcal T\) 是更新生成的动态结构，例如半群、范畴、偏序或带分支更新图；
  \item \(\mathcal R\) 是资源赋值，用于给每一步更新、每一次同步、每一次拼接赋代价；
  \item \(\mathcal K\) 是闭环或谱接口，用于从时间迹或重返结构抽取谱不变量。
\end{enumerate}

在这一模板中，没有哪一个分量可以单独被称为时空；时空不是其中之一，而是它们共同满足某些条件后所涌现出的二阶结构。换言之，时空不是输入，而是输出。

为了使 \(\mathfrak I\) 真正产生前几小节的骨架，还必须满足一组最小条件。

\subsubsection{七条最小条件}

\paragraph{（I）局部性条件}
\((\mathcal U,\operatorname{Cov})\) 必须构成一个区域—覆盖系统。也就是说，必须存在局部—整体的语义区分，不能只给出一个全局对象。若没有覆盖与限制，便没有共同支撑、没有区域共识，也就没有空间的最小涌现。

\paragraph{（II）预层/层条件}
赋值
\[
U\longmapsto \mathcal S(U)
\]
连同限制映射 \(\rho^U_V\) 至少应构成一个预层；若要得到真正的区域共识与整体重构，则必须进一步满足层条件：兼容局部数据可唯一拼接为整体数据。若只满足预层而不满足层，则可以讨论局部可读，但不能保证全局对象存在；这正对应上一小节的 Čech 障碍与规范差现象。

\paragraph{（III）观察分离条件}
必须存在一族观察投影
\[
\pi_i^U:\mathcal S(U)\to \mathcal E_i(U),\qquad i\in I,
\]
或等价地，一族不可区分关系 \(\approx_i^U\)，使得局部状态可被观察者纤维化。若所有局部状态在观测上完全不可分，则无法定义信息视界，也无法从状态中导出观察者。因此，观察者不是额外对象，而是局部状态在观测投影下的等价类结构。

\paragraph{（IV）精化与更新条件}
必须存在一个更细关系 \(\sqsubseteq\) 或某种等价结构，使局部状态能够被部分排序；并且原子动作 \(\alpha\in\mathcal A\) 的更新必须满足
\[
q\in \operatorname{Upd}_\alpha(p)\Longrightarrow q\sqsubseteq p.
\]
也就是说，更新的本质是精化，而不是任意跳跃。若更新不带来可比较的精化链，则无法从中导出时间箭头，也无法区分新决定与状态替换。

\paragraph{（V）决定包络单调性条件}
必须存在某个可观测静态片段 \(\mathcal O_{\mathrm{stat}}\)，并定义相应的决定包络
\[
\operatorname{Dec}_{\mathcal O}(p),
\]
使得精化满足
\[
q\sqsubseteq p
\Longrightarrow
\operatorname{Dec}_{\mathcal O}(p)\subseteq \operatorname{Dec}_{\mathcal O}(q).
\]
这是时间涌现的关键：若决定包络不单调，则无法把时间解释成已决定静态理论的扩张投影。

\paragraph{（VI）资源可加条件}
必须存在资源函数，对每一步可容许更新赋值
\[
\mathsf c_\alpha(p\to q)\in [0,+\infty],
\]
并使有限链代价可加。否则，前面资源几何就无从建立；没有资源几何，时间、因果与空间就都只剩下纯顺序关系，而不会具有物理上关键的代价、可实现性与稳定性意义。

\paragraph{（VII）闭环可读条件}
必须存在某种把时间重返、循环更新、primitive 模式或相关迹压缩成谱数据的接口。具体形式可以是：一个传播算子 \(\mathsf T\)；一个区域传播核 \(\mathsf G\)；一族时间相关函数 \(\mathcal G_{f,g}(z)\)；一个 zeta 生成元；或更一般的闭环计数函子。若完全没有闭环或谱接口，则本章前面关于谱是闭环精化的边界不变量的结论无法实例化，因而也不能称之为完整的物理型时空，只能算作一个局部逻辑系统。

\subsubsection{物理型时空的充分实例化定理}

在以上条件下，可以把什么叫做产生物理型时空写成一个统一定理。

\paragraph{定理（物理型时空的实例化定理）}
设 \(\mathfrak I\) 是一组时空实例化数据，并满足上述七条条件。则由 \(\mathfrak I\) 可构造出一个物理型时空骨架
\[
\mathfrak S(\mathfrak I)=
(\mathcal O_{\mathrm{obs}},
\mathcal X_{\mathrm{em}},
T_{\mathrm{em}},
\preceq_c,
d_{\mathcal R},
\mathrm{Spec}),
\]
其中：
\begin{enumerate}
  \item \(\mathcal O_{\mathrm{obs}}\) 是由观察投影诱导的观察者纤维系统；
  \item \(\mathcal X_{\mathrm{em}}\) 是由共同支撑、局部比较与区域共识诱导的最小空间区域系统；
  \item \(T_{\mathrm{em}}\) 是由决定包络增长诱导的时间投影；
  \item \(\preceq_c\) 是由可容许精化链生成的因果偏序；
  \item \(d_{\mathcal R}\) 是由资源赋值生成的方向化准度规；
  \item \(\mathrm{Spec}\) 是由闭环接口诱导的谱—zeta—primitive 边界不变量。
\end{enumerate}
换言之，任何满足七条条件的对象，都不是表示一个时空，而是生成一个时空骨架。

\paragraph{说明}
该定理的重要点在于生成二字。它表明：本章所谓物理型时空不是某一类特殊对象，例如流形、图、自动机、算子代数或群作用的专有属性，而是许多不同对象在满足同一组结构条件后，共同导出的一个高层不变量。其证明也并不额外引入新机制，而只是把前面各小节已经构造出的观察者、区域、时间、因果、资源与谱结构逐项收集，并验证它们都可由 \(\mathfrak I\) 的七条条件统一诱导出来。也就是说，本章并不在意起点是离散、连续、代数、组合、范畴还是算子；本章只在意这些起点能否在局部—观测—精化—资源—谱五层上被统一装配。

\subsubsection{哪些对象不能直接产生物理型时空}

为了避免误解，还需要反过来说明：许多常见对象单独拿来其实并不够。

\paragraph{（1）仅有集合或拓扑空间不够}
一个裸集合没有局部比较与精化链；一个单纯拓扑空间虽然有开集，但若没有局部状态、限制映射与拼接规则，就无法产生对象层 forcing，更不可能导出观察者或时间。

\paragraph{（2）仅有偏序不够}
一个偏序集可以提供先后，但若没有观测与决定包络，它不能区分时间推进与形式更细；若没有支撑与覆盖，它也不能产生空间。

\paragraph{（3）仅有图或自动机不够}
图或自动机可以给出更新与循环，但若没有区域支撑与局部观测，它们只提供时间或谱的一半，而不能给出真正的空间涌现。

\paragraph{（4）仅有层不够}
层结构能够处理局部—整体拼接，但若没有更新与资源，它只能提供空间的静态骨架，不能导出时间、因果与代价。

\paragraph{（5）仅有算子半群不够}
算子半群能给出时间演化和谱，但若没有状态纤维、局部区域与共识结构，它更接近一套全局动力系统，而不是本章意义下的物理型时空。

这些负例非常重要，因为它们说明：物理型时空不是任何单个数学对象的自然别名，而是一个多层模板的综合输出。

\subsubsection{哪些对象适合代入模板}

与上述负例对应，下面几类对象最适合作为本章模板的输入。

\paragraph{（A）站点/层 + 更新系统}
若给定一个站点 \((\mathcal U,\operatorname{Cov})\)、其上的状态预层或状态层 \(\mathcal S\)，再给定局部更新与限制相容，则这是最标准的输入类型。它天然适合第 \ref{sec:recursive-addressing} 节的地址—局部截面—\(\mathsf{NULL}\) 结构。

\paragraph{（B）符号动力系统 + 局部观察投影}
若给定一个子移位、SFT 或可归一化词系统，再给定局部窗读出与 primitive/zeta 接口，则它非常适合代入时间—空间交换与谱层，特别适合第 \ref{sec:pom} 节与小节 \ref{subsec:physical-spacetime-skeleton-time-space-exchange} 的读法。

\paragraph{（C）重写系统 + 规范横截面}
若给定一个值保持重写系统、一个规范形选择算子以及局部可比接口，则它适合代入第 \ref{sec:emergent-arithmetic} 节值层与本章时间箭头、资源几何的框架。因为时间等于规范化的单调推进在这一类对象中最容易显现。

\paragraph{（D）算子系统/传播核 + 区域分解}
若给定传播算子 \(\mathsf T\) 及其区域分块 \(\mathsf G\)，并且局部观测足以重建 resolvent 或热核，则这类对象特别适合作为小节 \ref{subsec:physical-spacetime-skeleton-time-space-exchange} 的时间—空间交换模板。

\paragraph{（E）账本/寄存器扩张系统}
若对象额外携带附加坐标、素数寄存器、守恒账本或残差方向，但主可见层由投影决定，则它们正是保守扩张的自然例子，适合放到第 \ref{sec:emergent-arithmetic} 节外置账本与本章资源几何中理解。

因此，不同数学对象并非平等地像时空，而是只在它们进入这一模板之后，才在更高层同构地生成同类骨架。

\subsubsection{一个最简可检查清单}

为了让后文实际操作更方便，可以把实例化模板压缩成一张检查表。对任意候选对象 \(\mathcal M\)，只要依次问：
\begin{enumerate}
  \item 有没有局部区域系统 \((\mathcal U,\operatorname{Cov})\)；
  \item 有没有局部状态或局部证书空间 \(\mathcal S(U)\)；
  \item 有没有限制与拼接；
  \item 有没有观测投影或不可区分关系；
  \item 有没有可容许精化或更新链；
  \item 有没有决定包络的单调性；
  \item 有没有资源代价函数；
  \item 有没有闭环或谱接口。
\end{enumerate}

若前四项都没有，则它甚至不是局部逻辑对象；若前六项有而后两项没有，则它最多生成逻辑型时空，还不能生成物理型时空；只有八项齐备时，它才真正满足本章意义下的物理型时空模板。

这一检查表的好处是：后文任何具体技术对象，只要按这八项去对照，就能立刻判断它处在扩张链的什么层级上。这样，全文的各种对象就不会再显得彼此平行，而会自然落位。

\subsubsection{本节结论}

本小节最终回答了哪些对象代入后才可能产生物理型时空这个问题。答案不是某一类特殊对象，而是：任何对象，只要它能提供局部区域、局部状态、限制与拼接、观察投影、可容许精化、决定包络单调性、资源代价和闭环谱接口，就有资格生成本章意义下的物理型时空。

反过来，若缺少这些条件中的关键部分，它顶多生成局部逻辑、局部时间、局部空间或局部谱中的某一部分，而不能生成完整骨架。

于是，本小节真正完成的是：把前面小节 \ref{subsec:physical-spacetime-skeleton-observer-fiber} 到小节 \ref{subsec:physical-spacetime-skeleton-local-global-obstruction} 逐节导出的观察者、空间、时间、因果、资源与谱，再次反过来压缩成一个实例化模板。这样，第 \ref{sec:physical-spacetime-skeleton} 节就不只是解释性章节，而成为一个真正的实例筛选器：它告诉读者，什么样的数学对象值得被看成物理型时空的候选，什么样的对象又还差哪些层次。

到这里，第 \ref{sec:physical-spacetime-skeleton} 节已经只差最后一步：把前面所有推导压缩成一条总链，明确写出从第 \ref{sec:logic-expansion-chain} 节统一上位逻辑到本章物理骨架的全程路线图。
