\section{Cut--Projection Model Sets and Finite-Resolution Readout}\label{sec:cut-project-readout}

\subsection{Model Set (D3.1)}

Take a compact measurable window (acceptance domain)
\[
W\subset E_{\perp},
\]
and an internal phase (window shift) $u\in E_{\perp}$. Define the cut--projection point set
\[
\Lambda(W,u):=\left\{\pi_{\parallel}(n):n\in\mathcal{L},\ \pi_{\perp}(n)\in W+u\right\}\subset E_{\parallel}.
\]
If labeling is considered, then for $x=\pi_{\parallel}(n)\in\Lambda(W,u)$, define the induced labeling
\[
\Sigma_{u}(x):=\sigma(n),
\]
whose well-definedness is guaranteed by (H2.3).

\subsection{Kernel-Smeared Window and Complex Amplitude Readout (D3.2)}

The ideal window indicator function $\ind_{W+u}$ corresponds to sharp selection, which is difficult to characterize finite resolution. Take a kernel
\[
K_{\varepsilon}:E_{\perp}\to[0,\infty),\qquad \varepsilon>0,
\]
satisfying $\int_{E_{\perp}}K_{\varepsilon}(y)\,\dd y=1$, and as $\varepsilon\to 0$, $K_{\varepsilon}$ approaches a Dirac family. Take an amplitude mapping
\[
a:\mathcal{A}\to\CC.
\]
Define on $E_{\parallel}$ the complex measure (or distribution)
\[
\Psi_{\varepsilon,u}:=\sum_{n\in\mathcal{L}} a(\sigma(n))\,K_{\varepsilon}(\pi_{\perp}(n)-u)\,\delta_{\pi_{\parallel}(n)} .
\]
To avoid technical issues with the square of distributions, further introduce a point spread kernel $\phi_{\delta}$ in physical space ($\delta>0$) and define the smoothed field
\[
\psi_{\varepsilon,u}(x):=(\Psi_{\varepsilon,u}*\phi_{\delta})(x),
\]
with the corresponding intensity readout defined as
\[
I_{\varepsilon,u}(x):=\big|\psi_{\varepsilon,u}(x)\big|^{2}.
\]
This paper understands ``observational statistics'' as repeatable statistics induced by $I_{\varepsilon,u}$ or its sampling mechanism (e.g., correlation functions, power spectra, event counting, etc.).

\subsection{Structural Source of Coherent Superposition Terms (T3.3)}

For any fixed $x\in E_{\parallel}$, if $\psi_{\varepsilon,u}(x)$ can be written as a finite or controlled sum $\sum_{j}A_j(x)$, then
\[
I_{\varepsilon,u}(x)=\left|\sum_{j}A_j(x)\right|^{2}
=\sum_{j}|A_j(x)|^{2}+\sum_{j\neq k}A_j(x)\overline{A_k(x)}.
\]
Therefore, the existence of interference terms is determined by two classes of mechanisms:
\begin{itemize}
  \item Multiple projection contributions superpose within the support of the physical space kernel $\phi_{\delta}$;
  \item Multiple internal coordinates simultaneously acquire nonzero weight within the effective support of $K_{\varepsilon}$.
\end{itemize}
This conclusion belongs to the algebraic identity level (T) and does not depend on any semantic mapping.
