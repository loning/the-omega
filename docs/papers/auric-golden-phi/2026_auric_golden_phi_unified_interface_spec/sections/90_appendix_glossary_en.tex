\section{Appendix: Glossary (Cross-Paper Alignment)}

\begin{itemize}
  \item \textbf{Scan:} Iteration / translation of the base system (such as $T_a$) or reversible update $U$.
  \item \textbf{Readout:} Finite-resolution observation kernel $\rho$ (window / partition / projection), outputting binary or finite alphabet values.
  \item \textbf{Stabilization:} Mapping that normalizes the raw readout window to a stable language (typically the Zeckendorf/golden-mean folding $\Fold_m$).
  \item \textbf{Fiber:} Preimage of the stabilization kernel $\mathcal{F}_m(x)$, objectifying invisible degrees of freedom.
  \item \textbf{Information-Theoretic Time:} Exponential contraction rate of cylindric set posterior measure with history length; equals KS entropy rate under generating partition conditions (SMB).
  \item \textbf{Golden Branch:} Parameter choice using $\varphi$ or its related irrational slope (continued fraction tail periodicity) as an anti-resonance / self-similar fixed point.
\end{itemize}
