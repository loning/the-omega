\section{附录 C：Sturmian 机械词复杂度定理（证明提纲）}
\label{app:sturmian-outline}

\subsection{机械词的形式}

对无理旋转 $\theta_{t+1}=\theta_t+\alpha$ 与两区间分割 $\mathcal{P}$，$w_t$ 为机械词。其平衡性来自：两段长度相同的前缀中 $1$ 的计数差至多 $1$。

\subsection{\texorpdfstring{复杂度 $p(n)=n+1$}{复杂度 p(n)=n+1}}

对每个 $n$，考虑长度 $n$ 的因子集合。由无理旋转的轨道在 $\TT^1$ 上稠密性以及分割端点的“切割点”结构，可证明因子数恰为 $n+1$。关键点在于：长度 $n$ 的因子对应于起点相位落在由 $n$ 个切割点生成的分割区间中的哪一个，区间数为 $n+1$。
