\section{Notation and Preliminaries}\label{sec:preliminaries}

This section fixes only global notation, object hierarchies, and minimal interface assumptions for frequency statements. Unless explicitly stated, no new mathematical claim is introduced here.

\subsection{Conventions (separating proof chains from interpretive prose)}\label{subsec:writing-conventions}
The auditable proof chain of this paper consists only of numbered definitions/lemmas/theorems/propositions/corollaries and their proofs. Interpretive paragraphs are used only to locate semantic interfaces and motivations, and must not be used as premises in any subsequent deduction. Whenever external results are invoked, we cite sources and state applicability conditions and the exact form used.

\subsection{Basic notation and object hierarchy}
\begin{itemize}
  \item \textbf{Number systems and sets:} \(\NN,\ZZ,\QQ,\RR,\CC\) denote natural numbers, integers, rational numbers, real numbers, and complex numbers, respectively.
  \item \textbf{Time and iteration:} time is an iteration index \(t\in\ZZ\) (or \(t\in\NN\)); \(T^t\) denotes the \(t\)-th iterate of a single-generator action.
  \item \textbf{Readout and window:} given a phase space \(X\) and measurable window \(W\subseteq X\), binary readout is \(s_t(x)=\ind_W(T^t x)\in\{0,1\}\).
  \item \textbf{Window microstates:} the length-\(m\) window microstate space is \(\Omega_m=\{0,1\}^m\).
  \item \textbf{Stable syntax and folding:} the stable-word space is \(X_m\subseteq\Omega_m\), and folding \(\Fold_m:\Omega_m\to X_m\) is constructed in Section \ref{sec:folding} with auditable implementation.
\end{itemize}

\subsection{Terminology: stable concepts and stable types}
Stable concepts and stable types are separated by layer: a stable concept is a measurable event in the finite-window event \(\sigma\)-algebra (Definition \ref{def:stable-concept}); a stable type is an element of the folded symbolic space \(X_m\) (see Section \ref{sec:folding} for the construction via \(\Fold_m\)).

\subsection{Frequency-interface setup}\label{subsec:freq-setting}
Whenever ``limit frequencies/invariant states'' are used, we assume a probability space \((X,\mathcal{B},\mu)\), a measure-preserving map \(T\), and measurable window \(W\in\mathcal{B}\), generating readout \(s_t(x)=\ind_W(T^t x)\). If conclusions must be independent of initial conditions, we work under unique ergodicity with the boundary-zero condition \(\mu(\partial W)=0\) on indicator windows (see Remark \ref{rem:unique-ergodic-indicator}).

\subsection{Ergodicity, frequency, and stable concepts}\label{subsec:prelim-ergodic-frequency}
For any event \(A\in\mathcal{B}\) and initial point \(x\in X\), define orbit frequency by
\[
\mathrm{freq}_N(A;x)=\frac1N\sum_{t=0}^{N-1}\ind_A(T^t x).
\]
If \(T\) is ergodic, Birkhoff's ergodic theorem gives \(\mathrm{freq}_N(A;x)\to\mu(A)\) for \(\mu\)-almost every \(x\) (\cite{WaltersErgodicTheory}).

\begin{remark}[Indicators under unique ergodicity]\label{rem:unique-ergodic-indicator}
Under unique ergodicity, if \(\mu(\partial W)=0\), then indicator readout \(f=\ind_W\) also admits initial-point-independent frequency limits; see \cite{WaltersErgodicTheory}.
\end{remark}

Let \(\mathcal{F}_m\) be the \(\sigma\)-algebra generated by window events of length at most \(m\) (equivalently, by cylinder sets of \(\Omega_m\)).
\begin{definition}[Statistically stable concept]\label{def:stable-concept}
We call \(A\in\mathcal{F}_m\) a stable concept at resolution \(m\) if there exists \(p(A)\in[0,1]\) such that for almost every \(x\),
\[
\lim_{N\to\infty}\mathrm{freq}_N(A;x)=p(A).
\]
In uniquely ergodic settings, \(p(A)=\mu(A)\) and is independent of \(x\).
\end{definition}
