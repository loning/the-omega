\section{Recursive Addressing: Derived Concepts Generated by Old-Layer Readout Sequences}\label{sec:recursive-addressing}

This section treats a structural question within the standard measurable dynamical system \((X,\mathcal{B},\mu,T)\) and finite-time-window readout caliber: given a family of measurable concepts, how to recursively generate a finer concept family from their finite-time-window readouts, and whether this process introduces extraneous objects at the measurable structure level. The core conclusion is: recursive addressing does not expand the existing visible \(\sigma\)-algebra; the recursively generated cylinder event family still falls within the old-layer visible \(\sigma\)-algebra \(\mathcal{G}^{(L)}\) (Proposition \ref{prop:recursive-addressing-refinement}), so that the new layer merely reselects and reorganizes visible events within \(\mathcal{G}^{(L)}\) (Corollary \ref{cor:recursive-addressing-visible-sigma-nonexpansion}, hence \(\mathcal{G}^{(L+1)}\subseteq \mathcal{G}^{(L)}\)). In the symbolic cylinder set caliber, prefix refinement corresponds to contraction of prefix ultrametric balls; see Section \ref{sec:spg}, paragraph \ref{par:spg-prefix-ultrametric}.

\subsection{Composite Generation of Addresses}

Suppose that at level $L$ a concept family $\mathcal{C}^{(L)}=\{C^{(L)}_1,\dots,C^{(L)}_{r_L}\}$ has been obtained, where each $C^{(L)}_i\in\mathcal{B}$ is measurable. Define the derived binary vector process
\[
\mathbf{b}^{(L)}_t(x):=\bigl(\ind_{C^{(L)}_1}(T^t x),\dots,\ind_{C^{(L)}_{r_L}}(T^t x)\bigr)\in\{0,1\}^{r_L}.
\]
For any length $\ell$ and any address
\[
a=\bigl(a_0,\dots,a_{\ell-1}\bigr)\in\bigl(\{0,1\}^{r_L}\bigr)^\ell,
\]
define its corresponding derived cylinder event
\[
C^{(L+1)}_{a,t}:=\{x\in X:\mathbf{b}^{(L)}_t(x)=a_0,\dots,\mathbf{b}^{(L)}_{t+\ell-1}(x)=a_{\ell-1}\}\in\mathcal{B}.
\]
Let $\mathcal{C}^{(L+1)}$ be a selected family of such cylinder events (e.g., taking $C^{(L+1)}_{a,0}$ for a chosen finite address set $A^{(L+1)}$). This gives a closed recursion: \textbf{derived concepts are cylinder events of old-layer readout sequences}, so that addresses come solely from observable data rather than extraneous primitives.

\begin{proposition}[$\sigma$-algebra refinement: recursive addressing introduces no extraneous structure]\label{prop:recursive-addressing-refinement}
Let $\mathcal{G}^{(L)}$ be the $\sigma$-algebra generated by shifts of old-layer concepts within finite time windows:
\[
\mathcal{G}^{(L)}:=\sigma\bigl(T^{-t}C_i^{(L)}:\ 1\le i\le r_L,\ t\in\ZZ\bigr).
\]
Then for any address $a$ and any $t$, the derived cylinder event $C^{(L+1)}_{a,t}$ belongs to $\mathcal{G}^{(L)}$. Thus recursive addressing merely performs ``cylinder set closure/refinement of existing observable events'' and introduces no extraneous measurable sets.
\end{proposition}

\begin{proof}
For any fixed \(i\) and \(t\), the function \(x\mapsto \ind_{C_i^{(L)}}(T^t x)=\ind_{T^{-t}C_i^{(L)}}(x)\) is \(\mathcal{G}^{(L)}\)-measurable.
Therefore, for any given address \(a=(a_0,\dots,a_{\ell-1})\), the event
\[
\{x:\mathbf b^{(L)}_t(x)=a_0,\dots,\mathbf b^{(L)}_{t+\ell-1}(x)=a_{\ell-1}\}
\]
can be written as a finite intersection of sets \(T^{-s}C_i^{(L)}\) and their complements (over \(s=t,\dots,t+\ell-1\) and \(i=1,\dots,r_L\)), hence belongs to the \(\sigma\)-algebra generated by these sets, i.e., belongs to \(\mathcal{G}^{(L)}\). This completes the proof.
\end{proof}

\begin{corollary}[Visible \texorpdfstring{$\sigma$}{sigma}-algebra does not expand: recursive cylinder events only reorganize within inner layers]\label{cor:recursive-addressing-visible-sigma-nonexpansion}
Following the notation of Proposition \ref{prop:recursive-addressing-refinement}.
Suppose the new-layer concept family \(\mathcal{C}^{(L+1)}\) is selected from certain derived cylinder events \(C^{(L+1)}_{a,t}\), and let
\[
\mathcal{G}^{(L+1)}:=\sigma\bigl(T^{-t}C:\ C\in \mathcal{C}^{(L+1)},\ t\in\ZZ\bigr).
\]
Then
\[
\boxed{\ \mathcal{G}^{(L+1)}\subseteq \mathcal{G}^{(L)}\ }.
\]
Therefore, the recursively generated cylinder event family does not expand the existing visible \(\sigma\)-algebra, but merely reselects and reorganizes visible events within \(\mathcal{G}^{(L)}\).
\end{corollary}

\begin{proof}
By Proposition \ref{prop:recursive-addressing-refinement}, for any address \(a\) and any \(t\in\ZZ\), the derived cylinder event \(C^{(L+1)}_{a,t}\) belongs to \(\mathcal{G}^{(L)}\).
Let \(C\in\mathcal{C}^{(L+1)}\); by construction there exist \(a,t_0\) such that \(C=C^{(L+1)}_{a,t_0}\).
Then for any \(s\in\ZZ\), we have \(T^{-s}C=T^{-s}C^{(L+1)}_{a,t_0}=C^{(L+1)}_{a,t_0+s}\in\mathcal{G}^{(L)}\).
Therefore all generators of \(\mathcal{G}^{(L+1)}\) belong to \(\mathcal{G}^{(L)}\), and hence \(\mathcal{G}^{(L+1)}\subseteq \mathcal{G}^{(L)}\). This completes the proof.
\end{proof}

\subsection{Recursive Semantics from Null to Projection}

Consistent with the ``visible \texorpdfstring{$\sigma$}{sigma}-algebra does not expand'' conclusion of Corollary \ref{cor:recursive-addressing-visible-sigma-nonexpansion}, recursive addressing can be semantically expressed as a \emph{readable prefix} mechanism of ``address precedes value''. For any candidate address \(a\in A^{(L+1)}\), before the address object is given, no value is assigned to its derived concept: the readout is a partial function, undefined at that input, and its failure must not be misread as the numerical value \(0\); it is represented by the intrinsic null value \(\mathsf{NULL}\) according to the convention of this paper, meaning ``non-addressable/undefined''. Once the address \(a\) is selected, the concept value is given by the binary projection \(x\mapsto \ind_{C_a^{(L+1)}}(x)\). The level recursion thus satisfies:
\begin{itemize}
  \item ``No address $\Rightarrow$ null (undefined)'';
  \item ``Address given $\Rightarrow$ binary projection ($0/1$)'';
  \item ``Address $\Rightarrow$ generated from old-layer readout''.
\end{itemize}
In type semantics, this means: if the address object is not given (or does not belong to the protocol-allowed \(\mathcal{A}_{\mathrm{adm}}\)), then there exists no evaluation function \(\ind_{C_a}\) that can be referenced at the object level (equivalently, \(1_{C_a}\) cannot be constructed as a totally defined readout within the protocol's visible domain);
the readout partial function is then undefined at that input, and its semantic consequence is represented by the intrinsic null value \(\mathsf{NULL}\) (which will be endogenously characterized in \S\ref{subsec:prefix-site-null} as the local section obstruction \(\mathscr{F}(a)=\varnothing\)).
The null value described in this section is a \emph{semantic null} (address missing, readout undefined); the orthogonal \emph{protocol null} (type system locked to a unitary slice) and \emph{collision null} (insufficient side-information budget for unique reconstruction) are discussed in \S\ref{subsec:xi-pw-type-safety-null} and Proposition \ref{prop:xi-null-three-way}. Under a more unified caliber, the ``complete address'' can be packaged as a multi-axis prefix (Definition \ref{def:multi_axis_address}), where collision null corresponds to insufficient residual axes, and the minimum side-information budget is given by Theorem \ref{thm:address-defect-law}.
This semantics is compatible with Boolean algebra closure and can also be realized at the operator algebra level via projection operators and their products (see Appendix \ref{app:op-algebra}).

\subsection{Prefix Site and Local Sections: Intrinsic Characterization of \texorpdfstring{$\mathsf{NULL}$}{NULL}}\label{subsec:prefix-site-null}
This subsection provides a formalization strictly compatible with ``address precedes value'': the address space is viewed as a site (cylinder site) generated by prefix partial order, and ``protocol-acceptable and single-valued verifiable readout/certificates'' are organized as (pre)sheaf objects on it. Its purpose is not to introduce new measure-theoretic structures, but to promote null (\(\mathsf{NULL}\)) to a clear existence obstruction: \emph{at the given address, no protocol-allowed local section exists}, thereby avoiding the ambiguity of misreading ``undefined'' as the numerical value \(0\).

\begin{definition}[Prefix site and cylinder cover]\label{def:prefix-site}
For simplicity, we write only for the binary alphabet \(\Sigma=\{0,1\}\) (the construction is completely analogous for a general finite alphabet \(\Sigma\)). Let \(\mathcal{A}:=\Sigma^{<\infty}\) be the set of all finite addresses, endowed with partial order by the prefix relation \(a\preceq b\).
Let \(\mathcal{A}_{\mathrm{adm}}\subseteq\mathcal{A}\) be the set of protocol-allowed addresses (in the recursive construction of this section, its prototype can be taken as the finite address families \(A^{(L)}\) selected at each layer and their closure under refinement).
For any \(a\in\mathcal{A}_{\mathrm{adm}}\), let the cylinder event \(C_a\subseteq X\) be as defined in Section \ref{sec:spg} (i.e., \(C_a=\omega_\infty^{-1}([a])\), where \([a]\subseteq\Omega_\infty\) is the symbolic cylinder set).
\par
A finite family \(\{b_i\succeq a\}_{i=1}^n\subseteq\mathcal{A}_{\mathrm{adm}}\) is called a \textbf{cylinder cover} of \(a\) if \(C_a=\bigcup_{i=1}^{n} C_{b_i}\).
This covering relation is consistent with the prefix topology of paragraph \ref{par:spg-prefix-ultrametric}: the clopen basis of \(\Omega_\infty=\varprojlim \Omega_k\) is given by cylinder sets \([a]\), so ``prefix refinement'' and ``covering decomposition'' are two equivalent descriptions of the same object.
\end{definition}

\begin{definition}[Protocol-acceptable readout (pre)sheaf]\label{def:prefix-sheaf-readout}
Fix a ``visible domain + checker'' readout protocol, whose abstract caliber is given in Definition \ref{def:xi-visible-read-null} (here we only use its structure that ``readout can be a partial map, with \(\mathsf{NULL}\) representing undefined'').
For each \(a\in\mathcal{A}_{\mathrm{adm}}\), define the set
\[
\mathscr{F}(a):=\{\text{readout/certificate objects on cylinder event }C_a\text{ that are protocol-allowed and single-valued verifiable in the type sense}\},
\]
and for refinement \(b\succeq a\), define the restriction map
\(\rho_{a\leftarrow b}:\mathscr{F}(a)\to\mathscr{F}(b)\)
as restricting the readout/certificate to the sub-cylinder \(C_b\) (equivalently: conditioning on a deeper prefix at the event level).
\end{definition}

\begin{proposition}[Local section existence and \texorpdfstring{$\mathsf{NULL}$}{NULL}]\label{prop:null-as-local-section-obstruction}
Under the caliber of Definitions \ref{def:prefix-site}--\ref{def:prefix-sheaf-readout}, the ``address precedes value'' semantics can be equivalently stated as:
\[
\text{The readout at address }a\text{ is non-}\mathsf{NULL}\text{ at the type level}
\quad\Longleftrightarrow\quad
\mathscr{F}(a)\neq\varnothing.
\]
Moreover, under the recursive addressing closure caliber (Proposition \ref{prop:recursive-addressing-refinement}), \(\mathscr{F}\) satisfies gluing uniqueness for any finite cylinder cover: if \(\{b_i\succeq a\}\) covers \(a\), and a family of local objects \(s_i\in\mathscr{F}(b_i)\) are compatible on overlaps (i.e., their restrictions on any intersection \(C_{b_i}\cap C_{b_j}\) are consistent), then there exists a unique \(s\in\mathscr{F}(a)\) such that \(s|_{C_{b_i}}=s_i\).
\end{proposition}

\begin{proof}
The first equivalence merely reformulates ``undefined (\(\mathsf{NULL}\))'' from the numerical level to an existence assertion at the object level: for a readout/certificate to be verifiable, it requires that at the given address there is indeed a protocol-allowed local object available for reference; the readout is considered non-\(\mathsf{NULL}\) at the type level if and only if such a local object exists.
\par
For gluing uniqueness: the cylinder cover is a finite union decomposition, and cylinder events are closed under refinement (by definition); recursive addressing further guarantees that all derived objects still fall within the \(\sigma\)-algebra generated by existing observable cylinder events (Proposition \ref{prop:recursive-addressing-refinement}).
Therefore, if local objects are consistent on overlaps, their set-level gluing is given by union and is unique; protocol acceptability is preserved under restriction maps, so the glued object still belongs to \(\mathscr{F}(a)\) and satisfies uniqueness.
\end{proof}

\begin{corollary}[Three-way decomposition of \texorpdfstring{$\mathsf{NULL}$}{NULL} (local section obstruction version)]\label{cor:null-trichotomy-local-section}
Under the above site/(pre)sheaf formulation, the three sources of \(\mathsf{NULL}\) (Definition \ref{def:xi-visible-read-null} and Proposition \ref{prop:xi-null-three-way}) can be unified as three mutually non-confusable local section obstructions:
\begin{enumerate}
  \item \textbf{Semantic null:} \(a\notin\mathcal{A}_{\mathrm{adm}}\), i.e., the protocol does not provide that address object; at the site level, there is no object from which to take a section, and the null value is directly given by ``lack of reference''.
  \item \textbf{Protocol null:} \(a\in\mathcal{A}_{\mathrm{adm}}\) but the visible domain/type system refuses to establish a readout on \(C_a\) (typically: the visible domain is locked to a certain slice and refuses additional coordinate axes), so that \(\mathscr{F}(a)=\varnothing\).
  \item \textbf{Collision null:} \(a\in\mathcal{A}_{\mathrm{adm}}\) and passes the checker, but under the ``single-valued verifiable readout'' type convention, if the underlying readout has many-to-one compression without an externally placed residual axis to injectivize the extended readout, then in that type it is still equivalently expressed as \(\mathscr{F}(a)=\varnothing\); the minimum side-information budget is given by Proposition \ref{prop:xi-null-three-way} and Theorem \ref{thm:address-defect-law}.
\end{enumerate}
Therefore, ``\(\mathsf{NULL}\)'' is not a numerical property of a string but a structural vacancy of site objects and (pre)sheaf fibers in the protocol sense: legitimacy is determined by the non-emptiness of \(\mathscr{F}(a)\).
\end{corollary}

\paragraph{Cohomological caliber for gluing obstructions: \texorpdfstring{$H^2$}{H2} witness}
Proposition \ref{prop:null-as-local-section-obstruction} internalizes \(\mathsf{NULL}\) as the object-theoretic assertion that ``no local section exists''.
In the subsequent multi-axis prefix semantics (Definition \ref{def:multi_axis_address}) and protocol closure of this paper, local certificate objects often carry a set of \emph{adjustable but necessarily auditable} compatibility labels (e.g., equivalence classes of fiber automorphisms/gauge choices; one can take their abelianization as coefficients, see Definition \ref{def:fold-gauge-group}).
In this case, ``compatibility on overlaps'' is not merely set-theoretic equality but may also include a verifiable second-order consistency constraint; its failure can be characterized as a certificate via a second-order obstruction class in \v{C}ech cohomology.

\begin{definition}[Gluing obstruction class (\v{C}ech \texorpdfstring{$H^2$}{H2} caliber)]\label{def:prefix-site-h2-gluing-obstruction}
Let \(A\) be a coefficient abelian group.
Consider the above prefix site \(\mathcal{A}_{\mathrm{adm}}\) and its cylinder covers.
Suppose that under a certain protocol caliber, the compatibility of local certificate objects can be organized into a ``compatibility sheaf'' with \(A\)-fiber (e.g., \(A\)-torsor/local object with gauge), such that for any cover \(\{b_i\succeq a\}\) and any family of local objects \((s_i\in\mathscr{F}(b_i))\), their discrepancy on double overlaps can be recorded by a family of \(A\)-valued transition data \(g_{ij}\), inducing on triple overlaps a \v{C}ech \(2\)-cocycle
\[
\alpha_{ijk}:=g_{ij}+g_{jk}+g_{ki}\in A,
\qquad
\alpha\in Z^2(\{b_i\},A).
\]
The cohomology class \([\alpha]\in H^2(\{b_i\},A)\) (taking the limit under cover refinement) is called the \textbf{gluing obstruction class} at address \(a\): \([\alpha]=0\) means that the family \((s_i)\) can be made strictly compatible on overlaps by an allowed local gauge adjustment, thus satisfying gluability; \([\alpha]\neq 0\) means there exists a structural twist preventing globalization.
\end{definition}

\begin{proposition}[\texorpdfstring{$H^2$}{H2} gluing obstruction \(\Rightarrow\) \texorpdfstring{$\mathsf{NULL}$}{NULL}]\label{prop:null-as-h2-obstruction}
Under the setting of Definition \ref{def:prefix-site-h2-gluing-obstruction},
if a verifiable address \(a\in\mathcal{A}_{\mathrm{adm}}\) has gluing obstruction class \([\alpha]\neq 0\),
then no protocol-allowed global local section (certificate object) exists at that address, so that
\(
\mathscr{F}(a)=\varnothing
\)
and the readout at the type level must be \(\mathsf{NULL}\) (Proposition \ref{prop:null-as-local-section-obstruction}).
\end{proposition}

\begin{proof}
Assume for contradiction that \(\mathscr{F}(a)\neq\varnothing\); take any global object \(s\in\mathscr{F}(a)\) and restrict to the cover \(\{b_i\}\) to get \(s_i:=s|_{C_{b_i}}\in\mathscr{F}(b_i)\).
Then these restrictions are strictly compatible on any overlap; by Definition \ref{def:prefix-site-h2-gluing-obstruction}, the induced transition data can be taken as trivial (so that \(\alpha\) is a zero cocycle, \([\alpha]=0\)), contradicting \([\alpha]\neq 0\).
Hence \(\mathscr{F}(a)=\varnothing\), and consequently the readout is \(\mathsf{NULL}\).
This completes the proof.
\end{proof}
