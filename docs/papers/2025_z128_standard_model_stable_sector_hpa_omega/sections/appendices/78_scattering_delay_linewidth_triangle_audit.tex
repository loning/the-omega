\subsection{Triangle audit: phase$\to$delay proxy vs linewidth proxy (audit)}
\label{app:scattering_delay_linewidth_triangle_audit}

This appendix records a small triangle-style consistency audit that relates three interface objects already present in the manuscript:
scattering phase data, a phase-derivative delay proxy, and a coarse linewidth proxy.
It is audit-only and does not claim a unique resonance model.

\paragraph{Input and conventions.}
\AuditTag We reuse the vendored registry \texttt{data/k4\_matching/scattering\_phase\_registry.json}.
For datasets that include a coarse resonance metadata entry $(E_0,\gamma)$, we compute a phase-derived delay proxy
$\tau_{\mathrm{phase}}(E_0)\approx 2\,\mathrm{d}\delta/\mathrm{d}E$ (bounded local-linear window family) and compare it to the linewidth proxy $\tau_\gamma\approx 4/\gamma$ as recorded in the registry notes.
