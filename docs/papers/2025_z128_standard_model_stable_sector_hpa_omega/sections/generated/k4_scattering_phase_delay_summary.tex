For each dataset we compute a signed central-difference proxy series $\tau_i:=2\,\mathrm{d}\delta/\mathrm{d}x$ on interior points (where $x$ is the dataset abscissa) and report summary statistics (median/min/max and the negative fraction). We additionally report a bounded window family ($k=1,2,3$) using local linear fits to make discretization sensitivity explicit. For NN-OnLine np tables with $x=T_{\mathrm{lab}}$, we also report two transparent coordinate-transform hypotheses ($T_{\mathrm{lab}}\to E_{\mathrm{cm,kin}}^{(\mathrm{NR})}$ and $T_{\mathrm{lab}}\to E_{\mathrm{cm,kin}}^{(\mathrm{REL})}$) over the same bounded window family, without selecting one. When the coordinate change is monotone ($\mathrm{d}y/\mathrm{d}x>0$), the sign of $\mathrm{d}\delta/\mathrm{d}y$ must match the sign of $\mathrm{d}\delta/\mathrm{d}x$; the reported Jacobian ranges make this condition explicit. Unit conventions are deferred to the matching layer under explicit $P_{\mathrm{phys}}$ if needed.
