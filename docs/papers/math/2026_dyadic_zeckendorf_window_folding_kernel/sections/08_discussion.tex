
\section{讨论与开放问题}

\begin{enumerate}
\item \textbf{Dyadic 计数的误差尺度（已证与可加强方向）。}本文已证明（定理 \ref{thm:dyadic-C1-bound}）
$$
\abs{C_1(m)-p2^m}=O(F_{m+1}),
$$
从而也得到 $O(\varphi^m)$ 级别的误差控制。一个自然的加强方向是：识别 $E_m$ 的相位调制结构，并在更强意义上（例如给出显式上确界或极限分布）刻画误差项。
\item \textbf{识别相位调制函数。}研究 $\theta_m=\mathrm{frac}(m\log_\varphi 2)$ 下 $E_m$ 的调制规律（旋转编码与 Ostrowski digit sum 提供工具链）。
\item \textbf{换能器最小化。}将导出的确定/可变长 transducer 做自动机最小化，获得更紧凑的“最小 carry 状态机”。
\item \textbf{无限态极限与谱接口。}研究 $M_m$ 的极限行为与可能的 Fredholm 行列式极限；并探索与算法判别性/谱隙的接口。
\end{enumerate}
