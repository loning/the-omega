
\section{两相分块的重叠接口视角（3 比特拼接规则）}

两相分块使得相邻时间步的块在空间上以 $3$ 比特重叠。可将一步更新等价地理解为：由“左块的后 $3$ 位”和“右块的前 $3$ 位”拼成 $6$ 位 micro，再送入 $\Fold_6$。

更具体地，令当步 offset 为 $0$，则相邻块为
$$
(\underbrace{x_1x_2x_3x_4x_5x_6}_{\text{block }j})\ (\underbrace{y_1y_2y_3y_4y_5y_6}_{\text{block }j+1}).
$$
下一步 offset 为 $3$ 时，跨界窗口之一为
$$
x_4x_5x_6y_1y_2y_3,
$$
这说明逆向重建时会出现跨块一致性约束：同一比特位置必须同时满足相邻窗口的候选原像选择。

由于长度为 $3$ 的无相邻 $1$ 模式恰有 $5$ 个（$000,001,010,100,101$），因此可以把接口态视为一个 $5$ 元字母表，并把局部拼接与折叠诱导为有限大小的接口规则表。该视角为实现约束传播（剪枝）提供了自然的局部结构。
