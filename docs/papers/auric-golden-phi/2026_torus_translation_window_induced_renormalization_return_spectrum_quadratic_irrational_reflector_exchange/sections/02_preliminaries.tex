\section{预备：连分数、误差尺度、诱导与 IET}

\subsection{一维旋转与连分数记号}

取 $\theta\in(0,1)\setminus\QQ$，定义旋转
\[
T_\theta(x)=x+\theta \pmod 1,\qquad x\in\TT=\RR/\ZZ.
\]
设连分数 $\theta=[0;a_1,a_2,\dots]$，收敛分数为 $p_i/q_i$（取 $q_{-1}=0,q_0=1$）。定义到最近整数距离
\[
\lVert t\rVert=\min_{n\in\ZZ}|t-n|,
\]
并定义误差尺度
\[
\delta_i=\lVert q_i\theta\rVert.
\]
则存在整数 $p_i$ 使
\[
q_i\theta-p_i=(-1)^i\delta_i.
\]
误差尺度满足递推恒等式
\[
\delta_{i-1}=a_{i+1}\delta_i+\delta_{i+1}.
\]

\subsection{区间诱导与区间交换}

对区间 $E\subset\TT$，诱导映射 $T_{\theta,E}$ 为分段平移，故属于区间交换变换（IET）。当分段数为 $2$ 时称为 $2$-IET；$2$-IET 经过端点识别与线性共轭等价于圆周旋转。由此，“诱导仍为旋转”可用“返回时间仅两值”与“诱导为 $2$-IET”表述为等价性质。

\subsection{Kac 公式}

对遍历系统 $(X,\mu,T)$ 与 $\mu(E)>0$，首返时间满足
\[
\mathbb{E}_{\mu_E}[r_E]=\frac{1}{\mu(E)}.
\]
该公式将窗口测度与平均回归长度直接联系，用于自相似参数的统计刻画。
