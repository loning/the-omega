\section{可复现实验}\label{sec:experiments}

本节在 Zeckendorf 截断规范体系（定义 \ref{def:fold_zeckendorf} 与定义 \ref{def:zeckendorf_trellis}）下，以统一的编码对象与指标考察 \WL{} 信息传播、残余轨道与纤维统计随 $m$ 的变化。所有图表均由脚本生成，并以 \texttt{sections/generated/*.tex} 的形式供正文直接引用。

\subsection{指标}

在每个 $m$ 上，我们构造带颜色编码图并运行 $1$-\WL{}（颜色细化），记录：
\begin{itemize}
  \item \textbf{稳定深度}：\WL{} 达到稳定所需迭代次数；
  \item \textbf{解析时间}：微观层 $X_m$ 是否被完全分解（全部唯一色），以及达到该分解所需迭代次数；
  \item \textbf{残余规模}：稳定后微观层未分解点数、最大未分解类大小。
\end{itemize}
此外，我们统计折叠纤维大小分布作为“压缩后残余自由度”的直接刻画。
