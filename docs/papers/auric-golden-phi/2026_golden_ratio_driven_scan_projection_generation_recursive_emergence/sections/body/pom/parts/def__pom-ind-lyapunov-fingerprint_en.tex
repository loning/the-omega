
\begin{definition}[Lyapunov fingerprint constant (typical independent-set lower-bound exponent)]\label{def:pom-ind-lyapunov-fingerprint}
Let $\nu$ be a stationary ergodic probability distribution on the golden-mean shift $X\subset\{0,1\}^{\mathbb N}$.
For a $\nu$-typical infinite sequence $x=x_1x_2\cdots$, denote by $x_{1..m}$ its length-$m$ prefix, and construct the interference graph $G(x_{1..m})$ according to Definition \ref{def:pom-carry-interference-graph}.
If the limit exists, define
\[
\Lambda_{\mathsf{Ind}}(\nu):=\lim_{m\to\infty}\frac{1}{m}\log \#\mathsf{Ind}(G(x_{1..m})).
\]
\end{definition}

\begin{remark}[Random matrix product perspective]\label{rem:pom-ind-random-matrix}
Under the representations in Corollary \ref{cor:pom-fiber-lower-bound-cascade} and Proposition \ref{prop:pom-ind-matrix-grammar}, $\#\mathsf{Ind}(G(x_{1..m}))$ can be viewed as a composite object of ``block products + intra-block two-letter matrix words.''
Therefore, under any given stationary ergodic source, the block sequence and intra-block defect pattern induce a stationary matrix product process; its top Lyapunov exponent (rescaled by the ``block vertex density / original length density'') provides an auditable interpretation and numerical estimation route for the typical lower-bound exponent $\Lambda_{\mathsf{Ind}}$.
\end{remark}

\subsubsection{Component decomposition of fibers and independent-set polynomials: from counting to the full distribution}\label{subsec:pom-fiber-indset}
Under the confluent terminating local rewriting framework, once a stable type \(x\in X_m\) is fixed, every preimage \(\omega\in\Fold_m^{-1}(x)\) can be generated by applying a number of inverse substitutions \(100\mapsto 011\) to \(x\) (corresponding to the forward Fibonacci carry \(011\mapsto 100\)).
When two inverse substitutions occupy overlapping length-\(3\) local windows, a non-binary digit (\(2\)) appears in the intermediate configuration, so admissible choices must satisfy a ``no adjacent selection'' conflict constraint.
We now consolidate this mechanism into a fully discrete, auditable object: the independent-set system on an induced path graph.

\begin{definition}[Candidate sites, induced path graph, and fiber generating function]\label{def:pom-fiber-adm-path}
Fix a resolution \(m\ge 2\). Write
\[
k:=\lfloor m/2\rfloor,
\qquad
k_{+}:=k+\mathbf{1}_{\{m\ \mathrm{odd}\}}=\lceil m/2\rceil .
\]
When \(m\) is odd, the hidden-bit splitting from Lemma \ref{lem:pom-one-bit} manifests as an extra endpoint degree of freedom on the inverse substitution chain; the notation \(k_{+}\) uniformly accommodates this endpoint.
For \(x\in X_m\), let \(\mathsf{Adm}(x)\subseteq\{1,\dots,k_{+}\}\) be the set of candidate sites at which the inverse substitution \(100\mapsto 011\) \emph{can be executed} under the ``high-bit to low-bit'' execution order.
Admissible choices of candidate sites must satisfy the non-adjacency constraint (otherwise overlapping windows produce non-binary digits), which naturally induces a path-graph constraint.
Let \(P_{k_{+}}\) be the path graph on vertices \(1,\dots,k_{+}\), and define the induced subgraph
\[
\Gamma_x:=P_{k_{+}}[\mathsf{Adm}(x)].
\]
\par
For \(\omega\in\Fold_m^{-1}(x)\), let \(r(\omega)\) denote the number of inverse substitutions used to generate \(\omega\) from \(x\) (under the canonical bijection given in Theorem \ref{thm:pom-fiber-indset-factorization}, this equals the size of the chosen independent set).
Define the fiber inverse-substitution generating function
\[
Z_x(t):=\sum_{\omega\in \Fold_m^{-1}(x)} t^{r(\omega)}.
\]
For any \(\ell\ge 0\), define the independent-set polynomial of the path graph \(P_\ell\) as
\[
I_\ell(t):=\sum_{S\in\mathsf{Ind}(P_\ell)} t^{|S|}.
\]
\end{definition}

\begin{theorem}[Exact component decomposition of fibers: independent-set system and multiplicative factorization]\label{thm:pom-fiber-indset-factorization}
For any \(x\in X_m\), there exists a candidate site set \(\mathsf{Adm}(x)\) uniquely determined by \(x\) such that
\[
\Fold_m^{-1}(x)\ \cong\ \mathsf{Ind}(\Gamma_x),
\qquad
\Gamma_x=P_{k_{+}}[\mathsf{Adm}(x)],
\]
where \(\mathsf{Ind}(\Gamma_x)\) is the family of independent sets of \(\Gamma_x\).
Under this canonical isomorphism, the exponent \(r(\omega)\) equals the size of the corresponding independent set, so
\[
Z_x(t)=\sum_{S\in\mathsf{Ind}(\Gamma_x)} t^{|S|}.
\]
Furthermore, if the connected components of \(\Gamma_x\) are isomorphic to paths \(P_{\ell_1},\dots,P_{\ell_r}\), then the generating function and the count decompose strictly as
\[
Z_x(t)=\prod_{i=1}^r I_{\ell_i}(t),
\qquad
d_m(x):=|\Fold_m^{-1}(x)|=Z_x(1)=\prod_{i=1}^r F_{\ell_i+2}.
\]
\end{theorem}

\begin{proof}
Fix the deterministic normalization strategy \(\mathsf S\) adopted in Definition \ref{def:pom-fold-prime-lift}, and use its induced reverse playback framework to canonically enumerate the fiber.
Since the forward rewriting system is confluent and terminating (Proposition \ref{prop:fold-rewrite-newman}), for any \(\omega\in\Omega_m\) there exists a finite trajectory reducing \(\iota_m(\omega)\) to its unique normal form; reverse playback then yields a deterministic generation process ``from \(x=\Fold_m(\omega)\) to \(\omega\).''
\par
Under the binary input framework, the only discrete degrees of freedom that need to be recorded in this reverse generation process arise from the triggering choices of inverse substitutions \(100\mapsto 011\): if two triggers have overlapping local windows, a digit \(2\) appears in the intermediate playback state, losing the binary property; thus admissible choices must satisfy the non-adjacency constraint, equivalent to selecting independent sets on the path graph \(P_{k_{+}}\).
Let \(\mathsf{Adm}(x)\) be the set of candidate sites that \emph{can actually be triggered} under this canonical playback framework, then each preimage \(\omega\in\Fold_m^{-1}(x)\) corresponds bijectively to an independent-set choice \(S\in\mathsf{Ind}(\Gamma_x)\), and the number of inverse substitutions equals \(|S|\).
Hence \(Z_x(t)=\sum_{S\in\mathsf{Ind}(\Gamma_x)}t^{|S|}\).
\par
Finally, the connected components of \(\Gamma_x\) are mutually disconnected, so independent sets are chosen independently on each component, yielding the multiplicative factorization of the generating function;
since the number of independent sets of the path \(P_\ell\) is \(F_{\ell+2}\), we obtain \(d_m(x)=Z_x(1)=\prod_i F_{\ell_i+2}\). \qed
\end{proof}

\begin{theorem}[Closed-form coefficients of the path independent-set polynomial]\label{thm:pom-path-indset-poly-closed}
For any \(\ell\ge 0\),
\[
I_{\ell}(t)=\sum_{j=0}^{\lceil \ell/2\rceil}\binom{\ell+1-j}{j}\,t^j.
\]
Therefore, under the decomposition of Theorem \ref{thm:pom-fiber-indset-factorization}, the number of preimages in the fiber that use exactly \(j\) inverse substitutions is given by the convolution product of the component coefficients, so the full distribution of \(r(\omega)\) can be completely reconstructed in closed form.
\end{theorem}

\begin{proof}
An independent set of size \(j\) is equivalent to choosing \(1\le s_1<\cdots<s_j\le \ell\) with \(s_{a+1}-s_a\ge 2\).
Setting \(u_a:=s_a-(a-1)\) yields a strictly increasing sequence \(1\le u_1<\cdots<u_j\le \ell+1-j\); the converse also holds.
Hence the number of independent sets of size \(j\) is \(\binom{\ell+1-j}{j}\), and summing over \(j\) yields the conclusion. \qed
\end{proof}

\begin{lemma}[Fibonacci fusion identity and strict submultiplicativity]\label{lem:pom-fib-fusion-submultiplicativity}
Adopt the Fibonacci extension \(F_0=0,F_1=1\).
For any integers \(a,b\ge 1\), the addition identity holds:
\[
F_{a+b-1}=F_aF_b+F_{a-1}F_{b-1}.
\]
In particular, when \((a,b)\neq(1,1)\),
\[
F_aF_b< F_{a+b-1}<F_{a+b}.
\]
\end{lemma}
\begin{proof}
From the standard addition formula \(F_{n+m}=F_nF_{m+1}+F_{n-1}F_m\) (derivable by matrix powers or induction), setting \(n=a\), \(m=b-1\) yields the first identity.
When \((a,b)\neq(1,1)\), we have \(F_{a-1}F_{b-1}>0\), so \(F_{a+b-1}>F_aF_b\).
Since \(F_{a+b}=F_{a+b-1}+F_{a+b-2}\) and \(F_{a+b-2}\ge 1\), we get \(F_{a+b}>F_{a+b-1}\). \qed
\end{proof}

\begin{corollary}[Component fusion gain for Fibonacci products (minimal bridging)]\label{cor:pom-fib-component-fusion-gain}
For any integers \(\ell,\ell'\ge 1\), the strict inequality holds:
\[
F_{\ell+2}F_{\ell'+2}<F_{\ell+\ell'+3},
\]
and the increment satisfies the closed form
\[
F_{\ell+\ell'+3}-F_{\ell+2}F_{\ell'+2}=F_{\ell+1}F_{\ell'+1}\ge F_{\min\{\ell,\ell'\}+1}.
\]
Under the component multiplicative decomposition of Theorem \ref{thm:pom-fiber-indset-factorization}, the above inequality can be interpreted as follows: if two path components \(P_{\ell}\) and \(P_{\ell'}\) can be joined into a longer path by filling in a bridging site, then the corresponding fiber cardinality strictly increases under this local joining operation, with the gain controlled from below by the Fibonacci tail term of the shorter component.
\end{corollary}

\subsubsection{Signed index of fibers and the \texorpdfstring{$\bmod 3$}{mod 3} obstruction}\label{subsec:pom-fiber-signed-index}
Under the independent-set model of Theorem \ref{thm:pom-fiber-indset-factorization}, the ``inverse substitution count spectrum'' within each fiber is not only countable but also naturally induces a signed index whose values are extremely rigid (the value of the independent-set polynomial at \(t=-1\)).

\begin{definition}[Signed index of a fiber]\label{def:pom-fiber-signed-index}
For any \(x\in X_m\), define its fiber signed index as
\[
\mathfrak{s}_m(x):=Z_x(-1)=\sum_{\omega\in\Fold_m^{-1}(x)}(-1)^{r(\omega)}.
\]
Under the isomorphism of Theorem \ref{thm:pom-fiber-indset-factorization}, \(\mathfrak{s}_m(x)\) is equivalent to the evaluation of the independent-set polynomial of the induced graph \(\Gamma_x\) at \(t=-1\).
\end{definition}

\begin{theorem}[Component-level periodicity law and vanishing criterion]\label{thm:pom-fiber-signed-index-periodicity}
Let \(J_\ell:=I_\ell(-1)\) (\(\ell\ge 0\)). Then \((J_\ell)_{\ell\ge 0}\) is a period-\(6\) sequence, and
\[
(J_\ell)_{\ell=0}^{\infty}=(1,0,-1,-1,0,1,1,0,-1,-1,0,1,\dots),
\qquad
J_\ell=0\ \Longleftrightarrow\ \ell\equiv 1\ (\mathrm{mod}\ 3).
\]
Therefore, if the connected components of \(\Gamma_x\) are isomorphic to paths \(P_{\ell_1},\dots,P_{\ell_r}\), then
\[
\mathfrak{s}_m(x)=Z_x(-1)=\prod_{i=1}^r J_{\ell_i}\ \in\ \{0,\pm 1\},
\]
and
\[
\mathfrak{s}_m(x)=0
\quad\Longleftrightarrow\quad
\exists\,i,\ \ell_i\equiv 1\ (\mathrm{mod}\ 3).
\]
\end{theorem}

\begin{proof}
The path independent-set polynomial satisfies the recurrence
\(
I_\ell(t)=I_{\ell-1}(t)+t\,I_{\ell-2}(t)
\)
(by classifying whether the terminal vertex is selected), with initial values \(I_0(t)=1\), \(I_1(t)=1+t\).
Substituting \(t=-1\) yields
\[
J_0=1,\qquad J_1=0,\qquad J_\ell=J_{\ell-1}-J_{\ell-2}\quad(\ell\ge 2).
\]
Direct computation of the first six terms from this linear recurrence gives
\(
J_0=1,J_1=0,J_2=-1,J_3=-1,J_4=0,J_5=1
\), and the recurrence implies \(J_{\ell+6}=J_\ell\) (verifiable by induction for any \(\ell\)), so the sequence has period \(6\).
Similarly, the zeros occur precisely at \(\ell\equiv 1\pmod 3\).
\par
Finally, from the multiplicative decomposition of Theorem \ref{thm:pom-fiber-indset-factorization},
\(
Z_x(t)=\prod_i I_{\ell_i}(t)
\),
setting \(t=-1\) yields \(\mathfrak{s}_m(x)=\prod_i J_{\ell_i}\), together with the value set and vanishing criterion. \qed
\end{proof}

\begin{corollary}[\texorpdfstring{$\bmod 3$}{mod 3} phase obstruction: determined by component lengths]\label{cor:pom-fiber-signed-index-mod3}
The component lengths \((\ell_i)\) of \(\Gamma_x\) induce an auditable obstruction class: whether any \(\ell_i\equiv 1\pmod 3\) exists determines the vanishing of \(\mathfrak{s}_m(x)\).
When \(\mathfrak{s}_m(x)\neq 0\), its sign is completely determined by the positions of the \(\ell_i\) in the above period-\(6\) table, so \(\mathfrak{s}_m(x)\) depends only on the component structure of the candidate site graph \(\Gamma_x\) and not on any external interpretive layer.
\end{corollary}

\begin{corollary}[Parity criterion for fiber cardinality: \texorpdfstring{$\bmod 2$}{mod 2} is completely determined by the \texorpdfstring{$\bmod 3$}{mod 3} class of component lengths]\label{cor:pom-fiber-parity-mod3}
Suppose \(\Gamma_x\cong\bigsqcup_i P_{\ell_i}\), and write
\(
d_m(x)=\card{\Fold_m^{-1}(x)}=\prod_i F_{\ell_i+2}
\)
(Theorem \ref{thm:pom-fiber-indset-factorization}).
Then
\[
d_m(x)\equiv 1\pmod 2
\quad\Longleftrightarrow\quad
\forall i,\ \ell_i\not\equiv 1\pmod 3,
\]
equivalently
\[
d_m(x)\equiv 0\pmod 2
\quad\Longleftrightarrow\quad
\exists i,\ \ell_i\equiv 1\pmod 3.
\]
\end{corollary}
\begin{proof}
The Fibonacci sequence modulo \(2\) has Pisano period \(3\), and
\(
F_n\equiv 0\pmod 2\iff n\equiv 0\pmod 3
\).
Therefore
\(
F_{\ell_i+2}\equiv 0\pmod 2\iff \ell_i+2\equiv 0\pmod 3\iff \ell_i\equiv 1\pmod 3
\).
From the product expression \(d_m(x)=\prod_i F_{\ell_i+2}\), \(d_m(x)\) is odd if and only if all factors are odd, i.e., \(\ell_i\not\equiv 1\pmod 3\) for all \(i\). \qed
\end{proof}

\subsubsection{Closed form of the maximum fiber and top-level spectral gap}\label{subsec:pom-top-fiber}
\begin{theorem}[Closed form of the maximum fiber]\label{thm:pom-max-fiber}
Adopt the Fibonacci extension $F_0=0,F_1=1$. For $m\ge 2$, the exact closed forms are
\[
D_{2k}=F_{k+2},
\qquad
D_{2k+1}=F_{k+2}+F_{k-1}\ (=2F_{k+1}).
\]
Therefore
\[
D_m\sim C'\,\varphi^{m/2},
\]
i.e., the maximum fiber growth rate is $\sqrt{\varphi}$. In particular, there exist constants $C_1,C_2>0$ such that
\[
C_1\,\varphi^{m/2}\ \le\ D_m\ \le\ C_2\,\varphi^{m/2}.
\]
\end{theorem}
\begin{proof}
For the folding normalization of $\{0,1\}^m$, the only local rewrite that can be triggered is
\(
011\mapsto 100
\)
(Fibonacci carry). Confluence implies that the normal form of each $\omega$ is unique, so for a fixed $x\in X_m$, $\omega\in\Fold_m^{-1}(x)$ if and only if $x$ can generate $\omega$ through a number of inverse substitutions $100\mapsto 011$. Each inverse substitution occupies a length-$3$ local window; if the starting points of two inverse substitutions are at distance $1$ or $2$, the overlapping windows produce a $2$ at some position, so the selectable sites must satisfy the ``no adjacent selection'' constraint. Setting $k=\lfloor m/2\rfloor$ and viewing the selectable sites as a path graph $P_k$ of length $k$, denote its independent-set count by $I_k$. Then
\[
I_0=1,\qquad I_1=2,\qquad I_k=I_{k-1}+I_{k-2}\ (k\ge 2),
\qquad I_k=F_{k+2}.
\]
Thus for any $x\in X_m$, $d_m(x)\le I_k$. When $m=2k+1$ is odd, by the overflow bit $b\in\{0,1\}$ from Lemma \ref{lem:pom-one-bit}, the fiber splits into two branches; fixing $b$ freezes one top candidate site, reducing the selectable chain length to $k-1$, so
\[
d_m(x)\le 2I_{k-1}=2F_{k+1}.
\]

We now construct a family achieving the upper bound. For $m=2,3$, take
\(
x^{(2)}=00,\ x^{(3)}=000
\); for other cases, write $m=4q+r$ ($r\in\{0,1,2,3\}$) and define
\[
x^{(m)}=
\begin{cases}
(0001)^{\,q-1}0000,& r=0,\ q\ge 1,\\[2pt]
(0001)^{\,q-1}00100,& r=1,\ q\ge 1,\\[2pt]
(0001)^{\,q}00,& r=2,\ q\ge 0,\\[2pt]
(0001)^{\,q-1}0000100,& r=3,\ q\ge 1.
\end{cases}
\]
This family satisfies $x^{(m)}\in X_m$, and the local zero blocks are sufficient to ensure that for any non-adjacent site subset $J\subseteq\{1,\dots,k\}$ (or $\{1,\dots,k-1\}$ for odd $m$), executing inverse substitutions from high bit to low bit, the required $100$ pattern is realizable at each step, yielding a unique $\omega\in\Fold_m^{-1}(x^{(m)})$. Therefore
\[
d_{2k}(x^{(2k)})=I_k=F_{k+2},
\qquad
d_{2k+1}(x^{(2k+1)})=2I_{k-1}=2F_{k+1}.
\]
The achievability of the upper bound gives the closed form for $D_m$; the asymptotic formula and constant bounds follow directly from the Fibonacci asymptotic $F_n\sim \varphi^n/\sqrt5$. \qed
\end{proof}

\begin{corollary}[Maximum fiber probability endpoint and auditable limit constant]\label{cor:pom-max-fiber-rate-endpoint}
Let \(w_m(x):=d_m(x)/2^m\) be the fold pushforward of the uniform microstate, and define the maximum fiber probability
\[
p_{\max}(m):=\max_{x\in X_m}w_m(x)=\frac{D_m}{2^m}.
\]
Then by the closed forms of Theorem \ref{thm:pom-max-fiber}, we have the explicit expressions
\[
p_{\max}(2k)=\frac{F_{k+2}}{2^{2k}},
\qquad
p_{\max}(2k+1)=\frac{2F_{k+1}}{2^{2k+1}}=\frac{F_{k+1}}{2^{2k}}.
\]
Moreover, the maximum fiber rate (equivalently the min-entropy endpoint rate)
\[
h_{\max}(m):=-\frac{1}{m}\log p_{\max}(m)
\]
converges to a closed-form constant:
\[
\boxed{\;
\lim_{m\to\infty}h_{\max}(m)=\log\!\left(\frac{2}{\sqrt{\varphi}}\right)\; }.
\]
This constant also serves as the auditable anchor point for the normalized endpoint of the higher-order R\'enyi fingerprint (see Proposition \ref{prop:pom-rq-qinfty-endpoint} where \(\lim_{q\to\infty}h_q^{\mathrm R}=\log(2/\sqrt{\varphi})\)).
\end{corollary}
\begin{proof}
From the even/odd closed forms above and the Binet asymptotic \(F_n\asymp \varphi^n\), we obtain
\[
-\frac{1}{2k}\log p_{\max}(2k)
=-\frac{1}{2k}\Bigl(\log F_{k+2}-2k\log 2\Bigr)
\longrightarrow \log 2-\frac12\log\varphi,
\]
and the odd branch is analogous, so the limit is \(\log(2/\sqrt{\varphi})\). \qed
\end{proof}

\begin{corollary}[Two-step recurrence and base values]\label{cor:pom-D-rec}
$D_m$ satisfies
\[
D_m=D_{m-2}+D_{m-4}\qquad(m\ge 6),
\]
with base values
\[
D_2=2,\quad D_3=2,\quad D_4=3,\quad D_5=4.
\]
\end{corollary}
\begin{proof}
From the closed forms of Theorem \ref{thm:pom-max-fiber}, $D_{2k}=F_{k+2}$ and $D_{2k+1}=2F_{k+1}$, and the Fibonacci numbers satisfy $F_{k+2}=F_{k+1}+F_k$. Substituting $m=2k$ and $m=2k+1$ respectively yields the recurrence; the base values are obtained by direct enumeration or substitution into the closed forms. \qed
\end{proof}

\begin{remark}[Generating function of the maximum fiber sequence and four-periodic subdominant oscillation]\label{rem:pom-D-generating-function}
To express the two-step recurrence as a unified linear recurrence, adopt the convention \(D_0:=1,D_1:=2\) (so that \((D_2,D_3,D_4,D_5)=(2,2,3,4)\) is compatible with Corollary \ref{cor:pom-D-rec}), then
\[
D_m=D_{m-2}+D_{m-4}\qquad(m\ge 4).
\]
Its characteristic polynomial is \(r^{4}-r^{2}-1\), with four characteristic roots \(\pm\sqrt{\varphi}\) and \(\pm i/\sqrt{\varphi}\).
The corresponding generating function is the strictly rational expression
\[
\sum_{m\ge 0} D_m\,z^m=\frac{1+2z+z^{2}}{1-z^{2}-z^{4}}.
\]
The radius of convergence is therefore \(1/\sqrt{\varphi}\) and the dominant growth rate is \(\sqrt{\varphi}\); the subdominant characteristic roots \(\pm i/\sqrt{\varphi}\) produce a period-\(4\) phase correction (controlled by \(i^m\)) of amplitude \(O(\varphi^{-m/2})\).
Equivalently, there exist constants \(A_\pm\) such that
\[
D_m=A_+(\sqrt{\varphi})^{m}+A_-(-\sqrt{\varphi})^{m}+O(\varphi^{-m/2}).
\]
\end{remark}

\begin{remark}[Bit quantization of the worst-case projection gap]\label{rem:pom-D-delay}
Viewing ``distinguishing microstates within a fiber'' as additional information that must be carried, the worst-case gap can be measured by
\[
\Delta_m^{\max}:=\left\lceil \log_2 D_m\right\rceil.
\]
By Theorem \ref{thm:pom-max-fiber},
\(
\Delta_m^{\max}\sim \frac{m}{2}\log_2\varphi
\), which provides a ``non-parallelizable information gap'' scale that grows linearly with the resolution $m$.
\end{remark}

\begin{remark}[One-bit overflow and the structural origin of the two-step recurrence]\label{rem:pom-overflow-rec}
By Lemma \ref{lem:pom-one-bit}, each fiber splits into only two branches $b=0,1$; and $b=1$ requires the last position to satisfy the zero-adjacency constraint. Combined with the ``no adjacent selection chain'' of local inverse substitutions, the maximum fiber count is equivalent to counting independent sets on a chain with step size $2$, which structurally explains the two-step recurrence $D_m=D_{m-2}+D_{m-4}$.
\end{remark}

Moreover, under two natural sampling measures---type-uniform \(U_m\) and microstate-uniform pushforward \(w_m\)---the hit rates of this extremal family yield two distinct exponential thinning rates (Corollary \ref{cor:pom-maxfiber-rarity-two-measures}).
The same table also provides the second-largest multiplicity \(D_m^{(2)}\) and the third-largest multiplicity \(D_m^{(3)}\) (Definition \ref{def:pom-top-fiber-spectrum}), as well as the even/odd alternation of the ratio \(D_m^{(2)}/D_m\). The following Theorem \ref{thm:pom-max-achievers-phase-stabilization}, Theorem \ref{thm:pom-second-max-fiber-closed-form}, and Theorem \ref{thm:pom-third-max-fiber-even-closed-form} provide the analytic sealing of the phase count and the top-level spectral gap (along with the explicit worst-case constant \(\theta_{\mathrm{gap}}\), see Corollary \ref{cor:pom-second-max-gap-constant}).
\end{remark}

\begin{theorem}[Stabilization of the phase count of maximum fiber achievers]\label{thm:pom-max-achievers-phase-stabilization}
For all sufficiently large \(m\), the maximum fiber achiever count \(\kappa_m^{\mathrm{max}}\) stabilizes to a constant phase count:
\[
\kappa_{2k}^{\mathrm{max}}=2\quad(k\ge 5),
\qquad
\kappa_{2k+1}^{\mathrm{max}}=4\quad(k\ge 6).
\]
Equivalently (threshold version):
\[
m\ge 10\ \text{and}\ m\ \text{even}\ \Rightarrow\ \kappa_m^{\mathrm{max}}=2,
\qquad
m\ge 13\ \text{and}\ m\ \text{odd}\ \Rightarrow\ \kappa_m^{\mathrm{max}}=4.
\]
\end{theorem}
\begin{proof}
From the proof of Theorem \ref{thm:pom-max-fiber}: a necessary condition for achieving the maximum fiber \(D_m\) is that ``the inverse substitution candidate site chain is fully utilized,'' i.e., on the candidate chain of length \(k=\lfloor m/2\rfloor\), every independent set must be realizable and yield distinct preimages; this forces the normal form \(x\in X_m\) to have a near-periodic kernel (see the \((0001)\) truncation family constructed in Theorem \ref{thm:pom-max-fiber}), and the endpoint constraints allow only finitely many phases.
The even endpoint constraint retains exactly two phases; the odd case additionally superimposes the hidden-bit splitting \(b\in\{0,1\}\) from Lemma \ref{lem:pom-one-bit}, thereby doubling the phase count to four. The above phase counts and the representative words of the achievers can be directly verified in Table \ref{tab:fold_max_fiber_achievers_phase} (the auditable window \(m\le 32\)).
\end{proof}

\begin{remark}[Induced graph structure characterization of the maximum achievers (stability threshold)]\label{rem:pom-max-achievers-graph-structure}
Under the induced graph representation \(\Gamma_x\cong\bigsqcup_i P_{\ell_i}\) of Theorem \ref{thm:pom-fiber-indset-factorization}, the fiber count is \(d_m(x)=\prod_i F_{\ell_i+2}\), so ``achieving the maximum fiber'' can be viewed as a purely combinatorial structural constraint.
Denote the maximum achiever set
\[
\mathcal{M}_m:=\{x\in X_m:\ d_m(x)=D_m\}.
\]
On the stability threshold interval (Theorem \ref{thm:pom-max-achievers-phase-stabilization}), the reversible site structure of the achievers rigidifies further into a unique type:
\[
m=2k\ \Rightarrow\ x\in\mathcal{M}_m\iff \Gamma_x\cong P_k,
\qquad
m=2k+1\ \Rightarrow\ x\in\mathcal{M}_m\iff \Gamma_x\cong P_{k-1}\sqcup P_1.
\]
Moreover, the achiever set is closed under the reversal involution \(\mathrm{rev}\).
Consequently, \(|\mathcal{M}_m|\) is sealed within this interval by the finite phase count to \(2\) (even) or \(4\) (odd), consistent with the finite-window audit of Table \ref{tab:fold_max_fiber_achievers_phase}.
\end{remark}

\begin{corollary}[Exponential thinning rates of maximum fiber achievers under two natural measures]\label{cor:pom-maxfiber-rarity-two-measures}
Let
\[
\mathcal{M}_m:=\{x\in X_m:\ d_m(x)=D_m\},
\qquad
U_m:=\mathrm{Unif}(X_m),
\qquad
w_m(x):=\frac{d_m(x)}{2^m}\ \ (x\in X_m).
\]
Then we have two \emph{exact} hit-rate formulas:
\[
U_m(\mathcal{M}_m)=\frac{\kappa_m^{\mathrm{max}}}{|X_m|}
=\frac{\kappa_m^{\mathrm{max}}}{F_{m+2}},
\qquad
w_m(\mathcal{M}_m)=\sum_{x\in\mathcal{M}_m}\frac{d_m(x)}{2^m}
=\frac{\kappa_m^{\mathrm{max}}\,D_m}{2^m}.
\]
Moreover, on the stability threshold interval (Theorem \ref{thm:pom-max-achievers-phase-stabilization} gives \(\kappa_m^{\mathrm{max}}\in\{2,4\}\)), the two quantities satisfy exponential-scale asymptotics:
\[
U_m(\mathcal{M}_m)=\Theta(\varphi^{-m}),
\qquad
w_m(\mathcal{M}_m)=\Theta\!\left(\left(\frac{\sqrt{\varphi}}{2}\right)^m\right).
\]
\end{corollary}
\begin{proof}
The first identity follows from the counting identity \(U_m(\mathcal{M}_m)=|\mathcal{M}_m|/|X_m|\) and \(|X_m|=F_{m+2}\); the second identity follows from the definition of \(w_m\) and the fact that \(d_m(x)\equiv D_m\) on \(\mathcal{M}_m\).
\par
For the asymptotics, \(F_{m+2}=\Theta(\varphi^m)\) (Binet formula), and by Theorem \ref{thm:pom-max-fiber}, \(D_m=\Theta(\varphi^{m/2})\); combined with \(\kappa_m^{\mathrm{max}}=O(1)\) from Theorem \ref{thm:pom-max-achievers-phase-stabilization}, the two exponential rates are obtained.
\end{proof}

\begin{lemma}[Fibonacci gap from forbidden pairs]\label{lem:pom-forbidden-pair-fib-gap}
Let \(P_k\) be the path graph on vertices \(1,\dots,k\) (edges \(i\!\sim\! i{+}1\)), and denote its independent-set count by \(I_k\) (so \(I_k=F_{k+2}\)).
\begin{enumerate}
  \item If \(k\ge 5\), then the number of independent sets on \(P_k\) \emph{simultaneously containing} vertices \(2\) and \(5\) is exactly \(F_{k-4}\) (when \(k\ge 6\), this can also be written as \(I_{k-6}\)).
  \item If \(k\ge 5\), then the number of independent sets on \(P_k\) \emph{simultaneously containing} vertices \(1\) and \(4\) is exactly \(I_{k-5}=F_{k-3}\).
\end{enumerate}
\end{lemma}
\begin{proof}
(1) When \(k=5\), the unique independent set containing \(\{2,5\}\) is \(\{2,5\}\) itself, with count \(1=F_1\).
When \(k\ge 6\), if the independent set contains \(\{2,5\}\), then vertices \(1,3,4,6\) are all excluded, and the remaining freely selectable part is the path \(7,\dots,k\), isomorphic to \(P_{k-6}\). Conversely, for any independent set of \(P_{k-6}\), adding \(\{2,5\}\) yields an independent set of \(P_k\) containing \(\{2,5\}\). Hence the count is \(I_{k-6}=F_{k-4}\).\;
(2) Similarly: when \(\{1,4\}\) is included, vertices \(2,3,5\) are excluded, and the remainder is the path \(6,\dots,k\), isomorphic to \(P_{k-5}\). \qed
\end{proof}

\begin{theorem}[Closed form of the second-largest fiber and explicit gap constant]\label{thm:pom-second-max-fiber-closed-form}
Adopt the Fibonacci extension \(F_0=0,F_1=1\), and let \(D_m^{(2)}\) be the second-largest fiber multiplicity (Definition \ref{def:pom-top-fiber-spectrum}).
Then for \(k\ge 5\), the closed forms are:
\[
D_{2k}^{(2)} = F_{k+2}-F_{k-4},
\qquad
D_{2k+1}^{(2)} = 2F_{k+1}-F_{k-4}.
\]
\end{theorem}
\begin{proof}
The proof strategy is entirely isomorphic to that of Theorem \ref{thm:pom-max-fiber}: the maximum arises from ``full-chain independent-set counting'' \(I_k=F_{k+2}\) (even) or \(2I_{k-1}=2F_{k+1}\) (odd).
\par
More precisely: in the interference graph independent-set DP (Lemma \ref{lem:pom-independence-dp-radius2}), the full-chain phase corresponds to all local steps falling on the \(p(t)=t-2\) branch, so by Lemma \ref{lem:pom-ind-local-recurrence}(1) one obtains the pure Fibonacci recurrence \(a_t=a_{t-1}+a_{t-2}\), giving \(a_k=I_k=F_{k+2}\) at the terminal.
When departing from the full-chain phase kernel of the maximum achievers, the smallest possible degradation is not simply shortening the chain (which would cause a \(\Theta(F_{k-1})\)-level drop), but rather the occurrence of a single ``radius-2 conflict'' causing \(p(t)\) to jump once (Lemma \ref{lem:pom-ind-local-recurrence}(2): one step changes from \(a_t=a_{t-1}+a_{t-2}\) to \(a_t=a_{t-1}+a_{t-3}\)).
Under the path graph \(P_k\) framework, this is equivalent to additionally forbidding a pair of vertices at distance \(3\) from being simultaneously selected in the full-chain independent-set choices; the earliest non-endpoint defect corresponds precisely to the forbidden pair \(\{2,5\}\).
By Lemma \ref{lem:pom-forbidden-pair-fib-gap}(1), forbidding the pair \(\{2,5\}\) removes exactly \(F_{k-4}\) from the full-chain count, yielding
\(
D_{2k}^{(2)}=F_{k+2}-F_{k-4}
\).
The odd case is analogous: the hidden-bit splitting decomposes the total count into the sum of two layers, where the minimal defect triggers one forbidden pair in only one layer, so the total count is
\(
D_{2k+1}^{(2)}=2F_{k+1}-F_{k-4}
\).
Details can be written step by step following the same ``inverse substitution--conflict constraint--Fibonacci recurrence'' chain as in Theorem \ref{thm:pom-max-fiber}.
\end{proof}

\begin{corollary}[Golden constant limit, exponential convergence, and auditable gap certificate]\label{cor:pom-second-max-gap-constant}
Let \(\varphi=\frac{1+\sqrt5}{2}\). For \(k\ge 5\), from the closed forms of Theorem \ref{thm:pom-second-max-fiber-closed-form} and Theorem \ref{thm:pom-max-fiber}, the exact ratios are
\[
\frac{D_{2k}^{(2)}}{D_{2k}}=1-\frac{F_{k-4}}{F_{k+2}},
\qquad
\frac{D_{2k+1}^{(2)}}{D_{2k+1}}=1-\frac{F_{k-4}}{2F_{k+1}}.
\]
The two even/odd branches converge respectively to closed-form golden constant platforms:
\[
\frac{D_{2k}^{(2)}}{D_{2k}}
\longrightarrow
1-\varphi^{-6}
=1-\frac{1}{9+4\sqrt5},
\qquad
\frac{D_{2k+1}^{(2)}}{D_{2k+1}}
\longrightarrow
1-\frac12\varphi^{-5}
=1-\frac{1}{11+5\sqrt5}.
\]
The convergence error is exponential:
\[
\left|\frac{D_{2k}^{(2)}}{D_{2k}}-\left(1-\varphi^{-6}\right)\right|=O(\varphi^{-2k}),
\qquad
\left|\frac{D_{2k+1}^{(2)}}{D_{2k+1}}-\left(1-\tfrac12\varphi^{-5}\right)\right|=O(\varphi^{-2k}).
\]
Denote the limit constant of the odd branch (which is also the asymptotic worst case) by
\[
\boxed{\;
\theta_\star\;(:=\theta_{\mathrm{gap}})\;:=1-\frac{1}{11+5\sqrt5}
=1-\tfrac12\varphi^{-5}
\approx 0.9549150281<1.
\;}
\]
Then ``there exists \(\theta<1\) such that \(D_m^{(2)}\le \theta D_m\)'' can be certified by the explicit uniform certificate
\[
\boxed{\;
\frac{D_m^{(2)}}{D_m}\le \frac{25}{26}\qquad(m\ge 2),
\;}
\]
where equality holds at \(m=13\) (and is therefore the globally optimal constant). For comparison, the asymptotically optimal candidate constant is \(\theta_\star\), and the platform fitting error is \(O(\varphi^{-2k})\), explaining the ``near-constant'' phenomenon in Table \ref{tab:fold_max_fiber_achievers_phase} for \(m\le 32\).
\end{corollary}
\begin{proof}
The ratio formulas are obtained by direct division of the closed forms.
The limit constants follow from the Binet formula \(F_n=\frac{1}{\sqrt5}(\varphi^n-\psi^n)\) (\(\psi=-\varphi^{-1}\)): for example,
\[
\frac{F_{k-4}}{F_{k+2}}
=\varphi^{-6}\frac{1-(\psi/\varphi)^{k-4}}{1-(\psi/\varphi)^{k+2}}
=\varphi^{-6}\left(1+O(\varphi^{-2k})\right),
\]
and similarly \(\frac{F_{k-4}}{F_{k+1}}=\varphi^{-5}\left(1+O(\varphi^{-2k})\right)\), which when substituted yield the two exponential-level errors.
The closed forms \(\varphi^6=9+4\sqrt5\), \(2\varphi^5=11+5\sqrt5\) can be obtained from the identity \(\varphi^n=F_n\varphi+F_{n-1}\) (taking \(n=5,6\)).

Finally, we establish the uniform certificate: from the above,
\[
\frac{D_{2k+1}^{(2)}}{D_{2k+1}}=1-\frac{F_{k-4}}{2F_{k+1}}
\le 1-\frac{1}{26}=\frac{25}{26},
\]
where the inequality is equivalent to \(F_{k+1}\le 13F_{k-4}\).
Writing \(n:=k-4\ge 1\), we need to show that \(F_{n+5}\le 13F_n\) holds for all \(n\ge 1\).
The inequality holds for \(n=1,2\) (\(F_6=8\le 13F_1\), \(F_7=13=13F_2\)), and if it holds for \(n,n+1\), then
\(
F_{n+7}=F_{n+6}+F_{n+5}\le 13F_{n+1}+13F_n=13F_{n+2}
\),
so by induction it holds for all \(n\); equality occurs only at \(n=2\) (i.e., \(k=6,m=13\)).
The even branch is stronger: since \(F_{k+2}=F_{k+1}+F_k<2F_{k+1}\), for \(k\ge 5\),
\[
\frac{D_{2k}^{(2)}}{D_{2k}}
=1-\frac{F_{k-4}}{F_{k+2}}
\;<\;
1-\frac{F_{k-4}}{2F_{k+1}}
=\frac{D_{2k+1}^{(2)}}{D_{2k+1}}
\le \frac{25}{26}.
\]
The finitely many initial cases \(m<10\) can be directly audited from Table \ref{tab:fold_max_fiber_achievers_phase}. \qed
\end{proof}

\begin{remark}[Extremal--near-extremal isolation band (stable separation of the top-level spectrum)]\label{rem:pom-maxfiber-isolation-band}
Let \(\mathcal{M}_m=\{x\in X_m:\ d_m(x)=D_m\}\) be the set of maximum fiber achievers.
Then for any \(x\notin\mathcal{M}_m\), \(d_m(x)\le D_m^{(2)}\) always holds.
By Corollary \ref{cor:pom-second-max-gap-constant}, there exists an explicit constant \(\theta<1\) (e.g., the global uniform \(\theta=\tfrac{25}{26}\), or the asymptotic worst-case constant \(\theta_\star\approx 0.954915\)) such that for sufficiently large \(m\),
\[
d_m(x)\le D_m^{(2)}\le \theta\,D_m\qquad(x\notin\mathcal{M}_m).
\]
Thus the top-level spectrum has a stable isolation band in the proportional sense from the near-extremal layer: the extremal layer is supported by the finite phase \(\kappa_m^{\mathrm{max}}=O(1)\) (Theorem \ref{thm:pom-max-achievers-phase-stabilization}), while all non-achiever fiber multiplicities are uniformly suppressed below \(\theta D_m\).
This isolation band provides a structural input requiring no additional assumptions for any subsequent inference that amplifies tail contributions via higher-order moments/pressure functions.
\end{remark}
