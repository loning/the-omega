\paragraph{Selenocysteine insertion site case study.}
Analyzed 893 Sec (UGA$\to$Sec) recoding sites from GenBank.
Domain distribution: Eukaryota: 893.
\textbf{Finding:} 75\% of Sec sites show higher $\overline{U}_{\mathrm{before}}$ than their corresponding terminal stops (mean diff = 4.71), consistent with elevated ``arithmetic friction'' upstream of recoding sites.
