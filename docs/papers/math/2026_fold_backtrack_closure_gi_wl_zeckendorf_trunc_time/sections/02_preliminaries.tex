\subsection{Zeckendorf 表示与无相邻 1 的 Fibonacci 字}

设 Fibonacci 数列采用 Zeckendorf 版本：$F_1=1$，$F_2=2$，$F_{k+2}=F_{k+1}+F_k$。Zeckendorf 定理断言：每个正整数都能唯一表示为若干不相邻 Fibonacci 数之和 \cite{zeckendorf1972representation}。

令
\[
Y_m=\bigl\{y\in\{0,1\}^{m}: y_i y_{i+1}=0,\ i=1,\dots,m-1\bigr\},
\]
则 $\abs{Y_m}=F_{m+2}$ 是经典计数事实：长度为 $m$ 的无相邻 $1$ 二进制串的数目满足同一递推。

\subsection{图同构、Weisfeiler--Leman 与相干配置}

\begin{itemize}
  \item \textbf{图同构（\GI{}）：}给定两张图 $G,H$，判定是否存在顶点双射 $\pi$ 使邻接关系保持。
  \item \textbf{$1$-\WL{}（颜色细化 / color refinement）：}迭代更新每个顶点颜色为“自身颜色 + 邻居颜色多重集”的哈希，直到稳定。稳定分割可视为相干配置（coherent configuration）的细化近似 \cite{wl2018symmetryvsregularity}。
  \item \textbf{Babai（2015/2016）：}\GI{} 在准多项式时间可解，算法核心构件之一是相干配置与 \WL{} 系列程序 \cite{babai2016gi}。
\end{itemize}
