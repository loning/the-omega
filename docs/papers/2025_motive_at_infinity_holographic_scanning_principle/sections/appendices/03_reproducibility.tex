
\section{Reproducibility notes}
\label{app:reproducibility}

The scripts used in Section~\ref{sec:experiments} are included in the paper directory:
\begin{itemize}
\item \texttt{scripts/period\_scan\_experiments.py} generates scan-period estimates for $\log 2$, $\pi$, $\zeta(2)$ and $\zeta(3)$ and writes \LaTeX{} table rows into \texttt{sections/generated/}. In particular it writes \texttt{log2\_rows.tex}, \texttt{pi\_rows.tex}, \texttt{zeta2\_rows.tex}, \texttt{zeta3\_rows.tex} and the auxiliary fit snippets \texttt{log2\_fit.tex}, \texttt{pi\_fit.tex}.
\item \texttt{scripts/alpha\_inverse\_search.py} performs an exhaustive bounded-complexity enumeration in the ansatz $a\pi^3+b\pi^2+c\pi$ and writes the top candidates into \texttt{sections/generated/alpha\_integer\_search\_rows.tex}.
\end{itemize}

All randomness is controlled by fixed seeds. The numerical values in the main text tables are obtained by executing these scripts on a standard Python~3 interpreter.
