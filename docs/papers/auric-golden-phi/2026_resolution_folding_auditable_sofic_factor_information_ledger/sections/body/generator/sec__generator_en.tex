\section{Scan--projection generator and finite-window microstates}\label{sec:generator}

This section introduces the minimal readout setting needed for the folding interface.

\subsection{Binary readout from a dynamical system}\label{subsec:generator-readout}
Let $(X,\mathcal{B},\mu)$ be a probability space and $T:X\to X$ a measurable transformation.
Fix a measurable window $W\in\mathcal{B}$ and define the binary readout
\[
s_t(x):=\ind_W(T^t x)\in\{0,1\},\qquad t\in\ZZ.
\]
The induced process on $\{0,1\}^{\ZZ}$ depends on $(T,\mu,W)$, but the folding pipeline below is defined at the purely symbolic level and can be applied to any input sequence.

\subsection{Finite-window microstate space}\label{subsec:generator-omega}
For a fixed resolution $m\ge 1$, the length-$m$ microstate space is
\[
\Omega_m=\{0,1\}^m.
\]
Given $s\in\{0,1\}^{\ZZ}$, each time $t$ yields a window microstate $\omega_m(s;t)\in\Omega_m$.
Empirical microstate distributions (from a finite sample $t=0,\dots,N-1$) will be denoted by $\hat{\mu}_{m,N}\in\Delta(\Omega_m)$, while the model-induced limiting distribution (when it exists) is denoted by $\mu_m\in\Delta(\Omega_m)$.

\subsection{Stable types and the need for a canonical map}\label{subsec:generator-stable-types}
The central structural problem is that the raw space $\Omega_m$ is exponentially large, while many windows represent the same stable type under a finite-resolution readout.
We address this by defining a canonical folding map
\[
\Fold_m:\Omega_m\to X_m,
\]
where $X_m$ is a stable language (defined in Section~\ref{sec:folding}) whose elements serve as canonical types.
The rest of the paper shows that this single map, together with its induced sliding block factor, is sufficient to produce computable invariants and a complete auditing decomposition.
