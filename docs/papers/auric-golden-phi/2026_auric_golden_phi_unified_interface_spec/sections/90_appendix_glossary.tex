\section{附录：术语表（跨论文对齐）}

\begin{itemize}
  \item \textbf{扫描（scan）}：底系统的迭代/平移（如 $T_a$）或可逆更新 $U$。
  \item \textbf{读出（readout）}：有限分辨率观测核 $\rho$（窗口/分割/投影），输出二值或有限字母表。
  \item \textbf{稳定化（stabilization）}：把原始读出窗口规范化为稳定语言的映射（典型为 Zeckendorf/golden-mean 折叠 $\Fold_m$）。
  \item \textbf{纤维（fiber）}：稳定化核预像 $\mathcal{F}_m(x)$，对象化不可见自由度。
  \item \textbf{信息论时间}：柱集后验测度随历史长度的指数收缩率；在生成分割条件下等于 KS 熵率（SMB）。
  \item \textbf{黄金分支（golden branch）}：以 $\varphi$ 或其相关无理斜率（连分数尾部周期）作为反共振/自相似固定点的参数选择。
\end{itemize}
