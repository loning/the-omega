  \item $V(w)$：稳定态 $w$ 的窗口值标记，使 $V:X_6\to\{0,\dots,20\}$ 为双射。
  \item uplift：$\Delta(N)=N-V(\Fold_6(N))\in U=\{0,21,34,55\}$。
\end{itemize}
