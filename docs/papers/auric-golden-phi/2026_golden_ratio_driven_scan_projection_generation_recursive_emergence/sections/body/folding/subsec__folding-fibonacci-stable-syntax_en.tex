\subsection{Fibonacci Weights and the Stable Syntax Set}\label{subsec:folding-fibonacci-stable-syntax}

Let the Fibonacci sequence $(F_k)_{k\ge1}$ satisfy
\[
F_1=F_2=1,\quad F_{k+2}=F_{k+1}+F_k.
\]
Define the stable type set of length $m$:
\[
X_m:=\{w\in\{0,1\}^m:\text{no subword }11\}.
\]
That is, $X_m$ is the binary syntax forbidding adjacent $1$'s (also known as the ``golden mean constraint''). Its cardinality satisfies
\[
|X_m|=F_{m+2},
\]
see \cite{LindMarcus1995}.
