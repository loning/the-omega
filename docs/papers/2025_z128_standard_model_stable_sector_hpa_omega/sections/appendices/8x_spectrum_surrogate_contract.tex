\subsection{Spectrum surrogate contract (auditable substitute for the spectrum condition)}
\label{app:spectrum_surrogate_contract}

\AuditTag The full AQFT spectrum condition (positive-energy support in the forward light cone) is a strong structural input.
This appendix provides an auditable surrogate contract that can be checked within finite protocol windows, and which is sufficient for the manuscript's controlled uses of time-directionality and scattering interfaces.
It is explicitly \emph{not} a proof of the full relativistic spectrum condition.

\subsubsection{Windowed positivity surrogate}
\begin{definition}[Windowed spectrum surrogate]
\label{def:windowed_spectrum_surrogate}
\MathTag Fix a declared time-translation subgroup (or semigroup) $t\mapsto \alpha_t$ on $\mathcal{A}_{\mathrm{prot}}$.
We say the dynamics satisfies a \emph{windowed spectrum surrogate} on a window $\mathcal{W}_{\mathrm{win}}$ if there exists a GNS implementation $U(t)=\exp(\iu tH)$ (Assumption~\ref{ass:vacuum_state_implementability}) such that, on the cyclic subspace generated by observables supported in $\mathcal{W}_{\mathrm{win}}$, the generator $H$ has a nonnegative expectation on all normalized vectors:
\[
\langle \psi, H\psi\rangle \ge 0.
\]
\end{definition}

\AuditTag Definition~\ref{def:windowed_spectrum_surrogate} is an operational positivity requirement.
It is weaker than the full joint-spectrum light-cone support condition, but it is auditable in a finite window if $H$ is identified with a protocol Hamiltonian/latency generator in the declared channel.

\subsubsection{Contract usage}
\begin{assumption}[Spectrum surrogate contract]
\label{ass:spectrum_surrogate_contract}
Whenever the manuscript invokes scattering/LSZ interfaces as theorem-facing consequences, it will declare:
\begin{itemize}
\item the window $\mathcal{W}_{\mathrm{win}}$ on which the surrogate is claimed,
\item the identification of the generator $H$ used in Definition~\ref{def:windowed_spectrum_surrogate},
\item the check/evidence pointer (table/script/citation) supporting the surrogate on that window.
\end{itemize}
\end{assumption}

\paragraph{Failure point.}
\AuditTag If the surrogate cannot be discharged, the manuscript downgrades to interface-only use of scattering/delay with explicit loss/error models, and records the failure in the evidence map (Appendix~\ref{app:minimal_failure_point_templates}).
