\section{扫描与协议时间：余维相位迭代与读出序列}

\subsection{扫描参数与时间定义}

定义协议时间为离散迭代计数 $t\in\ZZ_{\ge 0}$。令余维相位参数随 $t$ 迭代：
\[
u_t=u_{0}+t\,v\quad (\mathrm{mod}\ \Gamma),
\]
其中 $v\in E_{\perp}$ 为扫描方向，$\Gamma$ 可取为将 $E_{\perp}$ 适当商去以得到紧致相位空间的格（例如由 $\pi_{\perp}(\Lambda)$ 诱导）。于是随时间变化的三维可观测集为
\[
\Sigma_t := \Sigma(u_t).
\]
在该定义下，“时间序列”并非本体层流逝，而是对静态格点结构在余维相位参数上的顺序访问。

\subsection{有限分辨率读出核与诱导统计}

设读出算子由一个分辨率参数 $\varepsilon>0$ 控制，可通过窗口核或更一般的 POVM 效应族表述：
\[
\big\{E_k^{(\varepsilon)}\big\}_{k\in \mathcal{K}},\qquad \sum_{k\in\mathcal{K}}E_k^{(\varepsilon)}=\mathbf{1}.
\]
对某个有效态 $\omega_{\mathrm{eff}}$（可视作 $\omega_\Omega$ 在观测子代数上的限制）诱导概率
\[
P_k^{(\varepsilon)}=\omega_{\mathrm{eff}}\!\left(E_k^{(\varepsilon)}\right).
\]
因此，概率并非外加公设，而由读出仪器与有限分辨率共同诱导。

\subsection{时间箭头的协议定义}

本文不将时间箭头定义为本体层不可逆性，而采用协议层可审计的箭头定义：当读出分辨率随 $t$ 增加（例如前缀长度增长或核宽度缩小）时，观测可区分性单调上升，从而可定义“熵增样”指标为区分能力的增长或残差不确定性的下降。该定义不要求微观动力学不可逆，但可在有限读出下给出可计算的方向性量。
