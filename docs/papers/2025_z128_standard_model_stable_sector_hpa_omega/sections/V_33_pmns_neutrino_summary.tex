\subsection{A minimal neutrino mass-scale interface}
\label{subsec:neutrino_mass_interface}

At the anchor resolution $(m,n)=(6,3)$, the mass-spectrum closure of Section~\ref{sec:mass_spectrum_closure} anchors scheme-stable charged-lepton scales and treats neutrino absolute masses as an interface input.
To express neutrino scales in the same resolution language, we record a deterministic nearest-integer depth assignment for representative minimal-mass normal/inverted orderings inferred from oscillation splittings.
We use representative central values for $(\Delta m_{21}^2,|\Delta m_{31}^2|)$ from standard global fits \cite{PDGRPP2024,Esteban2020NuFIT}.
\begin{remark}[Status of the neutrino-scale assignment]\label{rem:neutrino_scale_status}
The nearest-integer depth assignment in Table~\ref{tab:neutrino_mass_interface} is an interface-level bookkeeping device: it expresses commonly quoted oscillation-inferred mass scales in the same additive depth coordinate used elsewhere, without claiming a unique absolute-mass prediction at $(m,n)=(6,3)$.
Any stronger neutrino-mass prediction requires additional physical identification input (e.g.\ a concrete mass-generation mechanism and threshold/matching conventions) beyond the minimal closure reported in this paper.
\end{remark}

\subsection{Hypothesis: neutrino smallness as a protocol-decoupling maintenance cost (interface)}
\label{subsec:neutrino_interface_hypothesis}

\InterfaceTag The table above treats absolute neutrino masses as a matching-layer input at $(m,n)=(6,3)$ (Remark~\ref{rem:neutrino_scale_status}).
We record the following interpretive hypothesis only; none of the closure statements in this section depends on it.

\InterfaceTag Appendix~\ref{app:forced_interface_lemmas} records that a sterile singlet $\nu_R$ is forced as the unique minimal anomaly-neutral one-multiplet-per-generation extension (Proposition~\ref{prop:nur_forced_by_minimal_anomaly}).
In the protocol language, such a neutral singlet can behave as a protocol-external / decoupled (``ghost-like'') mode (Section~\ref{subsec:p1_rh_neutrino}).
We propose to read the absolute neutrino scale as an \emph{idle maintenance cost} of this decoupling: a nonzero but strongly suppressed overhead required to maintain protocol-consistent chiral/gauge closure without populating additional charged stable types at the anchor.

\InterfaceTag Quantitatively, in the exponential map $\mu(r)=m_e\,\varphi^{r}$ (Section~\ref{sec:mass_latency_coordinate}), such an overhead corresponds to large negative depths and hence exponentially small $\mu$, consistent with the placement of the neutrino rows in Table~\ref{tab:neutrino_mass_interface}.

\paragraph{Falsifiability channel.}
Evidence for an unsuppressed right-handed neutrino mode that participates in the weak compensation transport within the same protocol class would contradict the protocol-external/decoupled identification used here (Section~\ref{subsec:p1_rh_neutrino}).
