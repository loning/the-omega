\section{unitary slice 审计接口与 \texorpdfstring{$\Xi_{\Delta,L}$}{Xi\_Delta\_L} 的类型锁定}\label{app:unitary-slice}

由 $u_L(s)=L^{2s-1}$ 与 $\mathrm{Phase}=\{u:\abs{u}=1\}$ 的等价（命题 \ref{prop:critical-line-unitary-slice}），临界线几何被转写为 unitary slice 的参数约束。闭包内投影词规约到接口正规形并把不可交换残差收束为异常签名，使得可核对参数轴仅剩相位 $\theta$。因此，任何可核对零点证书在闭包内必须满足 $\abs{u}=1$，从而对应 $\Re(s)=\tfrac12$。

在可执行实现中，unitary slice 审计接口可被组织为“相位扫描 $\theta$ + 可核对行列式/特征多项式证书”的协议：对给定 $\theta$ 计算 $\Delta(z,e^{i\theta})$（或等价谱对象），并输出精确或带误差界的零值/符号变化证书；任何引入径向自由度的尝试都会在类型系统中表现为额外连续参数，从而触发第 \ref{sec:fourth-register} 节的第四寄存器拒绝链。
