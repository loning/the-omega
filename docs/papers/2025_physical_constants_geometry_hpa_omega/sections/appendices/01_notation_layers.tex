\section{Notation and layer conventions}
\label{app:notation_layers}

We keep a strict separation of conceptual layers.

\begin{itemize}
    \item \textbf{Ontology layer.} Multiplicative structure and phase structure are treated as primitives.
    \item \textbf{Scan layer.} A genuine unitary scan operator $\Theta$ introduces time as iteration count.
    \item \textbf{Readout layer.} A window projection and an orthogonal cut map continuous structure to discrete distinguishable outcomes; canonical coding (Ostrowski/Zeckendorf) fixes the readout grammar.
    \item \textbf{Observable layer.} The residual mismatch (gap/impedance/noise) is the data-facing remainder and controls error budgets.
\end{itemize}

\paragraph{Resolution parameter $r$.}
The symbol $r$ denotes a resolution/coarse-graining parameter. Depending on context it is instantiated as coding bit depth, window scale, scan depth, or (in the $\Omega$ setting) effective compilation depth. The only requirement is that there exists a map $r\mapsto \mu(r)$ connecting resolution flow to running couplings.

\paragraph{Reproducibility.}
All finite rigidity checks and calibration tables in this paper are reproducible by a unified script included with the source: \texttt{scripts/hpa\_omega\_geometry.py}. Running \texttt{python3 scripts/hpa\_omega\_geometry.py emit-tex} writes the LaTeX row fragments into \texttt{sections/generated/}, which are input by Tables~\ref{tab:alpha_integer_search}, \ref{tab:mu_phase_factorizations}, \ref{tab:mu_integer_search}, \ref{tab:jarlskog_integer_search}, \ref{tab:alpha_G_integer_search}, and Appendix~\ref{app:resolution_map_calibration}. Running \texttt{python3 scripts/hpa\_omega\_geometry.py all} prints the corresponding values and search winners.
