\section{Scan and Protocol Time: Complementary Phase Iteration and Readout Sequence}

\subsection{Scan Parameters and Time Definition}

Define protocol time as discrete iteration count $t\in\ZZ_{\ge 0}$. Let the complementary phase parameter iterate with $t$:
\[
u_t=u_{0}+t\,v\quad (\mathrm{mod}\ \Gamma),
\]
where $v\in E_{\perp}$ is the scan direction, and $\Gamma$ can be taken as a lattice for appropriately quotienting $E_{\perp}$ to obtain a compact phase space (for example, induced by $\pi_{\perp}(\Lambda)$). Thus the time-dependent three-dimensional observable set is
\[
\Sigma_t := \Sigma(u_t).
\]
Under this definition, ``temporal sequence'' is not ontological layer flow, but rather sequential access to the static lattice structure over complementary phase parameters.

\subsection{Finite-Resolution Readout Kernel and Induced Statistics}

Let the readout operator be controlled by a resolution parameter $\varepsilon>0$, expressible via window kernels or more generally POVM effect families:
\[
\big\{E_k^{(\varepsilon)}\big\}_{k\in \mathcal{K}},\qquad \sum_{k\in\mathcal{K}}E_k^{(\varepsilon)}=\mathbf{1}.
\]
For some effective state $\omega_{\mathrm{eff}}$ (viewed as the restriction of $\omega_\Omega$ to the observable subalgebra), this induces probabilities
\[
P_k^{(\varepsilon)}=\omega_{\mathrm{eff}}\!\left(E_k^{(\varepsilon)}\right).
\]
Thus probability is not an external postulate, but is induced by the readout instrument and finite resolution together.

\subsection{Protocol Definition of the Temporal Arrow}

This paper does not define the temporal arrow as ontological layer irreversibility, but adopts an auditable protocol-layer definition: when readout resolution increases with $t$ (for example, prefix length growth or kernel width reduction), the distinguishability of observations increases monotonically, thus allowing definition of an ``entropy-like'' index as growth of distinguishing power or decline of residual uncertainty. This definition does not require microscopic dynamics to be irreversible, but provides a computable directional quantity under finite readout.
