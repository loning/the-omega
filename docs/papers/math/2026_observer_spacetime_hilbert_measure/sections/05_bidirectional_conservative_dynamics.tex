\section{双向同时演化：守恒扩展态与固定点/变分表述}

本节把“系统前向趋稳、观察者向上搜索、信息守恒”统一为同一个扩展态上的约束满足问题。关键点是：所谓“趋稳”只发生在\textbf{投影后的可见层}，而信息守恒发生在\textbf{扩展态}上；进一步地，时间轴可以被视为 uplift/历史胶带的组织与长度（负信息时间 \(\tautime\)）。

\subsection{扩展态与信息守恒}

设本体扩展态为
\[
x_t:=(s_t,u_t)\in\mathcal X,
\]
其中 \(s_t\) 是可见层（例如 Fold6 稳定词拼接得到的位串），\(u_t\) 是每步产生的隐藏边标签（uplift）。在 HPA-CA/Fold6 例子中，\(u_t\) 取有限字母表（如 \(\{0,21,34,55\}\) 的编码）并由局部核确定生成。

\begin{assumption}[守恒演化]
存在一个双射（可逆更新）
\[
T:\mathcal X\to\mathcal X,\qquad x_{t+1}=T(x_t),
\]
从而扩展态的信息在本体层守恒。
\end{assumption}

\begin{definition}[uplift 作为时间轴（本体约定）]
在本文的守恒表述中，uplift \(u_t\) 被视为“时间边标签/历史胶带”的增量：它记录了为了使扩展态更新可逆而必须携带的隐藏信息。由此，对有限窗口 \(t\in[t_0,t_0+W]\)，负信息时间可取为 uplift 胶带的编码长度 \(\tautime(u_{t_0:t_0+W})\)。观察者时间 \(\kappaobs\) 作为算法成本，在最小假设下与 \(\tautime\) 同阶等价（见预备知识中的定理）。
\end{definition}

\subsection{观察者：投影、观测一致性与动力学一致性}

观察者只看到投影
\[
y_t=\proj(x_t)=\proj(s_t)\in\mathcal Y,
\]
并且一般无法直接读取 \(u_t\)。因此“向上搜索”就是在给定观测序列 \(\{y_t\}\) 下，寻找某个扩展态轨迹 \(\{x_t\}\) 使其同时满足：
\begin{itemize}
  \item \textbf{观测一致性：} \(\proj(x_t)=y_t\)；
  \item \textbf{动力学一致性：} \(x_{t+1}=T(x_t)\)。
\end{itemize}

\subsection{固定点/变分：零能量等价于一致历史}

对有限时间窗 \(t\in[t_0,t_0+W]\)，定义离散能量（约束违背计数）：
\[
\mathcal E(\{x_t\};\{y_t\})
=\sum_{t=t_0}^{t_0+W}\mathbf 1[\proj(x_t)\neq y_t]
\;+\;
\sum_{t=t_0}^{t_0+W-1}\mathbf 1[x_{t+1}\neq T(x_t)].
\]

\begin{proposition}[一致历史的等价刻画]
对固定的观测 \(\{y_t\}\)，存在扩展态轨迹 \(\{x_t\}\) 同时满足观测一致性与动力学一致性，当且仅当存在 \(\{x_t\}\) 使得 \(\mathcal E(\{x_t\};\{y_t\})=0\)。
\end{proposition}

\begin{remark}[固定点与有限观察者]
在此表述下，观察者的策略可以被视为一个求解器：它试图通过局部传播与有限试探把 \(\mathcal E\) 推到 0。由于观察者有限，求解过程通常是局部化的（贪心、有限窗口、有限回溯）；并行性由推断层依赖图约束（见上一节）。
\end{remark}

\subsection{能量的可计算代理（实验口径）}

在实际实验中，直接对 \(\mathcal E\) 做全局优化会退化为一般约束满足问题；因此我们采用一个可审计、可快速计算的代理量来衡量“离一致解还有多远”。对符号环约束
\[
y_i=f(x_i,x_{i+1}),
\]
令每个未知 \(x_i\) 的可行域为 \(D_i\subseteq\mathcal A\)（\(\mathcal A\) 是有限字母表，如 \(|\mathcal A|=21\)）。定义总不确定性
\[
\mathcal E_{\mathrm{amb}}:=\sum_{i=1}^{n}(\abs{D_i}-1),
\]
它在域削减与贪心承诺（commit）过程中单调不增（直到冲突或收敛为单例域）。实验中我们用 \(\mathcal E_{\mathrm{amb}}\) 的下降曲线作为固定点迭代的“能量曲线”。

\begin{remark}[从能量代理到负信息时间]
\(\mathcal E_{\mathrm{amb}}\) 可被解释为“尚未写入 uplift 胶带的剩余不确定性”的一个可计算代理：当域逐步收缩到单例时，等价于把需要的隐藏信息逐步确定。因而，固定点迭代的下降曲线可以被视为对负信息时间（胶带长度）如何被分配/偿还的一种可审计投影。
\end{remark}
