\section{附录 C：线性与循环计数差分恒等式}
\label{app:linear-cyclic}

令 $a_m=\card{X_m}=F_{m+2}$。令 $c_m=\card{X_m^{\mathrm{cyc}}}$ 为循环合法词数（首尾亦不得同为 $1$）。可按首位取值与相邻约束建立递推并得到 $c_m$ 满足 Lucas 递推且 $c_m=L_m$。利用恒等式 $L_m=F_{m-1}+F_{m+1}$，得
\[
a_m-c_m=F_{m+2}-(F_{m-1}+F_{m+1})=F_{m-2}.
\]
因此边界伪像数量为 $F_{m-2}$，在 $m=6$ 时为 $F_4=3$。
