\section{结论}

本文以 Zeckendorf 截断折叠为规范，给出一个把“带时空语义的离散对象”编码为带颜色图同构问题的最小接口，并证明时空结构同构与编码图同构等价（定理 \ref{thm:gi_translation_spacetime}）。在该统一编码对象上，我们用 \WL{} 稳定深度、残余轨道与纤维统计构成一套可复现的指标体系，并给出 $m=3$ 至 $18$ 的扫描实验作为基准输出。

该框架的价值在于：它把“观测导致的信息压缩（纤维）”与“对称性/可见不变量（\WL{} 与相干配置）”置于同一可审计对象中，为后续进一步引入群作用分支控制、以及更复杂几何/时间关系下的系统比较提供了稳定的形式基础。
