\section{反射子与诱导的交换结构：因子系统与范畴化模板}

\subsection{Kronecker 反射子与幂等单子}

令 $\mathbf{Erg}$ 为遍历测度保持系统与因子映射构成的范畴。令 $\mathbf{Kron}\subset\mathbf{Erg}$ 为离散谱系统（等价紧阿贝尔群旋转）全子范畴。Kronecker 因子给出反射子
\[
K:\mathbf{Erg}\to \mathbf{Kron},
\]
并满足幂等性
\[
K\circ K\simeq K.
\]
普适性质表述为：对任意 $(X,T)\in\mathbf{Erg}$ 与 $(Y,S)\in\mathbf{Kron}$，任意因子映射 $X\to Y$ 唯一经由 $X\to K(X)$ 因子化。

\subsection{带窗口对象范畴与诱导函子}

定义带窗口范畴 $\mathbf{Erg}^{\ast}$：对象为三元组 $(X,T,E)$，其中 $E\subset X$ 可测且 $\mu(E)>0$。态射 $(X,T,E)\to(Y,S,F)$ 为因子映射 $\pi:X\to Y$ 满足窗口可拉回条件
\[
E=\pi^{-1}(F).
\]
在该范畴上定义诱导函子
\[
\mathrm{Ind}:\mathbf{Erg}^{\ast}\to\mathbf{Erg},\qquad (X,T,E)\mapsto(E,T_E).
\]
窗口可拉回保证回归时间下推与诱导后的因子结构自然存在。

\subsection{交换定理模板：底系统闭包性与纤维稳定性分解}

设 $\pi:X\to K(X)$ 为 Kronecker 因子映射，取 $F\subset K(X)$ 且 $E=\pi^{-1}(F)$。则诱导后存在自然因子映射
\[
\pi_E:\mathrm{Ind}(X,E)\to \mathrm{Ind}(K(X),F).
\]
为比较 $K(\mathrm{Ind}(X,E))$ 与 $\mathrm{Ind}(K(X),F)$，引入两类条件：
\begin{itemize}
  \item \textbf{底系统闭包性：}$\mathrm{Ind}(K(X),F)\in\mathbf{Kron}$。
  \item \textbf{纤维稳定性：}扩张 $X\to K(X)$ 的非等距部分在诱导下不产生新的等距因子（可由相对弱混合等随机性条件保证，见附录 \ref{app:relative-product}）。
\end{itemize}

\begin{theorem}[反射—诱导交换模板]\label{thm:reflector-induction-template}
设 $(X,T)\in\mathbf{Erg}$，令 $\pi:X\to K(X)$ 为 Kronecker 因子映射。取 $F\subset K(X)$ 且 $E=\pi^{-1}(F)$。若
\begin{enumerate}
  \item $\mathrm{Ind}(K(X),F)\in\mathbf{Kron}$；
  \item 扩张 $X\to K(X)$ 在诱导后保持相对随机性，从而不产生新的非平凡等距因子；
\end{enumerate}
则存在测度同构
\[
K(\mathrm{Ind}(X,E))\cong \mathrm{Ind}(K(X),F).
\]
\end{theorem}

\begin{proof}[证明纲要]
由条件 2 可知 $\mathrm{Ind}(X,E)\to \mathrm{Ind}(K(X),F)$ 的 Kronecker 因子由底系统控制；由条件 1 底系统自身已处于反射类 $\mathbf{Kron}$，故 $K(\mathrm{Ind}(X,E))$ 必与 $\mathrm{Ind}(K(X),F)$ 对齐。严证可用相对直积遍历性与诱导交换（附录 \ref{app:relative-product}）。证毕。
\end{proof}

\subsection{一维旋转的可诱导闭包窗口刻画}

在一维旋转 $(\TT,T_\theta)$ 中，若 $F=E$ 为区间，则定理 \ref{thm:two-value-criterion}--\ref{thm:two-value-iet} 给出底系统闭包性的可计算充要判别：
\[
\mathrm{Ind}(T_\theta,E)\in\mathbf{Kron}
\quad\Longleftrightarrow\quad
r_E\ \text{二值}
\quad\Longleftrightarrow\quad
b=\delta_{i-1}-c\delta_i,\ 0\le c<a_{i+1}.
\]
因此“可诱导闭包窗口”在旋转原型中具有完全算术化的分类。

\subsection{高阶推广问题}

将 $K$ 替换为高阶结构因子 $Z_s$（例如 Host--Kra 因子）可提出“诱导与高阶特征因子交换”的推广命题。其证明需要以高阶相对随机性替代相对弱混合，并在窗口可拉回条件下控制立方体系统的诱导行为。该方向构成后续工作。
