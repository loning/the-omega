Atomic-unit scaling, BO hierarchy, and the stability-window anchors used to interpret $(\alpha_{\mathrm{geo}},\mu_{\mathrm{geo}})$ in chemistry language. An optional mismatch-based interface template is recorded separately in Appendix~\ref{app:interface_phase_friction}. \\

\subsection{Reproducible scripts}
This paper directory includes a small helper script:
\begin{itemize}
\item \texttt{scripts/compute\_constants.py}: computes $\alpha_{\mathrm{geo}}^{-1}$ and $\mu_{\mathrm{geo}}$ and compares to CODATA central values (as recorded in \cite{Ma2025PCG}).
\end{itemize}
The scripts are written to be readable and auditable rather than maximally optimized.
