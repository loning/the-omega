# 9.1 分布式共识（客观性的纳什均衡）

**(Distributed Consensus - Objectivity as Nash Equilibrium)**

> **“如果世界是为你生成的，为什么我看到的红灯也是你的红灯？因为客观现实不是单一的真理，而是无数个玩家在交互中达成的共识。物理定律，就是那份巨大的分布式账本。”**

我们前面说，世界是为你生成的（UI理论）。但这有个大Bug：**唯我论**。
如果世界是你生成的，那我是谁？我是NPC吗？
如果我也是玩家，我想让猫死，你想让猫活，服务器听谁的？

本章将把**单机模式**升级为**联机模式（Multiplayer）**。
我们将证明：所谓的客观现实，不过是多智能体系统达成的**共识（Consensus）**。

### 9.1.1 维格纳的朋友：版本冲突

量子力学有个悖论叫**维格纳的朋友**：
*   朋友在实验室里，看到猫活了（版本A）。
*   维格纳在门外，认为朋友处于“看到死猫”和“看到活猫”的叠加态（版本B）。

如果每个人都有自己的私有现实，那世界早就分裂成无数个平行梦境了。
既然我们能在一个世界里聊天，说明系统运行着一套严格的**同步协议**。

### 9.1.2 现实是视角的交集

**定义 9.1.1（客观现实）**

客观现实既不是上帝视角，也不是你的私有视角。
客观现实是所有玩家视角的**最大公约数（交集）**。

$$ Real = \text{View}_{\text{A}} \cap \text{View}_{\text{B}} \cap \text{View}_{\text{C}} \dots $$

就像魔兽世界服务器：
*   玩家A看到了一棵树。
*   玩家B看到了那棵树。
*   系统只维护一个“树”的对象，并把它的引用广播给所有人。

只有被多个玩家**共同锁定**（观测）的状态，才是“硬”的物理现实。你脑子里的幻觉因为只有你一个人看见（没有共识），被系统判定为“虚幻”。

### 9.1.3 贝叶斯更新：波函数同步

共识是怎么达成的？通过**聊天（信息交换）**。

1.  **初始**：我认为电子在左，你认为在右（信念冲突）。
2.  **交互**：你对我喊：“我在右边抓到它了！”
3.  **同步**：我接收到信息。如果我信你（把你视为可靠的测量仪），我会更新我的概率分布。
4.  **结果**：我的波函数也瞬间坍缩到了右边。

**定理 9.1.1（共识收敛）**

只要大家讲道理（遵循贝叶斯规则），所有人的波函数会迅速收敛到一个**全局一致的状态**。这个状态就叫“客观事实”。

### 9.1.4 物理定律是纳什均衡

为什么共识总是收敛到物理定律（$F=ma$）上，而不是魔法上？
这是**博弈论**的结果。

把宇宙看作一个**预测游戏**。大家都要猜下一秒发生什么。
*   如果大家都乱猜，误差很大。
*   如果大家都同意一套**稳定的规则**（比如石头往下掉），所有人的预测误差最小。

**牛顿定律不是真理，它是进化稳定策略（ESS）。**
那个相信“石头往上飞”的玩家，早就因为预测错误被淘汰了（被石头砸死了）。活下来的玩家，脑子里都装着同一套物理引擎。

### 9.1.5 宇宙是区块链

在工程师眼里，这就是**区块链（Blockchain）**。

1.  **区块**：每一个发生的物理事件（坍缩）。
2.  **哈希链**：因果关系。现在必须包含过去的信息。
3.  **共识机制**：
    *   **工作量证明（PoW）**：你要改变现实，得消耗能量（做功）。防止有人用意念篡改数据。
    *   **广播**：光速 $c$ 是网络延迟。任何事件一旦发生，光速广播全服。
    *   **确认**：一旦信息被环境记录，区块就被**确认（Confirmed）**，成为不可更改的历史。

**结论**：

我们并不孤单。
所谓的“客观世界”，就是我们所有生命体共同维护的一份**去中心化的、防篡改的共享文档**。我们既是读者，也是作者。
