\section{Appendix C: Linear and Cyclic Counting Difference Identity}
\label{app:linear-cyclic}

Let $a_m=\card{X_m}=F_{m+2}$. Let $c_m=\card{X_m^{\mathrm{cyc}}}$ be the number of cyclically valid words (head and tail also cannot both be $1$). By constructing recurrence relations based on leading digit value and adjacency constraint, we find that $c_m$ satisfies the Lucas recurrence with $c_m=L_m$. Using the identity $L_m=F_{m-1}+F_{m+1}$, we obtain
\[
a_m-c_m=F_{m+2}-(F_{m-1}+F_{m+1})=F_{m-2}.
\]
Therefore, the number of boundary artifacts is $F_{m-2}$, which for $m=6$ equals $F_4=3$.
