\section{Information-Theoretic Time: Cylinder-Set Contraction and Entropy-Rate Arrow}\label{sec:info-time}

\subsection{History-Consistent Sets and Filtration (D6.1)}

For a stabilized output prefix $x_0^T:=(x_0,\dots,x_T)$, define the history-consistent set
\[
C_T(x_0^T):=\left\{\omega\in\{0,1\}^{T+m}:\ \forall 0\le t\le T,\ \Fold_m(\omega^{(m)}_t)=x_t\right\}.
\]
This set characterizes raw readout candidates still indistinguishable under the given output constraints. As $T$ increases, the constraints increase, and the set contracts in typical cases.

\subsection{Protocol-Level Definition of Temporal Arrow (D6.2)}

Define the protocol-level temporal arrow as:
\begin{itemize}
  \item If there exists a family of auditable posterior scale quantities (e.g., the induced measure of consistent sets, conditional entropy, or optimal encoding length) that monotonically contracts as $T$ increases, then define the temporal arrow in the direction of increasing $T$.
\end{itemize}
This definition lies entirely at the protocol level and does not introduce object-layer time coordinates.

\begin{remark}[Calibration of ``the Future'']
In this paper, ``the future'' strictly corresponds to the scale of uncertainty in the conditional distribution, for example,
$
H(x_{t+1}\mid x_{\le t})
$
or more generally posterior cylinder-set measure contraction indicators; we do not substantialize the residual as an additional ontological object.
\end{remark}

\subsection{Shannon--McMillan--Breiman Mechanism (T6.3, H6.3)}

Under ergodic measure-preserving systems with finite-generator partitions, the Shannon--McMillan--Breiman (SMB) theorem gives the exponential contraction rate of typical cylinder-set measure equal to metric entropy. This paper uses the following template:
\begin{itemize}
  \item \textbf{(H6.3)} The stabilized readout $(x_t)$ is induced by some ergodic process, and the partition used is a generating partition on the corresponding factor system;
  \item \textbf{(T6.3)} Then for typical $x_0^T$, the cylinder-set measure satisfies
  \[
  -\frac{1}{T}\log \mu([x_0^T])\to h_\mu,
  \]
  where $h_\mu$ is the Kolmogorov--Sinai entropy.
\end{itemize}
Hence, the ``temporal arrow'' can be rigorously expressed through the entropy-rate-controlled exponential contraction mechanism (Appendix \ref{app:smb}).
