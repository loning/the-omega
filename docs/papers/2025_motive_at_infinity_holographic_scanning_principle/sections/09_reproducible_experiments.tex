
\section{Reproducible experiments (pure Python)}
\label{sec:experiments}

This section provides reproducible toy experiments that validate the paper's \emph{new computable claims}: scan protocols in $\ScanAlg$ realize periods and admit auditable error decompositions. Standard mathematical facts (equidistribution, period closure properties) are not ``proven'' numerically; the experiments only demonstrate that the proposed implementations behave as predicted under finite resources.

\subsection{Reproducibility protocol}
\label{sec:reproducibility_protocol}

All experiments are implemented in pure Python~3 with no third-party dependencies. To reproduce the results:
\begin{itemize}
\item run \texttt{python3 scripts/period\_scan\_experiments.py} to generate the scan-period tables;
\item run \texttt{python3 scripts/alpha\_inverse\_search.py} to generate the low-complexity constant search table.
\end{itemize}
The scripts write \LaTeX{} row files into \texttt{sections/generated/} which are included below.

\subsection{Experiment V: low-complexity constant search for $\alpha^{-1}$}
\label{sec:constant_search_experiment}

As a toy model for ``selection under a bounded description budget'', we reproduce an exhaustive search over the low-complexity ansatz
\begin{equation}
\label{eq:alpha_ansatz}
v(a,b,c)=a\pi^3+b\pi^2+c\pi,\qquad a,b,c\in\ZZ_{\ge 0},\quad a+b+c\le 10,
\end{equation}
targeting the CODATA 2022 central value $\alpha^{-1}(0)=137.035999177$ \cite{CODATA2022RMP}. This complexity domain contains the geometric candidate $(a,b,c)=(4,1,1)$ used in the constants-geometry manuscript \cite{Ma2025PCG}. The goal here is not metrology, but a sharp \emph{uniqueness gap} under a fixed budget.

\begin{remark}[Running and scheme dependence (interpretation-layer note)]
The electromagnetic coupling $\alpha(\mu)$ is scale- and scheme-dependent in quantum field theory; CODATA quotes the low-energy value $\alpha(0)$ in a specific metrological convention. In this paper, the bounded-complexity search should be read as a \emph{protocol-level} rigidity signal at a fixed reference convention: it tests whether a low-description geometric expression is uniquely selected within a constrained ansatz class. Any map from a geometric baseline to an operational coupling across scales belongs to interpretation-layer modeling and is treated elsewhere in the HPA--$\Omega$ program.
\end{remark}

\begin{proposition}[Uniqueness gap at fixed coefficient-sum complexity]
\label{prop:alpha_integer_rigidity_mai}
Within the complexity domain $a,b,c\in\ZZ_{\ge 0}$ and $a+b+c\le 10$, the unique minimizer of $|a\pi^3+b\pi^2+c\pi-\alpha^{-1}|$ (with $\alpha^{-1}=137.035999177$) is $(a,b,c)=(4,1,1)$, with relative error $2.22\times 10^{-6}$. The next-best triple in the same domain has relative error at least $3.24\times 10^{-3}$.
\end{proposition}

\begin{proof}
This is a finite check by exhaustive enumeration over all triples $(a,b,c)\in\ZZ_{\ge 0}^3$ with $a+b+c\le 10$ and minimization of the absolute error; see \texttt{scripts/alpha\_inverse\_search.py}, which generates the top-candidate table rows included in Table~\ref{tab:alpha_integer_search}.
\end{proof}

\begin{corollary}[Robustness under target perturbations]
\label{cor:alpha_gap_robustness}
Let $V=\{a\pi^3+b\pi^2+c\pi:\ a,b,c\in\ZZ_{\ge 0},\ a+b+c\le 10\}$ and let $T=\alpha^{-1}=137.035999177$. Then the minimizer $v_\star=4\pi^3+\pi^2+\pi$ remains the unique minimizer of $|v-T'|$ over $v\in V$ for every perturbed target $T'$ satisfying $|T'-T|<m/2$, where $m$ is the best-vs-second-best margin in Lemma~\ref{lem:gap_stability}. In particular, the observed gap in Table~\ref{tab:alpha_integer_search} yields a wide robustness interval compared to metrological uncertainties.
\end{corollary}
