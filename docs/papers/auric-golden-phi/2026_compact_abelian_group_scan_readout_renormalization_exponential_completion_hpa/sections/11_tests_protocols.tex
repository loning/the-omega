\section{Falsifiable Predictions and Computational Testing Protocols}

\subsection{One-Dimensional Scan Tests}

Given several $\alpha$ values (including $\varphi^{-1}$, $\varphi-1$, and random irrationals), compare:
\begin{enumerate}
  \item decay of star discrepancy $D_N^*$;
  \item three-gap structure and gap distributions;
  \item distribution of $\varepsilon$-return times and suppression of short returns;
  \item frequency-error bounds over a fixed window family $\{W_j\}$.
\end{enumerate}

\subsection{Multidimensional Joint-Scan Tests}

Compare two step-vector classes:
\begin{itemize}
  \item degenerate class: $(\delta,\dots,\delta)$;
  \item non-resonant class: $\alpha_i=\varphi\sqrt{p_i}$ (or other rationally independent constructions).
\end{itemize}
Metrics include box coverage rate, $L^1$/Wasserstein deviation of empirical measure from Haar, and decay of inter-coordinate correlations.

\subsection{Symbolic Readout and Complexity Tests}

For rotation-coded sequences, compute complexity $p(n)$ and verify Sturmian minimal complexity. For $\alpha=\varphi^{-1}$, verify consistency between the empirical frequency vector and the substitution PF vector.

\subsection{Equidistribution Preservation Under Sparse Gating: A Verifiable Technical Highlight}

Let $(x_n)$ be an equidistributed sequence on $[0,1)$, and let $(S_n)$ be i.i.d. Bernoulli$(p)$ gating variables ($p\in(0,1)$), independent of $(x_n)$. Define the selected index set
\[
I_N=\{0\le n<N:S_n=1\},\qquad M_N=|I_N|.
\]
Let $(x_n)_{n\in I_N}$ be the sparse subsequence.

\begin{theorem}[Independent positive-density gating preserves equidistribution, almost surely]\label{thm:sparse-gating}
For any interval $J\subset[0,1)$,
\[
\lim_{N\to\infty}\frac{1}{M_N}\sum_{n\in I_N}\ind_J(x_n)=|J|
\]
almost surely.
\end{theorem}
The proof is given in Appendix \ref{app:sparse-gating}, together with an explicit finite-sample error decomposition: discrepancy term of the original sequence + concentration term induced by gating.

This theorem provides a rigorous basis for ``readout sparsification under independent gating still preserves uniformity,'' and allows $\varphi^{-1}$ to be used as a falsifiable parameterized gating probability.
