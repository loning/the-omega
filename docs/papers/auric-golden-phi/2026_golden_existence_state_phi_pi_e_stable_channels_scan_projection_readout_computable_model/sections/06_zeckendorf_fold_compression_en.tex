\section{Zeckendorf--Window Folding: Computable Compression from Microscopic States to Stable Types}

\subsection{Zeckendorf representation and window truncation}

Every non-negative integer $N$ can be uniquely written as a sum of non-adjacent Fibonacci numbers:
\[
N=\sum_{k\ge 1}c_k F_{k+1},\quad c_k\in\{0,1\},\quad c_kc_{k+1}=0.
\]
Define the window folding map
\[
\mathrm{Fold}_m(N):=(c_1,\dots,c_m)\in X_m,
\]
padding with $0$ when necessary.

\subsection{Computable compression and double structure: Stable types and degeneracy}

Let $\Omega_m=\{0,1,\dots,2^m-1\}$ denote the $m$-bit microscopic index set (interpreted in binary), and define the folding map
\[
\mathrm{Fold}_m:\Omega_m\to X_m.
\]
It compresses $2^m$ microscopic states into $F_{m+2}$ stable types. On the lower range $\{0,1,\dots,F_{m+2}-1\}$, $\mathrm{Fold}_m$ is a bijection; on the full range $\Omega_m$, $\mathrm{Fold}_m$ is surjective with non-trivial degeneracy distribution.
This compression is algorithmic: given $N$, compute Zeckendorf digits, then truncate.

\[
\card{X_6^{\mathrm{cyc}}}=18,\quad \card{X_6^{\mathrm{bdry}}}=3,

where the boundary words are precisely
\[
X_6^{\mathrm{bdry}}=\{100001,\ 100101,\ 101001\}.

Furthermore, the boundary words have a two-fold preimage structure under $\mathrm{Fold}_6$: each boundary word corresponds to exactly two microscopic indices differing by $F_9=34$, forming a ``rigid geometry'' of ``same boundary, different lifting amounts''.
The above structure is a pure mathematical result and can be completely verified by exhaustive enumeration, hence it is a foundational auditable output of the model.
