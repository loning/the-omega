\section{Protocol connections and toy holonomy on the Hilbert grid}
\label{sec:protocol_connections_holonomy}

This section records a minimal, auditable connection model that makes the slogan ``gauge fields as compensating connections'' concrete at finite resolution.
The construction is a toy model: it is discrete, finite, and fully computable at the minimal balanced scale $(m,n)=(6,3)$.
Its purpose is to exhibit, within the same protocol language as the rest of the paper, how nontrivial holonomy can arise when stable readout types are compared across neighboring Hilbert addresses.

\subsection{Fibers under projection: stable types with finite degeneracy}
\label{subsec:fiber_under_projection}

At $m=6$, the folding map $\mathrm{Fold}_6:\{0,\dots,63\}\to X_6$ is surjective and each stable type $w\in X_6$ has a finite preimage
\[
P(w):=\mathrm{Fold}_6^{-1}(w)\subset\{0,\dots,63\},
\qquad |P(w)|\in\{2,3,4\}.
\]
From the protocol viewpoint, $P(w)$ is a finite \emph{fiber} of microstates that project to the same stable readout label.
Comparing stable labels across space requires a convention for how these fibers are identified, which is the discrete origin of a compensating connection.

\subsection{A deterministic discrete connection on grid edges}
\label{subsec:deterministic_edge_connection}

Fix Hilbert order $n=3$ and embed indices $k\in\{0,\dots,63\}$ into an $8\times 8$ grid via Hilbert addressing (Section~\ref{sec:hilbert_addressing}).
Label each site by its stable type $w=\mathrm{Fold}_6(k)$.
For each undirected nearest-neighbor grid edge $\{a,b\}$, we define a deterministic transport map between the two endpoint fibers by the following rule:
\begin{itemize}
\item For each stable type $w$, list its fiber $P(w)$ in increasing order and pad it deterministically to length $4$ (the maximal degeneracy at $m=6$) by repeating its last element.
\item Define a cost between microstates by Hamming distance on their $6$-bit binary words.
\item Choose the minimum-cost bijection between the two length-$4$ padded fibers; this yields a permutation in $S_4$.
\item For the reverse orientation, use the inverse permutation.
\end{itemize}
This produces a discrete, non-abelian toy connection on edges, designed to be auditable and fully reproducible by a finite exhaustive search over $4!$ matchings per edge.

\subsection{A phase-register lift and a CP-odd invariant (toy)}
\label{subsec:holonomy_phase_lift_cp}

To allow CP-odd signatures in a holonomy-based description, one must go beyond purely real orthogonal representations.
As a minimal protocol-level bridge consistent with the $\ZZ_{128}$ phase-register stance, we can attach a deterministic discrete phase to each microstate and lift the edge transport to a unitary (phase-weighted) transport.
Projecting the resulting $4\times 4$ unitary plaquette holonomy to the $3$-dimensional sum-zero subspace and renormalizing by a deterministic Gram--Schmidt procedure yields an effective $3\times 3$ unitary matrix.
From this effective unitary one can compute a rephasing-invariant CP-odd quantity, e.g.\ the Jarlskog-type invariant
\[
J:=\Im\!\bigl(U_{00}U_{11}U_{01}^\ast U_{10}^\ast\bigr).
\]
