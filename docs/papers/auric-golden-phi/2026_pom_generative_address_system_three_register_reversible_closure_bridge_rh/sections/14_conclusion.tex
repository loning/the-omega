\section{结论}

本文提出并形式化投影本体数学（POM）的生成式地址语义：以可寻址读出刻画对象存在性，并以空值 $\NULL$ 表示“无地址则读出不定义”。在最小公理体系 POMmin 下，本文从二元微态读出生成稳定地址空间，并在该空间上构造与 $(\NN,+,\times)$ 同构的半环结构，从而在不预置算术原语的条件下实现基本算术的内生涌现。进一步，本文以素数寄存器外置残差，构造无损提升与可逆回放，并给出信息账本恒等式以分解投影压缩与残差信息之间的守恒关系；在投影词（PW）证书演算的可判定片段内，建立正规形唯一与判等可判定；在 unitary slice 核验机制下证明类型安全，从而把临界线约束内化为可见参数域上的证书化拒绝规则。

第 \ref{sec:conclusion-cluster} 节汇集关于编码、残差压缩、运算构造与 unitary slice 数值证书可重复性的结构性定理与构造，并将其与附录中的证明携带构造对接。

\subsection{主要贡献（按依赖链分组）}
\begin{enumerate}
  \item \textbf{语义层：}给出“可寻址读出 $\Leftrightarrow$ 存在性”的对象语义，并将 $\NULL$ 固定为证书缺失的逻辑输出，从而把可核验性内化为体系属性。
  \item \textbf{结构层：}在 POMmin 下构造稳定地址空间与折叠归一化，并证明在该对象域内可定义并获得与自然数半环同构的算术结构。
  \item \textbf{守恒与可逆性：}通过素数寄存器承载残差，建立无损提升与可逆回放机制，并用信息账本恒等式对可见熵、纤维体积项与残差项作严格分解；进一步引入 prime-register 预算度量并给出与折叠纤维账本、径向精度账本相容的下界约束。
  \item \textbf{证书语义：}在 PW 可判定片段内建立正规形与判等机制，并给出审计优先三值检查器与证书对象格式，使验证过程可离线复算且实现无关；在代数子语言中给出 unitary slice 的 Cayley 有理化与清分母后的实根隔离证书，从而获得零浮点核验后端。
  \item \textbf{临界线约束（健全性）：}在 unitary slice 核验机制下证明类型安全（健全性）：任何已可寻址且可核验的零点证书必满足 $\Re(s)=\tfrac12$。
  \item \textbf{桥接与边界：}通过 BridgeRH 桥接条件把经典零点事件归约到可核验对象域，从而给出条件性 RH 推论链；并以径向自由度的证书承载需求与可除群--自由阿贝尔群不相容的代数阻碍刻画“三寄存器闭包外延”的必要性（第四寄存器机制）。
  \item \textbf{结构性补充（可核验不变量与否证器）：}在既有三寄存器与强类型核验协议内，补充一组可直接复用的结构定理：相位紧化的显式 Möbius 共轭与有理相位高度预算（附录 \ref{app:phase-compactification-register-unification}），谱流绕数对 $H^2$-粘合障碍的整数化检测与全局 $\NULL$ 失败三分律（附录 \ref{app:spectral-flow-cohomology-min-register}），以及端点尾律与有限核极点格点刚性的可证伪下界（附录 \ref{app:obstruction-tail-pole-rigidity}）。
\end{enumerate}

\subsection{局限与可证伪性}
本文关于经典 RH 的结论均以桥接条件（假设 \ref{ass:bridge-rh}）及必要的地址完备性前提为依赖条件；健全性与完备性的逻辑分离见第 \ref{sec:bridge-rh} 节与讨论部分。另一方面，在固定验证规则与参数、并采用确定性验证器时，任何零点/非零/覆盖式 $\NULL$ 断言都必须伴随可离线核验的证书对象；验证失败即构成对相应断言的否证。可复现与可核验表述的形式化说明见附录 \ref{app:audit}，数值证书构造与统一编码层见附录 \ref{app:inject-code-audit} 及相关附录。

\subsection{结构性综合与资源相图}
附录 \ref{app:structural-synthesis-phase-diagram} 将“地址—守恒—寄存器—纤维—面积相位”之间的耦合整理为一组可核验的结构性判据，从而把 $\NULL$ 的发生机制从抽象的完备性缺口细化为可复算、可证伪、可归因的失败类型。就主文结论而言，可将其中与实现与审计最直接相关的要点压缩为三条：
\begin{itemize}
  \item \textbf{四因子记录轴（扩展保存的规范分解）：}在同时包含折叠/跨分辨率投影、同余/素数残差外置、相位周期折叠与端点紧化的观测链中，使扩展读出单射所需的最小记录轴可规范分解为
  $$
  r\ \cong\ r_{\mathrm{fin}}\times r_{\widehat{\ZZ}}\times r_{\mathrm{wind}}\times r_{\mathrm{end}},
  $$
  并分别对应有限缺陷、profinite 同余轴、绕数/周期折叠与端点载荷（离散分支 $+$ 连续精度势）。
  \item \textbf{二维资源相图（离散模积预算 $\times$ 端点精度预算）：}在固定验证规则与参数下，除“语义空值/规则空值”外，$\NULL$ 的可重复发生主要由离散侧的 prime-register 模积（或比特）预算与连续侧的端点精度预算共同控制；四象限判别与阈值化不等式汇总见附录 \ref{app:structural-synthesis-phase-diagram} 的表 \ref{tab:resource-phase-diagram}。
  \item \textbf{地址前缀合法与缩略图律（分辨率 $\times$ 可辨识性）：}在 canonical model 中，可解码地址语言 $\mathcal{L}$ 为前缀自由并具有显式 Kraft 松弛 $\sum_{a\in\mathcal{L}}2^{-|a|}=1/2$（定理 \ref{thm:canonical-prefixfree-kraft}），从而为“地址—残差—证书”的自描述打包提供编码余量；跨分辨率相容进一步把有限读出固定为逆极限圆柱约束，并给出前缀超度量下的直径律 $\mathrm{diam}(U_m)\le 2^{-m}$（定理 \ref{thm:thumbnail-inverselimit} 与推论 \ref{cor:ultrametric-cylinder-diameter}）。结合纤维单射化的记录预算下界（推论 \ref{cor:record-budget-lowerbound}）与碰撞阈值/有效扫描深度上界（命题 \ref{prop:collision-null-threshold} 与推论 \ref{cor:max-effective-scan-depth}），可将“扫描更久 $\Rightarrow$ 更清晰”的启发性表述分解为两条可核验结构律：分辨率由前缀长度控制，而可辨识性由记录轴预算与其相边界控制。
\end{itemize}
