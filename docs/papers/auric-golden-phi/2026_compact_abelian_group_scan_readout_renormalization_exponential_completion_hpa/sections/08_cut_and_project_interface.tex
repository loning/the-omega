\section{Hidden-Dimension/Window Interface: Cut-and-Project Model Sets}

\subsection{Definition of Model Sets}

Decompose $\RR^n=E_\parallel\oplus E_\perp$. Let $L\subset\RR^n$ be a lattice, with projections $\pi_\parallel,\pi_\perp$, and let $W\subset E_\perp$ be a window. Define the model set
\[
\Lambda=\{\pi_\parallel(\ell):\ell\in L,\ \pi_\perp(\ell)\in W\}.
\]
In this language, ``existence'' is formalized as window membership in internal space, while ``visible structure'' is given by external projection.

\subsection{Interface with Rotation Coding}

One-dimensional Sturmian sequences can be viewed as slicing codes of two-dimensional cut-and-project constructions; multidimensional torus scans correspond to higher-dimensional cut-and-project models. This places the ``hidden dimension--window--visible sequence'' correspondence in a unified protocol layer and provides a mathematical interface for quasicrystal-like aperiodic order.
