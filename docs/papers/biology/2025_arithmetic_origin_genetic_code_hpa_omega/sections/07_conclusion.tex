\section{Conclusion}
\label{sec:conclusion}

We constructed a reproducible minimal arithmetic--topological interface for the genetic code based on the $\mathrm{Fold}_6$ resolution-folding template.
Codons are embedded into a $6$-bit microstate space via an unknown two-bit nucleotide dictionary and are projected by Zeckendorf window folding to a stable type space $X_6$ of size $21$ with three boundary states.

Formulating ``reverse compilation'' as an identification problem over the finite space of $24$ encodings, we showed that a minimal start--stop boundary-homology anchor selects a unique encoding $\mu^\ast$:
\[
A\mapsto 00,\quad C\mapsto 01,\quad G\mapsto 10,\quad U\mapsto 11.
\]
Under $\mu^\ast$, $\mathrm{AUG}$ and $\mathrm{UAA}$ share the boundary word $100001$ and realize the rigid preimage pair $\{14,48\}$, yielding a testable start--stop $14/48$ symmetry split by the Fibonacci weight $34$.
We derived stop-codon fine structure, boundary-sector codon identities, and codon/sequence spectrum definitions, and we provided auditable scripts that reproduce all finite claims and enable large-scale genome tests.
