\section{稳定扇区、类型折叠与“物质化信息”表征}

\subsection{局域窗口与微态空间}

对任一时刻 $t$，在三维可观测集 $\Sigma_t$ 上考虑局域读出窗口（例如一个有限邻域或有限长度的比特窗口）。将其抽象为长度为 $m$ 的二元微态字
\[
\Omega_m:=\{0,1\}^{m},\qquad |\Omega_m|=2^{m}.
\]
该 $\Omega_m$ 不必被理解为真实粒子态，而是“有限分辨率读出后可记录的局域符号微态”。

\subsection{约束通道与稳定类型集}

引入一组可检验的“稳定性约束通道”，用以选择在协议读出下保持语法稳定的类型集合。为给出可计算原型，本文采用经典的“禁字语法”范式：设稳定类型集
\[
X_m:=\Big\{w\in\{0,1\}^{m}:\ \text{不含子串 }11\Big\}.
\]
这是符号动力系统中的有限型子移位原型。其计数满足 Fibonacci 递推：
\[
|X_m|=F_{m+2},
\]
其中 $F_{n}$ 为 Fibonacci 数列（$F_1=F_2=1$）。该计数可作为“在局域约束下可长期保持稳定的类型容量”的定量指标。

\subsection{折叠映射：从微态到稳定类型}

定义一个从微态到稳定类型的折叠算子
\[
\Fold_m:\Omega_m \twoheadrightarrow X_m,
\]
其作用是将不满足稳定语法的微态按某种规范化规则映射到最接近的稳定类型。为确保可审计，本文在附录中给出一类基于 Ostrowski/Zeckendorf 表示的规范折叠方案，使 $\Fold_m$ 可计算且具有明确的退化结构（不同微态可折叠到同一稳定类型）。退化结构可被理解为“读出分辨率不足导致的等价类”。

\subsection{可解码信息与物质化表征}

本文以\textbf{可解码信息}作为“物质化表征”的协议定义：在给定分辨率与约束通道下，落入稳定类型集 $X_m$ 并在扫描迭代中保持统计稳定（例如出现频率、邻接统计或缺陷预算受控）的读出输出，构成可持久的、可再识别的“对象化”结构候选。相应地：
\begin{itemize}
  \item “物质性”不被定义为本体层基本实体，而被定义为\textbf{稳定读出类型的持久性与可复现性}；
  \item “相互作用”可被定义为维持跨位置/跨尺度一致性所需的补偿规则或连接结构（例如约束一致性条件）。
\end{itemize}

\subsection{不可解码余项与协议意义上的“未来”}

对任意微态 $s\in\Omega_m$，折叠后仅保留稳定类型 $\Fold_m(s)$。微态中不被稳定类型吸收的余项可表述为“窗口外贡献”或“提升量”（uplift），其代表在当前分辨率下不可恢复的潜在自由度。将扫描迭代与分辨率增长（$m$ 随 $t$ 增大）结合时，可将“未来”定义为：\textbf{在给定时刻的分辨率尚无法解码、但在更高分辨率下可被纳入稳定类型或缺陷通道的那部分信息深度}。该定义避免将未来实体化为外在维度，并将其转化为可审计的“读出深度”概念。
