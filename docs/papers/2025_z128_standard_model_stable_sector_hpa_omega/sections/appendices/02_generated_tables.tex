All fragments in this appendix are outputs of \emph{deterministic} finite enumerations or bounded sweeps over explicitly stated finite domains (e.g.\ all words in $X_m$ for a fixed $m$, or all candidates in a bounded coefficient/denominator box).
When a caption says ``rows are generated by'' a script, the intended meaning is:
the script implements the stated finite enumeration/sweep and writes a \LaTeX{} fragment to avoid manual transcription errors.
No hidden continuous parameters, stochastic training, or non-audited optimization is used in generating these rows.

\subsection{Audit metrics for bounded-complexity closures}

For a positive reference target $x^{\mathrm{ref}}$ and a candidate prediction $x(\theta)$,
we use the (dimensionless) log-mismatch
\[
e(\theta):=\left|\log\!\left(\frac{x(\theta)}{x^{\mathrm{ref}}}\right)\right|.
\]
For multi-target closures we report the minimax objective
\[
E_\infty(\theta):=\max_i e_i(\theta).
\]
Tables~\ref{tab:audit_closure_metrics} and \ref{tab:audit_closure_quantiles} record candidate-domain sizes,
uniqueness gaps, and (for large candidate domains) distribution quantiles.
For a fixed candidate family $\Theta$ equipped with the uniform prior, the empirical frequency $N_{\le \epsilon}/|\Theta|$ can be read as the probability that a uniformly random candidate achieves $E_\infty\le \epsilon$.
When the minimizer is unique, the probability that a uniformly random candidate matches as well or better than the reported minimizer is $1/|\Theta|$.
These within-family probabilities provide explicit look-elsewhere context for the stated hypothesis classes; they do not claim a global significance over unrestricted expression grammars.

\subsection{Uncertainty robustness (minimizer stability under target perturbations)}
\label{app:audit_uncertainty}

To stress-test how stable the selected minimizers are under perturbations of the reference targets,
we sample reference values within explicit uncertainty models and recompute the minimizer under the same tie-break rules.
The sampling is deterministic (fixed RNG seed) and is intended as an audit-oriented robustness check.
We use simple truncated-normal models designed to keep targets in their admissible domains:
for positive scalar targets $x^{\mathrm{ref}}>0$, we sample $x'\sim\mathcal{N}(x^{\mathrm{ref}},\sigma)$ truncated to remain positive;
for mixing-angle targets quoted as $\sin^2\theta$, we sample $\sin^2\theta'\sim\mathcal{N}(\sin^2\theta,\sigma)$ truncated to $(0,1)$ and then use $s=\sqrt{\sin^2\theta'}$;
and for a phase reference $\delta$ we sample $\delta'\sim\mathcal{N}(\delta,\sigma_\delta)$ truncated to $[0,360]$ degrees.
When a standard reference uncertainty is explicitly quoted (e.g.\ PDG for $J$), we use it directly; otherwise (e.g.\ scheme-dependent electroweak quantities and matching-layer anchors) the adopted $\sigma$ values are recorded as conservative audit stress-test scales rather than as a statistical claim.

\subsection{Rigidity enumerations for closed constant targets}
\label{app:constant_rigidity_enumerations}

\begin{remark}[Why the coefficient-sum bound is not vacuous (order-of-magnitude check)]
\label{rem:alpha_simplex_nonvacuous}
In the simplex search domain $a,b,c\in\ZZ_{\ge 0}$ with $a+b+c\le S$,
one always has
\[
a\pi^3+b\pi^2+c\pi \le (a+b+c)\pi^3 \le S\,\pi^3.
\]
Using the classical bound $\pi<22/7$ gives $\pi^3<(22/7)^3\approx 31.1$ and
therefore $S\le 4 \Rightarrow a\pi^3+b\pi^2+c\pi<125$.
Since the reference electromagnetic inverse coupling satisfies
$\alpha_{\mathrm{em}}^{-1}\approx 137>125$ (CODATA/PDG; Table~\ref{tab:quant_summary}),
any nontrivial match requires $a+b+c\ge 5$.
Thus the bounded search $a+b+c\le 10$ is small but already above the minimal
order-of-magnitude threshold.
\end{remark}

\begin{remark}[Why the integer-$\pi^2$ sweep is effectively local (order-of-magnitude check)]
\label{rem:ew_alpha_pi2_nonvacuous}

Any integer $n$ for which $n\pi^2$ can compete must satisfy $n\approx x^{\mathrm{ref}}/\pi^2$.
Using $9<\pi^2<10$ gives the crude localization
\[
\frac{x^{\mathrm{ref}}}{10}<n<\frac{x^{\mathrm{ref}}}{9}.
\]
Since $x^{\mathrm{ref}}\approx 128$, only $n$ in a narrow band around $13$ can be relevant; the sweep $1\le n\le 50$ is a small explicit overbound that contains this band.
\end{remark}

\begin{remark}[Why the bounded-denominator rational sweep is nonvacuous]\label{rem:ew_sin2_denominator_nonvacuous}
For any real $x$ and any $Q\ge 1$, Dirichlet's approximation theorem implies the existence of a reduced rational $p/q$ with $1\le q\le Q$ and
\[
\left|x-\frac{p}{q}\right|<\frac{1}{qQ}\le \frac{1}{Q^2}.
\]
Thus the choice $Q=50$ guarantees (a priori) the existence of candidates within absolute error $\le 4\times 10^{-4}$ while keeping the hypothesis class finite and auditable.
\end{remark}

\begin{remark}[A nonvacuous magnitude window for the Jarlskog $(a,n)$ box]\label{rem:jarlskog_box_nonvacuous}
Let $J_{\mathrm{ref}}\approx 3\times 10^{-5}$ be the PDG-scale target used in the paper \cite{PDGRPP2024}.
Within the bounded box $1\le a\le 50$, if $n\le 5$ then
\[
\frac{1}{a\pi^n}\ge \frac{1}{50\pi^5}>\frac{1}{50(22/7)^5}\approx 6.5\times 10^{-5},
\]
so the entire $n\le 5$ slab is too large to match $J_{\mathrm{ref}}$ even at maximal $a$.
Thus any nontrivial rigidity search with $a\le 50$ must include $n\ge 6$; the chosen domain $1\le a\le 50$, $1\le n\le 20$ contains this minimal magnitude-viable window.
\end{remark}
