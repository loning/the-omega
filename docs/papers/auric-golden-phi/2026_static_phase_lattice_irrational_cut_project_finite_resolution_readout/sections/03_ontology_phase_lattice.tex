\section{本体层：六维整数格点相位骨架}

\subsection{微观索引格}

设
\[
\Lambda := \ZZ^{6}\subset \RR^{6}
\]
为六维超立方整数格点。本文将 $\Lambda$ 视为“相位—索引骨架”，用于组织微观自由度与可计算的地址结构。该设定本身不等同于“经验空间为六维”，而是一个用于构造协议读出与可观测投影的离散底层结构。

\subsection{静态全局态}

在抽象层面，可采用算子代数语言：给定准局部算子代数 $\mathcal{A}$ 与唯一归一化态 $\omega_{\Omega}$。该态静态存在；经验意义上的“演化”不作为本体层输入，而由协议层的扫描读出产生。为保持本文的可审计性，后续在多数构造中仅使用 $\Lambda$ 的几何与可计算结构，并不依赖 $\omega_{\Omega}$ 的特定微观实现。
