\section{Degenerate parameters and minimality check}\label{app:degeneracies}

This appendix records the explicit cancellations at the exceptional parameter values \(y\in\{-1,0,1\}\).

\subsection{\texorpdfstring{\(y=1\)}{y=1}}

At \(y=1\),
\[
N(t,1)=-(t-1)(t+1)^2,
\qquad
D(t,1)=(t-1)(t+1)^2(2t-1),
\]
so
\[
Z(t,1)=\frac{N(t,1)}{D(t,1)}=\frac{1}{1-2t},
\qquad
Z_m(1)=2^m.
\]

\subsection{\texorpdfstring{\(y=0\)}{y=0}}

At \(y=0\),
\[
N(t,0)=-(t-1)(t+1),
\qquad
D(t,0)=(t-1)^2(t+1),
\]
so after cancellation the reduced denominator degree drops from \(4\) to \(2\).

\subsection{\texorpdfstring{\(y=-1\)}{y=-1}}

At \(y=-1\), one has \(N(t,-1)=D(t,-1)\), hence \(Z(t,-1)\equiv 1\).

\subsection{Minimality for generic \texorpdfstring{\(y\)}{y}}

For $y\notin\{-1,0,1\}$, none of the above common factors occur; equivalently, $N(t,y)$ and $D(t,y)$ are coprime.
Therefore the reduced denominator has degree $4$ and the order-$4$ recurrence \eqref{eq:recurrence} is minimal, as used in Theorem~\ref{thm:minimal-order}.

\paragraph{Explicit Euclidean certificate in reciprocal variable.}
Set \(\lambda=1/t\) and define
\[
N_{\lambda}(\lambda,y):=\lambda^3N(1/\lambda,y)=\lambda^3+y\lambda^2+(y^2-y-1)\lambda+y^3-2y,
\]
\[
\Pi(\lambda,y):=\lambda^4D(1/\lambda,y)=\lambda^4-\lambda^3-(2y+1)\lambda^2+\lambda+y(y+1).
\]
Since \(N(0,y)=1\), \(t=0\) is never a common root, so \(N\) and \(D\) have a common factor in \(\QQ(y)[t]\) iff \(N_{\lambda}\) and \(\Pi\) have one in \(\QQ(y)[\lambda]\).

Direct elimination gives
\[
\Pi-\lambda N_{\lambda}=-(y+1)\lambda^3-(y^2+y)\lambda^2+(-y^3+2y+1)\lambda+(y^2+y)=:R_1,
\]
\[
R_1+(y+1)N_{\lambda}=y(y+1)^2(y-1)=:R_2.
\]
Hence any common divisor of \(\Pi\) and \(N_{\lambda}\) must divide \(R_2\).
If \(y\notin\{-1,0,1\}\), then \(R_2\neq0\), so
\[
\gcd_{\CC(\lambda)}(\Pi,N_{\lambda})=1.
\]
Under \(N(0,y)=1\), this is equivalent to
\[
\gcd_{\QQ(y)[t]}(N,D)=1,\qquad y\notin\{-1,0,1\}.
\]
Therefore the reduced denominator has degree \(4\) away from the listed exceptional points.

\subsection{Coefficient nonnegativity check}

Theorem~\ref{thm:coeff-nonneg} gives a complete proof that $a_{m,k}\ge0$. For reproducibility, we also record a finite-cutoff computational check: for each $m$, write
\[
Z_m(y)=\sum_{k=0}^{\lfloor (m+3)/2\rfloor} a_{m,k}y^k.
\]
This is immediate for $m\le 3$ from the initial values $Z_0=1$, $Z_k=(y+1)^k$ for $k=1,2,3$.

For $m\ge 4$, the recurrence \eqref{eq:recurrence} gives a coefficient-level relation:
\[
a_{m,k}=a_{m-1,k}+2a_{m-2,k-1}+a_{m-2,k}-a_{m-3,k}-a_{m-4,k-1}-a_{m-4,k-2}.
\]
Computing in~$\ZZ[y]$ for $m\le 5000$ with the support bound $k\le\lfloor (m+3)/2\rfloor$, we verified all coefficients are nonnegative for each tested $m$; the implementation is available as a stand-alone script (\texttt{scripts/coeff\_nonneg\_check.pl}), so this computational certificate can be reproduced or extended to larger truncation levels.
