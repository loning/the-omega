
\section{Falsifiability: predictions in the protocol language}
\label{sec:falsifiability}

The folding counts and tables are mathematical-layer facts.
The statements below are physical-layer predictions: they can be tested by numerical experiments or (where applicable) by observational constraints.

\subsection{P1: right-handed neutrinos as protocol-external / ghost modes}
\label{subsec:p1_rh_neutrino}

If weak chirality originates from a Hilbert-protocol orientation choice (Axiom~\ref{ax:scl}), then a neutral singlet $\nu_R$ can behave as a protocol-decoupled mode: it may be stable at the level of type labeling while remaining effectively unobservable through the weak compensation connection within a fixed protocol.
Operationally, this manifests as an ``invisible'' or ``ghost-like'' degree of freedom with extremely suppressed couplings at the readout level \cite{PDGRPP2024}.
\paragraph{Relation to the hidden microstates.}
At $m=6$, the protocol-unstable complement has size $|\Omega_6\setminus X_6|=64-21=43$.
In addition to protocol-decoupling within $X_6$, a stronger possibility is protocol-instability: if certain degrees of freedom are implemented as readout patterns outside $X_6$, they reside in this ghost sector and are absent from stable visible outputs.

\subsection{P2: chirality-domain defects and large-scale statistical signatures}
\label{subsec:p2_domain_walls}

If early-universe initialization admitted domains with different Hilbert orientation classes, domain boundaries would act as protocol defects.
Such defects should leave parity-sensitive statistical signatures (e.g.\ polarization correlations) tied to the chirality index sign.
\paragraph{Test strategy.}
The prediction is protocol-level: one should search for statistics that are invariant under orientation-preserving layout changes but change sign under reflection-like protocol swaps, consistent with Proposition~\ref{prop:chi_flip}.

\subsection{P3: resolution jumps and Fibonacci-structured spectrum thresholds}
\label{subsec:p3_resolution_jumps}

At window length $m$, the admissible stable type count is $|X_m|=F_{m+2}$ (Lemma~\ref{lem:xm_fib}).
If effective window length changes with energy or environment, the number of stable types should exhibit threshold behavior constrained by Fibonacci growth rather than arbitrary particle additions.
\paragraph{Fibonacci-structured thresholds.}
Since $F_{m+2}$ obeys $F_{m+2}=F_{m+1}+F_m$, any one-step resolution uplift $m\mapsto m+1$ admits only a constrained increment of stable type count.
This provides a rigid spectral-template prediction: new stable modes, if any, should enter in Fibonacci-structured batches.

\subsection{P4: CP violation magnitude tied to a rigid phase-space volume}
\label{subsec:p4_cp_volume}

If CP violation is controlled by a CP-odd phase space $\mathcal{M}_{\mathrm{CP}}$ with fixed volume and multiplicity as in \eqref{eq:j_geo}, then CP-odd observables should exhibit rigid low-complexity signatures and constrained drift patterns under protocol deformation.
\paragraph{Numerical rigidity target.}
Equation~\eqref{eq:j_geo} provides a concrete normalization target for the CKM Jarlskog invariant: $J_{\mathrm{geo}}=1/(11\pi^7)$.
Any protocol deformation model that claims to explain CP violation should either reproduce this rigidity signal or explain its systematic deviation in a controlled, testable way.
