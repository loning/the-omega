\section{观察者时空图：搜索过程生成的可审计对象}

\subsection{从 lifting 到搜索图}

当 \(\Lift_{\proj}(y)\) 非平凡时，观察者算法 \(\mathcal A\) 通常以“部分赋值 + 约束传播 + 回溯”的方式工作。由此自然产生一个图对象：
\begin{itemize}
  \item 节点表示某种中间状态（部分提升、当前颜色/分区、或候选集合）；
  \item 边表示一次局部扩展、传播更新，或一次回溯步；
  \item 节点与边可以携带由 \(\mathcal G\)（Hilbert 尺子）诱导的阶段标签（例如当前维度 \(d\)）。
\end{itemize}
我们把这一对象称为观察者时空图。它把“时间不是读取，而是搜索”的观点转化为可审计的组合对象：一方面，路径上的原子推断步骤给出观察者成本 \(\kappaobs\)；另一方面，若把每次消元/承诺所需的隐藏补全记录为 uplift 胶带，则路径也携带一条时间胶带，其编码长度给出负信息时间 \(\tautime\)。在最小假设下，\(\kappaobs\sim\tautime\)。

\subsection{与闭包图对象的关系（实例层）}

在后续实例中，\(\Clo\) 将被实现为包含“折叠边 + 微观几何边”的闭包图。观察者时空图不是闭包图本身，而是观察者在该闭包图上运行 lifting/细化/回溯算法时生成的二级对象；二者的区分保证了“切换维度”只改变观察者而不改变本体。
