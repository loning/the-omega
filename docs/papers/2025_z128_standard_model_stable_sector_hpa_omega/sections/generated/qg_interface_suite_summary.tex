\paragraph{Audit summary (QG interface suite).} \AuditTag This suite composes three interface bridges in a deterministic toy setting: (i) a protocol overhead proxy field $\chi(x)$ reconstructed by the paper's end-to-end curvature-bridge pipeline (noisy $\delta$ readout $\to$ bits $\to$ folding fibers $\to \hat\chi$), (ii) a budget-triggered cloud selection rule $m|\mathcal R_\star|\ge c\,I_{\mathrm{obs}}$ (capacity-only horizon trigger) and the induced boundary-perimeter diagnostic on the grid, and (iii) a one-channel Breit--Wigner scattering delay benchmark used to define a lapse proxy via $\chi_{\mathrm{WS}}=\log(\kappa/\kappa_0)$ and $N=\exp(-\gamma\chi_{\mathrm{WS}})$. The curvature proxy is the weak-field bridge $G_{00}\approx -2\gamma\,\Delta\chi$ evaluated with a periodic central-difference Laplacian at grid spacing $h=1$. Rows cover the balanced even-step family $(m,n)\in\{(6, 8, 10)\}\times\{(3, 4, 5)\}$ and a bounded family of budgets/margins $(I_{\mathrm{obs}},c)\in\{64,1024,10^6\}\times\{1,4,16\}$ with fixed $\gamma=1$ and a deterministic top-$k$ selection tie-break on $\hat\chi$.
