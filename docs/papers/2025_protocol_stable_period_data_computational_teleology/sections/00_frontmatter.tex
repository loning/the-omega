
\begin{abstract}
The principle of least action formalizes \emph{how} trajectories are selected, yet in standard formulations both the origin of effective potentials and the fine structure of dimensionless constants remain largely external inputs.
In an audit-driven framework based on holographic scanning protocols, we introduce a minimal operative target object:
\emph{Wish} as \emph{protocol-stable period data}---not a psychological statement, but a period datum whose value is invariant under a class of scan--readout protocols and can be stably approximated under finite resource constraints.

On a controlled class of Kronecker-type protocols we make the scan--period interface explicit via a functor $\HSP:\ScanAlg\to\PerDatum$ mapping a protocol to its associated Kontsevich--Zagier period datum.
This interface links finite-horizon time averages to regulated period integrals and yields deterministic finite-resource error certificates with two auditable components:
(i) a sampling term controlled by discrepancy and Hardy--Krause variation (Koksma--Hlawka type bounds) and (ii) a regularization/truncation term controlled by explicit analytic tails.

We then formulate a closed \emph{variational dynamics on protocol space}.
Treating a certified discrepancy bound and a description-cost proxy as a \emph{computational potential}, we derive a damped inertial gradient dynamics whose Lyapunov function is a finite-horizon ``minimal computational discrepancy'' energy.
This yields a concrete, falsifiable mechanism by which a protocol family can self-organize toward stable period targets while penalizing implementation complexity.

Finally, we provide reproducible pure-Python experiments:
one- and multi-dimensional Kronecker scans realizing $\log 2$, $\pi$, $\zeta(2)$, and $\zeta(3)$; an explicit error decomposition for truncated geometric kernels; and a low-complexity geometric search for a baseline fine-structure constant value exhibiting a pronounced uniqueness gap under bounded description budget.
\end{abstract}

\paragraph{Conventions.}
Unless otherwise stated, $\log$ denotes the natural logarithm and ``mod $1$'' refers to reduction in $\RR/\ZZ$.
We identify the $d$-torus with $\TT^d=(\RR/\ZZ)^d$ and use $[0,1)^d$ as the standard fundamental domain when writing integrals and discrepancy definitions.
The protocol time $t\in\ZZ_{\ge 0}$ denotes an iteration count of the protocol update rule.
