\subsection{接口断言（A 组）}\label{subsec:bridgepack-assertions}
\paragraph{共同前提：地址—账本—寄存器—相位}
在递归地址化的 \(\sigma\)-代数细化机制（命题 \ref{prop:recursive-addressing-refinement}）、折叠投影的信息账本恒等式（定理 \ref{thm:pom-kl-ledger}）、profinite 寄存器轴 \(G_\infty=\widehat{\ZZ}\) 及其角色直和分解框架（\S\ref{subsec:profinite-operator-l2}）、以及单位圆面积相位门与“残差轴外置/相位塔”原则（命题 \ref{prop:phase-residual-axis} 与 \ref{prop:compact-phase-tower}；定义 \ref{def:unit-circle-phase-precision-potential}）同时成立的前提下，可进一步得到下列八条非平凡且可审计的接口断言；其系统化表述见 \cite{Internal2026POMGenerativeAddressThreeRegisterBridgeRH}。下列条目仅记录最终陈述及其可检验含义，不复述推导。

\subsubsection{接口断言 1：递归地址化的寄存器化表述（地址非独立原语）}\label{app:bridgepack-assertion-1}
\begin{itemize}
  \item \textbf{断言：}对任意固定层级 \(L\) 与固定窗口长度 \(\ell\)，存在有限模 \(M:=2^{r_L\ell}\) 与可测编码映射 \(c_{t,\ell}:X\to \ZZ/M\ZZ\) 使得任意派生柱事件 \(C^{(L+1)}_{a,t}\)（\S\ref{sec:recursive-addressing}）都可写为一次“有限模寄存器读出”的逆像：
  \[
  C^{(L+1)}_{a,t}=\{x\in X:\ c_{t,\ell}(x)=\mathrm{code}(a)\in\ZZ/M\ZZ\}.
  \]
  因而，地址 \(\sigma\)-代数的细化在结构上等价于对某一 profinite 寄存器（至少包含 \(2\)-adic 子塔）的有限层读出细化；在逆极限意义下，递归地址化诱导出一个自然的 profinite 坐标轴，并可与 \(G_\infty=\widehat{\ZZ}\) 的同余塔接口拼接。
  \item \textbf{可检验含义：}若某一实现中“地址表/地址生成逻辑”无法等价消去为有限模读出（即无法在有限模寄存器读出后仅通过纯重写得到同一地址分割），则该实现隐含引入了超出“柱集闭包/细化”的额外结构，从而违背命题 \ref{prop:recursive-addressing-refinement} 的“仅细化、无外加可测集”约束。
\end{itemize}

\subsubsection{接口断言 2：离散纤维体积与连续精度势的张量化分解}\label{app:bridgepack-assertion-2}
\begin{itemize}
  \item \textbf{断言：}在同一计算链中同时出现（a）折叠类多对一投影（产生离散纤维多重度 \(d_m\) 与账本项 \(\kappa_m(\pi)=\mathbb{E}_\pi[\log d_m(X)]\)，见 \eqref{eq:gut_kappa_m_defect}）与（b）单位圆面积相位紧化（产生 Jacobian 精度势 \(\mathcal{P}(x)=-\log|\dd\upsilon/\dd x|\)，定义 \ref{def:unit-circle-phase-precision-potential}）时，存在一种规范的可逆化提升，使得“保持单射性所必须外置的残差预算”分裂为两个不可互相吞并的张量因子：离散纤维因子由 \(\mathbb{E}_\pi[\log d_m(X)]\) 控制，连续精度因子由 \(\mathbb{E}[\mathcal{P}(X)]\) 控制（命题 \ref{prop:unit-circle-phase-diff-entropy-ledger}）。两者在同一可逆提升中呈现为两类正交残差轴：折叠侧以 \(\log d_m\) 记账，紧化侧以 \(-\log|\dd\upsilon/\dd x|\) 记账（注 \ref{rem:unit-circle-phase-precision-ledger-vs-pom}）。
  \item \textbf{可检验含义：}若在实现中观察到“通过提高相位精度（减小 \(\Delta u\)）可以系统性抵消折叠纤维多重度带来的不可逆性”，则该现象必意味着实现未遵循上述张量化可逆提升，而发生了未被审计的跨轴耦合（等价于将部分离散纤维索引隐式编码进连续精度末位，从而引入不可复核的混码）。
\end{itemize}

\subsubsection{接口断言 3：寄存器文件的三分刚性（功能不可互代）}\label{app:bridgepack-assertion-3}
\begin{itemize}
  \item \textbf{断言：}在“信息守恒以扩展空间单射性表达”的语义下（公理 \ref{axiom:unit-circle-phase-extension-preserving}），最小寄存器文件呈现三分刚性，且三者在功能上不可互代：
  (i)~\emph{时间层缺陷寄存器}，用于把滑动窗口因子（sofic 因子）提升为单射，其需求来自时间同步/延迟不变量（注 \ref{rem:pom-finite-defect}）；
  (ii)~\emph{空间层同余（prime-register/profinite）寄存器}，用于 residue 并行读出与角色对角化，其容量由 \(\log|G_m|\) 或 \(\log P_m\) 等变量支配（推论 \ref{cor:pom-prime-register-quantile-budget}）；
  (iii)~\emph{连续层精度寄存器}，用于在单位圆面积相位紧化下外置尺度残差/精度负载（命题 \ref{prop:phase-residual-axis} 与 \eqref{eq:app-precision-amplification}）。
  因此，任何试图以“增大 prime-register 容量”消去“时间层缺陷寄存器”的方案在语义上必然失败：前者只能重分配空间预算，无法消除同步延迟类时间不变量。
  \item \textbf{可检验含义：}对同一程序在不同模数 \(P_m\) 下扩容 prime-register，若时间同步尾部（或右可逆性相关指标）仍保持不可消去的下界，则符合三分刚性预测；若反之出现“扩容同余寄存器显著降低同步缺陷”，则说明实现中将同步信息泄漏到了同余轴（属于未声明的跨轴编码）。
\end{itemize}

\subsubsection{接口断言 4：由地址深度与模数决定的角色分母截断（扭曲扫描的有限化）}\label{app:bridgepack-assertion-4}
\begin{itemize}
  \item \textbf{断言：}在 \(G_\infty=\widehat{\ZZ}\) 的角色分解语义下，扭曲通道由 \(\chi\in\widehat{G_\infty}\cong \QQ/\ZZ\) 索引（\S\ref{subsec:profinite-operator-l2}）。
  然而，对任一具体的有限资源实现：若其可观测地址仅依赖有限深度 \(\ell\)（递归地址化的柱事件层）且其 residue 读出仅涉及有限模 \(m\)（或 prime-register 的有限层），则该实现所能语义可见的扭曲角色必落在某一有限子群中，其分母被
  \[
  \operatorname{lcm}\!\bigl(m,\ 2^{r_L\ell}\bigr)
  \]
  所截断。等价地，在固定地址深度与固定模数读出下，“连续扭曲角扫描”不产生新的可观测自由度；超出分母截断的扫描仅对应不可观测的重参数化。
  \item \textbf{可检验含义：}若某实现声称“在固定地址深度与固定模数读出下，通过连续调节扭曲角获得了额外可重复的新模态”，则该声称可被证伪：新模态若可观测，则其应落在上述有限角色集合内；若不在，则只能来自未声明的新寄存器轴或未审计的额外观测门。
\end{itemize}

\subsubsection{接口断言 5：相位精度与 prime-register 容量的同一化定标}\label{app:bridgepack-assertion-5}
\begin{itemize}
  \item \textbf{断言：}单位圆面积相位读出具有精度放大律：当 \(|x|\) 大时，微小相位误差 \(\Delta u\) 被放大为 \(\Delta x\approx \pi x^2\Delta u\)，并给出可分辨最大量级
  \(
  |x|_{\max}\approx \frac{1}{\pi\Delta u}
  \)
  （式 \eqref{eq:app-precision-amplification}）。
  因此，若把相位盒离散精度与 prime-register 容量同一化（例如令 \(\Delta u\asymp 1/P_m\)），则必有
  \[
  |x|_{\max}\ \asymp\ \frac{P_m}{\pi}.
  \]
  结合 prime-register 可行带中以 \(\log P_m\) 为统一容量变量的闭式约束，可得：单位圆相位读出的动态范围上界与 residue/同余读出的可审计容量上界受同一预算（对数尺度）所约束。
  \item \textbf{可检验含义：}若在同一实现中观测到 \(|x|_{\max}\) 的可达范围显著超过由 \(\log P_m\) 预算所允许的尺度，则必意味着相位精度并未真正由 \(P_m\) 承载，而是额外调用了未记录的精度轴（例如隐式高精度浮点或隐藏寄存器），从而破坏“扩展保存/可审计残差”原则。
\end{itemize}

\subsubsection{接口断言 6：有限维紧纤维的不可行性（不足以同时承载全模数与连续相位）}\label{app:bridgepack-assertion-6}
\begin{itemize}
  \item \textbf{断言：}profinite 寄存器轴 \(G_\infty=\widehat{\ZZ}\) 的对偶角色域为 \(\widehat{G_\infty}\cong\QQ/\ZZ\)，而单位圆相位纤维 \(\TT\) 的对偶角色域为 \(\widehat{\TT}\cong\ZZ\)。
  因此，任何试图以有限维紧阿贝尔群（例如 \(\TT^d\)）同时承载“全模数角色谱（\(\QQ/\ZZ\)）”与“连续相位坐标”的方案，在对偶域上必然受限于可生成角色的结构，从而无法在语义上实现“统一全部模数的扭曲对角化”与“相位可逆紧化”两者兼得。
  若坚持扩展空间单射并允许将提升迭代为相位塔，则最小可行紧纤维必须为某种逆系统极限（相位塔极限对象），且一旦实现选择有限层截断，便不可避免触发“残差轴外置”的必要性（命题 \ref{prop:compact-phase-tower} 与 \ref{prop:phase-residual-axis}）。
  \item \textbf{可检验含义：}对任一声称“用有限个相位角即可同时替代 profinite 寄存器并保持可逆”的实现，只需在模数增长与地址深度增长的联合极限下审计其可区分角色模态是否真实增长；若模态不增长，则该实现只能是重参数化或隐含额外轴（均可被审计证伪）。
\end{itemize}

\subsubsection{接口断言 7：相位塔覆盖度对地址深度的量化下界（截断即残差）}\label{app:bridgepack-assertion-7}
\begin{itemize}
  \item \textbf{断言：}在采用典型的“幂覆盖型相位塔”（每层为有限覆盖，新增相位自由度对应有限阶角色扩张）的情形下，设第 \(k\) 层覆盖度为 \(d_k\)，则 \(K\) 层之后可语义分辨的相位角色分母至多增长到 \(\prod_{k=1}^{K}d_k\)。
  因此，要在不引入独立 profinite 寄存器的前提下把深度为 \(\ell\) 的地址细化（规模 \(\sim 2^{r_L\ell}\)）完全吸收进相位模态，必须满足
  \[
  \prod_{k=1}^{K}d_k\ \gtrsim\ 2^{r_L\ell}.
  \]
  若不满足，则必出现“地址可分辨度增长而相位模态预算不足”的结构性矛盾，唯一出路是外置残差轴（与命题 \ref{prop:phase-residual-axis} 同型）。
  \item \textbf{可检验含义：}可通过逐层增加相位提升层数并审计谱上是否出现新的可分辨正交模态来检验：若地址深度增长而相位模态不随之增长，则该地址细化必被迫落在独立寄存器轴上（否则发生不可逆丢失）。
\end{itemize}

\subsubsection{接口断言 8：可审计闭环的三级证书输出规范（地址—纤维—相位统一审计）}\label{app:bridgepack-assertion-8}
\begin{itemize}
  \item \textbf{断言：}在上述统一框架内，存在自然的、可机器复核的三级证书闭环，使“地址/纤维/相位”的信息守恒不依赖解释性叙述，而完全落为可复算对象：
  \begin{itemize}
    \item \textbf{地址层证书：}将地址细化编译为有限模读出后输出其模数与编码映射（从而地址分割可被复现）。
    \item \textbf{纤维层证书：}输出折叠账本项所需的 \(d_m\) 统计与残差散度定位（信息缺口被锁定为纤维内非均匀残差；见定理 \ref{thm:pom-kl-ledger}）。
    \item \textbf{谱/相位层证书：}对“角色分母截断”后的有限扭曲集合输出对应块算子的谱半径证书（例如 Lyapunov/LMI 型 PSD 证书，命题 \ref{prop:lyapunov-spectral-radius-certificate}），从而避免对不可穷尽的扭曲通道做不可审计扫描。
  \end{itemize}
  \item \textbf{可检验含义：}若任一实现无法在上述三层中给出某一层的可复算证书（尤其是相位—寄存器耦合处仅给数值结果而不给可复核证书），则该实现无法满足“扩展保存/可审计残差”的硬规格。
\end{itemize}

\begin{itemize}
  \item \textbf{（结构结论 1：completeness 缺口的定位与可审计替代）}RH 缺口被定位为地址完备性（假设 \ref{assump:xi-address-completeness}；亦见 Bridge\(^{RH}\) 合同的可寻址条款 \ref{assump:bridge-rh}-(2)）。该缺口可由 Hankel 秩/最小实现的稳定性判据（ACC-Rank）替代为可回归检查（注 \ref{rem:xi-acc-rank}）。

  \item \textbf{（结构结论 3：prime-like vs.\ trace 的通道归因指标）}\(\mathbf{R}_{m,2}\) 与 \(A_m\) 将“慢化瓶颈来自输入骨架还是边界残差”落为硬指标（定义 \ref{def:rho-m2-fingerprint}--\ref{def:rho-m2-anisotropy-index}）。
  \item \textbf{（结构结论 4：时间—空间对偶的预算律）}prime-register 的尾部预算可由 \(P(q,u)\) 的对偶给出，并且最优 \(q\) 只需在 kink 集合上做有限检查（命题 \ref{prop:pom-kink-principle-q-selection}；注 \ref{rem:pom-qstar-phase-diagram-breakpoints}）。
  \item \textbf{（结构结论 5：unitary-slice 的 RH 证书化）}unitary-slice 的“临界线性”可编译为 Cohn/Schur--Cohn 判别的半正定（SDP/LMI）证书接口，从而具备机器可核验形态（命题 \ref{prop:xi-rh-cohn-derivative}；注 \ref{rem:xi-schur-cohn-sdp-interface}）。
\end{itemize}
基于这三块硬接口，可将“信息守恒角度的对齐与 RH/GRH-型目标的合同化核验”收束为下列五条判据（均以本文既有接口为输入、在本文语言内可直接核验/证伪）：

\paragraph{判据 1（二位曲率为零的平坦性：严格交换的极限规格）}
把“严格交换”提升为二维平坦性判据。令标签轴曲率取异常的上同调类
\[
\kappa_{\mathrm{tag}}:=[\mathrm{Anom}]\in H^2(\mathbf{PW};\mathcal{A}_G),
\]
并令分辨率轴曲率由跨分辨率一致性残差的极限规格给出
\[
\kappa_{\mathrm{res}}(m):=\limsup_{N\to\infty}E_{m,N},
\qquad
E_{m,N}:=D_{\mathrm{TV}}\!\left(\hat\pi_{m,N},\ \pi_{m+1\to m*}\hat\pi_{m+1,N}\right)
\quad(\text{定义 \ref{def:multiscale-residual}}).
\]
若在所取极限规格下满足 \(\kappa_{\mathrm{tag}}=0\) 且 \(\kappa_{\mathrm{res}}(m)\to 0\ (m\to\infty)\)，则 prime-like \(\leftrightarrow\) trace 的严格交换不仅在单一分辨率成立，而且可沿分辨率塔以路径无关的方式提升到极限对象：任何“先 coarse-grain 再 lift”与“先 lift 再 coarse-grain”的可观测差异，都只能落在可消去的 coboundary 与消失的边界扰动事件（命题 \ref{prop:multiscale-residual-by-boundary}）之中；从而严格交换图在极限口径上可被严格化为真正的 commuting diagram（而非仅近似成立）。

\paragraph{判据 2（toy-RH 现象的证据权重：结构强迫与残差通道的区分）}
真实输入 \(40\) 状态核的 toy-RH “单一临界模态”现象并不自动构成对 RH 的逼近证据：其唯一达界特征值 \(-\sqrt{\lambda}=-\varphi\) 的存在可被一个隐藏的 \(({-}A_0)\) 因子结构性强制（注 \ref{rem:finite-rh-40-hidden-minusA0}），因此该现象首先应被理解为对“骨架因子嵌入正确且未被实现误差破坏”的一致性核对。与 Bridge\(^{RH}\) 相关的证据必须来自去除骨架强迫之后的残差通道（例如纵向残差 \(U^\perp\) 口径，命题 \ref{prop:real-input-40-skeleton-factor}），并在极限规格下满足合同条款的可寻址性、unitary-slice 类型锁定与 Fredholm-HTF/NonCancel 规格（假设 \ref{assump:bridge-rh}）。

\paragraph{判据 3（骨架/残差分离的 Hankel 最小实现过滤器）}
把“是否仅为骨架假象”转写为最小 realization 的硬证书。对桥包输出的序列型指纹（迹序列、moment 序列或其派生谱指纹），在骨架/残差分解（例如 \(\det(I-zM)=\det(I-zA)\det_{\mathrm{vert}}(z)\)，命题 \ref{prop:real-input-40-skeleton-factor}）下分别对骨架项与残差项施加 Hankel 最小实现（定理 \ref{thm:hankel-rank-minimal}；并见注 \ref{rem:two_layer_bridge_package_completed_minH}）：
\begin{itemize}
  \item \textbf{若临界现象主要由有限因子骨架主导，}则对应序列为有限个指数项的线性组合，其 Hankel 秩（等价于最小 realization 维数）保持常数级，不随 \(q\)/\(m\) 发生显著增长；
  \item \textbf{若临界现象由残差通道承载并与 prime-register 的可见复杂度绑定，}则最小 realization 维数将随 \(q\)/\(m\) 体现出可核验的增长下界（例如在非共振典型窗内，Hankel 秩达到模态截断上界 \(2\lfloor q/2\rfloor+1\) 的证书化情形，见定理 \ref{thm:pom-moment-hankel} 与表 \ref{tab:fold_collision_moment_hankel_rank}）。
\end{itemize}
该过滤器把“临界线信号”从直觉判断收束为可复算的维数证书：究竟是骨架项主导，还是残差通道承载不可约结构。

\paragraph{判据 4（异常核验的资源调度协议：放大—细分—抵消）}
异常“过小难以核验”的困难可被封装为范畴内部的资源调度律。异常在 moment 门下线性放大：
\[
[\mathrm{Anom}(\mathrm{MOM}_q\circ w)]=q\,[\mathrm{Anom}(w)]
\qquad(\text{命题 \ref{prop:pom-anom-moment-amplification}}),
\]
而 residue 细分（RCRT 空间化）在 \(q\)-矩压力上提供确定性降压窗口：
\[
P^{1-q}S_q(m)\ \le\ S_q^{(P)}(m)\ \le\ S_q(m)
\qquad(\text{推论 \ref{cor:pom-rcrt-pressure-reduction-law}}).
\]
因此可用两旋钮 \((q,P)\) 形成 ASC（Amplify--Split--Cancel）核验协议：先以 \(q\) 放大异常 gap，再以 \(P\) 的 residue 空间化把由高阶 moment 引入的碰撞压力在可审计上界内压回，从而把“异常是否为零”的核验从数值噪声问题转写为可控的算力/配额调度问题。

\paragraph{判据 5（合同化表述下的等价目标：Bridge\(^{RH}\) 的核验分解）}
在本文体系内，“接近 RH 证明”的目标等价于在某一极限规格上验证 Bridge\(^{RH}\) 合同（假设 \ref{assump:bridge-rh}）的四条条款，尤其是新增且最强的 Address completeness（每个零点必须 \(\mathbf{PW}\)-可寻址且非 \(\mathsf{NULL}\)）。结论 1--4 给出把该合同核验拆解为三类可审计缺口的判据化分解：
\textbf{二维平坦性}（\([\mathrm{Anom}]=0\) 且 \(\kappa_{\mathrm{res}}(m)\to 0\)）、\textbf{去骨架后的复杂度证书}（残差通道的 Hankel 最小实现呈现必须的增长/不可见缺口结构）、以及\textbf{合同新增点的可寻址构造}（并同时满足 unitary-slice 与 Fredholm-HTF/NonCancel 规格）。
\begin{enumerate}
  \item \textbf{（有限窗口素数性信息量的硬上界）}
  对任意只读 Zeckendorf 低位窗口 \(W_m\) 的判别器 \(\widehat Y=f(W_m)\)，其对素数性 \(Y=\mathbf{1}_{\mathrm{prime}}\) 的可用信息增益满足
  \(I(Y;\widehat Y)\le I(Y;W_m)\)（注 \ref{rem:prime-shadow-window-mi-algorithmic-lb}）。
  \emph{可检验含义：}表 \ref{tab:prime_shadow_window_mi} 显示当 \(m=6\)（\(|X_m|=21\)）时互信息仅为 \(8\times 10^{-3}\) bits 量级；
  因而任何“固定小窗口”机制不可能在该口径下等价恢复整数素数集合。
  复现脚本与数据口径见小节 \ref{subsec:prime-shadow-window-mi}。

  \item \textbf{（prime-register 的最小可逆侧信息；并天然按素数分解）}
  在区间读出/重建口径下，若希望把折叠的多对一压缩提升为“以概率 \(\ge 1-\varepsilon\) 近似可逆”，则外置侧信息必须覆盖纤维尾分位：
  取 \(B_m(\varepsilon)=\exp(m\gamma_m(\varepsilon))\)，任何满足 \(P_m>2B_m(\varepsilon)\) 的 CRT 寄存器即可把失败概率压至 \(\le\varepsilon\)（推论 \ref{cor:pom-prime-register-quantile-budget}），
  从而比特预算主尺度为 \(\log_2 B_m(\varepsilon)=\Theta(m\gamma_m(\varepsilon))\)。
  在逆极限语义下，该寄存器轴的结构坐标为
  \(
  \widehat{\ZZ}=\varprojlim_m \ZZ/m\ZZ\cong \prod_{p}\ZZ_p
  \)
  （单位版本为 \(\widehat{\ZZ}^{\,\times}\cong\prod_p\ZZ_p^{\times}\)），从而“按素数分解”的坐标轴并非额外装饰，而是可逆性侧信息在结构上被迫采用的不可约分解。
  \emph{可检验含义：}脚本 \texttt{scripts/exp\_fold\_tail\_budget\_gamma\_cert.py} 给出 \(\gamma_m(\varepsilon)\) 的可复现证书输出；
  Bridge-Kit 接口（\S\ref{subsec:pom-implementable-interfaces}）把该预算与异常常数项一并固化为回归测试指纹。

  \item \textbf{（prime-register 的谱侧变换律：压力削减带与自洽平方根配额）}
  prime-register 的 residue 轴并非只提供“可唯一重建”的语义通道；当将 (RCRT) 用作序门消元时，纤维按 residue 细分会在统计层面必然打散碰撞，从而在正矩压力上出现显式削减带：
  对任意 \(q>1\)，有
  \(
  P_m(q)-\frac{q-1}{m}\log P\le P_m^{(P)}(q)\le P_m(q)
  \)
  （推论 \ref{cor:pom-rcrt-pressure-reduction-law}）。
  进一步把该削减带与分位配额证书（推论 \ref{cor:pom-prime-register-q-quota-family}）拼接，并在桶内近均匀（Jensen 近取等）regime 下闭合同一容量变量 \(P\)，得到证书化的自洽平方根前沿：
  \[
  \boxed{\;
  \log P\ \gtrsim\ \frac{\log 2+m\,\gamma_m^{\mathrm{cert}}(\varepsilon)}{2}\;}
  \]
  （推论 \ref{cor:pom-rcrt-self-consistent-sqrt-budget}；其中 \(\gamma_m^{\mathrm{cert}}\) 由 \(\{r_q\}\) 的可审计下包络给出）。
  \emph{可检验含义：}同一 \(\log P\) 可一分为二：一半用于 CRT 承载阈值、另一半通过压力削减带返还到 \(q\)-矩尾证书，从而把“空间换时间”从通道选择提升为可核验的谱侧变换器设计。

  \item \textbf{（单位寄存器口径下 prime-like 侧与谱/迹侧的严格对齐）}
  将寄存器轴从 \(G_\infty=\widehat{\ZZ}\) 收缩到单位部分 \(G_\infty=\widehat{\ZZ}^{\,\times}\) 后，Dirichlet 角色族就是 \(L^2(G_\infty)\) 的 Fourier 基；
  “全角色平方根谱界”
  \(
  \sup_{\chi\neq 1}\rho(M_{m,\chi}(u))\le \lambda_1(u)^{1/2}
  \)
  与“全部非平凡 Fourier 模态的统一衰减”在算子化口径下等价（推论 \ref{cor:pom-dirichlet-grh-twisted-radius}；命题 \ref{prop:pom-profinite-artin-hilbert}）。
  \emph{可检验含义：}对给定核与 \(m\)，扫描 \(\sup_{\chi\neq 1}\rho(M_{m,\chi}(u))/\lambda_1(u)^{1/2}\) 即可对 GRH-型断言作直接证伪；
  代表性复现接口为 \texttt{scripts/exp\_real\_input\_40\_output\_potential\_dirichlet\_twists.py} 及其生成表格片段（表 \ref{tab:real_input_40_output_potential_dirichlet_twists}）。

  因而逆极限中不断出现的新自由度必须被显式控制。
  \emph{可检验含义：}脚本 \texttt{scripts/exp\_sync\_kernel\_real\_input\_40\_arity\_3d.py} 输出 \(c=N_2(\gamma)\bmod 5\) 的切片张量（正文对应 \verb|\input| 片段），并同时生成三维 DFT 头部模式表 \ref{tab:real_input_40_arity_335_n2_fourier_top}

  \item \textbf{（空间/时间同源信号：碰撞结构同时控制纤维多重度与最坏慢模）}
  折叠窗层的二阶碰撞核 Perron 常数 \(r_2\) 与轨道层最坏扭曲谱半径 \(\rho_{3,3,5}\) 在数值上高度贴合（注 \ref{rem:arity-335-r2-vs-rho}），提示“最慢模态”更可能由碰撞纤维积结构主导而非由输出细节主导。
  \emph{可检验含义：}跨层诊断量（注 \ref{rem:arity-335-cross-layer-diagnostics}）把 \((r_2,\rho_{3,3,5})\)、SVD 压缩与协方差预测并列为可审计指纹；
  若在更换模轴/权重/核族后仍持续观察到 \(\rho_{\mathrm{worst}}\) 与低阶碰撞常数 \(r_q\) 的稳定贴合，则“时空对偶=信息守恒”的同源性得到数值支持；否则该贴合可被直接证伪。

  \item \textbf{（三件套闭环：把“信息守恒路线”压缩为可回归的硬指标）}

  \emph{(i)}~可逆性侧信息闭环（\(\gamma_m(\varepsilon)\Rightarrow B_m(\varepsilon)\Rightarrow P_m\) 预算；推论 \ref{cor:pom-prime-register-quantile-budget}）；
  \emph{(ii)}~全角色族口径（单位寄存器 \(\widehat{\ZZ}^{\,\times}\) 上的 \(\sup_{\chi\neq 1}\) 谱界；推论 \ref{cor:pom-dirichlet-grh-twisted-radius}）；
  \emph{(iii)}~同源慢模诊断（碰撞核常数 \(r_q\) 与最坏扭曲常数 \(\rho\) 的跨层贴合；注 \ref{rem:arity-335-r2-vs-rho}）。
  \emph{可检验含义：}Bridge-Kit 一键脚本 \texttt{scripts/exp\_bridge\_kit.py} 将上述三类输出压缩为常数级指纹 JSON/片段，用作后续实现改动的强一致性回归测试接口。

  \item \textbf{（结论 1：分辨率平方根律）}
  在循环层 \(G_m=\ZZ/m\ZZ\) 上，令 \(\lambda_m=\rho(B_{\mathbf 1,m})\) 为平凡通道 Perron 根，\(\Lambda_m=\max_{\chi\neq \chi_0}\rho(B_{\chi,m})\) 为最坏扭曲谱半径（定理 \ref{thm:pom-profinite-axis} 的记号；阿贝尔情形 \(\rho\) 退化为角色 \(\chi\)）。
  在 near-coboundary 小角律支配下（推论 \ref{cor:dirichlet-modulus-diffusion-barrier} 的二次扩散标度口径），存在扩散常数 \(c_{\mathrm{diff}}>0\) 使最坏比值满足
  \[
  \boxed{\ \frac{\Lambda_m}{\lambda_m}
  =\exp\!\left(-\frac{c_{\mathrm{diff}}+o(1)}{m^2}\right)\qquad(m\to\infty)\ }.
  \]
  该 \(m^{-2}\) 主阶缺口来自对扭曲压力的二次展开（推论 \ref{cor:dirichlet-modulus-diffusion-barrier}），并与 cylinder 的 Chebotarev 相对误差界（推论 \ref{cor:pom-profinite-cylinder-effective-n}）拼接后给出下述双尺度选择律；其“谱隙税”形式亦见注 \ref{rem:pom-spectral-tax-workload}。
  因而对任意层级为 \(m\) 的 cylinder \(U=\pi_m^{-1}(A)\subseteq G_\infty\)（\(A\subseteq G_m,\ A\neq\varnothing\)），要把 Chebotarev 主项的相对误差压到 \(\le\delta\)，所需 primitive 长度的最小量级为
  \[
  \boxed{\ n_{\min}(m,\delta,U)\ \asymp\ \frac{m^2}{c_{\mathrm{diff}}}\Bigl(\log\frac{|G_m|}{|A|}+\log\frac{1}{\delta}\Bigr)\ }.
  \]
  反解地，在固定长度预算 \(n\) 下，对“最细分辨率”事件（例如 \(|A|=1\)）的可承载最大模数 \(m_{\max}\) 由隐式关系
  \[
  m_{\max}^2\Bigl(\log |G_{m_{\max}}|+\log\tfrac{1}{\delta}\Bigr)\ \asymp\ c_{\mathrm{diff}}\,n
  \]
  确定；特别地在循环层 \(|G_m|=m\) 且 \(\delta\) 为常数级（或多项式级）时，有数量级估计
  \[
  \boxed{\ m_{\max}(n,\delta)\ =\Theta\!\left(\sqrt{\frac{c_{\mathrm{diff}}\,n}{\log n}}\right)\ }.
  \]
  \emph{可检验含义：}该律把“可分辨模数”与“可用轨道长度”锁定在平方根关系上；并且 \(m^2\cdot\bigl(-\log(\Lambda_m/\lambda_m)\bigr)\) 应在 \(m\to\infty\) 时趋于常数 \(c_{\mathrm{diff}}\)（可由单位根扭曲谱扫描表直接审计）。

  \item \textbf{（结论 2：全 cylinder 同时均匀化的额外 \texorpdfstring{$\log m$}{log m} 审计税）}
  在同一层 \(m\) 上，若目标不是单个 cylinder，而是对全部共轭类（阿贝尔情形即全部单点 residue）所生成的 cylinder 族 \(\mathcal{U}_m\) 同时给出相对误差 \(\le\delta\) 的保证，则在 \(|\mathcal{U}_m|=\Theta(|G_m|)\) 的规模下，union bound 强制出现额外的 \(\log|G_m|\) 代价。
  在结论 1 的扩散标度下，
  \[
  \boxed{\ n_{\min}^{\mathrm{all}}(m,\delta)\ \asymp\ \frac{m^2}{c_{\mathrm{diff}}}\Bigl(\log |G_m|+\log\frac{1}{\delta}\Bigr)\ }.
  \]
  对循环层 \(G_m=\ZZ/m\ZZ\)，该式化为
  \[
  \boxed{\ n_{\min}^{\mathrm{all}}(m,\delta)\ \asymp\ \frac{m^2}{c_{\mathrm{diff}}}\Bigl(\log m+\log\frac{1}{\delta}\Bigr)\ }.
  \]
  该额外的 \(\log m\) 因子纯来自事件族规模（而非动力学尾项），与“谱隙税”口径完全一致（注 \ref{rem:pom-spectral-tax-workload}）。
  \emph{可检验含义：}把同一模数层的全部 residue 分布“并行审计”到精度 \(\delta\)，相比于只审计一个宏观 cylinder（\(|A|\asymp |G_m|\)）必然多支付一个 \(\log m\) 因子；该因子源自事件族规模，而非来自动力学尾项本身。

  \item \textbf{（结论 3：最坏角色选择律——循环层上恒为 \texorpdfstring{$j=\pm 1$}{j=±1}）}
  对 \(G_m=\ZZ/m\ZZ\)，令角色 \(\chi_j(k)=e^{2\pi i jk/m}\)。
  在 near-coboundary 小角二次律下，存在同一扩散常数 \(c_{\mathrm{diff}}>0\) 使得对 \(j\ll m\) 有
  \[
  \boxed{\ \log\frac{\lambda_m}{\rho(B_{\chi_j,m})}
  =\frac{c_{\mathrm{diff}}+o(1)}{m^2}\,j^2\qquad(m\to\infty)\ }.
  \]
  （对应的多维选择律由角格上的最短向量问题给出，见定理 \ref{thm:real-input-40-near-coboundary-svp}；循环层为其一维退化。）
  因而在所有非平凡角色中，使 \(\rho(B_{\chi_j,m})\) 取最大者（亦即使 \(\Lambda_m\) 取得者）必为最小非零 \(j\)：
  \[
  \boxed{\ \arg\max_{1\le j\le m-1}\rho(B_{\chi_j,m})\in\{1,m-1\}\ }.
  \]
  \emph{可检验含义：}在循环层的 profinite Chebotarev 口径下，“最坏扭曲”由最小非平凡角角色锁定；因此在审计 \(\Lambda_m/\lambda_m\) 时，只需扫描 \(j=\pm 1\) 即可捕获瓶颈通道。

  \item \textbf{（结论 4：扩散常数 \texorpdfstring{$c_{\mathrm{diff}}$}{c_diff} 的内生计算式）}
  上述三条的核心常数 \(c_{\mathrm{diff}}\) 不是拟合参数：它等价于平衡测度下“寄存器增量 cocycle”的方差密度（局部压力的二阶导）。
  设寄存器增量为 \(\gamma(e)\in\ZZ\)（边标记；见 \S\ref{subsec:profinite-operator-l2}），并令中心化变量 \(\tilde\gamma:=\gamma-\mathbb{E}[\gamma]\)。
  定义方差密度
  \[
  \sigma_\gamma^2:=\lim_{n\to\infty}\frac{1}{n}\mathrm{Var}\!\left(\sum_{t=0}^{n-1}\tilde\gamma(e_t)\right),
  \]
  则有内生恒等式
  \[
  \boxed{\ c_{\mathrm{diff}}=\frac{(2\pi)^2}{2}\,\sigma_\gamma^2\ }.
  \]
  该恒等式正是 near-coboundary 二次律在 \(F=\gamma\) 的特例：推论 \ref{cor:dirichlet-modulus-diffusion-barrier} 给出
  \(
  \log(\rho/\lambda)=-\frac12\sigma_\gamma^2(2\pi/m)^2+O(m^{-4})
  \)，从而主阶常数 \(c_{\mathrm{diff}}=2\pi^2\sigma_\gamma^2\)（与上式等价）。
  \emph{可检验含义：}该式把“慢模/扩散阈值”的常数完全锁定到一个可审计的二阶不变量（\(\sigma_\gamma^2\)）；在实现层面可通过压力 Hessian 或 Poisson 方程接口抽取，从而将 \(m,n,\delta\) 的选取从经验曲线提升为可复核的指纹常数。

  \item \textbf{（结论 5：Big-Witt 桥包强制的 \texorpdfstring{$p$}{p}-典型通道——“素数索引”并非外加）}
  Big-Witt/necklace 的严格交换桥包把迹 ghost \(a_n(u)\) 与 primitive Witt 坐标互换（注 \ref{rem:zetaK-commuting-diagram}；附录 \ref{app:witt-bridge-package}）。
  在 \(p\)-幂子塔上，该桥包自动诱导出 \(p\)-典型指数因子
  \[
  Z_p(T;u):=\exp\!\Bigl(\sum_{k\ge 0}\frac{a_{p^k}(u)}{p^k}T^{p^k}\Bigr),
  \]
  并由 Dwork 型同余 \(a_{p^k}(u)\equiv a_{p^{k-1}}(u^p)\ (\mathrm{mod}\ p^k)\) 锁定其 \(p\)-整性 \(Z_p(T;u)\in 1+T\,\ZZ_p[u][[T]]\)（定理 \ref{thm:witt-dwork-zp-integrality}）。

上述结论可被组织为三条相互耦合、且均可审计的主轴：\emph{\(p\)-典型通道}提供逐素数通道的 \(p\)-进整性护栏；\emph{\(L^2\) 能量恒等式}把空间同余偏差与时间扭曲迹能量严格对齐；\emph{\(m^2\) 扩散障碍}给出固定有限核无法实现 uniform-\(\sqrt{\lambda}\) 目标界的否定性约束，从而把“随模数增长的重整化族”定位为必要的推进方向。相应的形式闭合/解析边界与达界机制在结论 8 与结论 9 中分别被接口化表述并给出可检验含义。

最后指出：本文中的术语“涌现”仅用于组织动机与解释性叙事；任何后续推理均以编号结果为前提。关于黄金分支的“最优性”讨论亦严格限定在文中显式给出的数论证书链条之内，且不外推到更强的统计泛函最优性（见注 \ref{rem:what-is-optimized}）。
