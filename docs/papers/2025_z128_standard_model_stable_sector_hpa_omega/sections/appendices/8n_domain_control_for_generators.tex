\subsection{Domain control for unbounded generators (T3-1)}
\label{app:domain_control_for_generators}

\AuditTag This appendix records the strong-closure target for domain control required by any net$\leftrightarrow$field bridge and by scattering constructions.
The manuscript does not assume this as an implicit premise; instead, it packages it as an explicit condition bundle whose failure is recorded by the canonical W1 record (Appendix~\ref{app:minimal_failure_point_templates}).

\subsubsection{Condition bundle: common invariant domain}
\begin{assumption}[Common invariant domain for generating fields/operators]
\label{ass:common_invariant_domain_generators}
There exists a dense subspace $\mathcal{D}\subset\mathcal{H}$ such that:
\begin{itemize}
\item all declared smeared fields/operators $\Phi(f)$ preserve $\mathcal{D}$,
\item $\mathcal{D}$ is stable under adjoints and finite algebraic combinations required by the construction,
\item the vacuum vector (or cyclic vector) belongs to $\mathcal{D}$.
\end{itemize}
\end{assumption}

\paragraph{Theorem-facing consequence (template).}
\begin{proposition}[Well-defined bounded-algebra generation (template)]
\label{prop:domain_control_implies_net_generation_template}
\MathTag Under Assumption~\ref{ass:common_invariant_domain_generators}, the map ``(smeared) unbounded generators $\rightarrow$ bounded local algebras'' can be defined by functional calculus on $\mathcal{D}$, yielding a net of bounded operator algebras consistent with the locality/region assignment.
\end{proposition}

\AuditTag Proposition~\ref{prop:domain_control_implies_net_generation_template} is recorded as the logical bridge point.
Discharging it requires specifying the functional calculus class (e.g.\ Weyl exponentials) and verifying stability on $\mathcal{D}$; if that verification is not available, the manuscript remains in the bounded-algebra net language.
