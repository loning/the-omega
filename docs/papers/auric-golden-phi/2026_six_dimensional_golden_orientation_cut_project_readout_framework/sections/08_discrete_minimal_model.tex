\section{一个可穷举的离散最小模型：可逆本体与不可逆观测}

本节给出一个完全离散且可穷举验证的原型，用以展示“微观可逆 + 观测非单射 $\Rightarrow$ 宏观多值与稳定频率律”的可审计机制。该原型不作为对象层必然规律，仅作为可复现验证平台。

\subsection{原始态空间与观测核（D8.1）}

取 $m$ 固定，令原始窗口标签空间 $Y_m:=\{0,1\}^m$。观测核为 $\Fold_m:Y_m\to X_m$。定义纤维退化度
\[
d(x):=\card{\mathcal{F}_m(x)},\qquad x\in X_m.
\]

\subsection{可逆更新与推前分布（D8.2，T8.2）}

令微观更新 $U:Y_m\to Y_m$ 为置换（可由 Feistel 型局域构造实现，见附录 \ref{app:feistel}），则 $U$ 保持均匀分布。设 $u$ 为 $Y_m$ 上均匀分布，则可见分布
\[
q:= (\Fold_m)_*(u)
\]
满足
\[
q(x)=\frac{d(x)}{2^m}.
\]
此外，对任意微观分布 $\pi$，总变差满足推前不增：
\[
\big\|(\Fold_m)_*(\pi)-q\big\|_{\mathrm{TV}}
\le \|\pi-u\|_{\mathrm{TV}}.
\]
故在“微观近均匀混合”条件下，稳定态频率由退化谱主导。该结论为后续实验模板提供零模型参照：若系统观测频率显著偏离退化谱预测，则需由非均匀混合、非置换动力学或观测核偏离等机制解释。
