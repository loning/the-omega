\section{可核验性与可复现性说明（形式化视角）}\label{app:audit}

本文核心结构可被组织为“对象—机制—证书”的三元组：
\begin{itemize}
  \item \textbf{对象：}稳定地址空间与扩展残差空间（含三纤维）；
  \item \textbf{机制：}投影词规范形与 unitary slice 核验机制；
  \item \textbf{证书：}正规形判等、$\varepsilon$-sound 误差预算、根区间/strictification 拒绝证书。
\end{itemize}
在该组织方式下，“数学断言”被还原为可核验证书的存在性与可执行验证过程，从而将可核验性作为体系内部属性而非外部承诺。本文所有涉及“桥接”的结论均以显式条件形式给出（假设 \ref{ass:bridge-rh}），并将其分解为可逐项核验的分项约束（附录 \ref{app:bridge-rh-obligations}）。
