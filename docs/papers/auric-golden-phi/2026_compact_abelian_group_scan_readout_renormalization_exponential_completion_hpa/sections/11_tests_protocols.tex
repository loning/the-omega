\section{可反驳预测与计算检验协议}

\subsection{一维扫描检验}

给定若干 $\alpha$（含 $\varphi^{-1}$、$\varphi-1$ 与随机无理数），比较：
\begin{enumerate}
  \item 星差异度 $D_N^*$ 的衰减；
  \item 三间隙（three-gap）结构与间隙分布；
  \item $\varepsilon$-回归时间的分布与短回归抑制；
  \item 在固定窗口族 $\{W_j\}$ 下的频率误差界。
\end{enumerate}

\subsection{多维联合扫描检验}

对比两类步长向量：
\begin{itemize}
  \item 退化组：$(\delta,\dots,\delta)$；
  \item 去共振组：$\alpha_i=\varphi\sqrt{p_i}$（或其他有理无关构造）。
\end{itemize}
指标包括盒覆盖率、经验测度与 Haar 的 $L^1$/Wasserstein 偏差、维间相关性衰减。

\subsection{符号读出与复杂度检验}

对旋转编码序列计算复杂度 $p(n)$ 并验证 Sturmian 最小复杂度；对 $\alpha=\varphi^{-1}$ 验证频率向量与替换 PF 向量一致。

\subsection{稀疏门控的等分布保持：可检验技术亮点}

设 $(x_n)$ 为 $[0,1)$ 上等分布序列，令 $(S_n)$ 为独立同分布 Bernoulli$(p)$ 门控变量（$p\in(0,1)$），与 $(x_n)$ 独立。记被门控选中的指标集合
\[
I_N=\{0\le n<N:S_n=1\},\qquad M_N=|I_N|.
\]
令稀疏子序列为 $(x_n)_{n\in I_N}$。

\begin{theorem}[独立正密度门控保持等分布，几乎必然]\label{thm:sparse-gating}
对任意区间 $J\subset[0,1)$，几乎必然有
\[
\lim_{N\to\infty}\frac{1}{M_N}\sum_{n\in I_N}\ind_J(x_n)=|J|.
\]
\end{theorem}
证明见附录 \ref{app:sparse-gating}，并给出有限样本误差的显式分解：原序列的差异度项 + 门控的浓缩不等式项。

该定理为“独立门控下的读出稀疏化仍保留均匀性”提供严格基础，并允许将门控概率取为 $\varphi^{-1}$ 作为可反驳参数化选择。
