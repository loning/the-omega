\end{corollary}
\begin{proof}
The highest term of the Zeckendorf decomposition is \(F_9\) if and only if \(F_9\le M(N_f)<F_{10}\), i.e.,
\(
34\le 15N_f<55
\).
Dividing both sides by \(15\) yields \(34/15\le N_f<55/15\), so the unique integer solution is \(N_f=3\). \qed
\end{proof}
