\paragraph{Two-loop missing-sector perturbation audit summary (bounded).}
\AuditTag We extend the two-loop gauge-gauge running audit by modeling the omitted two-loop sectors (Yukawa traces / scalar contributions) as a bounded additive perturbation family $\eta_i\in\{-0.02,0,0.02\}$ in $\mathrm{d}\alpha_i^{-1}/\mathrm{d}\log\mu$. For each named-threshold scheme we select $n$ at $\eta=0$ by lexicographic minimization of $(\min_r E_\infty, n)$ and report the resulting $(r,E_\infty)$ bands across the declared perturbation family. The best baseline (at $\eta=0$) among the schemes is \texttt{Decouple\_QCD\_nf} with $n=10$ and $E_\infty\approx 0.830$.
