# docs/papers/math 工作追踪（数学方向）

本目录收集一组彼此关联但可独立推进的论文工程。每篇论文目录内都有独立的 `README.md`（工作追踪、复现入口、产物位置与下一步）。

## 总体主题（高层）

- **共同母题**：将“微观二进制态”通过某种折叠映射压到“禁邻语言”的稳定态，并把折叠造成的信息亏损组织为可审计的“时间/纤维/边标签”，进而研究：
  - 可逆扩展（无损化）
  - 逆向重建复杂度（观察者时间）
  - 图构造（trellis/闭包图/覆盖图）上的 WL/GI 行为
  - 图谱对象（谱隙、Ihara 型 $\zeta$）与复杂性之间的联系
- **路线 B（固定核）**：当前多条线索可以选择以固定的 $m=6$ 核为“本体模型”，把 $m$ 视为模型定义的一部分（而不是运行参数）。

## 论文列表（按目录）

- **`2026_hpa_ca_fold6_lossless/`**
  - **定位**：固定 $m=6$ 的分块元胞自动机（两相分区），以 $64\to 21$ 折叠核 + uplift 边标签实现“扩展态可逆”；在仅观测稳定层时，逆向变为约束搜索并定义观察者时间。
  - **建议阅读顺序**：先读这篇以建立“固定核（路线 B）”的统一模型直觉与记号。

- **`2026_hpa_64to21_slack_product_trellis_wl/`**
  - **定位**：以段首/段尾规则把 $2^n$ 微观态折到禁邻稳定态 $F_{n+2}$；构造 trellis 与宏观带权动力学，研究 WL/相干配置与压缩 WL2。
  - **备注**：该篇的折叠规则是局部段首算子，不是 Zeckendorf 截断折叠。

- **`2026_fold_backtrack_closure_gi_wl_zeckendorf_trunc_time/`**
  - **定位**：以 Zeckendorf 截断折叠为主，构造“折叠—回溯闭包图”，在同一对象上连接 GI/WL 与“时间纤维（尾部）”，并做多种几何邻接（含 2D/3D Hilbert）实验扫描。

- **`2026_dyadic_zeckendorf_window_folding_kernel/`**
  - **定位**：一般 $m$ 的 Zeckendorf 截断折叠核与 dyadic 边界计数；纤维结构、边界态换能器与加权有限 $\zeta$ 算子。
  - **备注**：这篇更偏“结构定理/工具箱”，但不要求把 $m$ 当作统一本体的自由参数。

- **`2026_cross_scale_resolution_folding_spectral_rigidity/`**
  - **定位**：从 $m=6$ 的折叠核与无损编码出发，构造单图覆盖与跨尺度接口，建立 Ihara 型 $\zeta$ 字典与“复杂性—谱刚性”不等式链；含一段条件性桥接假设（HTF）。

## 复现与产物的一般约定

- **运行方式（每篇独立）**：在各论文目录执行：

```bash
python3 -m pip install -r requirements.txt
python3 scripts/run_all.py
```

- **生成物位置（常见）**
  - `sections/generated/`：可被 `main.tex` 直接 `\input{...}` 的 `.tex` 片段，以及用于摘要的 `.json`/`.csv`
  - `artifacts/`：内容寻址或带 `manifest.json` 的实验产物（不同论文可能存在或命名不同）

## 工作追踪建议（持续推进方式）

- **每篇只保留一条主线**：将“本体模型/观测层/派生图/谱对象”的接口写清楚，避免把不同折叠定义混为一谈。
- **优先把结论写成可审计链条**：定义/假设 $\to$ 命题/定理 $\to$ 可复现实验或一致性检查（脚本生成，不手工改 `.tex`）。
