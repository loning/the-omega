
\section{Audit table: stratification and dependency chain}
\label{app:audit_dependency_chain}

\subsection{Stratification discipline}

\begin{itemize}
\item \textbf{Layer 0:} states and algebras only (Axioms~O1--O4).
\item \textbf{Layer 1:} scan--projection protocols, finite-resolution instruments, induced statistics, and the modular renormalization flow object (Axioms~O5--O6 and the mother-space choice in Section~\ref{sec:renormalization_flow_object}).
\item \textbf{Layer 2:} semantic interpretation (UV/IR, wormholes, physical spectra) as optional commentary. Layer~2 is never used as a premise.
\end{itemize}

\subsection{Dependency chain (closed part)}

The closed, auditable dependency chain of the paper is:
\begin{enumerate}
\item O5/O6 $\Rightarrow$ irrational rotation scan $x_t=x_0+t\alpha\pmod 1$ and induced measure (Theorem~\ref{thm:weyl_equidistribution}).
\item Modular surface geodesic flow $\Rightarrow$ Gauss-map suspension $\Rightarrow$ continued-fraction digit law (Theorem~\ref{thm:series_suspension} and~\eqref{eq:gauss_digit_law}).
\item Continued fractions $\Rightarrow$ Ostrowski coding of tick length $N$ as a locally auditable digit string (Section~\ref{sec:alpha_to_digits_ostrowski}).
\item Cusp interface $q=\e^{2\pi\iu\tau}$ $\Rightarrow$ discrete coefficient spectrum via $q$-expansion (Section~\ref{sec:cusp_qexp_interface}).
\item Slice--coefficient identity and scan sampling $\Rightarrow$ finite-$N$ coefficient estimator with discrepancy/Ostrowski error control (Theorem~\ref{thm:finiteN_coeff_bound} and Corollary~\ref{cor:ostrowski_digit_discrepancy}).
\item Hecke relations $\Rightarrow$ prime-generated skeleton constraining coefficient spectra (Section~\ref{sec:hecke_dynamics_prime}).
\end{enumerate}
