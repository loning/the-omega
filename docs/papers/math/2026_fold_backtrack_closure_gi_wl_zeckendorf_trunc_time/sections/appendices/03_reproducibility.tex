
\section{实验材料与可复现性说明}
\label{app:repro}

本文实验的最小可复现要素包括：
\begin{itemize}
  \item 固定 $m$ 后的折叠映射 $f_m$（由附录 \ref{app:fold} 的 Zeckendorf 贪心算法确定）；
  \item 微观邻接生成器（hypercube / bit-split lattice / Hilbert-lattice）；
  \item 闭包图构造与 $1$-\WL{} 迭代（附录 \ref{app:pseudo}）。
\end{itemize}

\paragraph{关键约定：初始着色。}
本文所有随文实验与生成图表均使用同一初始着色口径：微观端 $X_m$ 的所有顶点共享同一初始颜色；宏观端 $Y_m$ 的每个顶点 $y$ 具有唯一初始颜色标签。该设定保证 $1$-\WL{} 的第 $1$ 步至少细化到折叠纤维层级（引理 \ref{lem:wl-fiber-step1}），并与脚本产物保持一致。

推荐的归档方式是：对每次实验记录（i）参数（$m$、邻接类型、边界条件/维数分解），（ii）输出指标（$t_{\mathrm{stable}}$、$t_{\mathrm{resolve}}$、$u$、$s_{\max}$），以及（iii）生成的表格与图像文件清单。该清单可用 JSON/CSV 形式保存，并在论文同目录随文提供。
