\section{逻辑审计与层分离}

\subsection{正文层标签与分层规则}

\paragraph{四类内联层标签（正文）。}
本文在正文中使用四类内联层标签，以保证论证的可审计性与不可逆依赖纪律：
\begin{itemize}
  \item \MathTag\ \textbf{数学层（可证明）}：以定义、引理、定理等形式出现；其结论仅依赖于此前明确给出的数学输入与明确列出的假设/公理，不得以解释/对齐/审计叙述为前提。
  \item \InterfaceTag\ \textbf{接口/建模层（字典与外加结构）}：引入观测投影、残差承载、动力学类等外加结构与操作性字典；其地位在文中显式标注为“假设/公理/建模约定”，并给出可检验/可反驳的口径。
  \item \MatchTag\ \textbf{外部对齐层（比较口径）}：单位、对照目标、基准数据或比较口径等约定；这些约定用于报告与对齐，不得作为数学层证明前提。
  \item \AuditTag\ \textbf{审计层（复现、失败点、闭包选择）}：候选族/目标函数/tie-break 的闭包选择、复现参数、误差预算、最小失败点等审计性陈述；同样不得反向进入数学层证明链。
\end{itemize}

\paragraph{不可逆依赖纪律（No reverse dependence）。}
\AuditTag 任何 \MathTag 的证明与推导只允许依赖 \MathTag 的陈述以及在同一证明链中明确引入的假设/公理；
\InterfaceTag/\MatchTag/\AuditTag 的叙述只能作为解释、对齐或审计信息，\emph{不得}作为数学层推理前提。
模块级依赖图见附录 \ref{app:audit_overview}（图 \ref{fig:audit_dependency_map}），条目级依赖见推理台账附录 \ref{app:inference_ledger}。

\paragraph{台账状态（附录专用）。}
\AuditTag 推理台账（附录 \ref{app:inference_ledger}）使用五类状态标签 \textsf{[Math]}, \textsf{[Prot]}, \textsf{[Iface]}, \textsf{[CAP]}, \textsf{[Open]} 记录依赖与闭包状态；其中 \textsf{[CAP]} 的含义为“有限候选族 + 目标函数 + 决定性 tie-break 的闭包选择”，并与正文中的 CAP 闭包定义（定义 \ref{def:cap_closure}）一致。以上状态标签仅用于附录的依赖追踪，并非正文层标签。

\subsection{最小外加输入集合（核心版本）}

\AuditTag 本节给出“在不牺牲本文核心主张形状的前提下”的最小外加输入集合。这里所谓“外加输入”包括：接口建模假设（\InterfaceTag）、审计闭包口径（\AuditTag）、以及显式公理/可选结构（如第 6 节的残差充分性公理）。组合定理（第 4、7 节）本身属于数学层输出，不计入外加输入。\par

\paragraph{核心必需输入（支撑 C1--C3 与 CAP/3D 输出）。}
\AuditTag 下列输入足以支撑：两层时间纤维框架（C1）的结构表述、纤维谱/熵指标（C3）的可计算定义、以及“3D 作为 CAP 默认显示输出”的闭包口径（不把 3D 当作先验前提）。
\begin{enumerate}
  \item \textbf{有限窗语义与折叠协议（Prot）。}
  固定 $m$，定义 $\Omega_m=\{0,1\}^m$、稳定语言 $X_m\subset\{0,1\}^m$、以及折叠算子 $\Fold_m:\Omega_m\twoheadrightarrow X_m$（第 4--5 节）。
  \item \textbf{观测接口（Iface）。}
  存在观测投影 $\pi_m$，其输出落在 $X_m$（假设 \ref{ass:observation_projection}）。该输入用于把“折叠与稳定语言”对齐到“可观测输出”的语义层。
  \item \textbf{有限残差充分性（CAP/Axiom）。}
  公理 \ref{ax:finite_residual_sufficiency}：存在有限残差纤维 $R_m(x)$ 使得 $(x_m,r_m)$ 对未来可观测量充分。该输入是第二层时间纤维的核心闭包点（台账 \texttt{L-res-01}）。
  \item \textbf{CAP 闭包选择（Audit）。}
  采用定义 \ref{def:cap_closure} 的闭包规则，并在显示候选族 $\mathcal F_{\mathrm{disp}}$ 上指定一个可审计闭包键 $K_{\mathrm{disp}}$（定义 \ref{def:cap_disp_key}）：门槛坐标（回路可诊断性）+ 时间代理量（闭包图 WL1 的 $t_{\mathrm{resolve}},t_{\mathrm{stable}}$ 的稳健分位数聚合）+ 决定性 tie-break（低维/低复杂度优先）。由此得到“默认三维显示”为闭包输出（第 9、15 节）。
\end{enumerate}

\paragraph{可选输入（不属于核心必需，但用于扩展章节与群论化表述）。}
\AuditTag 下列输入可以删去而不影响上述核心链条的成立形状，但会削弱后续章节的某些结构化表述或把其变为纯解释/实现段落。
\begin{itemize}
  \item \textbf{Hilbert 丛承载（Iface，可选语义承载）。} 假设 \ref{ass:hilbert_bundle} 仅用于把“本体态”组织为统一数学载体；组合/折叠/计数不依赖它。
  \item \textbf{残差群化载体（Iface，可选）。} 假设 \ref{ass:finite_group_residual_carrier} 用于把残差输运/holonomy 置于同一有限群载体上。
  \item \textbf{空间齐性与正规形（Iface，可选）。} 假设 \ref{ass:space_homogeneity} 仅服务于第 9 节后半的时空运算正规形与实现化简，不作为组合定理前提。
  \item \textbf{多尺度、离散连接、双边界合成（Prot/Iface）。} 第 11--13 节的协议与假设用于扩展验证与算法框架，可按需启用。
\end{itemize}

\subsection{本文贡献列表（对应摘要中的主张）}

\begin{itemize}
  \item \textbf{组合不变量地基}：建立稳定语言与循环/边界分解的可证明计数不变量。
  \item \textbf{折叠与两层时间纤维}：以 $\Fold_m$ 与原像纤维组织观测压缩，并以残差充分性公理刻画未来相关自由度。
  \item \textbf{接口亏损不变量}：给出接口耦合项的纯组合表达，并将其作为后续局部化与时间成本的硬支点。
  \item \textbf{时间/空间/多尺度/双边界的统一接口}：给出时间成本、关系空间、多尺度相容与双边界合成的统一表述，并明确哪些结论属于解释层结构对应。
\end{itemize}
