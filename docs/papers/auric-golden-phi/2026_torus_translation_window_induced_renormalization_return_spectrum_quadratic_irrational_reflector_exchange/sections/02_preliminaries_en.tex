\section{Preliminaries: Continued Fractions, Error Scales, Induction, and IET}

\subsection{One-Dimensional Rotation and Continued-Fraction Notation}

Take $\theta\in(0,1)\setminus\QQ$ and define the rotation
\[
T_\theta(x)=x+\theta \pmod 1,\qquad x\in\TT=\RR/\ZZ.
\]
Let the continued fraction be $\theta=[0;a_1,a_2,\dots]$ with convergents $p_i/q_i$ (taking $q_{-1}=0,q_0=1$). Define the distance to the nearest integer
\[
\lVert t\rVert=\min_{n\in\ZZ}|t-n|,
\]
and define the error scale
\[
\delta_i=\lVert q_i\theta\rVert.
\]
There exist integers $p_i$ such that
\[
q_i\theta-p_i=(-1)^i\delta_i.
\]
The error scale satisfies the recurrence identity
\[
\delta_{i-1}=a_{i+1}\delta_i+\delta_{i+1}.
\]

\subsection{Interval Induction and Interval Exchange}

For an interval $E\subset\TT$, the induced map $T_{\theta,E}$ is a piecewise translation, hence an interval exchange transformation (IET). When the number of pieces is 2, it is called a 2-IET; a 2-IET is equivalent, via endpoint identification and linear conjugacy, to a circle rotation. Thus, ``induction remains a rotation'' can be expressed equivalently as ``return time takes only two values'' or ``induction is a 2-IET''.

\subsection{Kac's Formula}

For an ergodic system $(X,\mu,T)$ with $\mu(E)>0$, the first-return time satisfies
\[
\mathbb{E}_{\mu_E}[r_E]=\frac{1}{\mu(E)}.
\]
This formula directly relates the window measure to the average return length and is used to characterize self-similar parameters statistically.
