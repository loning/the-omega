
\section{引言}

当一个离散系统同时携带“空间邻接”（local geometry）与“时间结构”（可演化、可回溯或可检索的内部自由度）时，传统的图同构与 \WL{} 工具往往缺少一个直接的接口：我们既希望保留时空语义，又希望借助 Babai 体系中成熟的 refinement（\WL{}）、coherent configuration 与群作用分支控制。

本文的基本策略是：把“观测/折叠”显式建模为一个映射 $f:X\to Z$。其中 $X$ 是微观态空间（例如 $\{0,1\}^m$），$Z$ 是宏观稳定态/观测态集合（例如无相邻 $1$ 的 Fibonacci 语言），并把空间关系与时间关系一并编码进一个带颜色的组合对象。这样，\GI{} 的输入从“单层图”提升为“带类型与多关系的时空结构”，但仍可通过标准的编码化步骤归约为带颜色图同构，从而接入 Babai--\WL{}--相干配置的语言。

\paragraph{为何以 Zeckendorf 截断为规范。}
本文以 Zeckendorf 截断折叠作为规范观测：先将 $x\in\{0,1\}^m$ 解释为整数 $N(x)$，再取其 Zeckendorf 数码的前 $m$ 位作为宏观观测。该选择把黄金均值语言（禁止词 $11$）与算术编码自然对齐，并使“截断尾部”成为可计算的时间/纤维自由度，从而适合统一编码为 \GI{}/\WL{} 可处理的时空结构对象。

\paragraph{贡献概述。}
\begin{itemize}
  \item 给出一套时空结构对象与同构的统一定义，并提供到带颜色图同构的等价翻译定理；
  \item 在 Zeckendorf 截断规范下构造可计算的 trellis/闭包图，并给出可复现实验指标（\WL{} 稳定深度、残余轨道与纤维统计量）；
  \item 给出 $m=3$ 至 $18$ 的扫描实验，生成可直接引用的图表与表格，用于刻画 \WL{} 信息传播与纤维统计随尺度的变化。
\end{itemize}
