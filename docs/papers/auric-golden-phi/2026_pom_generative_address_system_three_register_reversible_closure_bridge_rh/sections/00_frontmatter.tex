\begin{abstract}
本文以“地址先于值”的可核验语义重述对象存在：设 $\Read:\Addr\rightharpoonup \mathrm{ValDom}$ 为偏函数读出，约定“未定义”与任意数值（含 $0$）严格分离；文中以 $\NULL$ 仅作未定义的记号（$\NULL\notin\mathrm{ValDom}$）。对象“存在”当且仅当存在地址使读出定义且可核验。\par
在最小公理体系 POMmin 下，我们构造稳定语法与折叠归一化 $\Fold_m:\Omega_m\twoheadrightarrow X_m$ 并给出可机械核验的正规形唯一与判等机制；在稳定地址空间内生定义运算 $(\oplus,\otimes)$ 并证明其与 $(\NN,+,\times)$ 半环同构。进一步地，引入记录轴单射化：以素数纤维（prime-register）外置折叠残差，给出提升/回放（lift/replay）并建立信息账本恒等式以分解可见熵与残差信息；在投影词（projection word, PW）的可判定片段内证明正规形唯一与判等可判定；在 unitary slice 强类型核验协议下得到健全性：任何通过核验的零点证书只能落在 $\Re(s)=\tfrac12$，偏移点在该闭包内读出未定义（$\NULL$）。\par
最后，在 BridgeRH 及地址完备性/可注入性/证书完备性等桥接前提成立时，我们给出条件性归约定理 $\mathrm{BridgeRH}\Rightarrow\mathrm{RH}$，并将每条桥接前提规格化为可否证的失败见证。
\end{abstract}
