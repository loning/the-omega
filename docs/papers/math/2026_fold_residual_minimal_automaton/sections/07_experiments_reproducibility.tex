\subsection{\texorpdfstring{实验 1：$m$ 扫描下的纤维谱与残差规模谱}{实验 1：m 扫描下的纤维谱与残差规模谱}}
对 $m\le m_{\max}$：
\begin{itemize}
  \item 枚举全部 $b\in\Omega_m$，计算 $\Fold_m(b)$，统计 $|X_m|$ 与纤维谱 $\{|F_m(x)|\}$；
  \item 计算所有深度的右等价类数 $|U_{m,k}|$；
  \item 输出摘要：最大纤维、平均纤维、以及残差规模谱的若干统计。
\end{itemize}
