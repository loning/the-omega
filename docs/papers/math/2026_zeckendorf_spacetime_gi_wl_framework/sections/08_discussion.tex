\section{讨论与局限}

\subsection{关于“时空结构”的选择}

本文的“时空结构”由三部分共同决定：空间关系 $R_{\mathrm{space}}$（例如 hypercube 邻接）、折叠观测 $\Fold$（Zeckendorf 截断）、以及由尾部投影 $\tau_m$ 与移位算子 $\Tail$ 诱导的时间关系（定义 \ref{def:zeckendorf_trellis}）。其中：
\begin{itemize}
  \item 空间关系决定了 \WL{} 信息扩散的几何通道；
  \item 折叠观测决定了块系统（纤维）如何嵌入编码图；
  \item 时间关系提供了对“被截断自由度”的一个规范化、可计算的组织方式。
\end{itemize}
同一折叠 $\Fold$ 在不同空间关系上可能呈现显著不同的 \WL{} 稳定深度与残余轨道行为；因此，“折叠核”与“几何邻接”应在概念上分离，并通过统一编码对象在同一框架下比较。

\subsection{局限：本文未进入 Babai 的群作用分支细节}

本文给出的翻译定理（定理 \ref{thm:gi_translation_spacetime}）与 \WL{}→相干配置落点（命题 \ref{prop:wl_to_cc}）提供了一个可审计接口，但并不试图重建 Babai 算法的全部技术链条。换言之，本文关注的是：在一个带时空语义的离散对象上，如何把“可见不变量（\WL{}）/残余轨道（对称性）/纤维统计（信息压缩）”闭合到同一可计算对象，而非证明一般 \GI{} 的复杂性界。

\subsection{可证伪点与进一步工作}

本文的可证伪点主要体现在以下方向：
\begin{itemize}
  \item 更换空间关系（例如从 hypercube 到不同维数的 lattice/Hilbert-lattice）后，\WL{} 稳定深度与残余比例是否出现可重复的“相变”；
  \item 更换时间关系（例如不同的尾部更新/压缩方式）后，指标是否保持同阶稳定，或出现系统性偏差；
  \item 在更大 $m$ 上，纤维统计（例如最大纤维与分布形状）是否与 \WL{} 深度存在可量化关联。
\end{itemize}
