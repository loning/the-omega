\section{讨论：多世界分支、主观承诺与“从虚无挤出泡泡”}

\subsection{分支不等于多条本体历史}
本文的“多世界”不是在本体层引入多条演化历史；本体仍是静态约束系统 \(\Clo\)。分支来自观察者对 uplift（尾部时间纤维）未知部分的展开过程：同一宏观观测 \(y\) 可以兼容多个尾部 \(t\)，并且 \(\Tail^{-1}\) 使该集合在展开方向产生分叉。

\begin{remark}[相互约束的三段链]
从约束角度看，本体系的相互制约可分为三段：\textbf{(i) 空间约束时间：}给定观测 \(y\) 把可行尾部限制在纤维 \(T(y)\)；\textbf{(ii) 时间约束时间：}\(\Tail\) 把不同“时刻”的尾部串成一致轨迹；\textbf{(iii) 能量约束主观：}\(\Energy\) 截断并行分支，迫使 commit。三段链均不改变本体守恒，只改变观察者可追踪的子集与主观路径。
\end{remark}

\subsection{能量与主观单线}
能量 \(\Energy\) 作为 beam width 强制 \(|\mathcal B|\le \Energy\)。当 \(\Tail^{-1}\) 的自然分支增长超过该上限时，观察者必须 commit 丢弃部分分支；因此主观体验可以被解释为“在资源约束下选择（或被迫选择）的一条 uplift 路径”。

\subsection{热寂与可逆性}
若只观察宏观压缩后的 \(y\) 层，系统呈现耗散/趋稳。守恒发生在扩展态上：尾部 uplift 记录了可逆性所需的逆信息。更复杂的模型中，观察者若要“抵抗热寂”，需要在自身内部对 \(y\) 与 \(t\) 的组织进行可逆的计算/反计算循环；本文把这部分留作后续可实现扩展（例如加入跨时刻的空间约束或自指约束）。
