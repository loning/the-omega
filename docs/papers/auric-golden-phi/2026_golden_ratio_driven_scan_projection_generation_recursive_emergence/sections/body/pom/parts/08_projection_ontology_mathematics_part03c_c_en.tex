\paragraph{From \texorpdfstring{$q$}{q}-fold Collision to Finite-State Moment-Kernel}
The core new point for second- and third-order is that collision moments are not merely ``enumerable sequences'' but are generated by a \textbf{finite-state fiber-product kernel}, thus falling entirely into the unified Perron--Frobenius/\(\zeta\) interface.
This fact holds for arbitrary \(q\ge 2\): after fixing \(q\), the constraint ``\(q\) windows fold to the same stable type'' is a finite-memory condition and can thus be compiled into a finite graph (SFT/sofic) and counted by an integer adjacency matrix.

\begin{definition}[\texorpdfstring{$q$}{q}-fold Collision Relation and Moment Sequence]\label{def:pom-moment-q}
For an integer \(q\ge 2\), define the \(q\)-fold collision relation
$$
R_m^{(q)}:=
\{(\omega^{(1)},\dots,\omega^{(q)})\in\Omega_m^q:\ \Fold_m(\omega^{(1)})=\cdots=\Fold_m(\omega^{(q)})\},
$$
and define the \(q\)-th order collision moment
$$
S_q(m):=|R_m^{(q)}|=\sum_{x\in X_m} d_m(x)^q.
$$
\end{definition}

\begin{proposition}[Existence and Executable Construction of Arbitrary-Order Moment-Kernels]\label{prop:pom-moment-kernel-exists}
For each fixed \(q\ge 2\), there exists a finite-state non-negative integer kernel (adjacency matrix) \(A_q\) with integer readout vectors \(u_q,v_q\) such that
$$
S_q(m)=u_q^{\mathsf T}A_q^{\,m-m_0}v_q\qquad(m\ge m_0),
$$
so \(\{S_q(m)\}_{m\ge m_0}\) satisfies some \textbf{finite-order integer-coefficient linear recurrence}.

Moreover, \(A_q\) can be explicitly constructed following the ``compilation route'' below (hence deducible, rewritable, and computable):
\begin{enumerate}
  \item Choose an implementation of the deterministic online kernel realizing \(\Fold_\infty\) (the synchronizing kernel with delay \(\delta_{\min}=3\), whose explicit finite-state representation is given in the appendix);
  \item Take \(q\) copies and form their synchronous direct product, expanding the state to a \(q\)-tuple;
  \item At each step retain only those transitions for which the \(q\) copies produce \textbf{identical output bits}, and project to the reachable essential strongly connected component;
  \item The resulting finite graph is a \(q\)-fold collision fiber-product kernel, whose adjacency matrix is the desired \(A_q\), and whose path count yields \(S_q(m)\).
\end{enumerate}
\end{proposition}

\begin{proof}
View \(\Fold_\infty\) as a deterministic finite transducer: input is window alphabet (or its input alphabet induced by two legal input orbits), output is stable address bits; its internal state space is finite and has constant delay (the online kernel of Proposition \ref{prop:pom-delay-min} is a concrete realization).
After fixing \(q\), the constraint ``\(q\) outputs match bitwise'' is a local synchronization constraint: it only requires comparing current output symbols for consistency at each step, hence remains finitely-state recognizable.
One can thus perform synchronous direct product on this transducer and apply the ``output-consistent'' filter to obtain a finite directed graph \(G^{(q)}\).
The count of legal paths of length \(m\) equals the count of \(R_m^{(q)}\) (i.e., \(S_q(m)\)), and can thus be written in the form \(u_q^{\mathsf T}A_q^{m-m_0}v_q\) for some non-negative integer adjacency matrix readout.
The linear recurrence follows immediately from the Cayley--Hamilton theorem, with integer coefficients (since \(A_q\) is an integer matrix). \qed
\end{proof}
