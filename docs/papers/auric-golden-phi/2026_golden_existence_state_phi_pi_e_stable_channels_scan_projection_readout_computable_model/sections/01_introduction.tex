\section{引言}

“存在/不存在”在经验层面表现为二值判别，但在理论层面可被视为同一本体对象经由读出协议投影后的结果。若观测被建模为有限分辨率的正交切割，则观测到的二值量既不需要预设为本体论原始实体，也不需要诉诸超出数学结构的外部断言；其出现可由“扫描--投影--编码”三步操作生成，并通过稳定性要求筛选可重复的读出结构。

本文的目标是给出一个同时满足以下条件的模型：
\begin{enumerate}
  \item \textbf{可计算性：}所有有限分辨率对象可在有限候选类上穷举或以显式算法生成；
  \item \textbf{可审计性：}将定义、定理与接口假设严格分层，避免在证明链中混入语义跳跃；
  \item \textbf{可证伪性：}模型输出以离散可检验不变量形式出现（计数、谱、退化度、边界结构、统计检验协议）。
\end{enumerate}

在该目标下，黄金分支的特殊性不以形而上优越性陈述，而以有限资源下的均匀性证书与语法最小复杂度性质刻画：以黄金比相关斜率生成的 Kronecker 轨道在有限样本下具有最优（或近最优）低差异常数；对应的二字母机械词为 Fibonacci/Sturmian 类，具有最小因子复杂度；对窗口语法的合法性筛选得到斐波那契式增长的稳定类型空间。由此，“黄金存在态”可作为稳定子空间上的规范化态定义，而“存在/不存在”作为投影读出的二值结果出现。
