\section{Appendix F: Cylinder Set Contraction Rate and Entropy Rate (Applicability Conditions)}
\label{app:smb-conditions}

Shannon--McMillan--Breiman (SMB) type conclusions require:
\begin{enumerate}
  \item $(\Omega,\mu,T)$ ergodic;
  \item the observable $\sigma$-algebra generated by a finite partition (or equivalently, the observation process corresponds to a generating partition).
\end{enumerate}

Under these conditions, cylinder set measure log on typical orbits contracts linearly in time, with slope equal to metric entropy. If the observation process is a factor process of the base system rather than a generating partition, we can still obtain versions expressed in terms of conditional entropy or factor entropy; the main text uses the generating partition case to maintain clarity of expression.
