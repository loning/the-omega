\section{From discrepancy to phase friction: key bounds and ``locking thermal death''}
\label{app:discrepancy_pf}

This appendix collects standard discrepancy facts used in Sections~\ref{sec:asm_discrepancy}--\ref{sec:third_law_template}.

\subsection{Star discrepancy and accumulated mismatch}
\label{app:star_discrepancy}

For a point set $\{x_1,\dots,x_N\}\subset[0,1)$, the star discrepancy is
\begin{equation}
  D_N^\ast = \sup_{0\le a\le 1}\left|\frac{1}{N}\#\{x_n<a\}-a\right|.
\end{equation}
If $y_1\le \cdots \le y_N$ are the sorted points, one has the exact 1D formula
\begin{equation}
  D_N^\ast
  = \max\left\{\max_{1\le i\le N}\left(\frac{i}{N}-y_i\right),
             \max_{1\le i\le N}\left(y_i-\frac{i-1}{N}\right)\right\}.
  \label{eq:Dstar_sorted_formula}
\end{equation}
The accumulated mismatch is $E_N := N D_N^\ast$ and the phase-friction entropy certificate is $S_{\mathrm{pf}}(N)=\kB E_N$.

\subsection{Badly-approximable slopes yield logarithmic mismatch growth}
\label{app:ba_log}

For Kronecker sequences $x_n=x_0+n\alpha\pmod 1$, discrepancy bounds depend on Diophantine properties of $\alpha$ \cite{KuipersNiederreiter1974,Cassels1957,DrmotaTichy1997}.
The main quantitative certificate used in the text is Theorem~\ref{thm:cf_discrepancy}: if $\alpha=[0;a_1,a_2,\dots]$ and $q_m\le N<q_{m+1}$, then
\begin{equation}
  E_N \le 1+\sum_{i=1}^m a_i.
\end{equation}
If $a_i\le A$ for all $i$, then $E_N\le 1+Am(N)$, and since $q_m\ge F_{m+1}$ for every continued fraction (because $a_i\ge 1$), one has the explicit bound
\begin{equation}
  m(N)\le \left\lceil \log_{\varphi}\!\left(\sqrt{5}\,N\right)\right\rceil,
  \qquad
  E_N \le 1 + A\left\lceil \log_{\varphi}\!\left(\sqrt{5}\,N\right)\right\rceil,
\end{equation}
which makes the logarithmic mismatch-growth compatibility fully explicit.
This is the controlled-mismatch regime used as the operational ``non-locking'' phase.

\subsection{Rational slopes yield linear mismatch growth}
\label{app:rational_linear}

If $\alpha=p/q$ is rational, the orbit is periodic with period $q$. In particular, the empirical distribution over $[0,1)$ cannot approach uniformity, and one has the universal bound
\begin{equation}
  D_N^\ast \ge \frac{1}{2q},
  \qquad
  E_N \ge \frac{N}{2q}
\end{equation}
for infinitely many $N$ (including multiples of $q$).
In the phase-friction interpretation, this corresponds to an operational ``thermal death'' by phase locking: mismatch accumulates linearly because the readout repeatedly revisits the same finite orbit.

\subsection{Golden branch as the canonical extremum}
\label{app:golden_extremum}

The golden branch $\varphi^{-1}$ is characterized by continued fraction coefficients $a_i\equiv 1$, hence it minimizes $\sum_{i=1}^m a_i$ for a given index $m$ and maximizes the rate at which $q_m$ grows relative to that sum.
Together with Hurwitz/Markov extremality for Diophantine approximation constants \cite{Cassels1957}, this makes the golden branch a canonical arithmetic choice when the operational objective is to delay low-order rational resonances under finite tolerance.
