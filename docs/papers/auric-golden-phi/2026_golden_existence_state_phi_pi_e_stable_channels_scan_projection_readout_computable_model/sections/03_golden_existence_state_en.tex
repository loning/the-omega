\section{Golden Existence State: Projection, Conditioning, and Effective Dimension}

\subsection{Microscopic state Hilbert space and existence projection}

Define the microscopic state space $\Omega_m:=\{0,1\}^m$ and set
\[
\mathcal H_m:=\ell^2(\Omega_m),
\]
with standard orthonormal basis $\{\lvert w\rangle:w\in\Omega_m\}$. Define the ``golden existence projection'' operator
\[
P_m:=\sum_{w\in X_m}\lvert w\rangle\langle w\rvert.
\]
This operator projects any state onto the ``syntactically legal'' stable subspace
\[
\mathcal H_m^{\mathrm{stab}}:=P_m\mathcal H_m.
\]

\subsection{Canonical definition of the golden existence state}

Take the uniform superposition state
\[
\lvert\mathrm{unif}\rangle:=2^{-m/2}\sum_{w\in\Omega_m}\lvert w\rangle,
\]
and define the golden existence state as its conditioning onto the stable subspace:
\[
\lvert\Phi_m\rangle:=\frac{P_m\lvert\mathrm{unif}\rangle}{\norm{P_m\lvert\mathrm{unif}\rangle}}
=\frac{1}{\sqrt{\card{X_m}}}\sum_{w\in X_m}\lvert w\rangle.
\]
This definition is independent of subjective language; its meaning is: at a given resolution $m$, a normalized reference state where all legal types appear with equal weight.

\subsection{``Existence/non-existence'' as binary projection readout}

Given an arbitrary density operator $\rho$ (a state on $\mathcal H_m$), define the probability of the ``existence event''
\[
\mathbb P(\mathrm{exist})=\mathrm{Tr}(P_m\rho),
\]
and the conditioned state when the ``existence event'' occurs
\[
\rho_{\mathrm{obs}}=\frac{P_m\rho P_m}{\mathrm{Tr}(P_m\rho)}.
\]
Therefore, ``only existence states can be observed'' can be rigorously expressed as: the observation statistics are given by $\rho_{\mathrm{obs}}$ as the effective state, not $\rho$ as the unconditioned state. This formulation transforms ``existence'' from an ontological assertion to a readout conditioning operation.

\subsection{Golden effective dimension and entropy rate}

Define the stable type growth rate (topological entropy):
\[
h_{\mathrm{top}}:=\lim_{m\to\infty}\frac{1}{m}\log \card{X_m}.
\]
For the golden mean constraint, we obtain $h_{\mathrm{top}}=\log\varph$, where $\varph=\frac{1+\sqrt5}{2}$. This yields the ``golden effective dimension'' (in binary units):
\[
d_{\mathrm{eff}}:=\lim_{m\to\infty}\frac{1}{m}\log_2\card{X_m}=\log_2\varph.
\]
This quantity lies between $0$ and $1$ and characterizes the exponential scale of distinguishable types in an $m$-bit microscopic space after syntactic stability filtering. If we interpret ``dimension'' as the growth exponent of distinguishable degrees of freedom, this exponent naturally takes the golden value.
