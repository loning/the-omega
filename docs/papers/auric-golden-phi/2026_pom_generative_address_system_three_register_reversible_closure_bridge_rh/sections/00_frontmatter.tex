\begin{abstract}
提出一种生成式数学框架——投影本体数学（Projection Ontological Mathematics, POM），以“可寻址读出”作为对象存在性的语义判据，并以空值 $\NULL$ 表示“未给定地址则读出不定义”，并约定 $\NULL\neq 0$。在最小公理接口（POMmin）下，构造稳定语法与折叠归一化算子，从二元微态读出生成稳定地址空间；在该稳定地址空间上定义 $(\oplus,\otimes)$ 并证明其与 $(\NN,+,\times)$ 半环同构，从而在不预置算术原语的条件下得到加法与乘法的涌现。进一步，以素数寄存器纤维外置折叠残差，构造无损提升与可逆回放，建立信息账本恒等式，对“投影压缩与残差信息”的守恒关系给出严格分解。基于投影词（projection word, PW）证书演算，证明局部片段中正规形唯一与判等可判定，并引入 unitary slice 审计接口得到类型安全定理：在三生成元正规化闭包下，任何满足 $\Re(s)\neq \tfrac12$ 的点不可寻址且读出为 $\NULL$。最后，将经典完成化函数的零点事件通过桥接合同 BridgeRH 编译进 POM 可审计对象域，导出条件主定理：BridgeRH 成立则经典黎曼猜想成立；并以“径向模式必须引入第四寄存器”给出反证模板，解释离线零点在三寄存器闭包中不可类型化的机制。
\end{abstract}
