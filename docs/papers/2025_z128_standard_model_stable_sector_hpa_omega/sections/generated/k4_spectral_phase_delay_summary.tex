\paragraph{Audit summary (K4 spectral phase $\to$ delay).} \AuditTag Dataset count: 3. For each dataset we compute a signed proxy series $\tau_i:=\mathrm{d}\phi/\mathrm{d}\omega$ (units: seconds) on interior points (central differences) and report median/min/max and the negative fraction. Sign convention note: in signal-processing language the (positive) group delay is often defined as $\tau_g:=-\mathrm{d}\phi/\mathrm{d}\omega$ for a transfer-function phase $\phi(\omega)$; thus negative $\tau$ corresponds to positive group delay under that convention. We additionally report a bounded window family ($k=1,2,3$) using local linear fits to make discretization sensitivity explicit. Datasets are read from \texttt{data/k4\_matching/spectral\_phase\_registry.json}.
