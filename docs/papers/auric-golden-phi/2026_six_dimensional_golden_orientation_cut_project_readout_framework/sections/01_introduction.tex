\section{引言与逻辑审计}

\subsection{研究目标}

本文目标是在严格分层的前提下，给出一套可计算、可检验、可替换的形式框架，使如下三类命题获得可反驳接口：
\begin{enumerate}
  \item \textbf{三维现象结构的生成}可由高维周期对象经切—投影与有限分辨率读出得到；
  \item \textbf{相干叠加与干涉条纹}可被归约为读出核与多源投影叠加的强度重构；
  \item \textbf{时间箭头}可在无本体时间流动假设下，被定义为观测代数（或后验柱集）在协议时间上的单调精化与信息率收缩。
\end{enumerate}

\subsection{分层规则}

为避免解释性语言反向进入推理前提，本文将陈述分为四类：
\begin{itemize}
  \item \textbf{定义（D）}：引入对象、映射与结构；
  \item \textbf{定理/命题（T）}：在给定定义与标准数学事实下可证明的结论；
  \item \textbf{模型假设（H）}：用于连接几何层与读出层的可替换结构性假设；
  \item \textbf{语义映射（I）}：将对象层或协议层量映射为物理语义的接口描述，不参与定理闭包。
\end{itemize}
全文的核心链条仅依赖（D）与（T），并显式标注所需（H）。

\subsection{贡献概述}

\begin{enumerate}
  \item 给出六维晶格—三维模型集—有限核读出的统一定义链，并在强度层面给出相干叠加的结构来源（第 \ref{sec:cut-project-readout}--\ref{sec:cut-project-readout} 节）。
  \item 以丢番图条件形式化“黄金分支取向”的反共振特征，并建立无理扫描的等分布与回归尺度模板（第 \ref{sec:golden-branch} 节）。
  \item 在符号层构造二值机械词读出，证明其 Sturmian 复杂度不变量，并在黄金分支得到 Fibonacci 型输出（第 \ref{sec:symbolic} 节）。
  \item 引入 $\Fold_m$ 作为 Zeckendorf 稳定化核，定义时间纤维与闭包固定点语义，并给出信息论时间箭头的可审计定义（第 \ref{sec:symbolic}--\ref{sec:info-time} 节）。
  \item 提供可证伪预测与统计检验管线，强调对照零模型与可识别性（第 \ref{sec:falsifiable} 节与附录）。
\end{enumerate}
