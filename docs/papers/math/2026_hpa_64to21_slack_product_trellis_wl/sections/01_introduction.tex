
\section{引言：$64\to 21$ 作为“折叠—时间”接口}

在许多离散系统中，稳定态往往由局部约束定义（例如“相邻不可同时为 $1$”），而微观态包含大量局部冲突。一个自然问题是：能否把“消除冲突”的过程严格化为一个局部算子，并把丢失的信息组织为结构化的“时间维度”，从而得到一个既可计算又可逆的表示？

本文给出一个最小但行为丰富的模型。
\begin{itemize}
  \item 微观态为所有长度 $n$ 的二进制串集合 $\Xn=\{0,1\}^n$（当 $n=6$ 时为 $64$ 态）。
  \item 宏观稳定态为满足禁邻约束（不含 $11$）的二进制串集合 $\Zn$（当 $n=6$ 时为 $21$ 态）。
  \item 折叠算子是半径 $1$ 的元胞规则：把每段连续 $1$ 只保留段首，其余 $1$ 进入“时间”。
  \item 时间推进同样是半径 $1$ 的元胞规则：把每段连续 $1$ 的段首剥离，剩余部分进入下一时刻。
\end{itemize}

该系统天然同时携带三种对象：数据（micro）、稳定投影（macro）、以及用于补齐折叠丢失信息的时间坐标（time/slack）。围绕 trellis 图与 Weisfeiler--Leman（$\WL$）稳定化，我们得到一条完全离散且可审计的结论链：
\begin{itemize}
  \item 微观到宏观的折叠在纤维上呈 product-of-chains（slack-product）结构；
  \item 宏观加权动力学 $Q_n$ 具有显式的子集枚举—乘法权重公式；
  \item $\WLTWO$ 的稳定染色给出相干配置，并可在宏观层给出“压缩 $\WLTWO$”以避免展开微观态。
\end{itemize}
