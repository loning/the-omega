\section{Generation Mechanism: Scan--Projection Generator and Object Closure}

\subsection{Scan--Projection Generator (SPG)}
Define a scan operator $S$ that samples an underlying process at a finite window as an element of $\Omega_m$; define a projection family $P$ that applies idempotent projections to the read and outputs auditable results. The scan--projection generator is defined as
$$
\mathrm{SPG} := P\circ S.
$$
This generator reduces repeatable read processes to visible objects on stable syntax; simultaneously it preserves auditable residual channels, avoiding irreversible information loss in the lossless lifting sense (see Section \ref{sec:ledger}).\par

\subsection{Recursive addressification and object universe}
Let $\Addr_0$ be the base address family (e.g., window positions, finite bit strings, basic projection gates). Define the recursive generation closure
$$
\Addr_{t+1} := \mathsf{Gen}(\Addr_t),
\qquad
\Addr := \bigcup_{t\ge 0}\Addr_t,
$$
where $\mathsf{Gen}$ is generated by three classes of operations: "combine—normalize—certify":
\begin{enumerate}
  \item Combine: form projection word and gate composition;
  \item Normalize: apply fold and PW normal form;
  \item Certify: output $\varepsilon$-sound or exact certificates such that equality judgment can be completed by deterministic verification rules.
\end{enumerate}

Define the object domain as the quotient by address equivalence:
$$
\Obj := \Addr/\!\sim,
$$
where the equivalence relation $\sim$ is generated by "identical read (or auditable isomorphism)." The key constraint is: the quotient relation must be verifiable by the PW certificate fragment; otherwise the object does not belong to the auditable object domain of this paper.\par
