\paragraph{\texorpdfstring{\(\tau\)}{tau} 的实验口径}
在该表中，我们给出一个可计算的负信息时间 proxy：将“需要显式承诺（commit）的次数”乘以 \(\log_2|\mathcal A|\)（\(|\mathcal A|=21\) 为字母表大小），得到估计的 uplift 胶带比特长度（单位：bits）。该 proxy 仅用于把“时间作为负信息胶带”落到可审计的数值列，并不替代本体层 uplift 的精确定义。
