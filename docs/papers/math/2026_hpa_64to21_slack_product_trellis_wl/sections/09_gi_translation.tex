
\section{与 Babai 图同构框架的对照翻译}

Babai 的图同构（GI）框架及其相关发展在技术上大量依赖三类对象：refinement（例如 $\WL$ 颜色细化）、coherent configuration（相干配置/关联方案的推广）、以及 individualization（对残余对称做有限分支）并配合群作用控制分支爆炸 \cite{babai2016gi,luks1982isomorphism,ivanov2013coherent,cameron1999permutation}.

在本文的 trellis 族上，对应关系是完全显式的：
\begin{itemize}
  \item \textbf{节点类型：}微观/宏观两层顶点；
  \item \textbf{关系结构：}$\WLTWO$ 稳定后的 $V\times V$ 颜色类给出相干配置（定理 \ref{thm:wl2_to_cc}）；
  \item \textbf{不确定性来源：}纤维 $\Head^{-1}(z)$ 的 slack-product 结构（定理 \ref{thm:slack_decomposition}）；
  \item \textbf{搜索复杂度：}由 $K(z),\mathsf{H}(z),D(z)$ 刻画的逆向分支规模与深度（定义 \ref{def:complexity_triple}）。
\end{itemize}

因此，把 GI 的“输入图”替换为本文构造的 trellis（或其宏观加权商图 $Q_n$）时，GI 的核心对象都能在这一完全离散模型中逐一落地。需要强调的是：本文并不声称解决一般 GI，而是提供一个足够简单但行为丰富的离散试验台，使得“时间深度/搜索复杂度/$\WL$ 稳定深度/相干配置”四者可在同一对象上闭合并可计算。
