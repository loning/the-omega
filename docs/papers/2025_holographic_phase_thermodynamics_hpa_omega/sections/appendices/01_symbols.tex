\section{Symbols and notation}
\label{app:symbols}

This appendix records frequently used symbols.

\begin{itemize}
  \item $\omega_\Omega$: normalized global state on the observable algebra $\mathcal{A}$.
  \item $\mathcal{A}$: (effective) observable algebra; $A\in\mathcal{A}$ denotes an observable.
  \item $U:\mathcal{A}\to\mathcal{A}$: intrinsic discrete-step automorphism (update).
  \item $U_{\mathrm{scan}}$: unitary scan operator in the Weyl pair (O6).
  \item $V$: pointer unitary; $\Pi_V$: its spectral measure.
  \item $\alpha\in(0,1)\setminus\QQ$: scan slope in the Weyl commutation relation.
  \item $\mathbb{T}\cong \RR/\ZZ$: circle (phase space); ``mod $1$'' denotes reduction in $\mathbb{T}$.
  \item $\varepsilon>0$: readout resolution parameter.
  \item $\{\mathcal{I}_k^{(\varepsilon)}\}$: readout instrument; $\{E_k^{(\varepsilon)}\}$: associated POVM effects; $\Lambda^{(\varepsilon)}=\sum_k\mathcal{I}_k^{(\varepsilon)}$: outcome-discarding channel.
  \item $x_n=x_0+n\alpha\bmod 1$: scan orbit points on $\mathbb{T}$.
  \item $D_N^\ast$: one-dimensional star discrepancy of $\{x_1,\dots,x_N\}$.
  \item $E_N=N D_N^\ast$: accumulated mismatch.
  \item $S_{\mathrm{rd}}=k_B(-\log w)$: log-weight readout entropy proxy.
  \item $S_{\mathrm{pf}}(N)=k_B E_N$: phase-friction entropy for a length-$N$ window.
  \item $\sigma(x)$: mismatch density (entropy production per scan step) at location $x$.
  \item $\kappa_\Phi$: coupling constant in the phase-potential source $\rho_\Phi=\kappa_\Phi\sigma$.
  \item $Q_\sigma=\int_{\RR^3}\sigma(\mathbf{x})\,\dd^3\mathbf{x}$: total mismatch charge of a localized source.
  \item $M_\Phi=\kappa_\Phi Q_\sigma$: exterior monopole strength in $\Phi(r)\sim -M_\Phi/r$.
  \item $\kappa(x)$: routing overhead (compilation depth) at $x$; $\kappa_0$ reference overhead.
  \item $\lapse(x)=\kappa_0/\kappa(x)$: computational lapse (slowdown factor).
  \item $\tau$: intrinsic scan time (step count); $t$: external/operational time.
  \item $\nu=\dd\tau/\dd t$: local tick rate; $T_c=\eta_T\nu$: computational temperature.
  \item $E$: computational flux (available resource rate); $I$: effective stable structure bits; $\Xi$: conjugate chemical potential.
  \item $\Phi$: phase potential; $\mathbf{P}_\Phi=-\nabla\Phi$: phase pressure.
  \item $Z_{\mathrm{geom}}$: geometric impedance term in the geometric Landauer principle.
  \item $\zeta_{\mathrm{geom}}$: dimensionless constant in $Z_{\mathrm{geom}}=\zeta_{\mathrm{geom}}\,k_B T_c\log(\kappa/\kappa_0)$.
\end{itemize}
