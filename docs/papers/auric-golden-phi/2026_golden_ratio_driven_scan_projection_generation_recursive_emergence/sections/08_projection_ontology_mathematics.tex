\section{投影本体数学：三纤维、三投影与投影词语法}\label{sec:pom}

\subsection{定位与对照：在既有骨架上提升到统一语法}\label{subsec:pom-position}
本节把“投影—本体—稳定读出”的核心器件在同一套形式系统中闭合：以现有折叠 $\Fold_m/\Fold_\infty$ 与序列级因子 $\Phi_m$（第 \ref{sec:folding} 节）、算子代数上的条件期望 $E_m$（附录 \ref{app:op-algebra}）、在线归一化延迟（定理 \ref{thm:online-delay-fold}）以及时间—空间交换图 $Z=E\circ M\circ T$（命题 \ref{prop:time-space-commuting-diagram}）为底座，引入\textbf{三条先验纤维}并把\textbf{加减乘除商余}统一为“同一本体演化 $U$ + 三类投影 $(P_Z,P_{\mathrm{prim}},P_{\le})$ + 线性化深度 $D_U$”的投影词语法。

\subsection{目标与基本命题}\label{subsec:pom-goal}
本节目标不是再造一套形式系统，而是从杂乱算术现象中抽取一个\textbf{本体结构}：存在先验的高维态空间与局部演化律，所有数学对象与运算仅是该本体在不同投影下的读出。相应的基本命题可整理为：
\begin{enumerate}
  \item \textbf{本体态空间与先验纤维：}本体态可分解为外表纤维 $\mathcal Z$ 与三条先验坐标纤维 $\mathcal S_\varphi,\mathcal T,\mathcal P$，并允许有限维余量/控制场 $\mathcal M$（见小节 \ref{subsec:pom-fibers} 与 \ref{subsec:pom-state-evolution}）。
  \item \textbf{本体演化与唯一原语：}本体演化 $U$ 具有局部性与有限传播；在过程语义层面，复合 $\circ$ 与折叠 $\Fold_\infty$ 构成最小原语集（见小节 \ref{subsec:pom-primitive-free}）。
  \item \textbf{三类投影：}规范投影 $P_Z$ 对应“取商并选截面”，原子投影 $P_{\mathrm{prim}}$ 对应“从时间迹读出 primitive 原子层”，序投影 $P_{\le}$ 对应比较/区间约束；三者构成读出分裂与复杂度分界（见小节 \ref{subsec:pom-projections} 与 \ref{subsec:pom-order-bottleneck}）。
  \item \textbf{空间—时间对偶：}读出必然产生空间代价与时间代价，两者通过嵌入—演化—投影正规形耦合（见小节 \ref{subsec:pom-resources}）。
\end{enumerate}

\subsection{扫描—投影生成器（SPG）}\label{subsec:pom-spg}
\begin{definition}[扫描—投影生成器]\label{def:pom-spg}
设 $\Gamma$ 为作用在配置空间上的群或半群，$S$ 为由局部规则驱动的扫描算子，$P$ 为每步执行的二值投影（规范/抑制、保留/丢弃）。定义扫描—投影生成器
\[
\mathrm{SPG}:=P\circ S,
\qquad
\mathrm{SPG}^t=P\circ S^t.
\]
在局部性与投影幂等性的约束下，$\mathrm{SPG}$ 把噪声轨道压缩为稳定读出，从而把“结构生成”统一为同一机制。
\end{definition}
\begin{remark}[反共振尺度选择（解释性）]\label{rem:pom-anti-resonance}
从 Hurwitz/Markov--Lagrange 谱的意义看，黄金比例族给出“最坏有理逼近”的极值，从而对扫描过程中共振污染具有最强抑制；因此尺度纤维选择 $\varphi$ 可被解释为反共振稳定性原则。该叙述仅作动机性说明，不作为后续推理前提。
\end{remark}

\subsection{既有硬骨架的可审计提炼}\label{subsec:pom-hard-skeleton}
\subsubsection{规范投影的商与截面}\label{subsec:pom-quotient-section}
令 $\mathcal{D}$ 为冗余数字配置空间，$\equiv$ 为由 Fibonacci 关系生成的同余（定义见第 \ref{sec:groupoid-zeckendorf} 节）。值映射 $\mathrm{Val}$ 在商 $\mathcal{D}/\!\equiv$ 上与 $(\NN,+)$ 同构（定理 \ref{thm:monoid-quotient-is-N}），而 $X_\infty$ 给出每个同余类的唯一规范代表。由此
\[
\Fold_\infty(a)=Z(\mathrm{Val}(a))
\]
是沿值保持轨道投影到横截面的截面算子（定理 \ref{thm:zeckendorf-transversal}）。因此 $P_Z$ 的幂等、满射与规范性源于“商 + 截面”的结构事实（定理 \ref{thm:fold-suite}）。

\subsubsection{时间—空间交换图}\label{subsec:pom-time-space-diagram}
命题 \ref{prop:time-space-commuting-diagram} 给出严格交换图 $Z=E\circ M\circ T$：时间侧以 $\Tr(T^n)$ 编码迭代统计，空间侧以 primitive 轨道谱实现 Euler 乘积与 Möbius 反演。该接口把“时间读出”与“空间原子分解”统一到同一 $\zeta$-行列式框架。

\begin{remark}[时间迹重建空间原子谱]\label{rem:pom-trace-to-prime}
由交换图与 Möbius/Witt 反演，给定时间侧迹序列 $a_n=\Tr(T^n)$ 即可重建 primitive 轨道数 $p_n$，并恢复 Euler 乘积。因而在固定核下，“时间侧观测 $\Rightarrow$ 空间侧原子谱”的反演是严格可审计的，不需要先枚举 primitive 循环。
\end{remark}

\begin{remark}[Witt 坐标与并行放大]\label{rem:pom-witt-amplifier}
在 Witt 向量视角下，迹序列 $a_n$ 是 ghost 分量，primitive 谱 $p_n$ 是 Witt 坐标。并行张量装配满足
\[
a_n^{\mathrm{glob}}(u)=a_n^{\mathrm{flow}}(u)^m
\]
且 primitive 谱由 Möbius 反演给出（推论 \ref{cor:par-add-global-lift-endpoints}）。因此素数长度的 primitive 项直接隔离了“不可约循环”与“幂重复循环”的差异，并随并行度 $m$ 被指数放大，可作为隐藏并行度与结构分解的无偏探针。
\end{remark}

\subsubsection{算术的去原语化与单一原语}\label{subsec:pom-primitive-free}
后继结构由 $S(c)=\Fold_\infty(c+e_1)$ 给出（定理 \ref{thm:successor-structure}），并诱导加法与乘法的迭代读出（推论 \ref{cor:add-from-successor} 与定理 \ref{thm:mul-from-successor}）。更进一步，过程层可压缩为“合成 $\circ$ 与折叠 $\Fold_\infty$”两类原语：定理 \ref{thm:composition-two-layer} 与 \ref{thm:arith-composition} 给出两层读出的一致实现，推论 \ref{cor:primitive-minimal-successor} 给出最小原语集。

\subsubsection{折叠压缩率与空间代价}\label{subsec:pom-fold-compression}
稳定类型集合满足 $|X_m|=F_{m+2}$，折叠压缩率为 $2^m/F_{m+2}$，并具有指数增长率 $(2/\varphi)^m$（附录 \ref{app:fold-multiplicity}）。该量是“分辨率不足导致信息压缩”的定量基准。

\subsubsection{条件期望与纤维平均}\label{subsec:pom-conditional-expectation}
折叠诱导的子代数 $\mathcal{B}_m$ 与条件期望 $E_m:\mathcal{A}_m\to\mathcal{B}_m$（命题 \ref{prop:fold-conditional-expectation}）给出“沿折叠纤维做平均”的算子化接口，从而把 $P_Z$ 在可观测层面的信息丢失机制精确化。

\begin{remark}[规范投影的双态]\label{rem:pom-pz-dual}
规范投影 $P_Z$ 同时具有两种相容实现：其一是在态/地址层面由 $\Fold_m$ 或 $\Fold_\infty$ 给出的横截面选择；其二是在可观测量层面由条件期望 $E_m$ 给出的纤维平均。二者分别刻画“唯一代表的选取”与“信息遗忘的量化”，共同组成 $P_Z$ 的双态结构。
\end{remark}

\begin{proposition}[条件期望塔]\label{prop:pom-expectation-tower}
对任意 $m_2\ge m_1$，由柱事件延拓给出代数包含
\(
\mathcal{A}_{m_1}\subseteq \mathcal{A}_{m_2}
\)
与
\(
\mathcal{B}_{m_1}\subseteq \mathcal{B}_{m_2}
\)。
并且条件期望满足
\[
E_{m_1}\circ E_{m_2}=E_{m_1}\qquad\text{于}\ \mathcal{A}_{m_2}.
\]
\end{proposition}
\begin{proof}
折叠在不同分辨率下满足截断相容性（见定理 \ref{thm:pom-inverse-limit}），因此“先细分再粗粒化”与“直接粗粒化”对纤维平均给出同一结果；即 $E_{m_1}$ 与 $E_{m_2}$ 形成条件期望塔。证毕。
\end{proof}

\begin{remark}[本体可见性判据]\label{rem:pom-visible-criterion}
对任意 $A\in\mathcal{A}_m$，有
\[
A\in\mathcal{B}_m\quad\Longleftrightarrow\quad E_m(A)=A.
\]
因此“外表可见/稳定读出”的对象等价于落在稳定子代数 $\mathcal{B}_m$（极限为 $\mathcal{B}_\infty$）中的可观测量。
\end{remark}

\subsection{三条先验纤维}\label{subsec:pom-fibers}
\begin{definition}[外表纤维 $\mathcal Z$]\label{def:pom-observable-fiber}
外表纤维取 Zeckendorf 稳定地址
\[
\mathcal Z:=X_\infty=\{(c_k)_{k\ge 1}: c_k\in\{0,1\},\ c_kc_{k+1}=0,\ \text{仅有限个 }1\}.
\]
值映射 $\mathrm{Val}(c)=\sum_{k\ge 1}c_kF_{k+1}$ 把外表与自然数同构；其本体含义是“在值纤维上选取唯一代表的 canonical section”（见定理 \ref{thm:zeckendorf-transversal}）。
\end{definition}

\begin{definition}[尺度纤维 $\mathcal{S}_\varphi$]\label{def:pom-scale-fiber}
取无理数 $\alpha\in(0,1)$ 的连分数 $\alpha=[0;a_1,a_2,\dots]$，Ostrowski 表示给出
\[
N=\sum_{n\ge 1} d_n q_{n-1},
\]
其中 $q_n$ 为收敛分母，数字 $(d_n)$ 满足合法约束。取 $\alpha=\varphi^{-1}$ 时，退化为 Fibonacci 权重与 Zeckendorf 合法语法（禁止相邻 $11$）。定义尺度纤维为该语法下的稳定地址空间（有限分辨率为 $X_m$，极限为 $X_\infty$），其折叠归一化由 $\Fold_m/\Fold_\infty$ 给出（第 \ref{sec:folding} 节）。
\end{definition}

\begin{remark}[更换尺度的代价斜率]\label{rem:pom-scale-slope}
若改用其它最终周期连分数（例如金属平均族）所诱导的稳定语法，其稳定类型规模一般满足 $|X_m|\asymp \lambda^m$。在保持二元读出 $|\Omega_m|=2^m$ 的前提下，折叠熵的斜率将变为
\[
S_Z(m)\sim m\log\!\left(\frac{2}{\lambda}\right),
\]
从而把“空间代价常数”系统性改写为底数 $\lambda$ 的函数。
\end{remark}

\begin{definition}[相位纤维 $\mathcal{T}$]\label{def:pom-phase-fiber}
设相空间为紧阿贝尔群（例如 $\TT^n$），其角色基为
\[
\chi_k(x)=e^{2\pi i\langle k,x\rangle},\quad k\in\ZZ^n.
\]
相位纤维 $\mathcal{T}$ 指由该角色结构诱导的谱坐标层，用于把可加观测量提升为可乘权重与卷积对角化（见第 \ref{sec:zeta-finite-part} 节与第 \ref{sec:high-dimensional-cut-project} 节）。
\end{definition}

\begin{definition}[素数寄存器纤维 $\mathcal{P}$]\label{def:pom-prime-fiber}
令 $\mathbb{P}$ 为素数集合，定义有限支撑指数向量空间
\[
\mathcal{P}:=\mathbb{N}^{(\mathbb{P})}=\{\mathbf{r}:\mathbb{P}\to\mathbb{N}\mid \mathbf{r}(p)=0\ \text{除有限多个 }p\}.
\]
定义值映射
\[
N(\mathbf{r})=\prod_{p\in\mathbb{P}} p^{\mathbf{r}(p)}.
\]
由算术基本定理（参见 \cite{Apostol1976}），$N(\cdot)$ 给出 $\mathcal{P}$ 与 $\mathbb{N}_{\ge 1}$ 的同构，从而把乘法线性化为坐标加法。由于每个状态仅激活有限多素数轴，该纤维满足“无限坐标系 + 局部触发”的可实现口径。
\end{definition}

\begin{remark}[两套自由交换幺半群坐标的并存]\label{rem:pom-two-monoids}
Zeckendorf 坐标与素数指数坐标分别线性化加法与乘法；同一整数对象拥有两套自由交换幺半群坐标（见注 \ref{rem:two-coordinate-monoids}）。本节所加的素数纤维即是该坐标系统在本体层的显式化。
\end{remark}

\begin{remark}[折叠残差的素数承载]\label{rem:pom-prime-carry}
每次 $P_Z$ 折叠都会在纤维内产生“不可见差异标签”（由 $d_m$ 计数）。由于任意有限集合都可嵌入有限支撑的素数幂坐标，素数寄存器纤维可视为一条通用承载轴：它把折叠产生的残差标签转移为可寻址的本体坐标，从而把“信息丢失”改写为“跨纤维存储”。
\end{remark}

\subsection{本体态空间与局部演化}\label{subsec:pom-state-evolution}
\begin{definition}[分辨率态空间]\label{def:pom-state-space}
对分辨率 $n$，定义本体态空间
\[
\mathcal{H}_n:=\mathcal{X}_n\times \mathcal{M}_n,
\]
其中 $\mathcal{X}_n$ 为外表坐标（如 $X_n$ 或 $X_\infty$ 的截断），$\mathcal{M}_n$ 为隐纤维（可包含 $\mathcal{S}_\varphi,\mathcal{T},\mathcal{P}$ 的局部激活块、同步核状态与余量等）。
\end{definition}

\begin{axiom}[局部性与有限传播]\label{ax:pom-locality}
存在本体一步演化算子
\[
U:\mathcal{H}_n\to\mathcal{H}_n
\]
使得每一步仅依赖有限窗口并只更新有限半径的局部块。该公理与第 \ref{sec:A-kernel-compare-main} 节的局部核/在线归一化口径一致。
\end{axiom}

\subsection{三类投影：规范投影、原子投影与序投影}\label{subsec:pom-projections}
\begin{definition}[规范投影 $P_Z$]\label{def:pom-proj-norm}
在窗口层，$P_Z$ 定义为 $\Fold_m:\Omega_m\to X_m$ 的规范化投影（定义 \ref{def:fold-word}），其实现为值保持的局部重写系统并满足终止与合流（定理 \ref{thm:fold-suite}）。在算子代数层，$P_Z$ 由折叠诱导的条件期望
\[
E_m:\mathcal{A}_m\to\mathcal{B}_m
\]
实现（命题 \ref{prop:fold-conditional-expectation}），因此 $P_Z$ 为幂等投影并与归约顺序无关。
\end{definition}

\begin{definition}[原子投影 $P_{\mathrm{prim}}$]\label{def:pom-proj-prim}
给定核/演化算子 $T$，令时间迹序列 $a_n:=\Tr(T^n)$。定义 primitive 轨道谱
\[
p_n:=\frac{1}{n}\sum_{d\mid n}\mu(d)\,a_{n/d}.
\]
记 $P_{\mathrm{prim}}(a):=(p_n)_{n\ge 1}$，则由 Euler 乘积与 Möbius/Witt 反演，有
\[
Z=E\circ P_{\mathrm{prim}}\circ T,
\qquad
Z=E\circ M\circ T.
\]
因此 $P_{\mathrm{prim}}$ 是把“时间迹”投影为 prime-like 原子层的规范读出门。
\end{definition}

\begin{definition}[序投影 $P_{\le}$]\label{def:pom-proj-order}
序投影 $P_{\le}$ 指把本体态映射到有序约束的读出证书（如符号、比较结果或区间约束），其目标是把“$0\le r<b$”一类的全局序关系编码为可观测输出。与 $P_Z$ 不同，$P_{\le}$ 一般不是环同态，也不保证局部可并行化；其读出通常需要跨窗口聚合，因此是不可并行增长的主要来源。
\end{definition}

\begin{remark}[范畴边界与不可并行增长]\label{rem:pom-factor-boundary}
任意滑动块因子码均具有常数在线延迟，因此所有随规模增长的读出深度必然来自非因子码投影（典型即 $P_{\le}$）或把混合留在演化深度 $D_U$ 中。这一“范畴边界”把增长项从算法技巧提升为结构性约束。
\end{remark}

\begin{definition}[角色/同余投影 $P_\chi$]\label{def:pom-proj-chi}
角色投影 $P_\chi$ 指把 primitive 轨道按可加观测量（如 $\chi(\gamma),N_-(\gamma),N_e(\gamma)$）做同余/角色分层，并读出 residue 类标签。其可由扭曲矩阵族 $M(q)$ 与 Dirichlet--Mertens 常数张量实现（见 \ref{subsec:arity-dirichlet-mertens-tensor}），因此是 $P_{\le}$ 在“序/同余/角色读出”方向上的具体化门，亦可视为对 $P_{\mathrm{prim}}$ 的角色化增强。
\end{definition}

\begin{remark}[序瓶颈的碰撞轴主导]\label{rem:pom-collision-axis}
在真实输入 40 状态核中，\(((3,3,5))\) 的最坏扭曲谱半径由纯碰撞 cocycle 达到（命题 \ref{prop:arity-335-collision-dominant}），说明序投影的最慢瓶颈并非“值轴”而是碰撞/相消轴。因而若以空间换时间，优先引入可分离的碰撞轴束比单纯扩展值通道更有效。
\end{remark}

\subsection{投影词语法与成本模型}\label{subsec:pom-words}
\begin{definition}[投影词与半群]\label{def:pom-projection-word}
令投影字母表 $\{Z,\le\}$ 分别代表一次 $P_Z$ 与一次 $P_{\le}$ 读出。对任意指令/微码 $I$，定义投影词
\[
W(I)=(k_Z(I),k_{\le}(I)),
\]
其中 $k_Z,k_{\le}$ 为规范/序投影的调用次数。令
\[
\mathcal{W}=\langle Z,\le\rangle^*/\sim,\qquad Z^2\sim Z
\]
为投影词半群（幂等律来自 $P_Z\circ P_Z=P_Z$）；其他等价关系可按具体实现的因果锥/局部可交换性附加。
\end{definition}

\begin{remark}[原子投影的扩展投影词]\label{rem:pom-word-prim}
若把原子投影纳入读出，则可扩展字母表为 $\{Z,\mathrm{prim},\le\}$，并记
\[
W^{\mathrm{full}}(I)=(k_Z(I),k_{\mathrm{prim}}(I),k_{\le}(I)).
\]
对算术指令默认 $k_{\mathrm{prim}}=0$，原子投影主要服务于 prime-like 谱的读出与机制审计。
\end{remark}

\begin{remark}[角色投影的投影词记号]\label{rem:pom-word-chi}
当序读出由 $P_\chi$ 实现时，可改记投影字母表为 $\{Z,\chi\}$，并写
\(
W_\chi(I)=(k_Z(I),k_\chi(I))
\)。
此时 $k_\chi$ 仅统计角色/同余投影的调用次数，作为 $k_{\le}$ 的具体化版本。
\end{remark}

\begin{definition}[成本模型]\label{def:pom-cost}
令 $\delta_Z$ 为一次规范投影的基准读出深度（例如在线归一化的固定延迟，见定理 \ref{thm:online-delay-fold}），令 $T_{\le}(n)$ 为一次序投影的聚合深度，令 $D_U(n)$ 为在本体演化中完成线性化所需的深度。则定义
\[
T_I(n)=k_Z(I)\,\delta_Z+k_{\le}(I)\,T_{\le}(n)+D_U(n).
\]
该模型把投影读出与演化深度分离，用于比较不同实现把“混合”置于时间还是空间的策略差异。
\end{definition}

\begin{remark}[原子投影读出成本]\label{rem:pom-cost-prim}
若需要读取 primitive 原子层谱，可在成本模型中添加
\[
k_{\mathrm{prim}}(I)\,T_{\mathrm{prim}}(n),
\]
其中 $T_{\mathrm{prim}}(n)$ 表示轨道层谱的读出或 Möbius 反演深度；对算术指令通常取 $k_{\mathrm{prim}}=0$。
\end{remark}

\begin{remark}[角色投影门下的时间上界]\label{rem:pom-cost-chi}
当序读出由 $P_\chi$ 实现时，可用 $\tau_{\mathrm{mix}}$ 作为 $T_{\le}$ 的有效尺度（见注 \ref{rem:pom-chi-mixing}），从而得到
\[
T_I(n)\ \approx\ k_Z(I)\,\delta_Z\ +\ k_\chi(I)\,\tau_{\mathrm{mix}}\ +\ D_U(n).
\]
这给出“投影词 $\Rightarrow$ 非并行开销”的直接量化接口。
\end{remark}

\subsection{空间—时间对偶与资源函数}\label{subsec:pom-resources}
\begin{definition}[嵌入—演化—投影正规形]\label{def:pom-normal-form}
对分辨率 $n$ 的运算 $f_n$，定义其正规形为
\[
f_n=\Pi_n\circ U^{T(n)}\circ \iota_n,
\]
其中 $\iota_n$ 为升维嵌入，$U^{T(n)}$ 为本体演化的迭代，$\Pi_n$ 为由 $P_Z,P_{\le}$ 组合的读出投影。
\end{definition}

\begin{definition}[空间代价与时间代价]\label{def:pom-space-time}
令 $\mathcal M_n$ 为实现 $f_n$ 时被激活的隐纤维块（素数轴、相位轴、余量状态等），定义
\[
S(n):=\log|\mathcal M_n|.
\]
定义时间代价为最小稳定步数
\[
T(n):=\min\{t:\ \Pi_n(U^t(\iota_n(x)))\ \text{对所有输入稳定}\}.
\]
空间—时间对偶律指：增大 $S(n)$ 可将混合线性化并降低 $T(n)$，反之限制 $S(n)$ 将迫使信息沿局部传播累积。
\end{definition}

\begin{corollary}[折叠诱导的空间下界]\label{cor:pom-space-lower-bound}
在分辨率 $m$ 上，若要求折叠纤维的微态可区分（即 $P_Z$ 不丢失该层信息），则隐纤维规模至少满足
\[
|\mathcal M_m|\ \ge\ \frac{|\Omega_m|}{|X_m|}=\frac{2^m}{F_{m+2}},
\]
等价地
\[
S(m)\ \ge\ S_Z(m)=\log\!\left(\frac{2^m}{F_{m+2}}\right).
\]
因此空间代价的最硬下界由折叠熵率直接锁定。
\end{corollary}

\subsection{统一算术：同一演化，不同读出}\label{subsec:pom-unified-arith}
\paragraph{加法}由“逐位叠加 $\Rightarrow$ 规范投影”给出：
\[
a\oplus b=\Fold_\infty(a+b),
\]
其投影词为 $W=(1,0)$（推论 \ref{cor:add-as-fold}）。

\paragraph{乘法}同样可视为“线性化 $\Rightarrow$ 规范投影”，其投影词仍为 $W=(1,0)$；差异体现在 $D_U(n)$ 与所选纤维：相位纤维路线把卷积对角化为点wise 乘，素数纤维路线把乘法线性化为指数坐标的加法（定义 \ref{def:pom-prime-fiber}）。该分解不改变本体原语，仅改变线性化深度与空间开销的分配。

\paragraph{减法}有两条读出路径：
（i）先以 $P_{\le}$ 判定符号/大小，再执行归一化；其投影词 $W=(1,1)$。
（ii）在冗余字母表中把符号内化到 $P_Z$ 的更强归一化中，避免显式 $P_{\le}$，从而 $W=(1,0)$ 但 $\delta_Z$ 增大。这一分解把“序信息”转移到规范投影的本体核中。
若序读出采用角色投影 $P_\chi$，则该步骤可视为对 residue/角色的稳定判定，其时间尺度由 $\tau_{\mathrm{mix}}$ 控制。

\paragraph{除法/商余}满足
\[
a=bq+r,\quad 0\le r<b,
\]
因此 $P_{\le}$ 是不可约读出步骤。由注 \ref{rem:division-as-selection} 的“解方程 + 规范形选择”口径可得：长除式对应 $k_{\le}$ 的线性增长；倒数/迭代式把多次乘法吸收到 $D_U(n)$ 中并以常数次 $P_{\le}$ 校正。两者的差异是投影词的不同实现，而非本体原语的差异。
在角色投影口径下，商余可由 $P_\chi$ 的同余分层稳定读出；其不可并行主尺度即为混合时间 $\tau_{\mathrm{mix}}$。

\begin{remark}[生成机制与“数学体系”的含义]\label{rem:pom-math-world}
“生成整个数学体系”在此不指形式系统的完备性，而指对象与运算的生成机制统一：对象作为本体态在投影族下的稳定读出，运算作为投影词的组合闭包。不同数学分支仅对应于所选纤维与投影闭包的差异，而非本体的差异。
\end{remark}

\subsection{折叠指标与投影熵率}\label{subsec:pom-projection-entropy}
本节以论文中的“全移位窗口 $\Omega_m$ 到黄金均值 SFT 语言 $X_m$ 的规范化截面”为基底：$X_m$ 是禁词 $(11)$ 的长度 $m$ 语言，$\Fold_m:\Omega_m\to X_m$ 把任意窗口微态投影到该语法块上，$\Phi_m$ 把窗口输出提升为序列级 sofic 因子化；相应的标记图 $G_m$ 由长度 $(m-1)$ 后缀状态与追加一比特构造（定义 \ref{def:G_m}）。在此框架下，纤维多重度 $d_m(x)$ 与条件期望 $E_m$ 是规范投影 $P_Z$ 的两类接口，以下结论给出其尺度结构。
\begin{definition}[折叠指标与投影熵率]\label{def:pom-fold-index}
令
\[
I_m:=\frac{|\Omega_m|}{|X_m|}=\frac{2^m}{F_{m+2}},
\qquad
S_Z(m):=\log I_m,
\qquad
h_Z:=\lim_{m\to\infty}\frac{S_Z(m)}{m}.
\]
$I_m$ 是折叠诱导的平均多重度指标，$S_Z(m)$ 与 $h_Z$ 分别刻画分辨率 $m$ 与单位分辨率的投影熵率。
\end{definition}

\begin{proposition}[折叠指标的渐近]\label{prop:pom-projection-entropy}
有
\[
S_Z(m)=m\log\!\left(\frac{2}{\varphi}\right)+O(1),
\qquad
h_Z=\log\!\left(\frac{2}{\varphi}\right).
\]
\end{proposition}
\begin{proof}
由附录 \ref{app:fold-multiplicity} 的渐近式
\(
I_m\sim C(2/\varphi)^m
\)
直接得到。证毕。
\end{proof}

\begin{corollary}[分辨率不足的空间门槛]\label{cor:pom-resolution-threshold}
若希望“每个稳定类型平均只对应不超过 $R$ 个微态”，则必须满足
\[
m\gtrsim \frac{\log R}{\log(2/\varphi)}.
\]
因此提高可区分性必然以分辨率/空间增长为代价。
\end{corollary}

\begin{remark}[折叠熵的二进制斜率]\label{rem:pom-fold-bits}
定义二进制单位的折叠熵

S_Z^{(2)}(m):=\log_2\frac{2^m}{F_{m+2}}.
\]
则

S_Z^{(2)}(m)=m\log_2\!\left(\frac{2}{\varphi}\right)+O(1)

给出每增加一位分辨率所“压扁”的平均信息量常数。
\end{remark}

\subsubsection{窗口折叠的最大纤维多重度}\label{subsec:pom-max-fiber}
记
\[
d_m(x):=\left|\Fold_m^{-1}(x)\right|,
\qquad
D_m:=\max_{x\in X_m} d_m(x).
\]
\begin{theorem}[最大纤维闭式]\label{thm:pom-max-fiber}
取 Fibonacci 延拓到 $F_0=0,F_1=1$。对 $m\ge 2$，有精确闭式
\[
D_{2k}=F_{k+2},
\qquad
D_{2k+1}=F_{k+2}+F_{k-1}\ (=2F_{k+1}).
\]
因此
\[
D_m\sim C'\,\varphi^{m/2},
\]
即最大纤维增长率为 $\sqrt{\varphi}$。特别地，存在常数 $C_1,C_2>0$ 使
\[
C_1\,\varphi^{m/2}\ \le\ D_m\ \le\ C_2\,\varphi^{m/2}.
\]
\end{theorem}
\begin{proof}
对 $\{0,1\}^m$ 的折叠规范化，唯一会被触发的局部重写是
\(
011\mapsto 100
\)
（Fibonacci 进位）。系统合流意味着每个 $\omega$ 的规范形唯一，因此固定 $x\in X_m$ 时，$\omega\in\Fold_m^{-1}(x)$ 当且仅当 $x$ 能通过若干次逆代换 $100\mapsto 011$ 生成 $\omega$。该逆代换占用长度 $3$ 的局部区间；若两次逆代换的起点相距 $1$ 或 $2$，区间重叠会在某一位产生 $2$，因此可选位点必须满足“不可相邻选择”的约束。令 $k=\lfloor m/2\rfloor$，把可选位点看作一条长度 $k$ 的路径图 $P_k$，记其独立集计数为 $I_k$。则
\[
I_0=1,\qquad I_1=2,\qquad I_k=I_{k-1}+I_{k-2}\ (k\ge 2),
\qquad I_k=F_{k+2}.
\]
于是对任意 $x\in X_m$ 有 $d_m(x)\le I_k$。当 $m=2k+1$ 为奇数时，由引理 \ref{lem:pom-one-bit} 的溢出比特 $b\in\{0,1\}$ 分裂为两支；固定 $b$ 会冻结最顶端一处候选位点，使可选链长度降为 $k-1$，从而
\[
d_m(x)\le 2I_{k-1}=2F_{k+1}.
\]

下面构造达到上界的族。对 $m=2,3$ 取
\(
x^{(2)}=00,\ x^{(3)}=000
\)；其余情形令 $m=4q+r$（$r\in\{0,1,2,3\}$）并定义
\[
x^{(m)}=
\begin{cases}
(0001)^{\,q-1}0000,& r=0,\ q\ge 1,\\[2pt]
(0001)^{\,q-1}00100,& r=1,\ q\ge 1,\\[2pt]
(0001)^{\,q}00,& r=2,\ q\ge 0,\\[2pt]
(0001)^{\,q-1}0000100,& r=3,\ q\ge 1.
\end{cases}
\]
该族满足 $x^{(m)}\in X_m$，且其局部零块足以保证：任取不相邻位点集合 $J\subseteq\{1,\dots,k\}$（奇数时为 $\{1,\dots,k-1\}$），按从高位到低位依次执行逆代换，所需的 $100$ 模式在每一步均可实现，从而得到唯一 $\omega\in\Fold_m^{-1}(x^{(m)})$。因此
\[
d_{2k}(x^{(2k)})=I_k=F_{k+2},
\qquad
d_{2k+1}(x^{(2k+1)})=2I_{k-1}=2F_{k+1}.
\]
上界可达即得 $D_m$ 的闭式；渐近式与常数界由 Fibonacci 渐近 $F_n\sim \varphi^n/\sqrt5$ 直接推出。证毕。
\end{proof}

\begin{corollary}[二步递推与基值]\label{cor:pom-D-rec}
$D_m$ 满足
\[
D_m=D_{m-2}+D_{m-4}\qquad(m\ge 6),
\]
并具有基值
\[
D_2=2,\quad D_3=2,\quad D_4=3,\quad D_5=4.
\]
\end{corollary}
\begin{proof}
由定理 \ref{thm:pom-max-fiber} 的闭式，$D_{2k}=F_{k+2}$ 与 $D_{2k+1}=2F_{k+1}$，而 Fibonacci 数满足 $F_{k+2}=F_{k+1}+F_k$。分别代入 $m=2k$ 与 $m=2k+1$ 即得递推；基值由直接枚举或闭式代入给出。证毕。
\end{proof}

\begin{remark}[最坏投影缺口的比特量化]\label{rem:pom-D-delay}
把“区分纤维内微态”视为必须携带的额外信息量，则最坏缺口可用
\[
\Delta_m^{\max}:=\left\lceil \log_2 D_m\right\rceil
\]
衡量。由定理 \ref{thm:pom-max-fiber} 得
\(
\Delta_m^{\max}\sim \frac{m}{2}\log_2\varphi
\)，它给出一种与分辨率 $m$ 线性增长的“不可并行信息缺口”标尺。
\end{remark}

\begin{remark}[一比特溢出与二步递推的结构来源]\label{rem:pom-overflow-rec}
由引理 \ref{lem:pom-one-bit}，每条纤维只分裂为 $b=0,1$ 两支；且 $b=1$ 必要求末位满足零相邻约束。结合局部逆代换的“不可相邻选择链”，最大纤维的计数等价于在步长为 $2$ 的链上作独立集计数，从而结构上解释了二步递推 $D_m=D_{m-2}+D_{m-4}$。
\end{remark}

\begin{corollary}[空间缺陷的夹逼区间]\label{cor:pom-defect-band}
令平均纤维多重度 $\overline d_m=2^m/F_{m+2}$。则
\[
\log \overline d_m\sim m\log\!\left(\frac{2}{\varphi}\right),
\qquad
\log D_m\sim \frac{m}{2}\log\varphi.
\]
因此空间缺陷在“平均尺度”与“最坏尺度”之间形成硬夹逼区间。
\end{corollary}

\begin{remark}[最坏尺度与平均尺度的偏离]\label{rem:pom-defect-gap}
由渐近式可得
\[
\frac{D_m}{\overline d_m}
=
\Theta\!\left(\left(\frac{\varphi^{3/2}}{2}\right)^m\right),
\qquad
\frac{\varphi^{3/2}}{2}\approx 1.029\ldots
\]
因此最坏纤维相对平均纤维的偏离虽为指数，但基数极小，表明折叠投影在“最坏空间损失”意义下仍保持温和的尺度膨胀。
\end{remark}

\subsubsection{在线延迟的不可约下界}\label{subsec:pom-delay-lb}
\begin{proposition}[单趟在线延迟 $3$ 的最小性]\label{prop:pom-delay-min}
任何实现 $\Fold_\infty:\{0,1,2\}^{\ZZ}\to X_\infty$ 的单趟在线转导器，其最小延迟满足
\[
\delta_{\min}(\Fold_\infty)\ge 3.
\]
结合定理 \ref{thm:online-delay-fold}，可得 $\delta_{\min}(\Fold_\infty)=3$。
\end{proposition}
\begin{proof}
在小节 \ref{subsec:online-delay} 的在线核中，输出满足
\(
e=\lfloor \varphi R(s)+d\varphi^{-3}\rfloor
\)，其中 $s$ 为长度 $3$ 的同步状态、$d\in\{0,1,2\}$ 为当前输入。取状态 $s=002$（其属于状态集 $Q$），则
\[
R(s)=2\varphi^{-3},\qquad
e=\left\lfloor 2\varphi^{-2}+d\varphi^{-3}\right\rfloor.
\]
当 $d=0$ 时 $e=0$，当 $d=1$ 时 $e=1$，故该位输出确实依赖于“向前第 $3$ 位”输入。任何延迟 $2$ 的单趟在线机在输出此位时尚未读到该输入，必产生冲突，从而不可能实现 $\Fold_\infty$。证毕。
\end{proof}

\begin{remark}[空间缺陷与时间缺陷的正交性]\label{rem:pom-space-time-orth}
最大纤维多重度给出“值投影”的最坏空间缺陷（定理 \ref{thm:pom-max-fiber}），而单趟在线延迟给出“步骤投影”的不可约时间缺陷（命题 \ref{prop:pom-delay-min}）。两者来源于不同的投影门，因而互不替代：增大空间并不能把 $\delta_{\min}$ 压到 $2$，而压低延迟也无法消除 $d_m$ 的纤维多重度。
\end{remark}

\(
d^{(K)}_m(x):=|K_m^{-1}(x)|
\)。
定义：
\[
S_K(m):=\max_{x}\log d^{(K)}_m(x)\quad(\text{空间指纹}),
\qquad
T_K:=\delta_{\min}(K)\quad(\text{时间指纹}),

并以

\Pi_K:=\{\zeta_K,\ \log\mathfrak{M}_K,\ \rho/\lambda,\ \text{Dirichlet--Mertens 常数张量等}\}
\]
作为谱指纹族（见第 \ref{sec:zeta-finite-part} 节）。三者分别量化“值投影损失”“在线不可并行延迟”与“机制谱细节”，在同一投影框架下互相正交。
\end{definition}

\begin{remark}[Fold 的三指纹]\label{rem:pom-fold-fingerprint}

\subsection{新结论簇 I：熵饱和与最大熵提升}\label{subsec:pom-entropy-maxent}
\begin{definition}[窗口值与外表值]\label{def:pom-window-value}
对 $\omega=\omega_1\cdots\omega_m\in\Omega_m$，定义窗口值
\[
N(\omega):=\sum_{k=1}^m \omega_k F_{k+1}.
\]
对 $x=x_1\cdots x_m\in X_m$，定义外表值
\[
V_m(x):=\sum_{k=1}^m x_k F_{k+1}.
\]
\end{definition}

\begin{lemma}[单隐藏位分解]\label{lem:pom-one-bit}
对任意 $\omega\in\Omega_m$，存在唯一 $b(\omega)\in\{0,1\}$ 使
\[
N(\omega)=V_m(\Fold_m(\omega)) + b(\omega)\,F_{m+2}.
\]
\end{lemma}
\begin{proof}
由 $\sum_{k=1}^m F_{k+1}=F_{m+3}-2$ 得 $0\le N(\omega)<F_{m+3}$。因此 $N(\omega)$ 的 Zeckendorf 表示中不可能出现权重 $F_{m+3}$，其非零位仅可能到 $F_{m+2}$。由 $\Fold_m$ 的定义，$\Fold_m(\omega)$ 给出前 $m$ 位，余下唯一可能的高位即 $F_{m+2}$，于是存在唯一 $b(\omega)\in\{0,1\}$ 使等式成立。证毕。
\end{proof}

\begin{proposition}[纤维自由度的二层分解]\label{prop:pom-fiber-decompose}
对任意 $x\in X_m$，记 $I(x)$ 为 $x$ 中可执行逆代换 $100\mapsto 011$ 的局部位点集合（以长度 $3$ 窗口计），并要求所选位点两两不相邻以避免重叠。则任意 $\omega\in\Fold_m^{-1}(x)$ 可视为“一个余量位 $b\in\{0,1\}$”与“一组不相邻逆代换位点”的组合；因此
\[
d_m(x)\le 2\cdot \#\{\text{路径图 }P_{|I(x)|}\text{ 的独立集}\}
\le 2F_{\lfloor m/2\rfloor+2}.
\]
\end{proposition}
\begin{proof}
由引理 \ref{lem:pom-one-bit}，给定 $\omega$ 的超出前 $m$ 位的信息至多是一位 $b$。其余自由度来自逆代换 $100\mapsto 011$ 的选择：当两次逆代换发生重叠时会产生非二元符号，因此合法选择只能来自一条线性链上的不相邻位点集合。路径图独立集计数即为 Fibonacci 数，从而得到上述上界。证毕。
\end{proof}

\begin{theorem}[一步可判别与右解析性]\label{thm:pom-right-resolving}
对任意 $m\ge 2$ 与任意 $v\in V_m=\{0,1\}^{m-1}$，有
\[
\Fold_m(v0)\neq \Fold_m(v1).
\]
因此标记图 $G_m$（定义 \ref{def:G_m}）是右解析（right-resolving）的：同一顶点出发的两条出边具有不同标记。
\end{theorem}
\begin{proof}
记 $\omega_0=v0$、$\omega_1=v1$。则 $N(\omega_1)-N(\omega_0)=F_{m+1}$. 若 $\Fold_m(\omega_0)=\Fold_m(\omega_1)$，由引理 \ref{lem:pom-one-bit} 得
\[
N(\omega_1)-N(\omega_0)\in\{0,F_{m+2}\},
\]
与 $F_{m+1}\neq F_{m+2}$ 矛盾。故两者标记不同，右解析性随之成立。证毕。
\end{proof}

\begin{theorem}[熵饱和：折叠不改变信息率]\label{thm:pom-entropy-saturation}
对任意 $m\ge 2$，像空间 $Y_m=\Phi_m(\{0,1\}^{\ZZ})$ 满足
\[
h_{\mathrm{top}}(Y_m)=\log 2.
\]
\end{theorem}
\begin{proof}
由于 $\Phi_m$ 是滑动块因子，必有 $h_{\mathrm{top}}(Y_m)\le \log 2$。另一方面，$G_m$ 每个顶点有两条出边，总长度为 $n$ 的路径数为 $2^{m-1}\cdot 2^{n}$。由定理 \ref{thm:pom-right-resolving}，在固定起点下标记序列决定唯一路径，因此长度 $n$ 的标记词数至少为 $2^{n}$。于是
\[
\log 2\le h_{\mathrm{top}}(Y_m)\le \log 2,
\]
结论成立。证毕。
\end{proof}

\begin{remark}[有限缺陷：从纤维多重度到有限部常数]\label{rem:pom-finite-defect}
熵饱和表明折叠在信息率意义下不压缩；其“丢失”体现为\textbf{有限缺陷}而非指数尺度。具体而言，给定标记序列 $y\in Y_m$，其前像路径数由起始顶点选择给出，故
\[
|\Phi_m^{-1}(y)|\le |V_m|=2^{m-1}.
\]
这种有限歧义可由纤维多重度 $d_m(x)$ 与条件期望 $E_m$ 的块平均结构刻画（命题 \ref{prop:fold-conditional-expectation}），并与 Abel/Hadamard 有限部常数形成互补的“常数级指纹”（定义 \ref{def:abel-finite-part} 及相关附录接口）。因此折叠的“丢失”属于有限分辨率残差，而非熵率损失。
\end{remark}

\begin{remark}[纤维平均与有限部常数的同一接口]\label{rem:pom-em-logm}
窗口尺度上，$E_m$ 通过 $d_m$ 对纤维做平均，压缩的是一次投影的不可观测自由度；轨道尺度上，Abel/Hadamard 有限部常数
\[
\log\mathfrak{M}(\theta)
=
\log C(\theta)
\;+\;
\sum_{k\ge 2}\frac{\mu(k)}{k}\log\zeta_\theta\!\bigl(z_\star(\theta)^k\bigr)
\]
（定义 \ref{def:abel-finite-part} 与命题 \ref{prop:abel-finite-part-mobius-zeta}）压缩的是 primitive 轨道乘积在无限尺度下的有限部漂移。因而 $E_m$ 与 $\log\mathfrak{M}$ 是同一“信息丢失接口”的微观/宏观两种尺度：前者是窗口纤维平均，后者是沿循环重复观测后的重整化常数；其导出的 $\mathsf{M}(\theta)=\gamma+\log\mathfrak{M}(\theta)$ 与 $P(\theta)$ 共同形成主尺度与有限部的双指纹（见 \ref{subsec:chi-ldp}）。
\end{remark}

\begin{definition}[推前与纤维均匀提升]\label{def:pom-maxent-lift}
把 $\mathcal{A}_m\simeq\mathbb{C}^{\Omega_m}$、$\mathcal{B}_m\simeq\mathbb{C}^{X_m}$ 识别为有限集上的函数代数（见命题 \ref{prop:fold-pushforward-lift}）。对任意分布 $\pi\in\Delta(X_m)$，定义纤维均匀提升
\[
\widetilde\pi(a):=\frac{\pi(\Fold_m(a))}{d_m(\Fold_m(a))},\qquad a\in\Omega_m.
\]
则 $(\Fold_m)_*\widetilde\pi=\pi$。
\end{definition}

\begin{theorem}[最大熵提升的唯一性]\label{thm:pom-maxent-lift}
固定任意 $\pi\in\Delta(X_m)$，在所有满足 $(\Fold_m)_*\mu=\pi$ 的分布 $\mu\in\Delta(\Omega_m)$ 中，Shannon 熵
\[
H(\mu):=-\sum_{a\in\Omega_m}\mu(a)\log\mu(a)
\]
的最大值唯一且由 $\widetilde\pi$ 取得。并且
\[
H(\widetilde\pi)=H(\pi)+\mathbb{E}_{\pi}[\log d_m(X)].
\]
\end{theorem}
\begin{proof}
固定 $x\in X_m$ 时，纤维 $\Fold_m^{-1}(x)$ 上的总质量为 $\pi(x)$。在该纤维内，熵在“均匀分配”处唯一取最大值（严格凹性）。对各纤维求和得到全局最大值与唯一性。直接代入 $\widetilde\pi$ 得
\[
H(\widetilde\pi)
=-\sum_{x\in X_m}d_m(x)\frac{\pi(x)}{d_m(x)}\log\!\left(\frac{\pi(x)}{d_m(x)}\right)
=H(\pi)+\sum_{x\in X_m}\pi(x)\log d_m(x).
\]
证毕。
\end{proof}

\begin{definition}[热力学缺陷与空间投影标量]\label{def:pom-kappa}
对任意分布 $\pi\in\Delta(X_m)$，定义
\[
\kappa_m(\pi):=\mathbb{E}_{\pi}[\log d_m(X)].
\]
由定理 \ref{thm:pom-maxent-lift}，$\kappa_m(\pi)=H(\widetilde\pi)-H(\pi)$，因此 $\kappa_m$ 给出“折叠纤维被压掉的自由度”的可观测标量刻画。
\end{definition}

\begin{remark}[窗口缺陷与有限部常数的同型]\label{rem:pom-kappa-logm}
窗口尺度上，$\kappa_m(\pi)$ 是一次折叠投影的对数纤维体积缺陷；轨道尺度上，$\log\mathfrak{M}(\theta)$ 是 primitive 轨道乘积在无限尺度下的 Möbius--Abel 正则化有限部（定义 \ref{def:abel-finite-part}）。二者分别给出微观/宏观的“纤维缺陷”接口，为跨尺度缺陷泛函的对齐提供了统一口径。
\end{remark}

\begin{remark}[与条件期望的对偶性]
纤维均匀提升 $\widetilde\pi$ 与条件期望 $E_m$ 构成对偶接口：$E_m$ 在观测量层面是“纤维平均”，而 $\widetilde\pi$ 在概率层面是“纤维均匀化”。二者分别给出折叠的算子化与信息论刻画。
\end{remark}

\begin{remark}[延迟归一化推迟律]\label{rem:pom-lazy-fold}
若中间演化 $U_t$ 在观测层不区分折叠纤维，即对任意 $g\in\mathcal{A}_m$ 有 $g\circ U_t\in\mathcal{B}_m$ 等价于 $g=\bar g\circ\Fold_m$（命题 \ref{prop:pom-fiber-invariance}），则
\[
E_m\circ U_t\circ E_m=E_m\circ U_t.
\]
因此在此类“纤维不区分”的演化段内，多次 $P_Z$ 可合并为末端一次，实现规范投影的推迟执行。
\end{remark}

\subsection{新结论簇 II：商余作为平移群胚横截面}\label{subsec:pom-division-groupoid}
\begin{definition}[平移群胚与基本域]\label{def:pom-translation-groupoid}
固定整数 $b>0$，令 $\mathbb{Z}$ 作用于 $\mathbb{Z}$：
\[
k\cdot a:=a-kb.
\]
其轨道即同余类 $a\bmod b$。取基本域
\[
\mathcal F_b:=\{0,1,\dots,b-1\},
\]
并定义投影
\[
\Pi_b(a):=\text{唯一满足 }a\equiv r\pmod b\text{ 且 }r\in\mathcal F_b\text{ 的 }r。
\]
\end{definition}

\begin{theorem}[商余作为横截面投影]\label{thm:pom-division-section}
对任意 $a\in\mathbb{Z}$，存在唯一 $(q,r)\in\mathbb{Z}\times\mathcal F_b$ 使
\[
a=qb+r,\qquad r=\Pi_b(a).
\]
其中 $q$ 是轨道坐标，$r$ 是沿平移轨道投影到横截面的像。
\end{theorem}
\begin{proof}
由整数除法算法与同余类代表的唯一性得到。平移群作用的轨道等于同余类，$\mathcal F_b$ 为其横截面，故投影 $\Pi_b$ 给出唯一 $r$，并据此确定 $q$。证毕。
\end{proof}

\begin{corollary}[中心余数横截面]\label{cor:pom-symmetric-remainder}
若改用对称基本域
\[
\mathcal F_b^{\mathrm{sym}}:=\left\{-\left\lfloor\frac{b}{2}\right\rfloor,\dots,\left\lceil\frac{b}{2}\right\rceil-1\right\},
\]
则仍有唯一分解 $a=qb+r$ 且 $r\in\mathcal F_b^{\mathrm{sym}}$。该选择等价于改变横截面而非改变本体演化，可将部分“区间校正”合并到单次序投影中。
\end{corollary}

\begin{remark}[与 Fold 的群胚类比]
定理 \ref{thm:pom-division-section} 与定理 \ref{thm:zeckendorf-transversal} 在结构上同型：二者均为“轨道 = 值纤维/同余类，横截面 = 规范代表”的投影机制；商 $q$ 与折叠残差的群胚坐标具有同一语义地位。
\end{remark}

\subsection{新结论簇 III：包含商余的扩展最小原语集}\label{subsec:pom-primitive-extended}
\begin{theorem}[扩展最小原语集]\label{thm:pom-extended-primitives}
在配置层，$\oplus,\otimes,\mathrm{div},\mathrm{quo},\mathrm{rem}$ 可由以下原语生成：
\begin{enumerate}
  \item 逐点叠加（自由交换幺半群结构）；
  \item Fibonacci 群胚生成元（值保持局部可逆重写）；
  \item 值纤维横截面投影 $\Fold_\infty$（规范投影）；
  \item 平移群胚横截面投影 $\Pi_b$（序/区间投影）。
\end{enumerate}
在过程层，等价表述为：仅以复合 $\circ$ 作为底层原语，再配合值投影 $\Fold_\infty$ 与序投影 $\Pi_b$ 把结果落回外表；原子投影 $P_{\mathrm{prim}}$ 作为谱读出接口独立施加。
\end{theorem}
\begin{proof}
加法与乘法由定理 \ref{thm:composition-two-layer} 与 \ref{thm:arith-composition} 的过程层读出实现，并由 $\Fold_\infty$ 落回稳定地址。商余由定理 \ref{thm:pom-division-section} 作为平移群胚横截面投影给出。其余运算由上述原语的组合闭包得到。证毕。
\end{proof}

\subsection{逆极限自然性与纤维不变量判别}\label{subsec:pom-new-results}
\begin{theorem}[逆极限自然性]\label{thm:pom-inverse-limit}
设对每个分辨率 $m$ 定义稳定层运算 $f_m:X_m\to X_m$，并满足对一切 $m_2\ge m_1$ 的截断投影
\[
\pi_{m_2\to m_1}\circ f_{m_2}=f_{m_1}\circ \pi_{m_2\to m_1}.
\]
则存在唯一的极限运算 $f_\infty:X_\infty\to X_\infty$ 使得对所有 $m$ 有 $\pi_m\circ f_\infty=f_m\circ \pi_m$。
\end{theorem}
\begin{proof}
由定理 \ref{thm:inverse-limit-golden}，$X_\infty\cong\varprojlim X_m$。相容性等式正是逆系统上的自然变换条件，因此由逆极限的泛性质得到唯一的 $f_\infty$。证毕。
\end{proof}

\begin{proposition}[纤维不变量判别]\label{prop:pom-fiber-invariance}
给定 $g:\Omega_m\to\mathbb{R}$，以下条件等价：
\begin{enumerate}
  \item 若 $\Fold_m(a)=\Fold_m(b)$ 则 $g(a)=g(b)$；
  \item 存在 $\bar g:X_m\to\mathbb{R}$ 使得 $g=\bar g\circ\Fold_m$；
  \item $g$（作为可观测量）属于折叠不变量子代数 $\mathcal{B}_m$（命题 \ref{prop:fold-invariant-subalgebra}）。
\end{enumerate}
\end{proposition}
\begin{proof}
$(1)\Rightarrow(2)$：定义 $\bar g(x)=g(a)$ 对任意 $a\in\Fold_m^{-1}(x)$，由 (1) 保证良定义。$(2)\Rightarrow(3)$：$g$ 在每条纤维上常值，故对应于 $\mathcal{B}_m$ 的坐标表示。$(3)\Rightarrow(1)$：$\mathcal{B}_m$ 的元素对纤维常值（命题 \ref{prop:fold-invariant-subalgebra}）。证毕。
\end{proof}

\begin{remark}[时间—空间对偶接口与素数影子]\label{rem:pom-time-space}
命题 \ref{prop:time-space-commuting-diagram} 给出的严格交换图把时间侧 $\Tr(T^n)$ 与空间侧 primitive 轨道谱对齐，从而为“时间—空间正交对偶”提供可审计接口。另一方面，有限核的 primitive 轨道谱与整数素数并不等同（见注 \ref{rem:prime-shadow-vs-primes}）：前者是核动力学的内禀素性，后者需要额外的素数索引算子族。素数寄存器纤维 $\mathcal{P}$ 正是对这一额外索引结构的本体化补充。
\end{remark}

\begin{conjecture}[profinite 轴上的 Chebotarev 提升]\label{conj:pom-profinite-axis}
设 $\{G_m,\pi_{m+1\to m}\}$ 为有限群投影系统，$G_\infty:=\varprojlim_m G_m$。对每个 $m$ 构造 $G_m$-扩张核并记其最坏扭曲谱比为
\[
\eta_m:=\max_{\rho\neq\mathbf 1}\frac{\rho(B_{\rho,m})}{\rho(B_{\mathbf 1,m})}.
\]
若存在 $\varepsilon\ge 0$ 使得对所有 $m$ 有 $\eta_m\le \lambda^{1/2-\varepsilon}$，则对 $G_\infty$ 的任意 cylinder 集合，其 primitive 轨道分布满足 Chebotarev 型主项与平方根级误差，并与有限层结果相容。该提升为“无限素数寄存器”提供可审计的 profinite 轴模型。
\end{conjecture}

\subsection{谱隙驱动的时间尺度与读出稳定}\label{subsec:pom-spectral-gap}
\begin{corollary}[谱隙控制的读出时间尺度]\label{cor:pom-spectral-gap-time}
设 $M_K(u)$ 原始，主特征值为 $\lambda_1(u)$，其余特征值最大模为 $\lambda_2(u)$。由定理 \ref{thm:kernel-weighted-prime-orbit}，
\[
B_n(u)=\frac{\lambda_1(u)^n}{n}+O\!\left(\frac{|\lambda_2(u)|^n}{n}\right),
\]
从而相对误差满足
\[
\left|\frac{nB_n(u)}{\lambda_1(u)^n}-1\right|
\le C\left(\frac{|\lambda_2(u)|}{\lambda_1(u)}\right)^n.
\]
给定目标精度 $\varepsilon\in(0,1)$，满足
\[
n\ \ge\ \frac{\log(C/\varepsilon)}{\log\!\bigl(\lambda_1(u)/|\lambda_2(u)|\bigr)}
\]
即可保证相对误差不超过 $\varepsilon$。若进一步满足核版 RH/GRH 条件（定义 \ref{def:kernel-rh}），则可用 $\lambda_1(u)^{1/2}$ 替代 $|\lambda_2(u)|$，从而得到平方根级衰减尺度（推论 \ref{cor:kernel-rh-sqrt-error}）。
\end{corollary}

\begin{remark}[自对偶与完成化偶性]\label{rem:pom-duality-even}
若同步核满足附录 \ref{app:kernel-self-dual} 的自对偶关系，则完成化后的 $\zeta$ 函数在 $\theta$ 变量上呈严格偶性。于是其对 $\theta$ 的奇阶导数在 $\theta=0$ 处消失，这对代价势的涨落统计施加对称性约束；相应的可调性仅能通过破坏该自对偶结构实现。
\end{remark}

\subsection{新结论簇 IV：指数尺度饱和与常数级指纹}\label{subsec:pom-lambda-saturation}
\begin{proposition}[指数尺度的输入饱和]\label{prop:pom-lambda-saturation}
对确定性、完备读入的同步核，Perron 根 $\lambda$ 主要由输入骨架决定，而核方向仅贡献更小模的谱修正。具体地，40 状态真实输入核满足 $\rho(M)=\rho(A)=\varphi^2$（命题 \ref{prop:real-input-40-skeleton-factor}），10 状态同步核满足 $\lambda=3$（附录 \ref{app:sync-kernel-basic} 的行列式分解）。因此 $\log\lambda$ 更接近“输入分支熵”的饱和尺度，而非机制差异的细粒度指纹。
\end{proposition}

\begin{remark}[区分机制的三类指纹]\label{rem:pom-mechanism-fingerprint}
当主尺度 $\lambda$ 饱和时，真正区分运算机制的对象来自常数级与扭曲谱层：
\begin{itemize}
  \item \textbf{有限部曲线 $\log\mathfrak{M}(\theta)$：}在同一切片上与 $P(\theta)=\log\rho(M_\theta)$ 并列记录，用以刻画常数级漂移（见 \ref{subsec:chi-ldp} 中的对比注）。
  \item \textbf{Dirichlet--Mertens 常数张量：}对按同余类分层的 primitive 轨道计数给出常数级偏置（见 \ref{subsec:arity-dirichlet-mertens-tensor} 及相关附录）。
  \item \textbf{最坏扭曲比 $\rho/\lambda$：}由 Chebotarev 型误差控制序投影混合时间尺度（定理 \ref{thm:kernel-chebotarev-exp} 与推论 \ref{cor:pom-order-mixing}）。
\end{itemize}
这三类量与 $\lambda$ 正交互补，构成“运算机制”的可审计指纹；因此当 $\lambda$ 被输入分支锁定时，核之间的差异必然落在 $\log\mathfrak{M}$ 与 Dirichlet--Mertens 张量等有限部接口上。
\end{remark}

\subsection{真实输入 40 状态核的 RH-sharp 谱界与 toy RH}\label{subsec:pom-rh-sharp}
\begin{theorem}[RH-sharp/Ramanujan 谱界]\label{thm:pom-rh-sharp}
真实输入 40 状态核的行列式分解
\[
\det(I-zM)=(1-z)^2(1+z)^3(1-3z+z^2)(1+z-z^2)

\mathrm{spec}(M)\setminus\{0\}

\qquad \lambda=\varphi^2.
\]
因此除 $\lambda$ 外的全部非零特征值 $\nu$ 满足
\[
|\nu|\le \sqrt{\lambda}=\varphi,
\]
且仅有一个非平凡特征值达界：$\nu_2=-\sqrt{\lambda}$。
\end{theorem}

\begin{corollary}[平方根振荡的最优性]\label{cor:pom-rh-sharp-an}
设 $a_n=\Tr(M^n)$，则

并且误差项不能改进到 $o(\lambda^{n/2})$。等价地，动力学版的“Chebyshev 平方根误差”在本核上达到临界最优。
\end{corollary}

\begin{proposition}[Lucas--平方闭式]\label{prop:pom-lucas-square}
令 Lucas 数

则

a_n=L_n^2+(-1)^n(L_n+1)+2.

\begin{corollary}[primitive 奇偶分裂]\label{cor:pom-prim-odd-even}

p_n=\frac{\lambda^n}{n}+\frac{\bigl((-1)^n-\mathbf{1}_{2\mid n}\bigr)\lambda^{n/2}}{n}

其中偶数情形的 $\lambda^{n/2}$ 级项在 Möbius 反演的 $d=1,2$ 两项间精确抵消（见附录 \ref{app:real-input-40-finite-rh}）。

\begin{theorem}[Dirichlet 极点晶格与 toy RH]\label{thm:pom-toy-rh}

给出，并满足

其中 $r=-\varphi$ 产生一条临界线晶格

\begin{proposition}[输出压力的二、三阶累积量闭式]\label{prop:pom-pressure-cumulants}

从而 $P''(0)\approx 0.0487412456$、$P'''(0)\approx -0.0158881374$。
\end{proposition}
\begin{proof}
对 $G(\lambda(u),u)=0$ 做隐函数求导，并用 $u=e^\theta$ 的链式法则把 $u$-导数转为 $\theta$-导数；代入 $u=1,\lambda=\varphi^2$ 即得。
\end{proof}

\begin{corollary}[零温极限常数]\label{cor:pom-pressure-zero-temp}
由附录 \ref{app:real-input-40-zeta-u} 可得 $\theta\to+\infty$ 时
\[
P(\theta)=\frac{\theta}{2}+\log c+o(1),
\]
其中 $c=\sqrt{y_{\max}}$，$y_{\max}$ 为方程 $y^4-6y^3+9y^2-y-1=0$ 的最大正根。
\end{corollary}

\subsection{素数影子到素数寄存器的桥接}\label{subsec:pom-prime-bridge}
\paragraph{有限轴束的扭曲与分解}
对有限群标签 $G$ 的扭曲矩阵族 $M_{K,\rho}(u)$ 与扭曲 $\zeta/L$-函数，命题 \ref{prop:kernel-artin-factorization} 给出 Artin 型因子化。该分解表明：有限轴束本质上是以 $\widehat G$ 为谱坐标系的“可审计纤维化”。

\paragraph{新增模轴的不可约性}
命题 \ref{prop:arity-335-n2-nondegenerate} 证明了第三轴 $N_2(\gamma)\bmod 5$ 无法由前两轴消去，因此新增模轴引入不可约的新自由度。这一事实把“增加轴束不是重标记”在核层面固定为可审计结论。

\begin{definition}[素数寄存器纤维的极限口径]\label{def:pom-profinite}
取模系统 $\{\ZZ/m\ZZ\}_{m\ge 1}$ 的射影极限
\[
\widehat{\ZZ}:=\varprojlim_m \ZZ/m\ZZ\ \cong\ \prod_{p\in\mathbb{P}}\ZZ_p,
\]
并将其作为“无限素数轴束”的极限对象。该极限把所有有限模轴束统一为同一纤维坐标体系，从而为“素数寄存器”提供结构性定义（参见 \cite{Apostol1976} 中关于 CRT 与 p-进分解的标准事实）。
\end{definition}

\begin{remark}[从有限扭曲到无限寄存器]
有限群扭曲提供“有限模轴束”的可审计谱分解；而新增轴的不可约性意味着该分解在模数增大时严格增加自由度。因而 $\widehat{\ZZ}$ 的极限口径与素数寄存器纤维 $\mathcal{P}$ 在结构上是兼容的：前者是“模轴束的完备化”，后者是“乘法坐标的线性化轴束”。
\end{remark}

\begin{remark}[同余轴的逆极限与角色对角化]\label{rem:pom-congruence-invlimit}
将有限同余轴 $\{\ZZ/m\ZZ\}_{m\ge 1}$ 视作投影系统，则其逆极限给出
\(
\widehat{\ZZ}\cong\prod_{p}\ZZ_p
\)；
对应的角色基
\(
\chi_{k/m}(n)=e^{2\pi i kn/m}
\)
是 Pontryagin 对偶上的自然坐标。由此“有限同余轴 + 相位对角化 + 扭曲 $\zeta$”形成一条可审计的构造路径，极限即为“无限素数寄存器纤维”的严格实现。
\end{remark}

\begin{remark}[素数长度作为并行结构探针]\label{rem:pom-prime-length-probe}
在张量装配的全局核上，迹序列满足 $a_n^{\mathrm{glob}}(u)=a_n^{\mathrm{flow}}(u)^m$，primitive 谱由 Witt/Möbius 反演给出（推论 \ref{cor:par-add-global-lift-endpoints}）。当 $n=\ell$ 为素数时，
\[
p_\ell^{\mathrm{glob}}(u)=\frac{1}{\ell}\Bigl(a_\ell^{\mathrm{flow}}(u)^m-a_1^{\mathrm{flow}}(u^\ell)^m\Bigr),
\]
从而素数长度的 primitive 项直接隔离了“不可约循环”与“幂重复循环”的差异。该差异对并行张量化极其敏感，可作为隐藏并行度与结构分解的无偏探针。
\end{remark}

\subsection{投影词正规形与读出层级塔}\label{subsec:pom-normal-form}
\begin{theorem}[半环闭包的一次投影正规形]\label{thm:pom-one-fold-normal-form}
令 $t$ 为由 $\oplus,\otimes,0_X,1_X$ 生成的任意项，变量取值于 $X_\infty$。则存在多项式
\(
P\in\NN[x_1,\dots,x_k]
\)
使得对任意 $c_1,\dots,c_k\in X_\infty$，
\[
t(c_1,\dots,c_k)=Z\!\left(P\bigl(\mathrm{Val}(c_1),\dots,\mathrm{Val}(c_k)\bigr)\right).
\]
因此在半环闭包内，规范投影 $P_Z$ 可在末端统一调用一次，而中间步骤可完全留在过程层。
\end{theorem}
\begin{proof}
由定理 \ref{thm:add-definitional} 与 \ref{thm:mul-definitional}，$\mathrm{Val}$ 给出 $(X_\infty,\oplus,\otimes)$ 与 $(\NN,+,\times)$ 的半环同构。任意项 $t$ 在 $\NN$ 上对应一个多项式 $P$；于是
\(
\mathrm{Val}(t(c_1,\dots,c_k))=P(\mathrm{Val}(c_1),\dots,\mathrm{Val}(c_k))
\)。
再由 $Z=\mathrm{Val}^{-1}$ 得结论。证毕。
\end{proof}

\begin{remark}[纲领：读出层级塔]\label{rem:pom-hyper-iteration}
定理 \ref{thm:pom-one-fold-normal-form} 表明，在半环闭包内“规范投影只需末端一次”。进一步可沿定理 \ref{thm:composition-two-layer} 的思路构造读出层级塔：第 $0$ 层以合成 $\circ$ 的一次迭代读出对应加法，第 $1$ 层以“加法迭代”对应乘法；按同样方式递归定义第 $k$ 层的“运算”为第 $k{-}1$ 层的迭代读出。该层级塔在过程层不引入新原语，而将复杂度转移为读出层级的提升。
\end{remark}

\subsection{序投影作为结构分界}\label{subsec:pom-order-bottleneck}
\begin{corollary}[序投影的不可约读出性]\label{cor:pom-order-bottleneck}
在分辨率 $m$ 固定且不引入新增纤维坐标的条件下，若某读出量 $g:\Omega_m\to\mathbb{R}$ 不属于折叠不变量子代数 $\mathcal{B}_m$，则仅靠规范投影 $P_Z$ 不能判定 $g$；要获得该读出，必须提高分辨率或引入序投影 $P_{\le}$（或等价的全局聚合机制）。该结论是命题 \ref{prop:pom-fiber-invariance} 的直接结构性推论。
\end{corollary}

\begin{corollary}[序投影的混合时间尺度]\label{cor:pom-order-mixing}
设分类读出由有限群标记扩展给出，并令 $\lambda_1(u)$ 为主谱半径、$\Lambda(u)$ 为最坏非平凡扭曲谱半径（定理 \ref{thm:kernel-chebotarev-exp}）。则分类计数的误差以指数率 $(\Lambda(u)/\lambda_1(u))^n$ 衰减，从而达到精度 $\varepsilon$ 的迭代深度满足
\[
n\ \gtrsim\ \frac{\log(1/\varepsilon)}{\log\!\bigl(\lambda_1(u)/\Lambda(u)\bigr)}.
\]
因此序投影的时间代价可由扭曲谱隙显式量化。
\end{corollary}

\begin{remark}[序投影的谱量刻度]
该结论表明：$P_{\le}$ 的时间代价不应仅以输入规模刻画，而应以谱量
\(
\tau_{\mathrm{mix}}=1/\log(\lambda_1/\Lambda)
\)
为基本尺度，并随误差门槛 $\varepsilon$ 作对数放大。它是“序投影门”的本体时间刻度。
\end{remark}

\begin{remark}[角色投影的混合尺度与数值锚点]\label{rem:pom-chi-mixing}
对角色投影 $P_\chi$，可定义混合尺度
\[
\tau_{\mathrm{mix}}:=\frac{1}{-\log(\rho/\lambda)},
\]
其中 $\rho$ 为最坏非平凡角色的谱半径，$\lambda$ 为 Perron 根。对 40 状态真实输入核的 $(2,2,2)$ 分层，生成表给出
\(
\rho_{2,2,2}/\lambda\approx 0.927372804879
\)
（见 \ref{subsec:arity-dirichlet-mertens-tensor}），从而 $\tau_{\mathrm{mix}}\approx 13.2$。该尺度给出 $P_\chi$ 的内禀读出时间标尺，与 $P_Z$ 的常数延迟形成正交的时间投影量。
\end{remark}

\begin{remark}[分层常数的总和守恒]\label{rem:pom-chi-sum}
对 residue 分层的 Dirichlet--Mertens 常数张量 $C_{r_1r_2r_3}$，有
\[
\sum_{r_1,r_2,r_3} C_{r_1r_2r_3}=\mathsf{M}.
\]
这并非偶然数值现象，而是角色投影 $P_\chi$ 的一致性约束：分层切片合并必须恢复总体有限部常数。生成表中的总和误差已达 $10^{-16}$ 量级（见 \ref{subsec:arity-dirichlet-mertens-tensor}）。
\end{remark}

\begin{remark}[有限核的素数影子与算术素数的分界]
在有限核框架中，Euler 乘积与 Möbius 反演给出的 prime-like 对象为 primitive 轨道谱（命题 \ref{prop:time-space-commuting-diagram}）。这类素性与整数素数不同（见注 \ref{rem:prime-shadow-vs-primes}），其差异提示了“序投影/新增纤维”作为结构分界的必然性：若要在本体层表达算术素数，需要引入额外的轴束或新的投影机制。
\end{remark}

\subsection{序投影的空间化}\label{subsec:pom-order-spatialization}
\begin{theorem}[序投影的空间化定律]\label{thm:pom-order-spatialization}
设 $B\ge 1$，取两两互素的模 $p_1,\dots,p_m$，令 $P=\prod_{i=1}^m p_i$。若 $P>2B$，则任意 $x\in[-B,B]$ 由其在模 $p_i$ 下的剩余类唯一确定。因而比较、符号与区间约束等序投影可以先在各模轴上点wise 计算，再通过 CRT 重建完成（参见 \cite{Apostol1976}）。
\end{theorem}
\begin{proof}
由中国剩余定理，模 $P$ 的剩余类与模 $\{p_i\}$ 的剩余类一一对应。若 $P>2B$，则区间 $[-B,B]$ 中的整数在模 $P$ 下唯一代表，故由模轴信息即可恢复 $x$ 并完成序判定。证毕。
\end{proof}

\begin{remark}[时间—空间转移的结构后果]
定理 \ref{thm:pom-order-spatialization} 表明：序投影的时间瓶颈可通过增加模轴束转移为可并行的空间代价。在并行 CRT 口径下，序判定的深度由重建电路决定，而非随位长线性增长；因此 $P_{\le}$ 的“不可并行增长”可被视为\emph{未激活足够模轴时}的结构性症状。
\end{remark}

\subsection{熵—延迟互补的结构猜想}\label{subsec:pom-entropy-delay}
\begin{conjecture}[延迟与 carry-free 复杂度的互补]\label{conj:pom-entropy-delay}
对固定基数与同一值不变量模板（零式 $+$ $q$-场），若在线归一化核的延迟 $\delta_Z$ 被压低，则其 carry-free 骨架的分支复杂度（例如 $\rho(A_0)$ 或对应 $\zeta$ 的谱指纹）必须上升；反之，若要求 carry-free 骨架更紧（低熵），则必须付出更长的延迟。该趋势与 $9/13/21$-local 三核的 carry-free $\zeta$ 三分分类一致（定理 \ref{thm:carry-free-zeta-trichotomy}）。
\end{conjecture}

\subsection{闭环总结：三条核心结论}\label{subsec:pom-summary}
以下三条结论构成本文在 POM 语境下的核心收束：
\begin{enumerate}
  \item \textbf{投影熵率由 $\varphi$ 锁定：}规范投影的空间代价由折叠指标 $I_m$ 控制，且单位分辨率熵率为
  \[
  h_Z=\log\!\left(\frac{2}{\varphi}\right)
  \]
  （命题 \ref{prop:pom-projection-entropy}）。
  \item \textbf{半环闭包的一次投影正规形：}任何由 $\oplus,\otimes$ 生成的项均可写为值层多项式后经一次 $P_Z$ 回到稳定地址（定理 \ref{thm:pom-one-fold-normal-form}）。
  \item \textbf{增长分界在序投影：}一旦读出量不再是折叠纤维不变量，必须引入 $P_{\le}$ 或增加纤维/分辨率（推论 \ref{cor:pom-order-bottleneck}）；其时间瓶颈可通过模轴束空间化转移（定理 \ref{thm:pom-order-spatialization}）。
\end{enumerate}
\paragraph{一句话结构定理}
数学的本体结构是“局部演化 $U$ + 三个投影门”：$P_Z$ 把值纤维群胚轨道投影到 Zeckendorf 横截面，其空间缺陷由 $d_m$ 与 $E_m$ 描述并在 primitive 循环尺度上重整化为 $\log\mathfrak{M}$ 与 Dirichlet--Mertens 常数张量；$P_{\mathrm{prim}}$ 把时间迹投影到 primitive 原子层并与 $Z=E\circ M\circ T$ 的交换图严格对齐；$P_{\le,b}$ 把平移纤维轨道投影到基本域横截面并给出商余，角色/同余读出则由 $P_\chi$（扭曲矩阵与常数张量实现）统一编码，其时间尺度由 $\rho/\lambda$ 给出。加减乘除商余的差异只体现在投影词组合方式与线性化深度（素数纤维或相位纤维路线）的选择上。

\subsection{ISA 与微码：投影词的抽象层实现}\label{subsec:pom-isa}
\paragraph{可见寄存器（外表）}
抽象层可取可数无限寄存器 $\{Z_i\}_{i\in\mathbb N}$；具体实现可截断为有限集合（例如 $Z_0,\dots,Z_{31}$）。可见寄存器内容始终保持在 $X_\infty$ 的规范地址上；写回时默认触发 $P_Z$。

\paragraph{隐纤维（程序不可见）}
隐纤维包含尺度纤维 $\mathcal{S}_\varphi$、相位纤维 $\mathcal{T}$、素数纤维 $\mathcal{P}$，以及同步核状态与余量（例如 $|\Sigma|=40$ 的真实输入核，见附录关于真实输入核的构造）。

\paragraph{指令层（投影词标注）}
\begin{itemize}
  \item \texttt{ZADD rd,ra,rb}：$W=(1,0)$。
  \item \texttt{ZMUL rd,ra,rb}：$W=(1,0)$（$D_U$ 由线性化纤维选择决定）。
  \item \texttt{ZSUB rd,ra,rb}（比较路线）：$W=(1,1)$。
  \item \texttt{ZSUBR rd,ra,rb}（符号内化路线）：$W=(1,0)$ 但 $\delta_Z$ 增大。
  \item \texttt{ZCMP rt,ra,rb}：$W=(0,1)$。
  \item \texttt{ZDIVMOD rq,rr,ra,rb}：依实现可取 $W\approx(2,\Theta(n))$ 或 $W\approx(2,2)$。
  \item \texttt{ZNORM rd,rs}：显式 $P_Z$，$W=(1,0)$。
  \item \texttt{ZPRIM rs}：原子层读出，$W^{\mathrm{full}}=(0,1,0)$。
\end{itemize}

\paragraph{微码原语（英文标签，用于可审计性）}
\begin{itemize}
  \item \texttt{LIFT\_SCALE}：进入 $\mathcal{S}_\varphi$；
  \item \texttt{LIFT\_PHASE}：进入 $\mathcal{T}$；
  \item \texttt{LIFT\_PRIME}：进入 $\mathcal{P}$；
  \item \texttt{EVOLVE(op)}：执行一步本体演化 $U$；
  \item \texttt{PROJ\_NORM}：执行 $P_Z$；
  \item \texttt{PROJ\_PRIM}：执行 $P_{\mathrm{prim}}$（trace $\Rightarrow$ primitive）；
  \item \texttt{PROJ\_ORDER}：执行 $P_{\le}$；
  \item \texttt{PROJ\_CHI}：执行 $P_\chi$（同余/角色分层投影）；
  \item \texttt{TWIST($\chi$)}：对角色/同余类做扭曲读出；
  \item \texttt{CLEAN}：排空有限余量并回写稳定地址。
\end{itemize}

\paragraph{机制审计接口}
规范投影 $P_Z$ 的实现核可用 $\zeta$、$\log\mathfrak{M}$、Dirichlet--Mertens 常数张量与 $\rho/\lambda$ 作为审计指纹（见第 \ref{sec:zeta-finite-part} 节）。原子投影 $P_{\mathrm{prim}}$ 与扭曲读出 \texttt{TWIST} 把 prime-like 轨道谱与 Chebotarev 型偏差转化为可计算指纹。序投影 $P_{\le,b}$ 与角色投影 $P_\chi$ 亦可按相同流程编译为有限同步核并抽取同类指纹，从而实现跨核对比。

\paragraph{统一微码模板}
\begin{itemize}
  \item \texttt{ZADD}：\texttt{LIFT\_SCALE; EVOLVE(add); PROJ\_NORM; CLEAN}.
  \item \texttt{ZMUL}（phase-route）：\texttt{LIFT\_PHASE; EVOLVE(phase-linearize); EVOLVE(pointwise-mul); PROJ\_NORM; CLEAN}.
  \item \texttt{ZMUL}（prime-route）：\texttt{LIFT\_PRIME; EVOLVE(pointwise-mul); PROJ\_NORM; CLEAN}.
  \item \texttt{ZSUB}：\texttt{PROJ\_ORDER(cmp); EVOLVE(sub); PROJ\_NORM; CLEAN}.
  \item \texttt{ZSUBR}：\texttt{LIFT\_SCALE; EVOLVE(signed-digit-sub); PROJ\_NORM(strong); CLEAN}.
  \item \texttt{ZDIVMOD}（reciprocal-route）：\texttt{EVOLVE(recip-iterate); PROJ\_ORDER(q); EVOLVE(r=a-bq); PROJ\_ORDER(fix); PROJ\_NORM(q); PROJ\_NORM(r); CLEAN}.
  \item \texttt{ZPRIM}：\texttt{EVOLVE(trace); PROJ\_PRIM; CLEAN}.
\end{itemize}

\begin{remark}[序读出采用 $P_\chi$ 的口径]
当序读出由角色投影 $P_\chi$ 实现时，可将上述微码中的 \texttt{PROJ\_ORDER} 替换为 \texttt{PROJ\_CHI}；其不可并行时间尺度由 $\tau_{\mathrm{mix}}$ 给出（注 \ref{rem:pom-chi-mixing}）。
\end{remark}

\begin{remark}[\texorpdfstring{$p$}{p}-local 与在线延迟的对应]\label{rem:pom-plocal-delay}
第 \ref{sec:A-kernel-compare-main} 节把并行归一化核的滑动窗口范围（$p$-local）与 MSDF 在线延迟建立对应，并给出单流在线机的最小状态规格（命题 \ref{prop:min-state-spec-flow}）。因此 $\delta_Z$ 并非外加常数，而是由所选归一化核的局部性与在线编译结构决定。
\end{remark}

以上 ISA/微码不引入新的算术原语，而是将“同一演化 + 三类投影 + 线性化深度”的差异组织为可审计的投影词。该抽象层与第 \ref{sec:folding} 节的折叠接口与第 \ref{sec:A-kernel-compare-main} 节的核指纹体系兼容。
