\subsubsection{Kernel Comparison: Unified Interface Across Different Alphabets and Folding Kernels (p-local => Online Delay)}\label{app:sync-kernel-A-compare}
The objective of this appendix is to compress the distinction between "changing alphabets / changing normalization kernels" into a single class of comparable objects, and to reduce the comparison quantities to computable synchronization graph invariants ($\zeta$, primitive orbit spectrum, "finite part constants," etc.).

\paragraph{Viewing kernels as digit-set conversions}
Fix the base $\beta=\varphi$. Given an output alphabet $A$, denote the input alphabet by
\[
B:=A+A.
\]
A "folding kernel / normalization kernel" is, at the algorithmic level, a value-preserving transformation (digit-set conversion):
\[
K:\ B^{\ZZ}\to A^{\ZZ},
\qquad
\sum_{j\in\ZZ}(Ku)_j\beta^j=\sum_{j\in\ZZ}u_j\beta^j,
\]
subject to the requirement that finite-support inputs map to finite-support outputs (corresponding to addition of finite representations).

\begin{definition}[\texorpdfstring{$(p)$}{p}-local, memory, and anticipation]\label{def:plocal}
Let $\varphi:A^{\ZZ}\to B^{\ZZ}$. We say $\varphi$ is $(p)$-local (a sliding block code) if there exist $r,t\in\NN$ and a local rule $\Phi:A^{p}\to B$ (where $p=r+t+1$) such that for any $u\in A^{\ZZ}$ and $v=\varphi(u)$,
\[
v_j=\Phi(u_{j+t},\dots,u_{j-r})\qquad(\forall j\in\ZZ).
\]
Here $r$ is called the memory and $t$ the anticipation (see Definition~1 in \cite{FrougnyHellerPelantovaSvobodovaParallelAlgorithmsSlides}; see also the definitional conventions in \cite{FrougnyPelantovaSvobodova2013MinimalDigitSets}).
\end{definition}

\begin{corollary}[Single-pass online delay]\label{cor:online-delay-from-plocal}
If $\varphi$ is $(t,r)$-local, then executing it in MSDF order as a single-pass online process requires waiting until $u_{j+t}$ has been read before outputting $v_j$, so its single-pass online delay is
\[
\delta(\varphi)=t.
\]
\end{corollary}

\paragraph{Synchronization graph and comparable spectral fingerprints}
Once $K$ is realized as a deterministic online finite-state transducer, its synchronizing part yields a finite directed graph $\Gamma_K$ (state set $Q_K$, edges labeled by input alphabet symbols), on which one can define an "atomic activity" potential (the $\kappa$ introduced below). This allows the differences between kernels to be compressed into a set of comparable spectral fingerprints.

\begin{definition}[Spectral fingerprint of a kernel (Route A)]\label{def:kernel-spectral-fingerprint}
For a given kernel $K$, define its spectral fingerprint as
\[
\mathfrak{F}(K):=\bigl(\delta(K),\ |Q_K|,\ \zeta_K(z,0),\ \lambda_K(u),\ \{B_{K,n}(u)\}_{n\le N}\bigr),
\]
where $\delta(K)$ is the single-pass online delay (Corollary \ref{cor:online-delay-from-plocal}), $|Q_K|$ is the number of synchronization states, $\zeta_K(z,0)$ is the $\zeta$ of the carry-free skeleton, $\lambda_K(u)=\rho(M_K(u))$ is the weighted pressure curve, and $B_{K,n}(u)$ is the primitive stratified spectrum (whose precise definition is given below).
\end{definition}

\paragraph{Relation to "minimal redundancy alphabet parallel kernels" (external benchmark)}
On the same base $\beta=\varphi$, Corollary~38 of \cite{FrougnyPelantovaSvobodova2013MinimalDigitSets} proves that parallel addition can be performed on
\[
A=\{-1,0,1\}\quad\text{or}\quad A=\{0,1,2\},
\]
and that both are \textbf{minimal} alphabets ($|A|=3$). Furthermore, an explicit parallel algorithm (Algorithm~G) for $A=\{-1,0,1\}$ is given in the lecture notes, with the addition being \textbf{21-local} (thus roughly corresponding to $\delta\approx 10$ in the online setting; see \cite{FrougnyHellerPelantovaSvobodovaParallelAlgorithmsSlides} and the 21/13/9-local comparison in the Leiden lecture notes \cite{Frougny2012NumbersAsStreamsLeiden}).

Once these parallel kernels are compiled into deterministic online transducers, their synchronization graphs likewise yield $\zeta$ and primitive spectra, thereby sharing the exact same comparison interface as the "mechanism kernels" in Table \ref{tab:sync-kernel-A-compare}; this paper treats them as an external benchmark for future integration, without carrying out the full synchronization graph compilation in the current version.
\par
On the other hand, \cite{Frougny1999OnlineAddition} proves that addition in the golden ratio base can be realized by an online finite automaton, but does not satisfy parallel ($(p)$-local) computability in the non-redundant representation setting; this provides an external reference boundary for the "online kernel vs.\ parallel kernel" distinction in this paper.

\paragraph{Precise anchoring of the three kernels in the literature: zero-expressions and locality}
To prevent "caliber drift of the same kernel across different lecture notes / implementations," this paper uniformly anchors the references for three classes of parallel kernels to the same set of lecture notes \cite{FrougnyHellerPelantovaSvobodovaParallelAlgorithmsSlides} (as well as its abstract formulation at AAMP VIII \cite{SvobodovaAAMPVIIIParallelAddition}):
\begin{itemize}
  \item \textbf{Strong zero-expression + $9$-local (golden ratio base)}: using $-\beta^4+7-\beta^{-4}=0$ as the injected zero-expression, addition on $A=\{-5,\dots,5\}$ is $9$-local;
  \item \textbf{Weak zero-expression + $13$-local (golden ratio base)}: using $-\beta^2+3-\beta^{-2}=0$ as the injected zero-expression, addition on $A=\{-3,\dots,3\}$ is $13$-local;
  \item \textbf{Minimal alphabet + $21$-local (Algorithm G)}: on $A=\{-1,0,1\}$, a two-phase elimination algorithm $G=A\circ B$ is given, with addition explicitly $21$-local; both phases use the weak zero-expression $-\beta^2+3-\beta^{-2}=0$.
\end{itemize}
These three points serve as the common input for the subsequent compression of "different alphabets / different folding kernels" into a single class of synchronization graph fingerprint objects in this appendix.

\begin{definition}[Zero-expression injection \texorpdfstring{$(+;q)$}{(+;q)}-field update]\label{def:zero-injection}
Given a Laurent polynomial
$$
Z(X)=\sum_{i=-h}^{k}b_iX^i,\qquad b_i\in\ZZ,
$$
and a base $\tau$ satisfying $Z(\tau)=0$. Take a finitely-valued integer field $q=(q_j)_{j\in\ZZ}$, and define a single update
$$
z'_j:=z_j-\sum_{i=-h}^{k}b_i\,q_{j-i}.
$$
\end{definition}

\begin{proposition}[Value preservation]\label{prop:zero-injection-value-preserving}
Under the conditions of Definition \ref{def:zero-injection} (and assuming $q$ has finite support, or both $z,q$ are finite-support sequences),
\[
\sum_{j\in\ZZ} z'_j\tau^j=\sum_{j\in\ZZ} z_j\tau^j,
\]
i.e., this update preserves the $\tau$-weighted value.
\end{proposition}

\begin{proof}
Substituting Definition \ref{def:zero-injection} and interchanging summations (justified by finite support):
\[
\sum_j z'_j\tau^j=\sum_j z_j\tau^j-\sum_j\sum_{i=-h}^{k}b_i q_{j-i}\tau^j
=\sum_j z_j\tau^j-\sum_{i=-h}^{k}b_i\tau^i\sum_\ell q_{\ell}\tau^{\ell}.
\]
Since $\sum_{i=-h}^{k}b_i\tau^i=Z(\tau)=0$, the second term vanishes. \qed
\end{proof}

\paragraph{Two sparse zero-expressions (golden ratio base)}
In the two sparse zero-expression special cases for the golden ratio base (see the Example/Algorithm paragraphs in \cite{FrougnyHellerPelantovaSvobodovaParallelAlgorithmsSlides}), these reduce to:
\begin{itemize}
  \item \textbf{Strong zero-expression ($9$-local)}:
  $$
  z'_j=z_j-7q_j+q_{j-4}+q_{j+4}.
  $$
  \item \textbf{Weak zero-expression (underlying $13$-local and $21$-local)}:
  $$
  z'_j=z_j-3q_j+q_{j-2}+q_{j+2}.
  $$
\end{itemize}

\paragraph{Compiling the three parallel kernels to BFS-enumerable online machines (single stream)}
To reduce the "local rules of a kernel" to computable objects, we decouple by congruence classes of the stencil, restricting the kernel to a single congruence stream (the $\pm 4$ stencil corresponds to 4 streams modulo $4$, and the $\pm 2$ stencil corresponds to 2 streams modulo $2$). On a single stream, the kernel becomes a deterministic online machine: at each step it reads one input symbol $v_n$ (digit-wise sum / intermediate alphabet symbol), updates its finite state, and outputs a fixed-delay output symbol. One can then use BFS to enumerate all reachable states, obtaining the single-stream synchronization graph $\Gamma^{\mathrm{flow}}_K$.

At the comparison level, \textbf{unweighted counting} degenerates: deterministic complete reading ensures that the out-degree from each state is fixed at $|B|$, so $\zeta$ merely reflects $|B|$. We therefore introduce an edge potential
\[
\kappa(e):=\#\{\text{newly determined nonzero }q\text{ events at this step}\},
\]
and weight by $u^{\kappa(e)}$ to obtain a weighted adjacency matrix family $M_K(u)$, whose spectral radius $\lambda_K(u)=\rho(M_K(u))$ forms a comparable "carry activity" curve. Setting $u=0$ further yields the carry-free skeleton (retaining only edges with $\kappa=0$), whose $\zeta$ and primitive spectrum provide a rigorous structural fingerprint.

\paragraph{Two-variable \texorpdfstring{$\zeta_K(z,u)$}{zeta(z,u)} and primitive stratified spectrum \texorpdfstring{$B_{K,n}(u)$}{B\_{K,n}(u)} (rigorous definition)}
Let $\Gamma_K$ be the single-stream synchronization graph with vertex set $Q_K$ and edge set $E_K$. For each edge $e:i\to j$, the activity follows the above formula $\kappa(e)\in\ZZ_{\ge 0}$. Define the weighted adjacency matrix family (accumulating multiple edges between the same pair of endpoints by weight)
\[
(M_K(u))_{ij}:=\sum_{e:i\to j}u^{\kappa(e)}\in\ZZ[u].
\]
For the edge shift (SFT) corresponding to this finite graph, define the two-variable dynamical $\zeta$ (\cite{BrinStuck2002,ParryPollicott1990Zeta})
\[
\zeta_K(z,u)
:=\exp\!\left(\sum_{n\ge 1}\frac{\Tr(M_K(u)^n)}{n}z^n\right)
=\frac{1}{\det(I-zM_K(u))}.
\]
For each primitive periodic orbit $\gamma$, define
\[
\kappa(\gamma):=\sum_{e\in\gamma}\kappa(e),
\]
and define the primitive stratified spectrum polynomial
\[
B_{K,n}(u):=\sum_{\substack{\gamma\ \mathrm{primitive}\\ |\gamma|=n}}u^{\kappa(\gamma)}\in\ZZ[u].
\]
Denote the periodic trace polynomial $a_{K,n}(u):=\Tr(M_K(u)^n)$. Then the Witt/M\"obius inversion gives a fully explicit formula from periodic traces to primitive fingerprints:
\[
B_{K,n}(u)=\frac{1}{n}\sum_{d\mid n}\mu(d)\,a_{K,n/d}(u^d)
\qquad\Bigl(\Leftrightarrow\ a_{K,n}(u)=\sum_{d\mid n} d\,B_{K,d}(u^{n/d})\Bigr),
\]
where $\mu$ is the M\"obius function. This collection of objects constitutes the "kernel fingerprint": differences between kernels are compressed into a single set of comparable sequences $\{B_{K,n}(u)\}_{n\le N}$ and (equivalently) the coefficient structure of $\zeta_K(z,u)$.

\paragraph{Global block-level online machine assembly: direct product states and tensor product matrices}
Under "block time" $n$, all congruence streams are fed synchronously. For the $\pm 4$ stencil (strong kernel) there are $m=4$ streams; for the $\pm 2$ stencil (weak kernel) there are $m=2$ streams. The global state is the direct product of stream states
\[
S_n^{\mathrm{glob}}=\bigl(S_n^{(0)},\dots,S_n^{(m-1)}\bigr),
\]
so the number of global reachable states satisfies $|Q_{\mathrm{glob}}|=|Q_{\mathrm{flow}}|^m$.

For the weighted matrix family $M(u)$ (edge weights $u^{\kappa(e)}$), since a single global step is equivalent to $m$ independent stream steps in parallel and $\kappa$ is additive across streams, the matrix satisfies a tensor product structure
\[
M_{\mathrm{glob}}(u)=\bigotimes_{r=0}^{m-1} M_{\mathrm{flow}}(u),
\qquad
\lambda_{\mathrm{glob}}(u)=\rho(M_{\mathrm{glob}}(u))=\lambda_{\mathrm{flow}}(u)^m.
\]
Similarly, the activity mean under uniform input satisfies $\mathbb{E}[\kappa_{\mathrm{glob}}]=m\,\mathbb{E}[\kappa_{\mathrm{flow}}]$.

\begin{proposition}[Endpoints, monotonicity, and global uplift of the pressure curve]\label{prop:lambda-endpoints-monotone-uplift}
For the weighted adjacency matrix family $M_K(u)$ of any single-stream synchronization graph (defined as above), its spectral radius
\[
\lambda_K(u):=\rho(M_K(u))\qquad (u\in[0,1])
\]
satisfies:
\begin{enumerate}
  \item \textbf{Endpoint ($u=0$)}: $\lambda_K(0)=\rho(A_0)$, where $A_0$ is the carry-free skeleton adjacency matrix (retaining only edges with $\kappa=0$).
  \item \textbf{Endpoint ($u=1$)}: $\lambda_K(1)=|B|$, where $|B|$ is the single-step input alphabet size (deterministic complete reading ensures exactly $|B|$ outgoing edges per state).
  \item \textbf{Monotonicity}: $u\mapsto \lambda_K(u)$ is non-decreasing and continuous on $[0,1]$.
  \item \textbf{Global uplift}: If the global system is assembled as a direct product of $m$ isomorphic streams, then
  \[
  \lambda_{\mathrm{glob}}(u)=\lambda_{\mathrm{flow}}(u)^m,
  \qquad
  \log\lambda_{\mathrm{glob}}(u)=m\,\log\lambda_{\mathrm{flow}}(u).
  \]
\end{enumerate}
\end{proposition}

\begin{proof}
\textbf{(1)} When $u=0$, $u^{\kappa(e)}$ equals $1$ only when $\kappa(e)=0$ and $0$ otherwise, so $M_K(0)$ equals the carry-free skeleton adjacency matrix $A_0$, hence $\lambda_K(0)=\rho(A_0)$.

\textbf{(2)} When $u=1$, every edge weight equals $1$, so each row sum of $M_K(1)$ equals the out-degree of that state; for a deterministic complete-reading machine, each state has exactly $|B|$ outgoing edges, so $M_K(1)\mathbf{1}=|B|\mathbf{1}$, i.e., $|B|$ is an eigenvalue. On the other hand, $\rho(M_K(1))\le \|M_K(1)\|_{\infty}=\max_i\sum_j (M_K(1))_{ij}=|B|$, hence $\rho(M_K(1))=|B|$.

\textbf{(3)} For $u\in[0,1]$, the matrix entries $(M_K(u))_{ij}$ are polynomials in $u$ with nonnegative coefficients, hence non-decreasing and continuous in $u$. The spectral radius of nonnegative matrices satisfies monotonicity: if $0\le A\le B$ (entrywise), then $\rho(A)\le \rho(B)$; continuity of $u\mapsto \rho(M_K(u))$ follows from continuous dependence of eigenvalues in finite dimensions.

\textbf{(4)} Under global assembly, $M_{\mathrm{glob}}(u)=\bigotimes_{r=0}^{m-1} M_{\mathrm{flow}}(u)$, and the Kronecker product satisfies multiplicativity of spectral radii: $\rho(A\otimes B)=\rho(A)\rho(B)$; by induction, $\rho(M_{\mathrm{glob}}(u))=\rho(M_{\mathrm{flow}}(u))^m$. Taking logarithms yields the conclusion.
\end{proof}

\begin{proposition}[Linear response invariant near zero temperature]\label{prop:lambda-linear-response}
Write
\[
M_K(u)=A_0+uA_1+u^2A_2+\cdots,
\]
where $A_k$ consists of the contributions from edges with $\kappa(e)=k$. If the Perron root $\lambda_0$ of $A_0$ is a simple eigenvalue (which holds when the carry-free skeleton is a primitive SFT), then $\lambda_K(u)$ is analytic near $u=0$ and satisfies
\[
\lambda_K(u)=\lambda_0+c_1u+O(u^2),
\qquad
c_1=\frac{\ell^{\mathsf T}A_1 r}{\ell^{\mathsf T}r},
\]
where $r,\ell$ are the right and left Perron eigenvectors of $A_0$, respectively.
\end{proposition}

\begin{corollary}[Exact first-order coefficients for the three kernels]\label{cor:lambda-linear-response-kernels}
For the single-stream compilations of $K_9/K_{13}/K_{21}$, the carry-free skeletons satisfy
\(
\lambda_0=7,\ 3,\ \varphi
\); accordingly,
\[
\lambda_{9}(u)=7+14u\quad(\text{exactly linear}),
\]
\[
\lambda_{13}(u)=3+\frac{8}{3}u+O(u^2),
\qquad
\lambda_{21}(u)=\varphi+\sqrt5\,u+O(u^2).
\]
Here $\sqrt5=\varphi+\varphi^{-1}$, and in general $c_1\in\QQ(\lambda_0)$.
\end{corollary}

\begin{corollary}[Zero-temperature carry density linear law and ordering]\label{cor:kappa-linear-response-order}
Under the weight $u^{\kappa}$, the equilibrium mean carry density satisfies
\[
\mathbb{E}_u[\kappa]=u\frac{\mathrm{d}}{\mathrm{d}u}\log\lambda_K(u),
\]
hence
\[
\mathbb{E}_u[\kappa]=\frac{c_1}{\lambda_0}u+O(u^2).
\]
For the three kernels,
\[
\mathbb{E}_u[\kappa]=2u+O(u^2)\ (K_9),\qquad
\mathbb{E}_u[\kappa]=\frac{8}{9}u+O(u^2)\ (K_{13}),\qquad
\mathbb{E}_u[\kappa]=(3-\varphi)u+O(u^2)\ (K_{21}),
\]
so the "carry resistance" ordering near zero temperature is $K_{13}<K_{21}<K_{9}$.
\end{corollary}

\begin{corollary}[Closed-form algebraic first-order response constant for \texorpdfstring{$K_{21}$}{K21}]\label{cor:k21-c1-sqrt5}
In the notation of Corollary \ref{cor:kappa-linear-response-order}, for \(K_{21}\),
\[
\lambda_0=\varphi,\qquad \frac{c_1}{\lambda_0}=3-\varphi,
\]
hence
\[
\boxed{\ c_1=\sqrt5\ }.
\]
\end{corollary}
\begin{proof}
From \(\frac{c_1}{\lambda_0}=3-\varphi\) and \(\lambda_0=\varphi\),
\[
c_1=\varphi(3-\varphi)=3\varphi-\varphi^2.
\]
Using \(\varphi^2=\varphi+1\), this simplifies to
\(
c_1=2\varphi-1
\).
Since \(\varphi=(1+\sqrt5)/2\), we obtain \(2\varphi-1=\sqrt5\). \qed
\end{proof}

\begin{remark}[Zero-temperature "carry resistance" two-dimensional scaling: slope \texorpdfstring{$\chi_0$}{chi0} and "slope/skeleton entropy" ratio \texorpdfstring{$\Xi$}{Xi}]\label{rem:zero-temp-two-scales}
Under the setting of Proposition \ref{prop:lambda-linear-response}, define the zero-temperature response slope (dimensionless)
$$
\chi_0:=\frac{c_1}{\lambda_0},
$$
and the entropy rate of the carry-free skeleton
$$
h_0:=\log\rho(A_0)=\log\lambda_0.
$$
One can then further define a normalized two-dimensional fingerprint
$$
\Xi:=\frac{\chi_0}{h_0}.
$$
Interpretatively, a small \(h_0\) indicates a tighter carry-free syntax (low skeleton entropy), while a large \(\chi_0\) indicates that once \(u>0\) is activated, the \(\kappa=1\) channel is heavily triggered at first order (high sensitivity to the temperature axis). Thus \((h_0,\chi_0)\) and their ratio \(\Xi\) provide an auditable interface that simultaneously reads out "skeleton complexity" and "zero-temperature activation sensitivity."
\end{remark}

Furthermore, the stream-level delay $\delta_{\mathrm{flow}}$ (in block time) corresponds to a digit-level online delay of
\[
\delta_{\mathrm{digits}}=m\,\delta_{\mathrm{flow}},
\]
which is consistent with the $(t,r)$ parameters of $p$-local as annotated in the original works (e.g., $9/13/21$-local correspond to $t=4,6,10$ respectively). \cite{FrougnyHellerPelantovaSvobodovaParallelAlgorithmsSlides,Frougny2012NumbersAsStreamsLeiden}
This is also consistent with the algorithm summary formulation at AAMP VIII. \cite{SvobodovaAAMPVIIIParallelAddition}

\begin{remark}[Two-dimensional upgrade of the entropy--delay complementarity: incorporating \texorpdfstring{$c_1$}{c1} into the complementary axis]\label{rem:entropy-delay-complement-c1}
In the three-kernel comparison, if one only compares the branching complexity of the carry-free skeleton (e.g., \(\rho(A_0)\) or \(h_0=\log\rho(A_0)\)), one loses the first-order information about "the number of edge channels most easily activated beyond the skeleton"; this information is precisely captured by \(A_1\) and \(c_1\) (Proposition \ref{prop:lambda-linear-response}).
Therefore, after aligning delays to the same scale (\(\delta_{\mathrm{digits}}\)), we suggest refining the complementarity conjecture into a two- or three-dimensional auditable interface, for example
$$
\bigl(\delta_{\mathrm{digits}},\ \rho(A_0),\ c_1\bigr)
\qquad\text{or equivalently}\qquad
\bigl(\delta_{\mathrm{digits}},\ h_0,\ \chi_0\bigr).
$$
The mechanistic interpretation is as follows: reducing \(\delta\) typically means making earlier decisions, which makes it more likely to produce edges with \(\kappa=1\) (\(c_1\) increases); if one further reduces the spectral radius of the carry-free skeleton (i.e., tightens \(\rho(A_0)\)), this typically corresponds to longer serial elimination chains (\(\delta\) increases) accompanied by a lower first-order activation slope (\(c_1\) decreases).
\end{remark}

\begin{proposition}[Strictly geometric two-variable \texorpdfstring{$\zeta$}{zeta} for \texorpdfstring{$K_9$}{K9}]\label{prop:k9-geometric-zeta}
For the single-stream synchronization graph of the strong kernel $K_9$, there exists an integer-coefficient polynomial $\alpha(u)=7+14u$ such that
\[
\boxed{\ \zeta_{9}(z,u)=\frac{1}{1-\alpha(u)\,z}\ }.
\]
Equivalently,
\[
\Tr(M_{9}(u)^n)=\alpha(u)^n,
\qquad
\zeta_{9}(z,u)=\exp\!\left(\sum_{n\ge 1}\frac{\alpha(u)^n}{n}z^n\right),
\qquad
c_m(u)=\alpha(u)^m\ (m\ge 0).
\]
\end{proposition}
\begin{proof}

\begin{remark}[Near-regular defect \texorpdfstring{$\Delta_{\mathrm{reg}}$}{Delta_reg}: converting \texorpdfstring{$(\rho(A),\rho(B))$}{rhoA,rhoB} to a comparable geometric prior]\label{rem:ihara-delta-reg}
On a $d$-regular undirected graph, the exact relation \(\rho(B)=d-1\), \(\rho(A)=d\) holds, giving \(\rho(A)-\rho(B)-1=0\).
One can therefore define
$$
\Delta_{\mathrm{reg}}:=\rho(A)-\rho(B)-1
$$
as the "near-regular defect": a smaller \(\Delta_{\mathrm{reg}}\) indicates that the growth rate relationship between ordinary walks and non-backtracking walks is closer to the regular case (difference locked at \(1\)); a larger \(\Delta_{\mathrm{reg}}\) indicates more inhomogeneous degree distribution and local structure, with the growth rate of non-backtracking walks more suppressed relative to ordinary walks.

To eliminate the "off by a constant \(1\)" scaling and facilitate direct cross-scale comparison, one can further define the normalized near-regular defect
\[
\varepsilon_{\mathrm{reg}}
:=\frac{\Delta_{\mathrm{reg}}}{\rho(A)-1}
=1-\frac{\rho(B)}{\rho(A)-1}.
\]
It also equals \(0\) in the regular limit and provides more consistent comparability for skeletons with different orders of magnitude of \(\rho(A)\) (see Table \ref{tab:parallel-addition-kernels-ihara-fingerprint}).

This quantity is complementary to the kernel-version RH/Ramanujan index \(R_K(u)=\lambda_\star(u)/\sqrt{\lambda_1(u)}\): the former is a "prior invariant" of skeleton geometry, while the latter is a "spectral gap quality" index of the weighted Hashimoto operator; together they determine the achievable error scale under the non-backtracking prime cycle calibration.
\end{remark}

\begin{remark}[Backtracking penalty \texorpdfstring{$\pi_{\mathrm{bt}}$}{pi_bt}: growth rate loss from ordinary walks to non-backtracking]\label{rem:ihara-pi-bt}
In addition to the near-regular defect, one can define the dimensionless backtracking penalty
$$
\pi_{\mathrm{bt}}:=1-\frac{\rho(B)}{\rho(A)}\in[0,1).
$$
It directly quantifies the proportional exponential growth rate loss incurred by "forbidding backtracking." The output of Table \ref{tab:parallel-addition-kernels-ihara-fingerprint} shows that among the three kernels, the \(21\)-local kernel has a relatively large \(\pi_{\mathrm{bt}}\), indicating a higher proportion of "reversible undo / short backtracking" structures in its atomic operation skeleton, making normalization of prime shadows via Ihara primes (non-backtracking) quantitatively more necessary.
\end{remark}

\begin{remark}[Backtracking entropy gap \texorpdfstring{$\Delta h$}{Delta h}: exponential gap derived from \texorpdfstring{$(\rho(A),\rho(B))$}{rhoA,rhoB}]\label{rem:ihara-entropy-gap}
Further converting \((\rho(A),\rho(B))\) to an "exponential scale" gap:
\[
\Delta h_K:=\log\rho(A)-\log\rho(B)=\log\!\left(\frac{\rho(A)}{\rho(B)}\right)\ge 0.

The growth rate ratio between ordinary closed walks and non-backtracking closed walks undergoes exponential amplification over length \(n\):
\[

Table \ref{tab:parallel_addition_kernels_backtracking_entropy_gap} gives the amplification magnitude at \(n=50\); for the \(21\)-local kernel, the amplification already reaches the \(\sim 10^2\) order of magnitude, indicating that in the minimal alphabet case, "primitive cycle" statistics are more easily contaminated by immediate-backtracking pseudo-periods, making normalization via Ihara primes quantitatively more necessary.

\paragraph{Ihara primes: normalized primes as non-backtracking atomic cycles}

Their Euler product is
\[
Z_K(t)=\prod_{p}\left(1-t^{\ell(p)}\right)^{-1},
