
\section{\GI{}/\WL{} 的等价翻译：从 Babai 语言到 \texorpdfstring{$64\to 21$}{64->21} 语言}

本节给出“\GI{}/\WL{} 的等价翻译”：把 Babai 使用的对象（相干配置、\WL{} 稳定化、同构与自同构群）翻译到折叠--闭包图模型。

\subsection{闭包图同构与折叠相容微观同构的等价}

\begin{theorem}[闭包 \GI{} 的等价翻译]\label{thm:gi-translation}
设两套数据 $(G^{\mu},f_m)$、$(H^{\mu},f_m)$ 共享同一个折叠规则 $f_m$，并构造闭包图 $\Clo(G^{\mu})$、$\Clo(H^{\mu})$（均在顶点集 $X_m\sqcup Y_m$ 上，且 $Y_m$ 端点带唯一颜色）。则以下命题等价：
\begin{enumerate}
  \item $\Clo(G^{\mu})$ 与 $\Clo(H^{\mu})$ 作为带颜色图同构；
  \item 存在双射 $\pi:X_m\to X_m$ 使得
  \begin{enumerate}
    \item $\pi$ 是 $G^{\mu}\to H^{\mu}$ 的图同构；
    \item $\pi$ 与折叠相容：对一切 $x\in X_m$，有 $f_m(\pi(x))=f_m(x)$。
  \end{enumerate}
\end{enumerate}
\end{theorem}

\begin{proof}
$(2)\Rightarrow(1)$：令 $\pi$ 在 $Y_m$ 上取恒等（因为 $Y_m$ 的每个点颜色唯一且必须固定），则 $\pi$ 自动保持折叠边 $(x,f_m(x))$ 与微观边，故扩展为闭包图同构。

$(1)\Rightarrow(2)$：闭包图同构必须保持颜色，因此必定把 $Y_m$ 点逐点固定，并把 $X_m$ 映到 $X_m$。折叠边的邻接也被保持，故推出 $f_m(\pi(x))=f_m(x)$。同时微观边被保持，$\pi$ 是微观图同构。
\end{proof}

\subsection{\WL{} 稳定化与折叠诱导相干配置细化的对应}

\begin{proposition}\label{prop:wl-cc}
在闭包图上运行 $1$-\WL{} 得到的稳定颜色分割诱导一个相干配置（至少是相干配置的一个细化近似），其关系类可由“颜色对”的邻接计数闭合给出。
\end{proposition}

\begin{remark}
这一步给出 Babai 框架的落点：相干配置是 \WL{} 细化所趋向的代数容器；\GI{} 在其中可转化为对自同构群、块系统与局部计数不变量的控制 \cite{babai2016gi,wl2018symmetryvsregularity}。在本文翻译里，\WL{} 的每一步就是“用可见稳定态标签 + 局部微观几何”去减少回溯树分支；稳定化深度可理解为一个可控的离散时间上界。
\end{remark}
