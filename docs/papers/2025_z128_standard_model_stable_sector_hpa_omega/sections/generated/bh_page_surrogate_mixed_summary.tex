\paragraph{BH5 mixed single-stream surrogate (audit).} \AuditTag This fragment reports a Page-like surrogate curve $U(t)$ (remaining micro-ambiguity bits) for a self-describing, single-stream radiation model: payload coarse labels and recovery digits are interleaved deterministically under a CAP-selected finite family.
