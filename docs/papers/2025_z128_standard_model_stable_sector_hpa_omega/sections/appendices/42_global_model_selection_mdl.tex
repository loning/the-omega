\section{Global model selection across candidate families (MDL / prefix-code audit closure)}
\label{app:global_model_selection_mdl}

This appendix closes the remaining cross-family model-selection gap (OP4) in an explicit audit form.
The main text and Appendix~\ref{app:generated_tables} already provide \emph{within-family} look-elsewhere context for each bounded-complexity closure via domain sizes and empirical frequencies such as $p_{\le\epsilon}=N_{\le\epsilon}/|\Theta|$ (Section~\ref{sec:limitations_related_work}, paragraph ``A minimal model-selection interpretation'').
What was still missing is a \emph{cross-family} aggregation rule that compares \emph{different} candidate families in a way that is finite, explicit, and free of hidden continuous hyperparameters.

\paragraph{Closure stance.}
We do \emph{not} claim a global significance over unrestricted expression grammars.
Instead, we close a fully explicit statement:
given a declared finite \emph{family registry} $\mathcal{R}$ (mainline families used by the paper \emph{plus} the already-audited counterfactual/null baselines), we assign a prefix-code (MDL) prior over families \cite{Rissanen1978MDL,HansenYu2001MDL} and compute a corresponding global look-elsewhere upper bound within $\mathcal{R}$.
Expanding $\mathcal{R}$ is an explicit enlargement of the audited search space and is treated as a new audit choice.
\AuditTag The corresponding minimal failure template (unregistered family enlargement) is recorded as (IC10) in Appendix~\ref{app:minimal_failure_point_templates}.

\paragraph{Relation to joint protocol-state closure.}
\AuditTag Appendix~\ref{subsec:tick_cap_joint_key_contract} records a \emph{within-protocol} theory-first closure in which the protocol state $(m,n,K)$ at a target scale $\mu$ is closed in one shot by minimizing a joint key $J_\mu$ that includes an MDL term and an explicit bounded sensitivity term.
The present appendix is a complementary \emph{cross-family} closure (OP4): it compares different hypothesis families after their internal CAP closures have been performed, using only a declared finite registry and a prefix-code prior, without introducing hidden scans or continuous hyperparameters.

\subsection{Family registry (declared hypothesis space)}

Each row specifies:
(i) the closure target (what is being matched),
(ii) the candidate family $\Theta$ (finite by construction),
(iii) its domain size $|\Theta|$ and within-family counts $N_{\le\epsilon}$ at fixed mismatch thresholds,
and (iv) a deterministic family identifier used for the MDL code.

$N_{\le\epsilon}\mapsto \min(|\Theta|,|\mathcal{K}|\,N_{\le\epsilon})$.
This makes the look-elsewhere enlargement from kernel scanning explicit and finite, without introducing continuous hyperparameters.

\subsection{Prefix-code / MDL weights (no continuous hyperparameters)}
\label{subsec:mdl_prefix_code}

To avoid an implicit family prior, we assign each family a self-delimiting code length \cite{Rissanen1978MDL}.
We use the Elias gamma code for positive integers: for $n\ge 1$,
\begin{equation}
\label{eq:elias_gamma_length}
L_\gamma(n):=2\lfloor \log_2 n\rfloor + 1.
\end{equation}
For each closure, the families listed in Table~\ref{tab:audit_global_mdl_family_registry} are given deterministic indices $n=1,2,\dots$ in a fixed order; we set
\begin{equation}
\label{eq:mdl_family_weight}
L_{\mathrm{fam}}:=L_\gamma(n),
\qquad
w_{\mathrm{fam}}:=2^{-L_{\mathrm{fam}}}.
\end{equation}
Because the Elias gamma code is prefix-free, the Kraft inequality holds:
$\sum_{n\ge 1}2^{-L_\gamma(n)}\le 1$.
Thus $w_{\mathrm{fam}}$ is a canonical MDL-style prior weight on the declared family indices, with no tunable real parameters.

\subsection{Cross-family look-elsewhere bound inside the registry}
\label{subsec:mdl_global_bound}

Fix a closure target and let $\mathcal{R}_{\mathrm{cl}}$ denote the subset of registered families for that target.
Within a family $\Theta$, treat candidates as uniformly distributed and define the empirical success frequency at threshold $\epsilon>0$ by
\[
p_{\le\epsilon}(\Theta):=\frac{N_{\le\epsilon}(\Theta)}{|\Theta|}.
\]
Let $\pi(\Theta)$ be the MDL prior over $\mathcal{R}_{\mathrm{cl}}$ obtained by normalizing weights:
\[
\pi(\Theta):=\frac{w_{\mathrm{fam}}(\Theta)}{\sum_{\Theta'\in\mathcal{R}_{\mathrm{cl}}} w_{\mathrm{fam}}(\Theta')}.
\]
Then the global within-registry success probability is bounded by the mixture
\begin{equation}
\label{eq:mdl_mixture_bound}
p_{\mathrm{global}}(\epsilon)
\;\le\;
\sum_{\Theta\in\mathcal{R}_{\mathrm{cl}}}\pi(\Theta)\,p_{\le\epsilon}(\Theta)
\;=\;
\sum_{\Theta\in\mathcal{R}_{\mathrm{cl}}}\pi(\Theta)\,\frac{N_{\le\epsilon}(\Theta)}{|\Theta|}.
\end{equation}
This is the cross-family analogue of the within-family probabilities reported in Table~\ref{tab:audit_closure_metrics} and Table~\ref{tab:audit_counterfactual}, now equipped with an explicit family prior derived from a prefix code.\footnote{For canonical MDL/universal-coding formulations of model selection and minimax regret (NML), see \cite{Rissanen1978MDL,Shtarkov1987NML,HansenYu2001MDL}.}
