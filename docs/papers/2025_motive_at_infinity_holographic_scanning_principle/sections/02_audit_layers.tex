
\section{Audit rules and layer discipline}
\label{sec:audit_layers}

The audit program enforces a strict separation between what is assumed, what is derived, and what is merely interpreted. This paper follows the same discipline as \cite{Ma2025HPA,Ma2025FoP,Ma2025STI}.

\subsection{Layer conventions}
\label{sec:layer_conventions}

\paragraph{Layer 0 (ontic).}
Only algebraic objects and states are allowed. No external time parameter, probability postulate, or observer semantics is assumed. In the present paper, Layer~0 objects are the underlying dynamical system (a torus rotation), the readout kernel, and the invariant measure.

\paragraph{Layer 1 (protocol).}
A protocol specifies how ``time'' is realized as an iteration count, how finite-resolution readout is implemented, and how statistics are induced from repeated readout. In this paper, ``time'' is the scan index $t\in\ZZ_{\ge 0}$, and probabilities arise from empirical distributions along scan orbits (Birkhoff averages) and, optionally, from finite ensembles of initial conditions used only as a numerical stabilization device.

\paragraph{Layer 2 (interpretation).}
Any physical semantics (spacetime, particles, gravity narratives) is permitted only as commentary. It may not appear as a premise in Layer~0/1 arguments. This paper stays in Layer~0/1 for the closed proof chain; interpretation-level language is avoided in theorems and proofs.

\subsection{A minimal ``Layer \texorpdfstring{$-1$}{-1}'' interface}
\label{sec:layer_minus_one}

Motives and their realization theories form a deep and wide subject. To keep the present paper auditable, we adopt a strict strategy.
\begin{itemize}
\item All closed statements in the main text use only the \emph{period} layer: integrals of rational functions on semialgebraic domains (Kontsevich--Zagier periods). This layer admits explicit definitions and stability properties required for finite-resolution protocols.
\item Motives appear only as \emph{organizational language} to name a potential source object behind multiple realizations of the same period data. No unproven conjecture about motives is used as an input.
\item Whenever a statement uses motive-level terminology in a programmatic way (e.g.\ a comparison with $\ell$-adic realizations), it is explicitly labeled as conjectural/programmatic and never used in the closed dependency chain.
\end{itemize}

In this sense, the paper uses a minimal ``Layer $-1$'' interface: not as a foundation beneath Layer~0/1, but as a controlled vocabulary for organizing where period data might come from and how it could connect to the Langlands chain.

\subsection{Audit status classification}
\label{sec:audit_status}

To make the boundary of the closed content explicit, Appendix~\ref{app:audit_table} provides a status classification:
\begin{itemize}
\item \textbf{Standard facts}: results from equidistribution and discrepancy theory (Weyl/Kronecker equidistribution, Koksma--Hlawka inequality).
\item \textbf{New definitions}: $\ScanAlg$, $\PerDatum$, $\HSP$, and protocol-stable period data (Sections~\ref{sec:periods_motives_wishes}--\ref{sec:scan_alg_and_hsp}).
\item \textbf{Closed conclusions}: the realization theorem (Section~\ref{sec:period_realization}) and the auditable error budget decomposition (Section~\ref{sec:error_budgets}).
\item \textbf{Programmatic conjectures}: the selection principle (Section~\ref{sec:selection_principle}) and the motive/Langlands commutative-diagram objective (Section~\ref{sec:langlands_compatibility}).
\end{itemize}
