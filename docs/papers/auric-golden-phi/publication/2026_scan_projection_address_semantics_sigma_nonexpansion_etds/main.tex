\title{Recursive Address Factors, Pressure Gaps, and Collision Thresholds\\
in Binary Codings of Measure-Preserving Systems}
\author{}
\date{}

\begin{document}

\begin{abstract}
Let $(X,\mathcal{B},\mu,T)$ be a measure-preserving system and let
$W\in\mathcal{B}$ be a binary readout set.  The coding map
$x\mapsto (\mathbf{1}_W(T^t x))_{t\geq 0}$ defines the visible symbolic
factor.  We study recursive address constructions obtained by pulling
back finite cylinder events through previously defined codings.  Each
stage is an internal sliding-block factor of the original visible
process, so the visible $\sigma$-algebras form a decreasing factor tower
and the corresponding factor entropies are non-increasing.  Compatible
address chains form a compact ultrametric inverse limit, and under a
completeness hypothesis this inverse limit reconstructs the visible
factor.

For finite observation, the optimal depth-$m$ classification error
admits an exact cylinder decomposition and a Tanaka-type martingale
identity.  In the Markov and regular-boundary regime, the boundary mass
is carried by a finite weighted automaton, the associated weighted
boundary zeta function is rational, and the error exponent is the
pressure gap between the ambient visible dynamics and the boundary
automaton.  For first-entry residue events of Markov holes, this
pressure gap is exactly the open-system escape rate.  For multiple
objects, collision failure at fixed resolution
has a Poisson threshold governed by the collision entropy of the visible
address law.  Finally, any auxiliary register that removes
fixed-resolution collisions injectively must carry exactly the hidden
conditional entropy of the visible address, yielding both average and
worst-case lower bounds on the extra memory required for exact
resolution.
\end{abstract}
