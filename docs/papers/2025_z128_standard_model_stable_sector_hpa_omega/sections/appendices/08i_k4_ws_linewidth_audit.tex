\section{K4 WS--linewidth calibration audit (externally falsifiable interface)}
\label{app:k4_ws_linewidth_audit}

\AuditTag This appendix records a minimal interface calibration audit that can be falsified by a single measured resonance.
Given phase-shift points $\delta(E)$ one may form a phase-derived delay proxy $\tau_{\mathrm{phase}}(E)\approx 2\,\mathrm{d}\delta/\mathrm{d}E$ (single-channel convention), while a single-resonance linewidth $\gamma$ provides a complementary proxy $\tau_{\gamma}\approx 4/\gamma$ in the same proxy units.
We compare these two proxies as a bounded audit check.
