\section{Inference ledger: what is implied within the declared input set}
\label{app:inference_ledger}

This appendix answers a compact audit question that arises repeatedly in the HPA--$\Omega$ program:
if one does \emph{not} introduce any additional axioms or free continuous inputs beyond what is explicitly declared in the main text, what physically meaningful conclusions can be inferred, and what is their dependency status?
We summarize the answer as a layered ledger.
The purpose is not to add new claims, but to make explicit which statements are (i) theorem-level consequences of finite combinatorics, (ii) finite protocol constructions, (iii) conditional interface implications under stated dictionaries, and (iv) bounded-complexity closures with reported mismatch factors.

\paragraph{Notation for status tags.}
We use four audit-facing tags:
\begin{itemize}
\item \textbf{[Math]} theorem-level statement in the mathematical layer (finite definitions and proofs).
\item \textbf{[Prot]} finite protocol construction (explicit algorithm on a finite model; no continuum limit assumed).
\item \textbf{[Iface]} physical identification statement (a dictionary/assumption stated in protocol language).
\item \textbf{[CAP]} bounded-complexity closure (finite candidate family + deterministic tie-break rules).
\end{itemize}
Matching-layer dictionaries (units, scheme dependence, threshold conventions) are recorded explicitly as such in the main text; they are not treated as new premises here.

\subsection{Mathematical-layer consequences (no physical identification needed)}
\paragraph{Stable-sector grammar and counts.}
\begin{itemize}
\item \textbf{[Math]} \textbf{Fibonacci admissible counts.}
For every $m\ge 1$, the $\varphi$-admissible set $X_m\subset\Omega_m$ (forbidden substring ``11'') satisfies $|X_m|=F_{m+2}$ (Lemma~\ref{lem:xm_fib}).
In particular, $|X_6|=21$.

For $m\ge 4$, the wrap-around predicate $D_\pi$ induces a canonical cyclic/boundary split
$X_m=X_m^{\mathrm{cyc}}\sqcup X_m^{\mathrm{bdry}}$ with
$|X_m^{\mathrm{bdry}}|=F_{m-2}$ and $|X_m^{\mathrm{cyc}}|=F_{m+2}-F_{m-2}$
(Proposition~\ref{prop:cyc_bdry_size}).
At $m=6$ this is $21=18\oplus 3$ with explicit boundary words (Corollary~\ref{prop:cyc_bdry_6}).
\item \textbf{[Math]} \textbf{Fold surjectivity.}
The truncation folding map $\mathrm{Fold}_m:\{0,\dots,2^m-1\}\twoheadrightarrow X_m$ is surjective for every $m\ge 1$ (Proposition~\ref{prop:foldm_surjective}), and in particular $\mathrm{Fold}_6:\{0,\dots,63\}\twoheadrightarrow X_6$ (Lemma~\ref{lem:fold6_surjective}).
\item \textbf{[Math]} \textbf{Canonical integer labeling of $X_6$.}
The Zeckendorf-value map $V:X_6\to\{0,\dots,20\}$ is a bijection (Proposition~\ref{prop:V_bijection}).

\subsection{Interface-level implications (conditional on stated dictionaries)}
