
\section{Wigner--Smith time delay as an interface for measuring computational lapse}
\label{app:wigner_smith}

If computational lapse is interpreted as an operational time-delay density, then scattering theory provides a natural measurable proxy.
Given a unitary scattering matrix $S(E)$ as a function of energy $E$, the Wigner--Smith time-delay matrix is
\begin{equation}
\label{eq:wigner_smith}
Q(E)=-\iu\,S(E)^\dagger\frac{\dd S}{\dd E}.
\end{equation}
A common scalar summary is the total delay
\begin{equation}
\label{eq:tau_ws_trace}
\tau_{\mathrm{WS}}(E)=\Tr Q(E).
\end{equation}
In the present framework, $\tau_{\mathrm{WS}}(E)$ can be interpreted as a measurable time-delay proxy for routing overhead at energy/scale $E$.
Choosing a reference tick duration $\tau_0$ defines a dimensionless overhead proxy
\[
\kappa_{\mathrm{WS}}(E):=\frac{\tau_{\mathrm{WS}}(E)}{\tau_0},
\qquad
\lapse_{\mathrm{WS}}(E):=\frac{\kappa_0}{\kappa_{\mathrm{WS}}(E)}.
\]

Standard references for time delay include \cite{Wigner1955,Smith1960}.

\begin{remark}[What \texorpdfstring{$\kappa_{\mathrm{WS}}(E)$}{kappaWS(E)} is (and is not)]
\label{rem:kappa_ws_scope}
The proxy $\kappa_{\mathrm{WS}}(E)$ is an \emph{energy/scale-dependent} delay observable derived from a scattering measurement.
It is not, by itself, the same object as the spatial compilation field $\kappa(x;G_{\mathrm{phys}},\pi_n,\mathcal{G})$ (Definition~\ref{def:kappa_local}).
Connecting the two requires an additional experimental/modeling identification specifying how the measured scattering channel probes localized degrees of freedom and how the energy scale $E$ corresponds to a protocol resolution band.
\end{remark}

\subsection{Protocol: from measured \texorpdfstring{$S$}{S}-parameters to \texorpdfstring{$\kappa_{\mathrm{WS}}$}{kappaWS}}
\label{app:wigner_smith_protocol}

The definition \eqref{eq:wigner_smith} is operational once $S(E)$ is available as a calibrated function of energy (or frequency).
In many experiments one measures $S$ as a function of angular frequency $\omega$ or frequency $f$.
Writing $E=\hbar\omega$, one has
\[
\frac{\dd S}{\dd E}=\frac{1}{\hbar}\frac{\dd S}{\dd \omega},
\]
so an equivalent formulation is $Q(\omega)=-(\iu/\hbar)\,S(\omega)^\dagger(\dd S/\dd\omega)$.
The following steps define a minimal, auditable pipeline.

\paragraph{Step 1: acquire and calibrate \texorpdfstring{$S$}{S}.}
Measure the complex scattering matrix elements on a grid of energies/frequencies.
Calibration should remove systematic phase delays from the measurement chain and fix a reference plane so that $S$ represents the sample/device.

\paragraph{Step 2: diagnose (approximate) unitarity and losses.}
Equation \eqref{eq:wigner_smith} is standard for unitary $S$ (lossless elastic scattering).
In realistic settings absorption, dissipation, or imperfect calibration can make $S$ non-unitary.
Operationally one should report a unitarity diagnostic (e.g.\ $\|S^\dagger S-I\|$ in multi-channel settings or $|S(E)|$ in the 1-channel setting) and either:
(i) restrict attention to bands where unitarity holds to a stated tolerance, or
(ii) interpret $\tau_{\mathrm{WS}}$ as an effective delay proxy under a stated loss model.

\paragraph{Step 3: set derivative resolution and regularize.}
Time-delay estimates differentiate noisy data, so $\dd S/\dd E$ must be regularized.
A minimal method is a central finite difference on a uniform grid:
for sampled energies $E_k$ with step $\Delta E$,
\[
\left.\frac{\dd S}{\dd E}\right|_{E_k}\approx \frac{S(E_{k+1})-S(E_{k-1})}{2\Delta E}.
\]
In the 1-channel case one may equivalently unwrap the phase $\delta(E)=\arg S(E)$ and compute $\tau_{\mathrm{WS}}(E)=\dd\delta/\dd E$, which avoids branch-cut artifacts at $\pm\pi$.
If smoothing is used (moving average, local polynomial fit), the window size should be reported because it sets the effective resolution.

\paragraph{Step 4: compute \texorpdfstring{$Q$}{Q} and \texorpdfstring{$\tau_{\mathrm{WS}}$}{tau_WS}.}
With a derivative estimate in hand, evaluate $Q(E)$ by \eqref{eq:wigner_smith} and take the trace \eqref{eq:tau_ws_trace}.
In multi-channel settings, one may additionally inspect eigenvalues of $Q(E)$ (proper delay times) and report their distribution; the trace is the simplest scalar compression.

\paragraph{Step 5: normalize to \texorpdfstring{$\kappa_{\mathrm{WS}}$}{kappaWS} and report stability.}
Choose a reference tick duration $\tau_0$ and define $\kappa_{\mathrm{WS}}(E)=\tau_{\mathrm{WS}}(E)/\tau_0$.
Because $\tau_{\mathrm{WS}}$ is a derivative estimate, uncertainty scales roughly like $\delta\tau_{\mathrm{WS}}\sim \delta S/\Delta E$ (or $\delta\delta/\Delta E$ in the phase method).
A minimal report should therefore include the sampling step $\Delta E$ (or $\Delta f$), the smoothing window, and a basic stability check under moderate changes of $\Delta E$ and smoothing window.

\paragraph{Script interface.}
The script \path{scripts/exp_wigner_smith_kappa.py} implements the central-difference/phase-unwrapping pipeline in a dependency-free way.
It includes a 1-channel Breit--Wigner toy model for $S(E)$ and supports replacing it by a physical model or experimental data source.

\paragraph{A one-channel Breit--Wigner model (analytic check).}
For a single-channel elastic scatterer, one may write $S(E)=\e^{\iu\delta(E)}$ and the Wigner--Smith delay reduces to the phase derivative $\tau_{\mathrm{WS}}(E)=\dd\delta/\dd E$.
A minimal exactly unitary resonance model is the Breit--Wigner form
\begin{equation}
\label{eq:breit_wigner_S}
S(E)=\frac{E-E_0-\iu\gamma/2}{E-E_0+\iu\gamma/2},
\end{equation}
whose phase rises by $\pi$ across the resonance.
In this case one obtains the Lorentzian delay profile
\begin{equation}
\label{eq:breit_wigner_tau}
\tau_{\mathrm{WS}}(E)=\frac{\gamma}{(E-E_0)^2+(\gamma/2)^2}.
\end{equation}
The toy implementation in \path{scripts/exp_wigner_smith_kappa.py} computes $\tau_{\mathrm{WS}}(E)$ numerically via a phase-unwrapped finite difference and provides an auditable interface for replacing \eqref{eq:breit_wigner_S} by a physical $S(E)$.

\subsection{A minimal device-level realization (Hamiltonian, lead coupling, and tick calibration)}
\label{app:wigner_smith_device_level}

To make the Wigner--Smith interface concrete at the level requested by experimental/numerical tests, we record a minimal open-system model that produces \eqref{eq:breit_wigner_S} and therefore an explicit $\kappa_{\mathrm{WS}}$.

\paragraph{Device Hamiltonian and coupling (one level, one channel).}
Let the device have a single internal mode $\ket{0}$ with Hamiltonian
\[
H_{\mathrm{dev}}=E_0\,\ket{0}\!\bra{0}.
\]
Couple this mode to a single propagation channel (lead) in the standard wide-band approximation so that the retarded self-energy is purely imaginary, $\Sigma(E)\approx -\iu\,\gamma/2$ with $\gamma>0$.
Equivalently, the effective non-Hermitian Hamiltonian is
\[
H_{\mathrm{eff}}:=H_{\mathrm{dev}}-\iu\,\frac{\gamma}{2}\,\ket{0}\!\bra{0}.
\]
Then the on-shell scattering matrix is unitary and equals the Breit--Wigner form \eqref{eq:breit_wigner_S}.
In this realization, the linewidth $\gamma$ is the coupling-induced decay rate (inverse lifetime) of the internal mode.

\paragraph{Tick period and the dimensionless overhead proxy.}
To compare with compilation overhead (which is measured in discrete ticks), fix a reference tick duration $\tau_0$ in seconds.
Operationally, $\tau_0$ is the duration of one primitive substrate tick, i.e.\ the time required to execute a chosen reference primitive on the physical platform (or, in a wave network, the calibrated delay of a single standard cell).
Then
\[
\kappa_{\mathrm{WS}}(E)=\frac{\tau_{\mathrm{WS}}(E)}{\tau_0}
\]
is a dimensionless, directly measurable delay/overhead proxy.

\paragraph{Resonance-height normalization (closed form).}
For \eqref{eq:breit_wigner_tau} one has, at the resonance energy $E=E_0$,
\begin{equation}
\label{eq:kappa_ws_at_resonance}
\tau_{\mathrm{WS}}(E_0)=\frac{4}{\gamma},
\qquad
\kappa_{\mathrm{WS}}(E_0)=\frac{4}{\gamma\,\tau_0}.
\end{equation}
Thus, in this minimal model the overhead proxy is proportional to the inverse linewidth.
This provides a clean experimental/numerical handle: $\gamma$ can be extracted from the measured phase jump or delay peak width, and \eqref{eq:kappa_ws_at_resonance} then yields $\kappa_{\mathrm{WS}}(E_0)$.

\subsection{A testable map from \texorpdfstring{$\kappa_{\mathrm{WS}}(E)$}{kappaWS(E)} to spatial \texorpdfstring{$\kappa(x)$}{kappa(x)} (calibrated interface)}
\label{app:wigner_smith_calibrated_map}

The spatial field $\kappa(x)$ is defined by compilation depth on a hardware graph (Definition~\ref{def:kappa_local}), whereas $\kappa_{\mathrm{WS}}(E)$ is defined by a scattering delay measurement.
To relate them in a concrete platform one must specify a \emph{localization map} (how a spatial location $x$ is addressed by a scattering channel) and a \emph{band map} (how an energy/frequency band corresponds to a protocol resolution/time scale).
We record a minimal calibrated interface that is sufficient for quantitative tests.

\begin{assumption}[Localized resonance probe (calibrated delay-to-depth identification)]
\label{ass:ws_to_kappa_x}
For each coarse-grained spatial location $x$ (or for each probe region centered at $x$ at readout scale $\varepsilon$), there exists an experimentally realizable scattering configuration with:
\begin{itemize}
\item a localized resonance centered at energy $E_0(x)$ with extracted linewidth $\gamma(x)$;
\item a fixed platform tick duration $\tau_0$ (calibration);
\item a fixed local-update clock task family used to define $\kappa(x)$.
\end{itemize}
The calibrated identification is
\begin{equation}
\label{eq:ws_to_kappa_x}
\kappa(x)\ \approx\ \kappa_{\mathrm{WS}}(E_0(x))\ =\ \frac{4}{\gamma(x)\,\tau_0},
\end{equation}
up to a location-independent constant factor that depends only on the chosen clock task normalization (cf.\ Proposition~\ref{prop:clock_task_equivalence}) and on the probe geometry.
\end{assumption}

\begin{remark}[Quantitative test form]
\label{rem:ws_test_form}
Under Assumption~\ref{ass:ws_to_kappa_x}, the lapse dictionary predicts
\[
N(x)=\frac{\kappa_0}{\kappa(x)}
\ \approx\
\frac{\kappa_0}{\kappa_{\mathrm{WS}}(E_0(x))}
=\frac{\kappa_0\,\gamma(x)\,\tau_0}{4},
\]
so lapse ratios are directly expressed in terms of measurable linewidth ratios:
\[
\frac{N(x_1)}{N(x_2)}\approx \frac{\gamma(x_1)}{\gamma(x_2)}.
\]
This gives a concrete experimental/numerical falsifiability channel: one extracts $\gamma(x)$ (or, more generally, $\tau_{\mathrm{WS}}(E)$) from measured $S$-data and compares the induced lapse field (or its ratios) against the gravitational templates of Section~\ref{sec:gravity}.
\end{remark}

\subsection{Candidate experimental platforms (example)}
\label{app:wigner_smith_platforms}

The Wigner--Smith interface is most natural in platforms where a scattering description is already standard.
One concrete example is a microwave cavity / microwave network experiment in which $S(f)$ is measured directly as complex $S$-parameters over a frequency band; the group delay and resonance widths are extracted from phase evolution and delay peaks.
Another common arena is mesoscopic transport, where multi-channel scattering matrices and time delays arise naturally.
In either case, the minimal protocol is the same: measure $S$ on a frequency grid, calibrate, differentiate with stated regularization, and report $\tau_{\mathrm{WS}}$ and $\kappa_{\mathrm{WS}}$ with uncertainty diagnostics.

\subsection{Relation to spatial overhead \texorpdfstring{$\kappa(x)$}{kappa(x)}}
\label{app:wigner_smith_relation_kappa_x}

The compilation field $\kappa(x)$ is defined from a spatial task family and a hardware graph, whereas $\kappa_{\mathrm{WS}}(E)$ is defined from a spectral/time-delay measurement.
To map between them in a concrete system one must specify how the scattering channel probes localized degrees of freedom and how the energy scale $E$ corresponds to a protocol resolution band.
Operationally, one may use $\kappa_{\mathrm{WS}}(E)$ as a calibrated overhead proxy and compare redshift-type ratios across energies/bands, or use it as an input to fit an effective lapse profile once a spatial identification is supplied by the experimental model.

\paragraph{Directly measurable observables.}
In laboratory settings where a scattering description is available, the most direct measurable objects are the scattering matrix elements (e.g.\ microwave/mesoscopic $S$-parameters) as functions of energy/frequency.
From these one extracts:
\begin{itemize}
\item the phase $\arg S(E)$ (or multi-channel eigenphases) and its energy derivative (group delay);
\item resonance locations $E_0$ and linewidths $\gamma$ via fits of phase jumps or delay peaks;
\item in the multi-channel case, the full time-delay matrix $Q(E)$ and its trace $\tau_{\mathrm{WS}}(E)=\Tr Q(E)$.
\end{itemize}
Fixing a reference tick duration $\tau_0$ turns the measured delay into the dimensionless overhead proxy $\kappa_{\mathrm{WS}}(E)=\tau_{\mathrm{WS}}(E)/\tau_0$, and hence into a lapse proxy $\lapse_{\mathrm{WS}}(E)=\kappa_0/\kappa_{\mathrm{WS}}(E)$.
