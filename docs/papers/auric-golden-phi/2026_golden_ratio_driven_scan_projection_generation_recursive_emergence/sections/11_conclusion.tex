\section{结论}

本文围绕扫描—投影生成器及其诱导的折叠/读出算子，给出一组可独立审计的原创结论。为强调可复核性，下列条目均以定义/定理编号为锚点：
\begin{enumerate}
  \item \textbf{（递归地址化的结构性极简性）}证明递归地址化仅对应于可测柱事件族的 $\sigma$-代数细化，不引入外加结构（命题 \ref{prop:recursive-addressing-refinement}）。
  \item \textbf{（有限窗口折叠与跨分辨率相容）}构造有限窗口折叠 $\Fold_m$ 及其可计算实现，并证明合流性、逆系统相容与 sofic 因子接口的统一结论（定理 \ref{thm:fold-suite}；并见定义 \ref{def:fold-word} 与命题 \ref{prop:fold-basic}）。
  \item \textbf{（投影本体数学与信息账本）}建立投影本体数学框架：定义扫描—投影生成器与投影词演算（定义 \ref{def:pom-spg}、\ref{def:pom-projection-word}、\ref{def:pom-projword-2cat}），并给出相对熵缺陷的闭式信息账本恒等式及其推论（定理 \ref{thm:pom-kl-ledger} 与推论 \ref{cor:pom-ent-increase-equals-kl}），从而将粗粒化的信息损失对象化为可计算的残差项。
  \item \textbf{（最大纤维族的相位数与顶层纤维谱闭式）}在折叠纤维计数上，给出最大纤维闭式并进一步封口最大达到者相位数与次大/第三大纤维能级缺口（定理 \ref{thm:pom-max-fiber}、\ref{thm:pom-max-achievers-phase-stabilization}、\ref{thm:pom-second-max-fiber-closed-form}、\ref{thm:pom-third-max-fiber-even-closed-form}；推论 \ref{cor:pom-second-max-gap-constant} 与注 \ref{rem:pom-phase-defect-resource-meters}）。
  \item \textbf{（读出塔重写与可判定闭环）}在投影词的局部读出塔片段上证明终止性与合流性并给出正规形（定理 \ref{thm:pom-rewrite-termination-confluence}），并由此得到词问题的可判定性与审计闭环（命题 \ref{prop:pom-projword-decidable}、\ref{prop:pom-rewrite-audit-loop}）。
  \item \textbf{（碰撞核编译与共振判别）}对任意阶碰撞矩给出有限状态的 moment-kernel 编译与 Perron 主谱刻画（定理 \ref{thm:pom-collision-kernel-ak}），并给出模态约束导致 Hankel 秩下降的充分判别，从而将共振定位为可检验的机制（定理 \ref{thm:pom-moment-resonance}）。
  \item \textbf{（profinite 轴上的 Chebotarev 提升）}在核版 GRH 的平方根界假设下，沿素数寄存器的逆极限轴提升有限层 Chebotarev 计数，并对任意 cylinder 集合给出平方根级等分布误差（定理 \ref{thm:pom-profinite-axis}）。
\end{enumerate}

最后指出：本文中的术语“涌现”仅用于组织动机与解释性叙事；任何后续推理均以编号结果为前提。关于黄金分支的“最优性”讨论亦严格限定在文中显式给出的数论证书链条之内，且不外推到更强的统计泛函最优性（见注 \ref{rem:what-is-optimized}）。
