\section{Preliminary Definitions and Notation}

\subsection{Fibonacci Numbers and Zeckendorf Digits}

We adopt the Fibonacci sequence $(F_k)_{k\ge 0}$: $F_0=0,F_1=1,F_{k+1}=F_k+F_{k-1}$. The Zeckendorf representation uses weights $(F_k)_{k\ge 2}$, namely the sequence
\[
1,2,3,5,8,13,21,34,55,\dots
\]
For any integer $n\ge 0$, there exists a unique digit sequence $(z_k(n))_{k\ge 2}\in\{0,1\}^{\NN}$ such that
\[
n=\sum_{k\ge 2} z_k(n)\,F_k,\qquad z_k(n)\,z_{k+1}(n)=0\ \ \forall k\ge 2.
\]
We call $(z_k(n))$ the Zeckendorf digits of $n$.

\subsection{Primitive Readout Space and Stable Language}

Given a resolution parameter $m\in\NN$, we define the primitive readout label space
\[
Y_m=\{0,1,\dots,2^m-1\}.
\]
We define the stable language of length $m$ as
\[
X_m=\{w\in\{0,1\}^m:\text{$w$ contains no substring }11\}.
\]
We write $w=(w_m,\dots,w_1)$, where $w_m$ is the most significant bit, with local constraint $w_{j+1}w_j=0$ (for $1\le j<m$).

\subsection{Distance and Pushforward}

For probability distributions $\mu,\nu$ on finite sets, the total variation distance is defined as
\[
\norm{\mu-\nu}_{\TV}=\frac{1}{2}\sum_x\abs{\mu(x)-\nu(x)}.
\]
For a deterministic map $\Pi$, the pushforward operator $\Pi_*$ is defined as
\[
(\Pi_*\mu)(A)=\mu(\Pi^{-1}(A)),
\]
where $A$ is a subset of the target space.
